# Intelligent Workspace

> Intelligent Workspace は、Svelte、Vite、CRXJS で構築された先進的な Manifest V3 ブラウザ拡張機能であり、高生産性ワークスペース環境です。インテリジェントなタブ整理、自動およびルールベースのクラスタリング、自律型 AI エージェントの実行（Google Gemini Cloud API および Chrome Built-in Prompt API をサポート）、ページ内の Vim スタイルリンクナビゲーション、41 種類のプレフィックスを備えた Omnibar コマンドシステム、マルチフォーマットのノート作成（リッチテキスト、チェックリスト、Kanban、Mermaid ダイアグラム、KaTeX 数式）、高忠実度のメディアキャプチャとブラウザ内 WASM OCR、ドリフトゼロのアラームとオフスクリーン音声再生を備えたポモドーロタイマー、Declarative Net Request (DNR) による Web アクティビティ計測、ドメイン制限、サイトブロックを統括します。

## 1. アーキテクチャ基盤 & ランタイムライフサイクル

本拡張機能は Google Chrome の Manifest V3 アーキテクチャに基づいて動作し、バックグラウンド Service Worker、サンドボックス化された UI パネル、オフスクリーン音声ドキュメント、およびページ内コンテンツスクリプトオーバーレイの間で永続プロセスを分離・疎結合化しています。

1. **マニフェスト構成 (`manifest.json`)**:
   - **パーミッション（21 項目）**: `tabs`、`tabGroups`、`storage`、`favicon`、`contextMenus`、`notifications`、`sidePanel`、`scripting`、`downloads`、`downloads.open`、`system.display`、`declarativeNetRequestWithHostAccess`、`cookies`、`history`、`sessions`、`bookmarks`、`readingList`、`clipboardWrite`、`alarms`、`offscreen`、および `idle`。
   - **ホストパーミッション**: `["<all_urls>"]`。
   - **Service Worker**: 同期的な `importScripts` モジュール読み込みを使用する `src/core/background.js`。
   - **ツールバーアクション**: 意図的に `default_popup` を省略。ランタイムで `chrome.action.setPopup({ popup: '' })` を強制適用し、`chrome.action.onClicked` が同期的に発火してポップアップ初期化の遅延なしにユーザーがピン留めしたビューで `chrome.sidePanel` を開くようにしています。
   - **Omnibox キーワード**: 登録キーワード `"find"`。
   - **コマンド**: `commands` 配下に登録された 24 個のシステムレベルキーボードショートカット。
   - **コンテンツセキュリティポリシー (CSP)**: `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`。

2. **プロセス間通信セキュリティ**:
   - `src/core/background/messaging.js` は、コンテンツスクリプトからのメッセージを明示的なホワイトリスト (`ALLOWED_CONTENT_SCRIPT_ACTIONS`) に照らしてフィルタリングします。権限のない Web フレームが内部ストレージの書き込み、任意の Chrome API、またはルール変更処理を呼び出すことはできません。

3. **デュアル実行ワールド**:
   - コンテンツスクリプトは、`ISOLATED`（拡張機能スコープ）と `MAIN`（ページ実行スコープ）の両方のワールドで動作します。`allowRightClickHook.js`、`videoPipHook.js`、`youtubePreviewAudioHook.js`、`youtubeShortsFeedHook.js` などのスクリプトは `MAIN` で実行され、プロトタイプメソッドのインターセプト、プロパティ記述子のオーバーライド、およびカスタムイベントの直接処理を行います。

## 2. セクション 1: ルール管理 (Gestionar Reglas)

ルール管理サブシステムは、ユーザーが定義した厳格な決定論的基準に基づいてタブのグループ化を自動化します。

### 2.1 データスキーマ (`CustomRule`)
各カスタムルールは以下のインターフェースに従います。
```typescript
interface CustomRule {
  name: string;        // 1〜16文字。空白文字を含めることはできません。
  color: RuleColor;    // 9色のいずれか: 'grey' | 'blue' | 'red' | 'yellow' | 'green' | 'pink' | 'purple' | 'cyan' | 'orange'
  urls: string[];      // 有効なURL、ドメイン、またはホスト名の配列。
  active: boolean;     // ルール評価を有効化または無効化するマスタートグル。
  isStarred?: boolean; // UIでの優先順位付けのためにルールをお気に入りに設定するオプションフラグ。
}
```

### 2.2 優先順位アーキテクチャ
`src/core/background/groupManager.js` の `groupTabs()` によってタブが処理される際、タブは厳格な階層順序でグループ化レイヤーに対して評価されます。
1. **カスタムルール (`applyCustomRules`)**: 出現順またはユーザーの優先順位に従って有効なカスタムルールとマッチングします。グループ化されたタブ ID は `groupedTabIds` に登録され、以降のレイヤーから除外されます。
2. **特殊システムグループ**: システム URL がインターセプトされ、専用のカラーグループにクラスタリングされます。
   - `chrome://` およびブラウザ内部ページ
   - `file:///` ローカルディスクファイル
   - `chrome-extension://` 拡張機能ページ
   - IP アドレス & Localhost（`localhost`、`127.0.0.1`、`[::1]`、IPv4/IPv6 ホスト）
3. **ドメインクラスタリング**: タブ数が `domainThreshold`（デフォルト: 2 タブ）以上の場合、同一ルートドメインを共有するタブがグループ化されます。
4. **サブドメインクラスタリング**: 有効な場合、ドメイン内のタブが特定のサブドメインごとにグループ化されます（例: `docs.github.com` と `gist.github.com`）。
5. **その他 ("Misc") グループ**: グループ化のしきい値を満たさない未クラスタリングの残余タブは、`Misc` グループに配置されます（配置位置は設定可能: 先頭 `start`、末尾 `end`、またはアルファベット順 `alpha`）。

### 2.3 URL の正規化 & マッチングセマンティクス
マッチングエンジン（`src/core/background/utils.js` の `matchesRule(tabUrl, ruleUrl)`）は、厳密な正規化を適用します。
- **スキーム非依存**: HTTP プロトコルと HTTPS プロトコルは交換可能として扱われます（`http://example.com` は `https://example.com` にマッチ）。非 Web プロトコル（`file://`、`chrome://`）は完全なスキーム一致が必要です。
- **ホストの正規化**: 先頭の `www.` プレフィックスは除去されます（`www.github.com` は `github.com` に正規化）。ホスト名は小文字に変換され、punycode による国際化ドメイン名 (IDN) をサポートします。
- **ポートの区別**: ルールにポートが指定されている場合（例: `localhost:3000`）、タブはその正確なポートと一致する必要があります。
- **パスのマッチング**: 末尾のスラッシュは除去されます。ルールにパスが指定されている場合（例: `example.com/docs`）、その正確なパスまたはサブパス（`example.com/docs/api`）を持つタブにマッチしますが、兄弟パス（`example.com/blog`）にはマッチしません。
- **クエリ & ハッシュのマッチング**: ルールにクエリ文字列（`?page=1`）またはハッシュ（`#section`）が明示的に含まれている場合、タブはそれらのパラメータと一字一句一致する必要があります。
- **数値 Dword 保護 (`ruleValidation.js`)**: バリデータは、WHATWG URL パーサーが有効な IPv4 整数 DWORD として処理してしまう単なる数値入力（例: `3242342424`）を厳格に拒否し、予期しないグループ化の乱れを防止します。

### 2.4 ルール管理設定の詳細解説
ルールマネージャーは、充実した動作制御および設定スイートを提供します。
- **ストレージルーティングの選択**: ユーザーはルールストレージの保存先として、`chrome.storage.sync`（Google プロファイルにログインしているすべてのデバイス間で設定を同期。Chrome の同期クォータである合計 100 KB、項目あたり 8 KB の制限あり）と `chrome.storage.local`（何百ものパターンを含む大規模なルールセットに適した無制限のローカル容量）のいずれかを選択できます。
- **クラスタリングマスタートグル & しきい値**:
  - `toggle-clustering`: ユーザーが作成したカスタムルールを無効化することなく、自動ドメイン/サブドメインクラスタリングを有効化または無効化するマスターキーボードショートカットおよび UI トグル。
  - `domainThreshold`: 自動タブグループをトリガーするために必要な同一ドメインの最小タブ数（デフォルト: 2 タブ）。1 から 50 まで設定可能。
  - `subdomainThreshold`: 個別のサブグループクラスターを作成するまでに必要なサブドメインの最小タブ数。
  - サブドメイントグル (`toggle-subdomain-grouping`): 独立したサブドメインを区別します（例: `news.ycombinator.com` と `ycombinator.com`）。
- **グループのアルファベット順自動ソート (`toggle-sort-alpha`)**: ブラウザのタブストリップ内の開いているすべてのタブグループに対してアルファベット順を強制するリアルタイムソートエンジン（`Ctrl+Shift+S` / `Cmd+Shift+S`）。
- **視覚的ステータスプレフィックス (`toggle-prefixes`)**: 閲覧状態を示すためにグループタイトルの先頭に動的に付加される絵文字マーカー。
  - `🔒`（南京錠）: グループ内に未訪問・未読のタブが含まれている。
  - `🔍`（ルーペ）: グループ内の一部のタブが訪問済みである。
  - `🗝️`（開いた鍵）: グループ内のすべてのタブが開かれ、確認済みである。
  - `⚠️`（警告）: 別のウィンドウグループとの間で重複するグループ名の競合が検出された。
- **アイドル状態グループの自動折りたたみ (`toggle-collapse-timer`)**: タブストリップを整理された状態に保つため、非アクティブなグループを自動的に折りたたみます。
- **マスター一時停止グループ化 (`feature_pauseGrouping`)**: タブをユーザー任意の配置のまま保持したいアクティブなリサーチセッション中に、すべての自動グループ化操作（ルールマッチングとヒューリスティッククラスタリングの両方）を一時停止するマスターフリーズスイッチ。
- **単一タブのグループ化 (`featureSingleTabGrouping`)**: 複数タブのしきい値要件をバイパスし、マッチするタブが 1 つだけでもカスタムルールによって即座にタブグループを作成できるようにします。
- **コンパクトビュー (`toggle-compact-mode`)**: グループタイトルのバッジを 1 文字のみでレンダリングすることにより、ブラウザタブストリップのタブヘッダー幅を最小化します。
- **ドラッグ＆ドロップによる優先順位変更**: `Rules.svelte` リスト内でルールを並べ替えると、評価の優先順位が即座に変更されます。最上位のルールが最初に評価されます。
- **あいまい検索 (Fuzzy Search)**: ルールマネージャーおよび Omnibar 内のライブフィルタリングにより、タイトルまたは一致する URL パターンからルールを即座に特定できます。
- **JSON インポート / エクスポート**:
  - `add` モード: 重複を破棄しながら、インポートしたルールを既存のコレクションにマージします。
  - `overwrite` モード: スキーマ検証後、アクティブなルールコレクションをインポートしたペイロードで完全に置き換えます。
- **動的ルール作成**: Chrome のブックマークフォルダまたはサブグループのドメインコレクションから、ワンクリックでカスタムルールを直接作成できます。
- **ルールの重複排除 (`feature_v100_dedup_add_to_rule`)**: 既存のカスタムルールに URL やドメインを追加する際、重複する URL パターンを自動的に除去し、ルールの肥大化と冗長な評価を防止します。

### 2.5 操作 & 永続化 (`mutateRulesAndSync`)
- **一元化されたミューテーター**: すべてのルール変更は、`src/core/background/handlers/rules.js` の `mutateRulesAndSync(mutateFn, sendResponse)` を経由します。これにより、ストレージの同期、インメモリキャッシュの更新 (`extensionSettings.customRules`)、UI への通知 (`rulesUpdated`)、および自動タブ再グループ化 (`groupTabs()`) が保証されます。
- **リアルタイムバリデーション**: 保存前に、名前の一意性、長さ（1〜16 文字）、使用文字の制限、および有効な URL 構文のリアルタイムチェックを実施します。

### 2.6 呼び出し方法
- **ルールマネージャーページ (`Rules.svelte`)**: フルタブビューまたはサイドパネル（`?view=rules` / `pg`）からアクセス可能。完全なドラッグ＆ドロップによる並べ替え、インラインカラーピッカー、URL タグチップ、およびルールトグルを提供します。
- **Omnibar コマンド**:
  - `rl:` — ルールを検索し、関連付けられた URL を開きます。
  - `cr: <name> [, url1, url2]` — コマンドバーから直接新しいルールを作成します。
  - `atcr:` — アクティブタブのドメインまたは URL を既存のルールに追加します。
  - `atr:` — 選択した開いているタブまたは手動入力した URL を既存のルールに追加します。
  - `ccr:` — カスタムルールの色を変更します。
  - `dr:` — ルールまたはルール内の個々の URL を削除します。
  - `er:` — 既存のルールを編集または名前変更します。
- **コンテキストメニュー**:
  - ページを右クリック -> "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa"。
  - ページを右クリック -> "Añadir a Regla Existente" -> ルールを選択 -> "Añadir Raíz del Sitio" / "Añadir URL Completa"。
  - ページを右クリック -> "Reglas" -> 有効状態の切り替え、すべてのルール URL を開く、または一致するタブを閉じる。
- **キーボードショートカット**:
  - `Alt+R`: ルールマネージャーを開きます。
  - `Alt+M`: すべてのルールのアクティブ状態を一括切り替えします (`toggle-all-rules`)。

## 3. セクション 2: グループ一覧 & 操作 (Listar Grupos)

グループ一覧ビューは、ブラウザのタブグループおよび個々のタブを確認、操作、並べ替えるためのインタラクティブなワークスペースを提供します。

### 3.1 UI アーキテクチャ
- **コンポーネントスタック**: `ListGroup.svelte`、`GroupCard.svelte`、`GroupActions.svelte`、`TabItem.svelte`、および `TabActions.svelte` で構築されています。
- **カードの機能**: グループタイトル、カラーバッジ、タブ数ピル、折りたたみ/展開のアコーディオン切り替え、カードのピン留め、およびカスタマイズ可能なアクションボタングループを表示します。
- **タブアイテム**: タブのファビコン（カラーフォールバック付き）、タイトル、音声再生中バッジ、ミュートインジケーター、アクティブ状態インジケーター、およびタブごとのアクション（閉じる、複製、ピン留め、分割、破棄）を表示します。

### 3.2 グループのライフサイクル & 動作
- **アコーディオン制御**: スムーズな展開および折りたたみ状態。オプションの自動アコーディオンモードでは、新しいグループが展開されたときにアイドル状態のグループを自動的に折りたたみます。
- **非アクティブ自動折りたたみアイドルタイマー**:
  - 視覚的な煩雑さを軽減するため、アイドル状態のタブグループを自動的に折りたたみます。
  - 2 種類の個別のしきい値: 非アクティブグループは 1 分間の非アクティブ後に折りたたまれ (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`)、アクティブグループは 15 分間の非アクティブ後に折りたたまれます (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`)。0 から 1440 分まで設定可能。
- **インライン名前変更 & グレースピリオド**:
  - ユーザーはブラウザのタブストリップまたは UI 内で直接グループ名を変更できます。
  - `GROUP_NAMING_GRACE_MS` (5000ms) により、ユーザーの編集中は自動再グループ化を一時停止し、入力途中のタイトル上書きを防止します。
  - 評価中、ゼロ幅スペース（`\u200B`、`\u200C`、`\u200D`、`\u2060`、`\uFEFF`）は除去されます。
  - 自動生成されたグループの名前を変更すると、ユーザー命名グループに変換され、対応するカスタムルールが更新されるか、恒久的としてマークされます。
- **視覚的グループプレフィックスインジケーター**:
  - 状態シンボルを動的に付加します: `🔒`（未訪問）、`🔍`（一部閲覧）、`🗝️`（すべて閲覧済み）、`⚠️`（名前の競合）。
- **ドラッグ＆ドロップによる並べ替え**: グループ内でのタブの並べ替え、グループ間でのタブの移動、またはグループカード自体の並べ替えのために `sortable.js` と統合されています。
- **非表示グループ機能**:
  - ブラウザのタブストリップにおいて、グループタイトルの先頭に `_hidden_` を付加します。
  - メインリストビューからグループカードを非表示にし、`HiddenGroupsBar.svelte` に移動させます。
  - ユーザーはワンクリックでグループを即座に再表示または復元できます。

### 3.3 グループ操作 & メモリ管理
- **グループ解除 (Ungroup)**: グループを解散し、タブをウィンドウ内に開いたまま保持します。
- **グループを閉じる (Close Group)**: グループ内のすべてのタブを閉じ、グループ ID を解放します。
- **他のグループを閉じる (Close Other Groups)**: 現在フォーカスされているグループ以外のすべてのタブグループを閉じます。
- **すべてのタブを再グループ化 (`Alt+Shift+R`)**: カスタムルール、システムグループ、およびドメインクラスター全体に対して包括的な再評価パスを実行します。
- **グループスクリーンショット巡回 (Group Screenshot Walk)**: グループ内のすべてのタブを順次切り替えてキャプチャします（`Cs` 表示領域、`Cp` ページ全体、`CP` ページ全体の分割パーツ）。

### 3.4 グループバックアップ & 復元サブシステム
- **IndexedDB `backupsGroups` ストア**:
  - 単一のタブグループまたは開いているすべてのグループのワークスペース全体の snapshot を、IndexedDB `Intelligent_Workspace` のストア `backupsGroups` にバックアップします。
  - 完全なグループ構造（グループタイトル、色、折りたたみ状態、タブのタイトル、URL、ファビコン、ピン留め状態、相対的なタブ位置）をキャプチャします。
  - **メモリ節約**: バックアップされたタブは正常に閉じられ、システム RAM を解放して CPU 負荷を軽減します。
  - **復元メカニズム**:
    - `ListGroup.svelte` 内のバックアップ UI ビューによるワンクリックグループ復元。
    - キーボードショートカット `br`（復元）および `bg`（すべてバックアップ）。
    - Omnibar コマンド `bgr:`（バックアップされたグループの検索と復元）および `b:`（ブックマーク検索）。
  - **JSON エクスポート & インポート**: マシン間のシームレスな移行や長期的なオフラインアーカイブのための完全な JSON バックアップエクスポートおよびインポート。

### 3.5 非表示グループバーのパーキング YouTube プレーヤー
- **アーキテクチャ (`HiddenGroupsBar.svelte`)**:
  - ユーザーがアクティブな YouTube 動画ビューから移動した場合、またはサイドパネル内で動画コンテンツを起動した場合、プレーヤーは閉じられたり失われたりしません。パーキング YouTube インジケーター (`.youtube-indicator`) として `HiddenGroupsBar.svelte` に自動的にドッキングされます。
  - `src/ui/stores/appStore.svelte.js` 内の `hiddenYoutubeView` ストアを通じてリアクティブに管理されます。
  - **ワンクリックアクション**:
    - パーキングされたインジケーターをクリックすると `restoreYoutubeView()` が呼び出され、プレーヤーがアクティブなワークスペースビューに即座に戻ります。
    - 削除バッジをクリックすると `discardYoutubeView()` が呼び出され、再生をクリーンに終了してリソースを解放します。
  - ListGroup ビュー上部の非表示タブグループの横にシームレスに配置され、アクティブなタブリストを乱すことはありません。

## 4. セクション 3: ナビゲーション & タブ管理 (Navegación)

高速キーボードナビゲーションとワークスペース制御により、マウス操作なしでシームレスなマルチタブ操作が可能になります。

### 4.1 高速タブジャンプジェスチャー
- **ジェスチャー構文**: `Alt + [groupPrefix] + [tabIndex] + Enter`
- **実行方法**:
  - `Alt` を押しながらグループ名またはプレフィックス文字を入力し、続けて目的の 1 から始まるタブインデックスを入力して、`Enter` を押します。
  - 例: `Alt + git + 2 + Enter` は、「GitHub」グループ内の 2 番目のタブに直接ジャンプします。
  - インデックス `0` は、グループ内の*最後*のタブへのショートカットとして機能します。
  - インデックスを省略すると、グループ内の*最初*のタブにジャンプします。
  - アクセント記号は自動的に除去され (`deaccent`)、マッチング時にダイアクリティカルマークが正規化されます。

### 4.2 ステップ移動、スワップ、ライフサイクルキー
- `s`: 直前にアクティブだったタブ (`previousActiveTabId`) に即座に切り替えます。
- `h` / `l`: 前/次のタブにステップ移動します（ページがスクロール可能な場合は水平スクロール）。
- `H` / `L`: ブラウザ履歴を戻る/進む。
- `t`: 新しい空白のタブを開きます。
- `x`: 現在のアクティブタブを閉じます。
- `yt`: 現在のタブを複製します。
- `r` / `R`: ページを再読み込み / キャッシュを無視して強制再読み込み。
- `d` / `u`: ページの最下部 / 最上部までスクロール。
- `j` / `k`: スムーズに下 / 上スクロール（75px ステップ）。
- `f`: Vim リンクヒントを起動（クリック可能な要素の上に文字が表示され、クリック可能）。
- `cf`: 対象 URL をクリップボードにコピーするための Vim リンクヒントを起動。

### パワーユーザー向け

より高度なユーザーは、ブラウザを全画面モードにして、マウスを一切使わずにキーボードのみで完全にナビゲートできます。

#### 全画面没入 & マウスフリーブラウジング
- **全画面切り替え**: `F11` (Windows/Linux) または `Command+Control+F` (macOS) を押します。ブラウザの UI、アドレスバー、タブストリップ、OS のパネルが非表示になり、ディスプレイの 100% がコンテンツ専用になります。
- **ページ内 Vim リンクナビゲーション (`f` / `cf`)**:
  - `f` を押すと、DOM 内のすべてのクリック可能な要素、ボタン、入力、リンクの上に、コントラストの高い 2 文字の黄色いリンクヒントが生成されます。
  - ターゲットに一致する 2 文字を入力すると、マウスを使わずに直接クリックをシミュレートできます。
  - `cf` を押すと、対象リンクの URL をシステムのクリップボードに直接コピーするヒントバッジがトリガーされます。
  - `vp` を押すと、対象リンクのページ内プレビューモーダルが開きます。
  - いつでも `Esc` を押してリンクヒントをキャンセルし、通常のスクロールに戻ることができます。
- **瞬時のタブジャンプ & 切り替え**:
  - `Alt + [groupPrefix] + [tabIndex] + Enter`: 高速タブジャンプジェスチャーを実行（例: `Alt + dev + 1 + Enter` は "Dev" グループの最初のタブに直接ジャンプ。インデックス `0` はグループ内の最後のタブを選択）。
  - `s`: 現在のタブと直前にアクティブだったタブ (`previousActiveTabId`) の間を瞬時にスワップ。
  - `h` / `l`: タブストリップ内の前/次のタブへ順番にステップ移動。
  - `H` / `L`: ブラウザのナビゲーション履歴を前後に移動。
  - `t` / `x` / `yt`: 新規タブを開く (`t`)、現在のタブを閉じる (`x`)、タブを複製 (`yt`)。
- **フローティング Omnibar コマンドサブシステム (`o`)**:
  - 任意のページで `o` を押して、中央に配置された Omnibar オーバーレイを呼び出します。
  - `@` を押すと、全 41 個のコマンドプレフィックスのインタラクティブな一覧が表示されます。
  - `f: <query>` と入力すると、開いているすべてのウィンドウにわたって深い全文タブ検索が実行されます。
  - `sp:` と入力すると、任意のサイドパネルビュー (`rules`、`listgroup`、`notes`、`gallery`、`gemini`、`activity`、`themes`、`hints`、`downloads`) に直接ルーティングされます。
  - `qai: <query>` または `qaia: <task>` と入力して、キーボードから手を離さずに Gemini に問い合わせたり、自律型ブラウザエージェントに指示を出したりできます。
  - `ts:` と入力して、開いているタブを左右並列の分割画面に分割します。
- **ページ内ナビゲーション & フォーカス**:
  - `j` / `k`: スムーズに下 / 上スクロール（75px 刻み）。
  - `d` / `u`: 半ページ分下 / 上スクロール。
  - `i`: ページ内のメインテキスト入力フィールドにカーソルフォーカスを即座に移動。
  - `ESC`: 入力フィールドのフォーカスを解除し、キーボードフォーカスをナビゲーションモードに戻します。

### 4.3 オーディオ & サウンド管理
- 音声を再生しているタブには、ListGroup UI 内にスピーカーバッジが表示されます。
- `st`: 現在のアクティブタブのミュート状態を切り替えます。
- `so`: ブラウザ全体のすべての可聴タブをミュートします。
- コンテキストメニュー: "Silenciar Todas las Pestañas" / "Reactivar Sonido en Todas las Pestañas"。

### 4.4 画面分割ワークフロー
- **トリガー**: Vim ヒント `ts` または Omnibar プレフィックス `ts:`。
- **動作**: `chrome.system.display` を使用して画面ジオメトリを計算します。2 つのタブを隣接するウィンドウに左右並列で分割し、専用の `Split` タブグループとしてまとめます。
- **復元**: 分割ウィンドウを閉じるか画面分割を切り替えると、元のウィンドウサイズと座標が復元されます。

### 4.5 YouTube ループ再生サブシステム
YouTube ループ再生サブシステムは、YouTube プレーヤーに直接統合された高精度なメディアループコントロールを提供します。
- **デスクトッププレーヤーボタン (`#itg-yt-loop-button`)**: 標準の YouTube プレーヤーコントロールバー (`.ytp-right-controls`) 内、Cast / リモートボタンまたは PiP ランチャーの左側に挿入されます。アニメーション SVG ループ記号、切り替えハイライトスタイル (`ytp-loop-active`、`var(--interactive-color, #ff4444)`)、および `aria-pressed` 状態を備えています。
- **Shorts プレーヤーボタン (`#itg-yt-shorts-loop-button`)**: YouTube Shorts の右側コントロール列 (`ytd-shorts`) 内の `#itg-yt-shorts-loop-wrapper` に挿入され、縦型動画コンテンツのワンクリックループ再生を提供します。
- **ループメニュー & PiP ポップアップ (`#itg-yt-loop-menu` & `#itg-pip-loop-popup`)**: ループボタンにホバーまたはクリックすると、包括的なループ設定メニューが開きます。
  - **A-B ループ**: インタラクティブなレンジスライダーと手動時間入力フィールドを使用して、ミリ秒単位の精度でカスタム開始点 (A) と終了点 (B) を設定できます。
  - **サイクルモード & シーケンス繰り返し**: 特定のループの繰り返し回数を設定するか、無限ループモード (`itg-loop-seq-inf`) を切り替えます。
  - **ループリスト & マルチセグメントシーケンス**: 設定された繰り返しに従って連続して再生される複数の A-B ループインターバルをキューに追加します。
  - **ステータス & 再生時間表示**: 現在のループインターバル内のリアルタイム再生位置とメディア全体の長さ (`00:00 / 00:00`) を表示します。
  - **マスタートグル (`youtubeLoopEnabled`)**: `chrome.storage.sync` および `local` に永続化され、Customize Hints 設定ページ (`YoutubeLoopSection.svelte`) から YouTube および YouTube Shorts 全体でループボタンを有効化または無効化できます。

### 4.6 YouTube Shorts プレビュー音声
- **音声ミュート解除フック (`youtubePreviewAudioHook.js`)**:
  - `ytd-video-preview` 要素の `#inline-preview-player` プロパティにアクセスするため、`MAIN` 実行ワールドで実行されます。
  - **強制ミュートの克服**: YouTube はオーディオコントロールをクリアし、内部の `volumechange` リスナーを通じて `muted = true` を復元することにより、Shorts プレビューに強制ミュートを適用しています。
  - 本拡張機能は、ホバー時に対象の `<video>` 要素の `HTMLMediaElement.prototype.muted` プロパティ記述子をフックします。ユーザーによるミュート解除を許可しながら YouTube の強制再ミュートを破棄し、マウスが離れるまでループ再開を挟んでも途切れることなく音声が再生され続けるようにします。

### 4.7 ピクチャーインピクチャー (PiP) アーキテクチャ
- **ドキュメントピクチャーインピクチャー (`wp`)**:
  - モダンな `documentPictureInPicture` API を活用して、常に最前面に表示されるフローティングウィンドウ内に Web ページ全体またはテキストスニペットを開きます。
  - メディア転送時に動画の再生タイムスタンプを自動的に同期します。
  - 再試行ロジック (`itgRetryIfPipFrameRefused`) を備え、終了時に DNR iframe ヘッダーをクリーンアップします。
- **動画ピクチャーインピクチャー (`wv`)**:
  - `videoPipHook.js` を介して `HTMLVideoElement.prototype.requestPictureInPicture` をフックします。
  - ループコントロールと再生速度セレクターを備えたカスタム PiP フレームに対象動画プレーヤーをリダイレクトします。
- **Auto-PiP**:
  - `as`: スクロール時の Auto-PiP 切り替え（ビューポート外にスクロールしたときに動画を PiP で起動）。
  - `ah`: タブ非表示時の Auto-PiP 切り替え（別のタブに切り替えたときに動画を PiP で起動）。

### 4.8 ページ閲覧モード & 視覚オーバーレイ
- **CSS フィルタテーマ**: Web ページに非破壊的なスタイルを挿入します。
  - `mb` / `mB`: Black（ダーク・高コントラスト）— タブスコープ / グローバルスコープ。
  - `ms` / `mS`: Sepia（ウォームペーパー）— タブスコープ / グローバルスコープ。
  - `mp` / `mP`: Paper（モノクロ・グレースケール）— タブスコープ / グローバルスコープ。
  - `ml` / `mL`: Light（ソフトホワイト）— タブスコープ / グローバルスコープ。
  - `me` / `mE`: ユーザー定義のカスタム CSS フィルタ — タブスコープ / グローバルスコープ。
  - `ESC`: アクティブなページフィルタを即座に削除。
- **リーダーモード & 音声読み上げ (TTS)**:
  - `fetchContentForReaderView`: 広告、サイドバー、ナビゲーションのノイズを除去し、クリーンな記事コンテンツを抽出します。
  - テキストを一文ずつ読み上げる内蔵テキスト読み上げ (TTS) エンジン。
  - キーボードナビゲーションコントロール: `zp`（再生/一時停止）、`zn`（次の文）、`zb`（前の文）、`zq`（リーダーオーバーレイを閉じる）。

### 4.9 テンプレート変数を備えたテキストスニペットサブシステム
テキストスニペットサブシステム（`src/utils/hint/snippets.js` および `src/utils/snippet-panel.js` の `SnippetManager`）は、入力欄、textarea、またはリッチエディタ内でテキストショートカットを展開することにより、入力を高速化します。
- **トリガー方式**: ショートカットの後にスペースを入力するか、`$$` と入力してインタラクティブなスニペット検索ポップアップを呼び出します。
- **Clipboard API の統合**: Clipboard API を介したフォーマット済み HTML およびプレーンテキストの挿入をサポートし、Google Docs、Notion、Slack などの複雑なエディタとの 100% の互換性を確保しています。
- **テンプレート変数**: 展開の瞬間に変数を動的に解決します。
  - `{{date}}` / `date`: ロケールフォーマットの日付 (`toLocaleDateString`)。
  - `{{isodate}}` / `isodate`: ISO 8601 形式の日付 (`YYYY-MM-DD`)。
  - `{{longdate}}` / `longdate`: 曜日、日、月、年を含む長い形式の日付。
  - `{{time}}` / `time`: 2 桁フォーマットの時刻 (`HH:MM`)。
  - `{{datetime}}` / `datetime`: 日付と時刻の組み合わせ。
  - `{{weekday}}` / `weekday`: 完全な曜日名（例: Monday）。
  - `{{day}}` / `day`: 月の日付 (1-31)。
  - `{{month}}` / `month`: 完全な月名（例: October）。
  - `{{year}}` / `year`: 4 桁の完全な年。
  - `{{tomorrow}}` / `tomorrow`: 翌日の日付 (+1 日)。
  - `{{yesterday}}` / `yesterday`: 前日の日付 (-1 日)。
  - `{{nextweek}}` / `nextweek`: 7 日後の日付 (+7 日)。
  - `{{timestamp}}` / `timestamp`: エポックミリ秒タイムスタンプ (`Date.now()`)。
  - `{{url}}` / `url`: アクティブな Web ページの URL (`window.location.href`)。
  - `{{domain}}` / `domain`: アクティブなドメインのホスト名 (`window.location.hostname`)。
  - `{{pagetitle}}` / `pagetitle`: アクティブなドキュメントのタイトル (`document.title`)。
  - `{{uuid}}` / `uuid`: 暗号学的に安全な一意の識別子 (`crypto.randomUUID()`)。
  - `{{random}}` / `random`: 1 から 1000 までのランダムな整数。
  - `{{clipboard}}` / `clipboard`: システムクリップボードのバッファテキスト。

### 4.10 組み込み生産性ツール
- **右クリック許可フック (`allowRightClickHook.js`)**:
  - 右クリックコンテキストメニュー、コピー、切り取り、またはテキスト選択を無効化する悪意のある Web スクリプトを無力化するため、`MAIN` 実行ワールドに挿入されます。
  - `contextmenu`、`copy`、`cut`、`selectstart`、`mousedown`、`mouseup` における `preventDefault()` および `stopPropagation()` をインターセプトします。
  - 永続的な `MutationObserver` を介して、インラインの `oncontextmenu="return false"` ハンドラーをクリアします。
  - 正当な Web エディタ（Google Docs、Telegram Web）の動作を破壊しないよう、クリップボードのペイロードを検証します。
- **Cookie エディタ**: アクティブなドメインの HTTP および HTTPS クッキーを検査、編集、作成、削除するページ内モーダル。
- **QR コードジェネレーター**: モバイル端末への迅速な引き継ぎのため、アクティブタブの URL の SVG/Canvas QR コードを生成します。
- **クリーン PDF 印刷エクスポート**: クリーンなドキュメントアーカイブのため、ヘッダー、広告、ナビゲーションノイズを除去した状態で対象ページを `print.html` 経由でルーティングします。

### 4.11 包括的な 3 段階の重複排除 & インテリジェント破棄
- **包括的な 3 段階の重複排除**:
  1. **タブの重複排除 (`removeDuplicateTabsCommand`)**: ウィンドウ間またはフォーカスされたグループ全体の開いているタブをスキャンし、重複する URL を特定して、`Split` スクリーンタブを除外した上で、アクティブまたは最も古いタブを保持しながら重複タブを閉じます。デスクトップ概要通知を表示します。
  2. **ブックマークの重複排除**: Chrome のブックマークツリーを詳細にスキャンし、フォルダ間で完全に一致する URL の重複を特定して、ブックマークを整理するためのバッチ統合を提供します。
  3. **ルールの重複排除 (`feature_v100_dedup_add_to_rule`)**: 既存のカスタムグループ化ルールに URL を追加する際、重複する URL パターンを自動的に除去し、ルールの肥大化を防止します。
- **インテリジェントなメモリ破棄 (`suspendInactiveTabsIntelligently`)**:
  - アラーム `itg-periodic-tasks` を介して 1 分ごとに評価されます。
  - `discardingTimeMinutes`（デフォルト: 60 分）以上非アクティブなタブを破棄（サスペンド）します。
  - 組み込みの免疫保護: アクティブなタブ、音声を再生中の可聴タブ、ピン留めされたタブ、またはすでにサスペンドされているタブは絶対に破棄しません。

## 5. セクション 4: AI アシスタント & 自律型エージェント (Asistente AI)

AI アシスタントは、大規模言語モデルをブラウザに統合し、文脈理解、自動化されたワークフロー、およびブラウザの直接操作を提供します。

### 5.1 デュアルモデルエンジンアーキテクチャ
1. **Google Gemini Cloud API (`gemini-api.js`)**:
   - Google Generative Language REST エンドポイント（`v1beta/models/{model}:generateContent` および `:streamGenerateContent`）と統合。
   - Gemini 2.5 Flash、Gemini 2.5 Pro、およびカスタムモデルエンドポイントをサポート。
   - **マルチキーローテーション**: `geminiApiKeysList` 内でキープールを管理。ストレージの難読化には `enc_` プレフィックスを使用。
   - **指数バックオフ**: 自動バックオフ再試行（1.5 秒 -> 3 秒 -> 6 秒）により HTTP 429 クォータ枯渇を処理。
   - **検索グラウンディング**: Google Search Grounding (`google_search: {}`) を有効化。検索ツールのクォータ制限により HTTP 403 が発生した場合は、グラウンディングなしで自動的に再試行。
2. **Chrome Built-in AI / Prompt API (`localAiService.js`)**:
   - `window.LanguageModel` を介したオンデバイスの Gemini Nano 統合。
   - ネットワーク通信ゼロのローカル実行をサポート。モデルの利用可能性チェックとライブダウンロード進捗追跡を含みます。

### 5.2 自律型ブラウザエージェント (`agent-backend.js`)
自律型エージェントは、40 以上の構造化ツールを通じて完全なブラウザ制御を提供します。
- **タブ & グループ制御**: `getOpenTabs`、`switchToTab`、`createNewTab`、`closeTab`、`closeTabs`、`duplicateTab`、`findAndSwitchToTab`、`groupTabs`、`ungroupTabs`、`deleteTabGroup`、`collapseTabGroup`、`expandTabGroup`、`collapseAllGroups`、`expandAllGroups`、`setGroupColor`、`renameTabGroup`、`regroupAllTabs`、`removeDuplicateTabs`、`closeTabsWithSound`。
- **ナビゲーション & 検索**: `openUrl`、`searchGoogle`、`getActiveTab`、`getActiveTabContent`。
- **ナレッジ & ブックマーク**: `getBookmarks`、`searchBookmarks`、`createBookmark`、`getHistory`、`getRecentlyClosed`。
- **ルール & 外観**: `getRules`、`createRule`、`updateRule`、`deleteRule`、`getActiveTheme`、`getSavedThemes`、`applyTheme`。

### 5.3 テイントトラッキング & プロンプトインジェクション防御
信頼できない Web ページからの間接的なプロンプトインジェクション攻撃を無力化するため、エージェントバックエンドは厳格なテイントトラッキング（汚染追跡）を実装しています。
- **テイントマーキング**: `getActiveTabContent` を呼び出して Web ページからテキストを抽出すると、現在の実行セッションが汚染されたものとしてマークされます (`taintedAgentRuns.add(runId)`)。
- **送信ガード (Egress Guard)**: 汚染された実行セッションでは、外部送信ツール (`AGENT_EGRESS_TOOLS`) の呼び出しが厳格に禁止されます。
  * `openUrl`、`searchGoogle`、`createBookmark`、`createRule`、`addUrlToRule`、`createSiteShortcut`、`updateSiteShortcut`、`updateRule`。
- **拒絶メカニズム**: 未処理の例外をスローするのではなく、エンジンは構造化されたセキュリティ説明を返します。その後、LLM はユーザーの明示的な同意なしに外部データを外部へ持ち出すことはできない旨をユーザーに伝えます。

### 5.4 スケジュール設定された Gemini クエリサブシステム (`GeminiScheduleModal.svelte`)
- **バックグラウンド実行エンジン**:
  - `chrome.alarms` (`gemini-scheduled-*`) を介して、バックグラウンド Service Worker 内でスケジュールされた AI プロンプトの実行を直接自動化します。
  - 1 日あたり最大 6 つのスケジュールクエリをサポート (`MAX_TIMES = 6`)。
  - **スケジュールモード**:
    - 繰り返しスケジュール: 選択した曜日に繰り返し実行 (`selectedDays`)。
    - 単発スケジュール: 指定した特定の日時に実行 (`formDate`)。
  - **プロンプト制限**: リアルタイム文字数カウンターを備え、1,000 文字の厳格なプロンプト制限を強制 (`MAX_QUERY_CHARS = 1000`)。
  - **バックグラウンド通知**: バックグラウンドクエリが完了すると、スニペットプレビュー付きのデスクトップ通知を発行します。通知をクリックすると、サイドパネルチャット内の該当応答スレッドが即座に開きます。

### 5.5 Gemini 会話管理 & エクスポート
- **永続的 IndexedDB ストレージ (`geminiConversations`)**: マルチターンのチャットセッションは、IndexedDB `Intelligent_Workspace` のストア `geminiConversations` に保存されます。
- **全文履歴検索**: Omnibar コマンド `lai:`（会話の閲覧）および `laiq:`（メッセージの検索）を介して、過去のすべての会話および個々のメッセージを即座に検索できます。
- **4 種類のエクスポートフォーマット**:
  1. **装飾付き HTML**: スタイル設定された会話バブル、ロールバッジ、タイムスタンプ、およびシンタックスハイライトされたコードブロックを備えたフォーマット済みスタンドアロン HTML ドキュメント。
  2. **Raw JSON**: メッセージ配列、トークン使用量、モデル構成、および検索引用を含む完全な構造化データダンプ。
  3. **Markdown**: 見出し、タイムスタンプ、コードフェンス（` ``` `）でフォーマットされた標準 Markdown ファイル。
  4. **プレーンテキスト**: メールやメモに適した、フォーマットのないクリーンな会話トランスクリプト。
- **グラウンディングメタデータの追跡**: モデル ID、トークン使用統計、実行タイムスタンプ、および Google Search Grounding によって返されたソース引用を追跡します。

### 5.6 マルチモーダル入力 & ファイル添付 (`feature_geminiAttachFiles`)
- **マルチモーダル添付**: トグル `feature_geminiAttachFiles` により、チャットプロンプト内で画像やドキュメントを直接添付できるようになります。
  - 画像ファイル（JPEG、PNG、WebP、HEIC/HEIF）。
  - PDF ドキュメントおよび研究論文。
  - プレーンテキストファイルおよびコードファイル。
  - CSV 構造化データセット。
- **音声サポート**:
  - ハンズフリーでプロンプトを口述筆記するための Web Speech STT（音声テキスト変換）。
  - 応答を音声で読み上げるための Web Speech TTS（テキスト音声合成）。

### 5.7 呼び出し方法
- **サイドパネルルート**: `?view=gemini` またはショートカット `pa`。
- **ページ内 Omnibar プレフィックス**:
  - `qai: <query>` — 設定された Gemini モデルに直接質問します。
  - `qaia: <prompt>` — ツール実行を伴う自律型エージェント経由でプロンプトを実行します。
  - `lai:` — 過去の AI 会話を閲覧します。
  - `laiq:` — すべての AI 会話メッセージを対象に全文検索します。
- **Omnibox AI タブ検索 (`find <query>`)**:
  - URL バーのキーワード `find` によりハイブリッド検索を開始します。
  - 正規表現の単語境界スコアリングと Gemini のセマンティック解決を組み合わせ、自然言語クエリに基づいて開いているタブを特定してフォーカスします。

## 6. セクション 5: ノートビュー & ナレッジ管理 (Ver Notas)

ブラウザのタブグループおよびナビゲーションコンテキストに紐付けられた、ローカルファーストでコンテキスト認識型のノート作成エンジンです。

### 6.1 ストレージアーキテクチャ (`notesStore`)
IndexedDB データベース `Intelligent_Workspace` (v8) 内のオブジェクトストア `notesStore` に保存されます。
```typescript
interface NoteRecord {
  id: string;          // 一意のノート識別子。
  title: string;       // ノートのタイトル。
  text: string;        // リッチテキスト HTML、Markdown、またはシリアライズされたタスクペイロード。
  type: NoteType;      // 'text' | 'checklist' | 'kanban'
  url?: string;        // ノートが作成されたオリジン URL。
  contextKey: string;  // ノートをワークスペース階層にバインドするスコープキー。
  createdAt: number;   // 作成タイムスタンプ。
  modifiedAt: number;  // 最終編集タイムスタンプ。
  isPersistent: boolean; // グループ削除クリーンアップからノートを保護するピン留めフラグ。
}
```

### 6.2 特化型ノートフォーマット & 高度なレンダリング
1. **テキストノート (`NoteTextEditor.svelte`)**:
   - リッチテキスト `contenteditable` サーフェス。
   - メディアを直接埋め込み: 画像、音声、動画、および PDF ドキュメント。
   - 組み込みの HTML サニタイズ処理とリアルタイムの単語・文字数カウンター。
   - **Mermaid ダイアグラムのレンダリング**: Markdown のコードフェンス（` ```mermaid `）から動的なフローチャート、シーケンス図、クラス図、ステートマシンを直接レンダリング。
   - **KaTeX 数学 LaTeX**: 高精度なタイポグラフィでインライン数式（`$...$`）およびブロック数式（`$$...$$`）をレンダリング。
2. **チェックリストノート (`NoteChecklistEditor.svelte`)**:
   - 個別の完了チェックボックスを備えたインタラクティブなタスクリスト。
   - キーボードによる項目の並べ替えと進捗管理をサポート。
3. **Kanban ノート (`NoteKanbanEditor.svelte`)**:
   - 3 列のワークフローボード: `To Do` -> `In Progress` -> `Done`。
   - 迅速なタスクステータス遷移のためのサイクリングステータスチップ。
- **動的な可逆変換**: ノートはテキスト、チェックリスト、Kanban の表現間で情報を失うことなく相互変換できます。

### 6.3 スコープ & コンテキスト階層
ノートは `contextKey` を介して閲覧コンテキストにバインドされます。
- **グループスコープ (`g_<groupId>` または `g_<groupKey>`)**: タブグループ全体に紐付けられます。
- **サブグループスコープ (`s_<groupId>_<domain>`)**: タブグループ内の特定ドメインに紐付けられます。
- **グループ外スコープ (`g_ungrouped` / `s_ungrouped_<domain>`)**: タブグループ外のタブ上で作成されたノート。
- **ポモドーロ & 一般スコープ (`pomodoro`, `general`)**: ワークスペース全体のノート。
- **孤立検出エンジン (Orphan Detection Engine)**: タブグループまたはドメインが削除された際、関連付けられた非永続ノートは孤立検出器によってキャプチャされます。ノートは UI 上でアクセス可能なまま保持され、再割り当てや削除が可能です。

### 6.4 呼び出し方法
- **UI ランチャー**: グループカードおよびサブグループカード上の「Ver Notas (ノートを表示)」ボタン、ポップアップヘッダーの「Quick Notes」ボタン、サイドパネルルート `?view=notes` (`pk`)。
- **コンテキストメニュートリガー**: 任意の Web ページ上でテキストを選択 -> 右クリック -> "Crear Nota desde Selección" (`note-from-selection`)。選択したテキストを自動的に抽出し、最も近い `h1`〜`h3` 見出しをタイトルとして設定します。
- **Vim ヒント**: `ao` により現在の選択範囲からノートを作成。
- **Omnibar**: `lnt:` により即時全文検索付きのノートブラウザを開きます。
- **音声読み上げ**: エディタ内の TTS ボタンにより、Web Speech API を使用してノートの内容を音声で読み上げます。

## 7. セクション 6: メディア & ギャラリービュー (Ver Galería)

高性能なメディアキャプチャ、注釈付け、および光学文字認識 (OCR) パイプラインです。

### 7.1 キャプチャモード & エンジニアリング（全 7 種類のキャプチャタイプ）
本拡張機能は、単一タブ、タブ横断、切り抜き、パレット操作をカバーする 7 種類の特殊なキャプチャ方式を実装しています。
1. **`visible` (表示ビューポートキャプチャ - `cs`)**:
   - `chrome.tabs.captureVisibleTab` を使用して、アクティブタブの正確な表示ビューポートをキャプチャします。
   - キャプチャを IndexedDB の `screenshots` ストアに自動的にコミットし、画像のビットマップをシステムのクリップボードに直接コピーします (`screenshotSavedAndCopied`)。
2. **`fullPage` (シームレスな全ページスクロールキャンバス - `cp`)**:
   - プログラムによるページスクロールを実行し、ドキュメントの総スクロール高さを計算します。
   - スクロールバーを非表示にし、初期セグメント以降の sticky/fixed ナビゲーションバーを非表示にして表示の乱れを排除します。
   - ビットマップスライスを最大 30,000px の高さの `OffscreenCanvas` に結合し (`captureFullPageDataUrl`)、フレームキャプチャ間に Chromium 準拠の 600ms の遅延を強制します。
3. **`fullPageParts` (連続分割セグメント - `cpp` / `cP`)**:
   - 縦に長いドキュメントを連続した個別のビューポート高さの画像パーツに分割し (`captureFullPageParts`)、ページ分割用に最大 60 個の番号付き画像チャンクを生成します。
4. **`area` (インタラクティブな矩形ドラッグ切り抜き - `ca`)**:
   - `area-selector.js` を挿入し、リアルタイムのバウンディングボックス寸法を表示する十字カーソルキャンバスをオーバーレイします。
   - ドラッグ可能な選択ハンドル、寸法ツールチップ、確定トリガー、`Esc` キーによるキャンセル、および複数タブの切り抜きキューイング (`handleCaptureAreaFromShortcut`) を備えています。
5. **`groupTabs` (アクティブグループタブの一括巡回 - `Cs`, `Cp`, `CP`)**:
   - アクティブなタブグループ内のすべてのタブを順次反復処理します (`handleCaptureGroupFromShortcut`)。
   - 表示領域、全ページ、または分割パーツモードでの一括キャプチャをサポートし、それらを統合コレクションにまとめます。
6. **`omnibarPickedTabs` (カスタムマルチタブキューキャプチャ)**:
   - Omnibar コマンド `cs:`、`cp:`、`cpp:`、または `ca:` を介して開始されます (`handleCaptureTabs`)。
   - ユーザーがフィルタリングしたすべてのタブにわたって連続キャプチャを実行し、リアルタイムの進捗インジケーターを提供します。
7. **`colorPickerCapture` (バックグラウンド画面スポイトフォールバック)**:
   - ネイティブの `window.EyeDropper` サポートを欠くオペレーティングシステム（例: Linux）において、高精度な HEX スポイト拡大鏡ツールを機能させるためのバックグラウンド画面キャプチャを取得します。

### 7.2 ギャラリー UI & 永続化
- **インターフェース**: ライトボックスズーム、パン、回転ツールを備えたレスポンシブなメイソンリー/グリッドレイアウト。
- **永続化 (`screenshots` ストア)**: IndexedDB `Intelligent_Workspace` に保存されます。ピン留めされていないキャプチャはメンテナンス中に自動的にパージされます。ピンアイコンをクリックすると (`isPersistent = true`)、キャプチャが無期限に保持されます。

### 7.3 エクスポート、ブラウザ内 OCR、外部マークアップ
- **エクスポート形式 (`captureDownloadFormats`)**:
  - 高効率フォーマット: PNG、WebP、AVIF。
  - `pdf.js` を介した複数ページ結合 PDF ドキュメントのエクスポート。
- **オンデバイス WASM OCR**:
  - 事前ロードされたスペイン語と英語 (`spa+eng`) の言語モデルを利用するブラウザ内 Tesseract.js WebWorker。
  - 画像データをネットワーク経由で送信することなく、テキストをクリップボードに直接抽出します。
- **ダイレクト送信統合**:
  - 抽出された OCR テキストまたは画像添付ファイルを、Notes (`notesStore`) または Gemini AI プロンプト (`feature_geminiAttachFiles`) にワンクリックで転送。
- **Excalidraw マークアップ**: ワンクリックエクスポートにより、キャプチャした画像を `https://excalidraw.com/` に直接送信し、フリーハンド描画、矢印、ベクター注釈を付けることができます。

### 7.4 呼び出し方法
- **UI**: グループカードのカメラボタン、ポップアップのクイックアクション、サイドパネルギャラリールート `?view=gallery` (`ps`)。
- **Vim ヒント**: `cs`（表示領域）、`cp`（ページ全体）、`cP`（パーツ分割）、`ca`（エリア切り抜き）、`Cs`（グループ全タブ表示領域）、`Cp`（グループ全タブページ全体）、`CP`（グループ全タブパーツ分割）。
- **Omnibar プレフィックス**: `cs:`、`cp:`、`cpp:`、`ca:`、および `limg:`（ギャラリー閲覧）。

## 8. セクション 7: ポモドーロ & タイマースイート (Pomodoro)

ブラウザのスリープサイクルを挟んでも絶対的な精度を維持できるように設計された集中およびタイマースイートです。

### 8.1 タイミングエンジン & バックグラウンドアーキテクチャ
- **ドリフトゼロのタイムスタンプ計算**: 状態は絶対 Unix タイムスタンプ (`startTime`、`pausedAt`) とともに `chrome.storage.local` に永続化されます。Service Worker の終了、ブラウザの再起動、およびオペレーティングシステムのスリープ状態が発生しても、クロックのズレ（ドリフト）は生じません。
- **アラームディスパッチャー**:
  - `chrome.alarms` によって駆動される高解像度カウントダウンティッカー (`pomodoroTick` 1 秒インターバル)。
  - `itg-periodic-tasks`（1 分インターバル）によって管理されるバックグラウンドメンテナンスおよび長期インターバルスイープ。
- **オフスクリーン音声チャイム (`offscreen.html`)**: 音声チャイムは、`AUDIO_PLAYBACK` を理由として作成された専用の Chrome Offscreen ドキュメントを介して生成されます。メモリを節約するため、音声完了後 3.5 秒で自動的に閉じます。

### 8.2 網羅的な 4 つのタイミングモード
1. **ポモドーロ (`pomodoro`)**:
   - 作業時間: 1〜180 分（デフォルト: 25 分）。
   - 短い休憩: 1〜120 分（デフォルト: 5 分）。
   - 長い休憩: 1〜180 分（デフォルト: 15 分）。
   - 長い休憩までのサイクル数: 1〜12 サイクル（デフォルト: 4）。
   - 目標サイクル数: 1〜99 サイクル（デフォルト: 8）。
   - 作業の自動開始、休憩の自動開始、通知アラートを設定可能。
2. **ストップウォッチ (`cronometro`)**: ラップ記録および「一時停止を停止とする」機能を備えたプログレッシブタイマー。
3. **カウントダウン (`temporizador`)**: 時間、分、秒を指定するカスタムカウントダウンタイマー。
4. **目標時刻アラーム (`tiempo`)**: カレンダーの日付ピッカーと時計セレクターにより、将来の正確なタイムスタンプにアラームを設定。

### 8.3 ページ内フローティングタイマーウィジェット
- リアルタイムのカウントダウン、一時停止/再開、スキップボタンを Web ページ上に直接表示するドラッグ可能な最小限のオーバーレイ。
- 拡張機能パネルやポップアップに戻ることなく、集中セッションを監視できます。

### 8.4 グループ自動折りたたみアイドルタイマー
- 集中ルーチンと連動して動作し、非アクティブグループを 1 分間の非アクティブ後 (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`) に、アクティブグループを 15 分間の非アクティブ後 (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`) に自動的に折りたたみます。0 から 1440 分まで設定可能。

### 8.5 プロジェクトのタグ付け & メタデータ
各セッションは以下の分類メタデータをサポートします。
- プロジェクト名（最大 18 文字）
- プロジェクトタグ（例: `#research`、`#dev`）
- プロジェクトフォルダ（例: `/client/project`）

### 8.6 アナリティクスエンジン & 19 種類の KPI カード
完全なダッシュボード（`dashboard.html` またはサイドパネルの `dashboard.html?context=sidepanel`）は、重複排除されたセッション（`sessionStarted` による `dedupeSessions`）から 19 個の主要業績評価指標 (KPI) を計算します。
1. `focus`: 総集中時間。
2. `sessions`: 完了した合計セッション数。
3. `cycles`: 完了した合計作業サイクル数。
4. `efficiency`: 平均効率パーセンテージ (`総集中時間 / 総時間 * 100`)。
5. `activeDays`: 一意のアクティブ日数。
6. `break`: 合計休憩時間。
7. `interruptions`: 手動による一時停止/中断の合計回数。
8. `interruptionTime`: 一時停止状態で費やされた累積時間。
9. `bestSession`: 最長の中断なし単一集中セッション。
10. `avgFocus`: 完了サイクルあたりの平均集中時間。
11. `totalTime`: 作業と休憩に費やされた累積時間。
12. `workRest`: 作業時間と休憩時間の比率 (`1 : X`)。
13. `distractionRate`: 集中時間 1 時間あたりの中断回数。
14. `bestDay`: 1 週間で最も生産的な曜日。
15. `goldenHour`: 1 日の中で最も集中力が高かったピーク時間帯（例: `10:00 - 11:00`）。
16. `projects`: 記録された個別のプロジェクト数。
17. `avgIntDuration`: 各中断の平均継続時間。
18. `topProject`: 累積集中時間が最も長いプロジェクト。
19. `focusIntensity`: アクティブ日あたりの平均集中時間。

追加のビジュアルアナリティクスとして、Day Streak Heatmap カレンダー、1 時間ごとの集中度分布棒グラフ、プロジェクト多様性内訳、および完全な JSON データインポート/エクスポートが含まれます。

## 9. セクション 8: アクティビティ & 履歴パネル (Panel de Actividad)

Declarative Net Request (DNR) によるトラッキング、アナリティクス、および Web ガバナンスエンジンです。

### 9.1 データエンジン & ストレージトポロジー (`ITG_WEB_ACTIVITY`)
`ITG_WEB_ACTIVITY` 配下で管理されます。
- `wa:day:YYYY-MM-DD`: 日ごとのドメインカウンター (`{ domains: { host: { t: seconds, v: visits, s: sessions, h: { hour: seconds } } } }`)。
- `wa:days`: 記録された日付キーのマスターインデックス配列。
- `wa:recent`: 最新の 400 件の訪問タイムラインエントリを格納するリングバッファ。
- `wa:openSegment`: `chrome.storage.session` 内のアクティブな計測セグメント。アイドルイベントを発火させずにマシンがスリープした場合に統計が歪むのを防ぐため、`WA_MAX_SEGMENT_SECONDS = 900s` (15 分) に制限されています。
- **アイドル検出**: `chrome.idle` を使用（デフォルト: 300 秒 / 5 分）。`countAudible = true` の場合、ウィンドウがフォーカスされていなくても音声再生によってアクティブな追跡が維持されます。
- **保持期間**: `retentionDays`（デフォルト: 180 日）より古い日次レコードを自動的に破棄します。

### 9.2 Declarative Net Request (DNR) サイトブロッカー
- **動的ルール割り当て**: ID 範囲 `9000` から `9999` に動的ルールを割り当てます。
- **リダイレクトターゲット**: ブロックされたリクエストは `src/ui/pages/web-activity/blocked.html?d=<domain>&u=\1` にリダイレクトされます。
- **開いているタブのスイープ**: サイト制限時間が切れると、バックグラウンドワーカーは該当ドメインと一致する既存の開いているタブを即座にスイープしてリダイレクトします。
- **日をまたぐスケジュールの処理**: 深夜 0 時をまたぐスケジュール（例: `22:00` から `02:00`）は、日付の境界を越えて自動的に評価されます。
- **猶予 / スヌーズ期間 (+5 分)**: ブロック画面では、`wa:snoozeUses` で追跡される一時的な 5 分間のスヌーズパスが許可されます。

### 9.3 非対称セキュリティロック (`blockLock.js`)
サイト制限は、非対称パスワードロックで保護できます。
- **ハッシュストレージ**: ランダムな 16 バイトのソルトと SHA-256 の 16 進ダイジェストを保存します (`wa:settings.blockPassword`)。
- **非対称ルールポリシー**: 新しい制限を作成する場合や、ルールをより厳しくする場合（制限時間を減らす、スケジュールの制限を追加するなど）は、パスワードが**要求されることはありません**。
- **保護されるアクション**: パスワードが要求されるのは、**ルールを緩和する場合**（制限の削除、制限時間の増加、スケジュールの無効化など）、または 1 日の無料しきい値を超えてスヌーズを呼び出す場合 (`snoozePasswordAfter`) のみです。

### 9.4 カテゴリ分類 & ビジュアルアナリティクス
- **16 種類の組み込みカテゴリ**: `social`、`video`、`music`、`news`、`shopping`、`reading`、`entertainment`、`dev`、`work`、`education`、`games`、`finance`、`mail`、`ai`、`search`、`other`。
- **カスタムカテゴリ**: 先頭に `custom:` が付いたユーザー定義カテゴリをサポート。
- **集中度比率 (Focus Ratio)**: 生産的カテゴリ（`dev`、`work`、`education`、`reading`、`finance`、`mail`）と気が散るカテゴリ（`social`、`video`、`games`、`shopping`、`entertainment`）を対比させます。
- **ビジュアル**: Chart.js による時間別アクティビティ分布、カテゴリのドーナツチャート内訳、およびドメインランキングリスト。

### 9.5 ダウンロードマネージャーサブシステム (`switchMainView('downloads')`)
- **専用ルート**: サイドパネル内で `switchMainView('downloads')` (`?view=downloads`) を介してアクセス。
- **直接的な Chrome API 統合**: `chrome.downloads` をフックして、ブラウザのすべてのダウンロードをリアルタイムで追跡、管理、検査します。
- **リアルタイムあいまい検索**: ファイル名、ファイルパス、またはダウンロード元 URL による即時検索。
- **ステータスフィルタチップ**: 状態別にダウンロードをすばやくフィルタリング: `All`、`In Progress`、`Complete`、`Paused`、および `Interrupted`。
- **カレンダー日付範囲フィルタリング**: 特定の日付または時間帯でダウンロードを絞り込みます。
- **グループ一括ダウンローダー**: アクティブグループ内の開いているタブからすべてのダウンロードリンクを抽出し、進捗追跡付きで同期された一括ダウンロードを開始します。
- **ファイル管理**: ワンクリックでのファイル直接オープン (`chrome.downloads.open`) およびフォルダ内表示 (`chrome.downloads.show`)。

### 9.6 最近閉じたタブ & 閲覧履歴サブシステム
- **最近閉じたタブビュー**:
  - `chrome.sessions.getRecentlyClosed` と直接統合。
  - ダイアクリティカルマークおよびアクセントの自動除去 (`deaccent`) を備えたリアルタイム検索。
  - ワンクリックまたは Omnibar コマンド `c:` による単一タブの復元およびウィンドウ全体のセッション復元。
- **閲覧履歴ビュー**:
  - 冗長な `chrome.history.search` クエリの発生を抑えるための、10 秒の TTL インメモリキャッシュを備えた詳細検索。
  - ドメイン、キーワード、カレンダーの日付範囲による検索フィルタリング。
  - 既に開いている場合はタブへのワンクリック切り替え、開いていない場合は新規タブ作成。Omnibar `h:` からアクセス可能。

### 9.7 テーマスケジュールサブシステム (`ThemeScheduleModal.svelte`)
- **自動テーマスケジューリング**:
  - テーマサイドパネルビュー（`?view=themes` / `pt`）内の `ThemeScheduleModal.svelte` を介して管理。
  - 時間帯 (`HH:MM`) およびアクティブな曜日 (`[0..6]`) に基づく自動テーマ切り替えをサポート。
  - 最大 7 個のグローバルテーマスケジュール (`MAX_GLOBAL_SCHEDULES = 7`)。
  - **自動復元**: 指定された終了時刻に、デフォルトの昼間用または職場用テーマに自動的に戻ります。
  - **デスクトップアラート**: 自動テーマ切り替えが発生した際にデスクトップ通知を発行 (`chrome.notifications`)。
  - **デュアル永続化**: `savedThemes` および `themeSchedules` 配下の `chrome.storage.sync`（ローミング設定）および `chrome.storage.local` に永続化。

### 9.8 コンパクトサイドパネルビュー
- **サイドパネルルート (`?view=activity` / `pw`)**: 期間セレクターチップ（`Today`、`7d`、`30d`、`All`）およびドメイン制限プログレスバーを備えた、リアルタイム監視用に最適化された 350px のカラム。

## 10. マルチモーダル呼び出しマトリクス

### 10.1 ポップアップ UI インターフェース
- **Rules タブ**: クイックルールトグル、アクティブ状態インジケーター、およびルール URL ランチャー。
- **Groups タブ**: タブ切り替えとグループクリーンアップを備えたコンパクトなアコーディオンリスト。
- **AI ランチャー**: クエリをサイドパネルにルーティングするダイレクトチャット入力ボックス。
- **クイックアクションツールバー**: エリアスクリーンショット、全ページキャプチャ、クイックノート、ポモドーロ開始/一時停止、サイドパネル展開用のワンクリックボタン。

### 10.2 サイドパネルナビゲーションルート (`?view=...`)
- `?view=rules` — 包括的なルールマネージャーおよび URL パターンエディタ (`pg`)。
- `?view=listgroup` — ドラッグ＆ドロップによる並べ替えを備えた完全なグループおよびタブワークスペース (`pl`)。
- `?view=notes` — ノートワークスペース（Text、Checklist、Kanban、Mermaid、KaTeX）(`pk`)。
- `?view=gallery` — スクリーンショットギャラリー、OCR、Excalidraw ツール (`ps`)。
- `?view=gemini` — マルチモーダル AI アシスタントおよび自律型エージェントインターフェース (`pa`)。
- `?view=activity` — Web アクティビティトラッカー、制限、カテゴリメトリクス (`pw`)。
- `?view=themes` — テーマエディタおよび自動スケジューリングパレット (`pt`)。
- `?view=hints` — Vim ショートカット、Omnibar、YouTube ループ設定 (`pn`)。
- `?view=downloads` — ダウンロードマネージャーおよび一括リンクダウンローダー (`switchMainView('downloads')`)。

### 10.3 マニフェストキーボードショートカット（24 コマンド）
1. `toggle-current-group` (`Ctrl+Shift+Z` / Mac `Command+Shift+Z`): アクティブグループの折りたたみを切り替え。
2. `toggle-all-groups` (`Ctrl+Shift+Q` / Mac `Command+Shift+Q`): すべてのグループの折りたたみを切り替え。
3. `toggle-sort-alpha` (`Ctrl+Shift+S` / Mac `Command+Shift+S`): アルファベット順のグループソートを切り替え。
4. `open-popup` (`Alt+Shift+P`): ポップアップを開くか、サイドパネルにフォーカス。
5. `toggle-collapse-timer`: グループ自動折りたたみタイマーを切り替え。
6. `toggle-all-rules`: すべてのカスタムルールのマスタートグル (`Alt+M`)。
7. `toggle-expand-all`: ワークスペース内のすべてのグループを展開。
8. `rules-manager`: 専用タブでルールマネージャーを開く (`Alt+R`)。
9. `toggle-prefixes`: 視覚的グループプレフィックスインジケーター（`🔒`、`🔍`、`🗝️`、`⚠️`）を切り替え。
10. `toggle-domain-grouping`: 自動ドメインクラスタリングを切り替え。
11. `toggle-subdomain-grouping`: 自動サブドメインクラスタリングを切り替え。
12. `toggle-compact-mode`: 1 文字のコンパクトなグループタイトルを切り替え。
13. `toggle-chrome-grouping`: 特殊な Chrome 内部ページグループを切り替え。
14. `toggle-files-grouping`: 特殊なローカル `file://` ページグループを切り替え。
15. `toggle-extensions-grouping`: 特殊な `chrome-extension://` グループを切り替え。
16. `toggle-misc-grouping`: 未クラスタリングの「その他」グループを切り替え。

### 10.6 コンテキストメニューツリー階層（全 5 グループ & 30 以上のアクション）
コンテキストメニューは、5 つの機能コマンドグループに編成された完全な階層ツリーを提供します。
1. **グループ 1: ルール & URL サブメニュー**:
   - ルールのマスターチェックボックストグル ("Activar/Desactivar Todas las Reglas")。
   - 個々のカスタムルールを即座に有効化または無効化するルールごとのトグル。
   - "Abrir Todas las URLs": 選択したルールに登録されているすべてのターゲット URL を開きます。
   - 動的な開いているタブ数 `[N]` を備えた個別の URL サブメニュー: URL と一致する現在開いているタブ数を表示し、URL へのワンクリック遷移を提供し、一致するすべてのタブを終了するための "Cerrar Pestañas para esta URL" を提供します。
   - クイックルール作成: "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa"。
   - 既存のルールへの追加: "Añadir a Regla Existente" -> ルールを選択 -> "Añadir Raíz del Sitio" / "Añadir URL Completa"。
2. **グループ 2: タブのクリーンアップ & オーディオコントロール**:
   - "Eliminar Pestañas Duplicadas [N]": 検出された重複タブの数を表示し、ウィンドウ全体でそれらを閉じます。
   - "Eliminar Pestañas por Dominio": 開いているタブ数 `[N]` とともにすべてのドメインを一覧表示する動的サブメニューにより、ドメインごとの正確なタブクローズが可能。
   - "Cerrar Todos Excepto el Grupo Activo": アクティブにフォーカスされているグループを保持し、他のすべてのグループを閉じます。
   - "Reagrupar Todas las Pestañas": 開いているすべてのタブに対して、完全なバックグラウンド再グループ化パスをトリガーします。
   - "Silenciar Todas las Pestañas" / "Reactivar Sonido en Todas las Pestañas": グローバルな音声ミュートおよびミュート解除コントロール。
3. **グループ 3: 閲覧、選択 & ノート**:
   - "Leer Página en Voz Alta" (TTS): オーバーレイコントロールを備えたページ全体のテキスト読み上げリーダー。
   - "Leer Selección en Voz Alta": 音声合成を使用して、強調表示された DOM 選択範囲を音声で読み上げます。
   - "Crear Nota desde Selección": テキストの選択範囲を抽出し、最も近い見出し (`h1`-`h3`) からノートタイトルを自動的に導出し、`notesStore` に保存します。
4. **グループ 4: 拡張機能の起動、PiP & パネル**:
   - "Abrir como PiP" / "Abrir como Ventana Emergente": 対象のページ、強調表示された選択範囲、または対象の画像をフローティング Picture-in-Picture またはスタンドアロンのポップアップウィンドウで起動します。
   - "Abrir Extensión": 拡張機能のポップアップを開くか、サイドパネルを展開します。
   - "Gestionar Reglas": 専用のブラウザタブで完全なルールマネージャーを開きます。
   - ダイレクトサイドパネルランチャー: List Groups (`?view=listgroup`)、Themes (`?view=themes`)、AI Assistant (`?view=gemini`)、および Customize Hints (`?view=hints`) へのワンクリックルーティング。
5. **グループ 5: 設定 & クラスタリングオプション**:
   - **グループ管理 (Gestión de Grupos)**: 現在のグループの切り替え (Alternar Grupo Actual - アクティブグループの折りたたみを切り替え)、すべてのグループの切り替え (Alternar Todos los Grupos - 全グループの折りたたみを切り替え)。
   - **グループ化オプション (Opciones de Agrupación)**:
     - インテリジェントグループ化 (Agrupación Inteligente - 自動ヒューリスティッククラスタリングの切り替え)。
     - コンパクトモード (Modo Compacto - 1 文字グループタイトルモードの切り替え)。
     - ドメイン / サブドメイン (Dominio / Subdominio - ドメインおよびサブドメイングループ化の切り替え)。
     - 特殊ページ (Páginas Especiales): Chrome ページ (`chrome://`)、ローカルファイル (`file:///`)、拡張機能 (`chrome-extension://`)、その他 (`Misc`)、IP アドレス & Localhost。
   - **一般オプション (Opciones Generales)**:
     - アルファベット順にソート (Ordenar Alfabéticamente - タブストリップ全体でアルファベット順を強制)。
     - 「その他」グループの配置 (Ubicación Miscelánea): 先頭 (`start`)、末尾 (`end`)、アルファベット順 (`alpha`)。
     - 自動折りたたみタイマー (Temporizador de Auto-Colapso - アイドルグループ折りたたみタイマーの切り替え)。
     - 視覚的プレフィックス (Prefijos Visuales - `🔒`、`🔍`、`🗝️`、`⚠️` 状態マーカーの切り替え)。
     - リンクプレビュー (Vista Previa de Enlaces - ページ内リンクプレビューモーダルの切り替え)。

## 11. ストレージスキーマ & データ永続化

本拡張機能は、IndexedDB と Chrome Storage API をまたがるマルチティアストレージモデルを使用しています。

### 11.1 IndexedDB データベース: `Intelligent_Workspace` (スキーマバージョン 8)
1. `screenshots`: keyPath: `'id'`、autoIncrement: true。セカンダリインデックス: `'createdAt'`。バイナリスクリーンショット、キャンバスデータ URL、永続フラグ、寸法、およびセグメント合計インデックスを保持します。
2. `geminiConversations`: keyPath: `'id'`、autoIncrement: true。セカンダリインデックス 0 個（ID により取得/管理）。マルチターンチャットスレッド、メッセージロール、トークンメトリクス、および検索グラウンディングメタデータを保存します。
3. `notesStore`: keyPath: `'id'`、autoIncrement: false。セカンダリインデックス 0 個（contextKey によりメモリ内でフィルタリング）。リッチテキスト、チェックリスト配列、Kanban ボードカード、Mermaid 仕様、および KaTeX 数式を保存します。
4. `backupsGroups`: keyPath: `'group.id'`。セカンダリインデックス 0 個（ネストされた `'group.id'` をキーとするバックアップグループオブジェクトを保存）。圧縮されたグループ構造、色、タイトル、および閉じたタブのレコードを保存します。
5. `pomodoroStats`: keyPath: `'id'`、autoIncrement: true。セカンダリインデックス: `'projectName'` (keyPath `'projectName'`) および `'savedAt'` (keyPath `'savedAt'`)（`date` インデックスなし）。集中度アナリティクス、サイクルメトリクス、および中断ログを保持します。

### 11.2 Chrome Storage デュアルルーティング (`StorageService`)
- `chrome.storage.sync`（ユーザーのデバイス間で同期するポータブルな設定用）と `chrome.storage.local`（大容量の環境設定用）の間で読み書きを動的にルーティングします。
- 主要モデル:
  - `customRules`: ルール定義の配列 (`[{ name, color, active, urls }]`)。
  - `clusterConfig`: 自動クラスタリングパラメータ（しきい値、コンパクトモード、特殊カテゴリ）。
  - `userPrefixes`: 絵文字プレフィックスの割り当て (`{ lock, openKey, loupe, checked, warning }`)。
  - `activeTheme`、`savedThemes`、& `themeSchedules`: `ThemeScheduleModal.svelte` を介して構成された 9 パレットのカラー構成およびスケジュールされたローテーションルール。
  - `pomodoroState`: リアルタイムセッションタイムスタンプ、一時停止時間、およびサイクル目標。
  - `wa:settings` & `wa:limits`: Web アクティビティトラッキング環境設定、サイト制限、およびスケジュール枠。
  - `youtubeLoopEnabled`: YouTube および Shorts のループボタンを制御するブール値フラグ。

### 11.3 Chrome Storage セッション (`chrome.storage.session`)
超高速で一時的なランタイム連携に使用されます。
- `tabsEverActive`: 現在のブラウザセッション中にアクティブ化されたタブ ID のセット。
- `groupExpandedEver`: 現在のセッション中に展開されたグループの記録。
- `groupInfoMap`: グループ ID を動的タイトルおよびクラスタリングタイプにマッピングするリアルタイムレジストリ。
- `splitScreenState`: 元の画面寸法を復元するためのキャッシュされたウィンドウ境界情報。
- `contextMenusSignature`: 高速なタブ切り替え中の冗長なコンテキストメニュー再構築処理を防止するハッシュシグネチャ。
- `wa:openSegment`: 現在アクティブな Web サイトの時間セグメント。
- `hiddenYoutubeView`: `HiddenGroupsBar.svelte` にドッキングされたパーキング YouTube プレーヤービューへの参照。

## 12. 防御的エンジニアリング & エッジケース処理

1. **Declarative Net Request ヘッダーブロック解除 (`dnr.js`)**:
   - 動的 DNR ルールを介してレスポンスヘッダーを変更し、`X-Frame-Options` および制限的な `Content-Security-Policy` ヘッダーを除去することで、外部サイトをサイドパネルおよび Picture-in-Picture の iframe 内にレンダリングできるようにします。
   - **WhatsApp Web の安全性**: WebAssembly による Signal 暗号化実装の破損を防ぐため、`web.whatsapp.com` 上の `Cross-Origin-Opener-Policy` (COOP) および `Cross-Origin-Embedder-Policy` (COEP) を明示的に保持します。
2. **右クリック & 選択のブロック解除機能 (`allowRightClickHook.js`)**:
   - コピー、貼り付け、コンテキストメニュー、テキスト選択をブロックする悪意のある Web サイトを無力化します。
   - `contextmenu`、`copy`、`cut`、`selectstart`、`mousedown`、`mouseup` における `preventDefault()` および `stopPropagation()` をインターセプトするため、`MAIN` ワールドで実行されます。
   - `MutationObserver` を介してインラインの `oncontextmenu="return false"` ハンドラーを除去します。
   - キャンセルされた貼り付けイベントを再注入する前にクリップボードの内容を検証することで、正当な Web アプリケーション（例: Telegram Web、Google Docs）を保護します。
3. **YouTube ホバープレビュー音声強制ミュートのオーバーライド (`youtubePreviewAudioHook.js`)**:
   - `ytd-video-preview #inline-preview-player` 上の `MAIN` ワールドで実行されます。
   - ホバー時に対象の `<video>` 要素の `HTMLMediaElement.prototype.muted` プロパティ記述子をオーバーライドします。
   - YouTube 内部の `volumechange` 強制ミュートの競合状態を排除し、ホバー中のループ再開時にもミュート解除状態の音声を維持します。
4. **YouTube Shorts フィードシーケンスナビゲーションフック (`youtubeShortsFeedHook.js`)**:
   - `ytd-shorts` 上の `MAIN` ワールドで実行されます。
   - 拡張機能の隔離されたワールドからは不可視である `shortsProcessedSequence` プロパティをインターセプトし、ページをリロードしたりフローティングウィンドウの状態を失ったりすることなく、`ytd-app` 上でネイティブの `yt-navigate` イベントをディスパッチします。
5. **無限スクロールキャンバスの保護**:
   - メモリ不足によるブラウザタブのクラッシュを防ぐため、全ページスクリーンショットの巡回を最大 60 セグメント (`MAX_FULL_PAGE_SEGMENTS`) および最大キャンバス高さ 30,000px (`MAX_FULL_PAGE_CANVAS_PX`) に制限します。
6. **Linux 画面カラーピッカースポイトフォールバック**:
   - Chromium の `window.EyeDropper` API を欠く Linux 環境で動作している場合、本拡張機能は `screen-color-picker.js` を挿入し、RGB/HEX/HSL 計算機能を備えた 9 倍拡大ピクセルレンズをレンダリングします。
7. **起動時セッションセトリング遅延**:
   - グループ割り当てを評価する前にセッションタブとウィンドウ状態を安定させるため、ブラウザ起動時にグループのプルーニング（整理）を 20 秒間遅延させます (`groupsHaveSettledAfterStartup()`)。
