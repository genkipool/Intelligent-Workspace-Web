# Intelligent Workspace

> Ang Intelligent Workspace ay isang advanced na Manifest V3 browser extension at produktibong workspace environment na binuo gamit ang Svelte, Vite, at CRXJS. Pinamamahalaan nito ang matalinong pagsasaayos ng tab, awtomatiko at nakabatay sa panuntunang clustering, autonomous na pagpapatakbo ng AI agent (sumusuporta sa Google Gemini Cloud API at Chrome Built-in Prompt API), in-page na Vim-style na link navigation, isang 41-prefix Omnibar command system, multi-format na pagtatala (rich text, mga checklist, Kanban, mga Mermaid diagram, mga KaTeX formula), high-fidelity na media capture at in-browser WASM OCR, Pomodoro timing na may zero-drift na mga alarma at offscreen audio playback, at Declarative Net Request (DNR) na pagsukat sa aktibidad sa web, mga limitasyon sa domain, at pag-block ng site.

## 1. Arkitektural na Pundasyon at Runtime Lifecycle

Tumatakbo ang extension sa ilalim ng arkitektura ng Manifest V3 ng Google Chrome, pinaghihiwalay ang mga persistent na proseso sa isang background Service Worker, mga sandboxed na panel ng UI, mga dokumento ng audio na offscreen, at mga in-page content script overlay:

1. **Pagsasaayos ng Manifest (`manifest.json`)**:
   - **Mga Pahintulot (21 aytem)**: `tabs`, `tabGroups`, `storage`, `favicon`, `contextMenus`, `notifications`, `sidePanel`, `scripting`, `downloads`, `downloads.open`, `system.display`, `declarativeNetRequestWithHostAccess`, `cookies`, `history`, `sessions`, `bookmarks`, `readingList`, `clipboardWrite`, `alarms`, `offscreen`, at `idle`.
   - **Mga Host Permission**: `["<all_urls>"]`.
   - **Service Worker**: `src/core/background.js` gamit ang magkakasabay (synchronous) na `importScripts` modular loading.
   - **Aksyon sa Toolbar**: Sadyang inalis ang `default_popup`. Ipinapatupad ng runtime ang `chrome.action.setPopup({ popup: '' })`, tinitiyak na ang `chrome.action.onClicked` ay mag-trigger nang synchronous at magbubukas ng `chrome.sidePanel` sa naka-pin na view ng user nang walang latency sa pagpapasimula ng popup.
   - **Keyword ng Omnibox**: Nakarehistrong keyword na `"find"`.
   - **Mga Command**: 24 na keyboard shortcut sa antas ng system na nakarehistro sa ilalim ng `commands`.
   - **Content Security Policy**: `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`.

2. **Seguridad ng Inter-Process Communication**:
   - Sinasala ng `src/core/background/messaging.js` ang mga mensahe mula sa mga content script laban sa isang tahasang whitelist (`ALLOWED_CONTENT_SCRIPT_ACTIONS`). Ang mga web frame na walang pribilehiyo ay hindi maaaring tumawag sa panloob na storage writers, arbitraryong Chrome APIs, o mga nagbabago ng panuntunan.

3. **Dalawahang Daigdig ng Pagpapatupad (Dual Execution Worlds)**:
   - Gumagana ang mga content script sa parehong `ISOLATED` (saklaw ng extension) at `MAIN` (saklaw ng pagpapatupad ng pahina) na mga daigdig. Ang mga script tulad ng `allowRightClickHook.js`, `videoPipHook.js`, `youtubePreviewAudioHook.js`, at `youtubeShortsFeedHook.js` ay tumatakbo sa `MAIN` upang humarang sa mga pamamaraan ng prototype, i-override ang mga property descriptor, at direktang mangasiwa ng mga custom na event.

## 2. Seksyon 1: Pamamahala ng mga Panuntunan (Gestionar Reglas)

Pinapagana nang awtomatiko ng subsystem ng Pamamahala ng mga Panuntunan ang pagpapangkat ng tab batay sa mahigpit at tiyak na pamantayan na tinukoy ng user.

### 2.1 Data Schema (`CustomRule`)
Ang bawat pasadyang panuntunan ay sumusunod sa sumusunod na interface:
```typescript
interface CustomRule {
  name: string;        // 1 to 16 characters. Must contain no whitespace characters.
  color: RuleColor;    // One of 9 colors: 'grey' | 'blue' | 'red' | 'yellow' | 'green' | 'pink' | 'purple' | 'cyan' | 'orange'
  urls: string[];      // Array of valid URLs, domains, or hostnames.
  active: boolean;     // Master toggle enabling or disabling rule evaluation.
  isStarred?: boolean; // Optional flag marking rule as a favorite for prioritized UI ordering.
}
```

### 2.2 Arkitektura ng Precedence
Kapag pinoproseso ang mga tab ng `groupTabs()` sa `src/core/background/groupManager.js`, sinusuri ang mga tab laban sa mga layer ng pagpapangkat sa mahigpit na pagkakasunod-sunod ng hirarkiya:
1. **Mga Pasadyang Panuntunan (`applyCustomRules`)**: Tumutugma sa mga aktibong pasadyang panuntunan sa pagkakasunud-sunod ng hitsura o priyoridad ng user. Kapag naipangkat na, ang mga tab ID ay nirerehistro sa `groupedTabIds` at ibinubukod mula sa mga susunod na layer.
2. **Mga Espesyal na Grupo ng System**: Ang mga URL ng system ay hinaharang at tinitipon sa nakalaang mga may-kulay na grupo:
   - `chrome://` at mga panloob na pahina ng browser
   - `file:///` mga lokal na file sa disk
   - `chrome-extension://` mga pahina ng extension
   - Mga IP Address at Localhost (`localhost`, `127.0.0.1`, `[::1]`, mga host ng IPv4/IPv6)
3. **Clustering ng Domain**: Ang mga tab na nagbabahagi ng parehong root domain ay pinapangkat kung ang bilang ng tab ay umaabot o lumalampas sa `domainThreshold` (default: 2 tab).
4. **Clustering ng Subdomain**: Kung pinagana, ang mga tab sa loob ng mga domain ay pinapangkat ayon sa mga partikular na subdomain (hal., `docs.github.com` laban sa `gist.github.com`).
5. **Sari-saring ("Misc") Grupo**: Ang mga natitirang hindi na-cluster na tab na hindi nakakatugon sa mga threshold ng pagpapangkat ay inilalagay sa grupong `Misc` (ang pagkakalagay ay maaaring i-configure: `start`, `end`, o paalpabeto `alpha`).

### 2.3 Pag-normalize ng URL at Semantika ng Pagtutugma
Ang matching engine (`matchesRule(tabUrl, ruleUrl)` sa `src/core/background/utils.js`) ay nagpapatupad ng mahigpit na pag-normalize:
- **Agnostiko sa Scheme**: Ang mga protocol ng HTTP at HTTPS ay itinuturing na mapagpapalit (`http://example.com` ay tumutugma sa `https://example.com`). Ang mga protocol na hindi web (`file://`, `chrome://`) ay nangangailangan ng eksaktong tugma ng scheme.
- **Pag-normalize ng Host**: Inaalis ang mga unahang prefix na `www.` (ang `www.github.com` ay nagiging `github.com`). Ang mga hostname ay ginagawang lowercase at sumusuporta sa mga internationalized domain name (mga IDN) sa pamamagitan ng punycode.
- **Sensitibo sa Port**: Kung ang isang panuntunan ay tumutukoy ng port (hal., `localhost:3000`), dapat tumugma ang tab sa eksaktong port na iyon.
- **Pagtutugma ng Path**: Inaalis ang mga trailing slash. Kung ang isang panuntunan ay tumutukoy ng path (hal., `example.com/docs`), tumutugma ito sa mga tab na may eksaktong path na iyon O mga subpath (`example.com/docs/api`), ngunit hindi tumutugma sa mga katabing path (`example.com/blog`).
- **Pagtutugma ng Query at Hash**: Kung ang isang panuntunan ay tahasang naglalaman ng query string (`?page=1`) o hash (`#section`), dapat tumugma ang tab sa mga parameter na iyon nang eksakto.
- **Proteksyon sa Numeric Dword (`ruleValidation.js`)**: Mahigpit na tinatanggihan ng validator ang mga purong numerong input (hal., `3242342424`) na itinuturing ng mga WHATWG URL parser bilang mga wastong IPv4 integer DWORD, na pumipigil sa hindi sinasadyang pagbaluktot ng pagpapangkat.

### 2.4 Detalye ng mga Setting sa Pamamahala ng Panuntunan
Ang Rules Manager ay nagbibigay ng komprehensibong hanay ng mga kontrol sa pag-uugali at mga setting:
- **Pagpili ng Routing ng Imbakan**: Maaaring iruta ng mga user ang imbakan ng panuntunan sa pagitan ng `chrome.storage.sync` (para sa naka-synchronize na mga setting sa lahat ng device na naka-sign in sa profile ng Google, napapailalim sa mga quota ng Chrome sync na 100 KB sa kabuuan at 8 KB bawat aytem) at `chrome.storage.local` (para sa walang limitasyong lokal na kapasidad na angkop para sa malalaking hanay ng panuntunan na naglalaman ng daan-daang pattern).
- **Pangunahing Switch ng Clustering at mga Threshold**:
  - `toggle-clustering`: Pangunahing shortcut sa keyboard at switch sa UI na nagpapagana o nagdi-disable sa awtomatikong clustering ng domain/subdomain nang hindi pinapatay ang mga panuntunang ginawa ng user.
  - `domainThreshold`: Minimum na bilang ng tab na kinakailangan mula sa parehong domain upang mag-trigger ng awtomatikong pangkat ng tab (default: 2 tab). Maaaring isaayos mula 1 hanggang 50.
  - `subdomainThreshold`: Minimum na bilang ng tab para sa mga subdomain bago gumawa ng hiwalay na mga cluster ng subgroup.
  - Switch ng Subdomain (`toggle-subdomain-grouping`): Nagbubukod sa mga independiyenteng subdomain (hal., `news.ycombinator.com` laban sa `ycombinator.com`).
- **Awtomatikong Pag-uri-uri ng mga Grupo nang Paalpabeto (`toggle-sort-alpha`)**: Real-time na sorting engine na nagpapatupad ng paalpabetong pagkakasunod-sunod sa lahat ng bukas na pangkat ng tab sa tab strip ng browser (`Ctrl+Shift+S` / `Cmd+Shift+S`).
- **Visual Status Prefixes (`toggle-prefixes`)**: Mga emoji marker na dinamikong inilalagay sa unahan ng mga pamagat ng grupo upang ipahiwatig ang katayuan ng pag-inspeksyon:
  - `🔒` (Kandado): Naglalaman ang grupo ng mga hindi pa nabibisita at hindi pa nababasang tab.
  - `🔍` (Lente): Naglalaman ang grupo ng mga bahagyang nabisitang tab.
  - `🗝️` (Bukas na Susi): Ang lahat ng tab sa grupo ay nabuksan at nasuri na.
  - `⚠️` (Babala): May natukoy na banggaan ng dobleng pangalan ng grupo sa ibang window group.
- **Awtomatikong Pag-collapse ng mga Idle na Grupo (`toggle-collapse-timer`)**: Awtomatikong nagko-collapse ng mga grupo kapag hindi aktibo upang mapanatiling maayos ang tab strip.
- **Pangunahing Pag-pause ng Pagpapangkat (`feature_pauseGrouping`)**: Pangunahing switch ng pag-freeze na pansamantalang sinuspinde ang lahat ng awtomatikong operasyon ng pagpapangkat (parehong pagtutugma ng panuntunan at heuristic clustering) sa mga aktibong sesyon ng pagsasaliksik kung saan ang mga tab ay dapat manatili sa sariling pagkakaayos ng user.
- **Pagpapangkat ng Isang Tab (`featureSingleTabGrouping`)**: Nagbibigay-daan sa mga pasadyang panuntunan na agad na gumawa ng pangkat ng tab para sa isang tumutugmang tab, nilalampasan ang kinakailangang threshold ng maraming tab.
- **Compact View (`toggle-compact-mode`)**: Pinaliit ang lapad ng header ng tab sa tab strip ng browser sa pamamagitan ng pag-render lamang ng mga single-letter badge para sa mga pamagat ng grupo.
- **Priyoridad sa pamamagitan ng Drag-and-Drop**: Ang muling pagsasaayos ng mga panuntunan sa listahan ng `Rules.svelte` ay agad na nagbabago sa kanilang precedence ng pagsusuri. Ang mga panuntunan sa itaas ay unang sinusuri.
- **Fuzzy Search**: Live na pag-filter sa Rules Manager at Omnibar na nagbibigay-daan sa agarang paghahanap ng mga panuntunan ayon sa pamagat o tumutugmang mga pattern ng URL.
- **Pag-import / Pag-export ng JSON**:
  - Mode `add`: Pinagsasama ang mga na-import na panuntunan sa kasalukuyang koleksyon, inaalis ang mga duplicate.
  - Mode `overwrite`: Ganap na pinapalitan ang aktibong koleksyon ng panuntunan ng na-import na payload pagkatapos ng pagpapatunay ng schema.
- **Dinamikong Paggawa ng Panuntunan**: Isang-click na paggawa ng mga pasadyang panuntunan nang direkta mula sa mga folder ng bookmark ng Chrome o mga koleksyon ng domain ng subgroup.
- **Deduplication ng Panuntunan (`feature_v100_dedup_add_to_rule`)**: Awtomatikong inaalis ang mga duplicate na pattern ng URL kapag nagdaragdag ng mga URL o domain sa mga kasalukuyang pasadyang panuntunan, na pumipigil sa paglobo ng panuntunan at paulit-ulit na pagsusuri.

### 2.5 Mga Operasyon at Persistence (`mutateRulesAndSync`)
- **Sentralisadong Mutator**: Ang lahat ng pagbabago sa panuntunan ay dumadaan sa `mutateRulesAndSync(mutateFn, sendResponse)` sa `src/core/background/handlers/rules.js`. Tinitiyak nito ang pag-synchronize ng imbakan, pag-refresh ng in-memory cache (`extensionSettings.customRules`), abiso sa UI (`rulesUpdated`), at awtomatikong muling pagpapangkat ng tab (`groupTabs()`).
- **Live na Pagpapatunay**: Ang real-time na pagpapatunay ay sumusuri sa pagiging natatangi ng pangalan, haba (1-16 na character), mga paghihigpit sa character, at wastong syntax ng URL bago i-save.

### 2.6 Mga Paraan ng Pagtawag (Invocation Modalities)
- **Pahina ng Rules Manager (`Rules.svelte`)**: Maa-access sa full-tab view o side panel (`?view=rules` / `pg`). Nagbibigay ng kumpletong drag-and-drop na muling pagsasaayos, inline color picker, mga chip ng tag ng URL, at mga switch ng panuntunan.
- **Mga Command ng Omnibar**:
  - `rl:` — Maghanap ng mga panuntunan at buksan ang mga nauugnay na URL.
  - `cr: <name> [, url1, url2]` — Direktang gumawa ng bagong panuntunan mula sa command bar.
  - `atcr:` — Idagdag ang domain o URL ng aktibong tab sa isang umiiral na panuntunan.
  - `atr:` — Idagdag ang mga napiling bukas na tab o manu-manong URL sa isang umiiral na panuntunan.
  - `ccr:` — Baguhin ang kulay ng isang pasadyang panuntunan.

## 3. Seksyon 2: Paglista ng Grupo at mga Operasyon (Listar Grupos)

Ang view ng Paglista ng Grupo ay nagbibigay ng interactive na workspace para sa pag-inspeksyon, pagmamanipula, at muling pagsasaayos ng mga pangkat ng tab at indibidwal na mga tab sa browser.

Nako-configure mula 0 hanggang 1440 minuto.
- **Inline na Pagpapalit ng Pangalan at Grace Period**:
  - Maaaring palitan ng mga user ang pangalan ng mga grupo nang direkta sa tab strip ng browser o sa UI.

  - Ang mga zero-width space (`\u200B`, `\u200C`, `\u200D`, `\u2060`, `\uFEFF`) ay inaalis sa panahon ng pagsusuri.

- **Mga Visual na Indicator ng Prefix ng Grupo**:

  - **Pag-export at Pag-import ng JSON**: Buong pag-export at pag-import ng backup sa JSON para sa tuluy-tuloy na paglipat sa pagitan ng mga makina at pangmatagalang offline na pag-archive.

## 4. Seksyon 3: Pag-navigate at Pamamahala ng Tab (Navegación)

Ang pinabilis na pag-navigate sa keyboard at mga kontrol sa workspace ay nagbibigay-daan sa maayos na pagkontrol ng maraming tab nang hindi gumagamit ng mouse.

### 4.1 Kumpas ng Mabilisang Paglipat ng Tab (Fast Tab Jump)
- **Syntax ng Kumpas**: `Alt + [groupPrefix] + [tabIndex] + Enter`
- **Pagpapatupad**:
  - Pindutin nang matagal ang `Alt` at i-type ang pangalan o mga titik ng prefix ng grupo, na sinusundan ng nais na 1-based na index ng tab, pagkatapos ay pindutin ang `Enter`.
  - Halimbawa: Ang `Alt + git + 2 + Enter` ay direktang lilipat sa pangalawang tab sa grupong "GitHub".
  - Ang index na `0` ay nagsisilbing shortcut para sa *huling* tab sa grupo.
  - Ang pag-alis sa index ay lilipat sa *unang* tab sa grupo.
  - Ang mga accent ay awtomatikong inaayos (`deaccent`) at ang pagtutugma ay nagno-normalize ng mga diacritic.

### 4.2 Pag-usad, Pagpapalit, at mga Pindutan ng Lifecycle
- `s`: Agad na lumipat sa dating aktibong tab (`previousActiveTabId`).
- `h` / `l`: Umusad sa nakaraan / susunod na tab (o mag-scroll nang pahalang kung pinapayagan ng pahina).
- `H` / `L`: Mag-navigate pabalik / pasulong sa kasaysayan ng browser.
- `t`: Magbukas ng bagong blangkong tab.
- `x`: Isara ang kasalukuyang aktibong tab.
- `yt`: I-duplicate ang kasalukuyang tab.
- `r` / `R`: I-reload ang pahina / Piliting i-reload nang nilalampasan ang cache.
- `d` / `u`: Mag-scroll sa pinakaibaba / pinakataas ng pahina.
- `j` / `k`: Maayos na mag-scroll pababa / pataas (hakbang na 75px).
- `f`: Isaaktibo ang mga Vim link hint (lumilitaw ang mga titik sa ibabaw ng mga naki-click na elemento upang ma-click).
- `cf`: Isaaktibo ang mga Vim link hint upang kopyahin ang target na URL sa clipboard.

### Para sa mga advanced na user

Maaaring ilagay ng mga mas bihasang user ang browser sa full-screen mode at mag-navigate nang buo gamit ang keyboard, nang hindi gumagamit ng mouse.

#### Full-Screen Immersion at Pagba-browse nang Walang Mouse
- **I-toggle ang Full-Screen**: Pindutin ang `F11` (Windows/Linux) o `Command+Control+F` (macOS). Ang chrome ng browser, address bar, tab strip, at mga panel ng operating system ay itatago, na naglalaan ng 100% ng display sa nilalaman.
- **In-Page Vim Link Navigation (`f` / `cf`)**:
  - Pindutin ang `f` upang bumuo ng high-contrast na dalawang-titik na dilaw na link hint sa ibabaw ng bawat naki-click na elemento, button, input, at link sa DOM.
  - I-type ang dalawang titik na tumutugma sa iyong target upang gayahin ang direktang pag-click nang walang interaksyon ng mouse.
  - Pindutin ang `cf` upang i-trigger ang mga hint badge na kumukopya sa URL ng target na link nang direkta sa clipboard ng iyong system.
  - Pindutin ang `vp` upang magbukas ng in-page preview modal ng target na link.
  - Pindutin ang `Esc` anumang oras upang kanselahin ang mga link hint at bumalik sa normal na pag-scroll.
- **Mabilisang Paglipat at Pagpalit ng Tab**:
  - `Alt + [groupPrefix] + [tabIndex] + Enter`: Isagawa ang kumpas ng Mabilisang Paglipat ng Tab (hal., ang `Alt + dev + 1 + Enter` ay direktang lilipat sa unang tab sa grupong "Dev"; ang index na `0` ay pipili sa huling tab sa grupo).
  - `s`: Agad na magpalit sa pagitan ng kasalukuyang tab at ng dating aktibong tab (`previousActiveTabId`).
  - `h` / `l`: Sunod-sunod na humakbang sa nakaraan / susunod na tab sa tab strip.
  - `H` / `L`: Gumalaw pabalik / pasulong sa kasaysayan ng pag-navigate sa browser.
  - `t` / `x` / `yt`: Magbukas ng bagong tab (`t`), isara ang kasalukuyang tab (`x`), o i-duplicate ang tab (`yt`).
- **Floating Omnibar Command Subsystem (`o`)**:
  - Pindutin ang `o` sa anumang pahina upang ilabas ang nakagitnang overlay ng Omnibar.
  - Pindutin ang `@` upang ipakita ang interactive na direktoryo ng lahat ng 41 command prefix.
  - I-type ang `f: <query>` upang magsagawa ng malalimang full-text na paghahanap ng tab sa lahat ng bukas na window.
  - I-type ang `sp:` upang direktang iruta ang pag-navigate sa anumang view ng Sidepanel (`rules`, `listgroup`, `notes`, `gallery`, `gemini`, `activity`, `themes`, `hints`, `downloads`).
  - I-type ang `qai: <query>` o `qaia: <task>` upang mag-query sa Gemini o mag-utos sa autonomous browser agent nang hindi inaalis ang mga kamay sa keyboard.
  - I-type ang `ts:` upang paghiwalayin ang mga bukas na tab sa magkatabing split screen.
- **In-Page Navigation at Focus**:
  - `j` / `k`: Maayos na mag-scroll pababa / pataas (dagdag na 75px).
  - `d` / `u`: Kalahating pahinang pag-scroll pababa / pataas.
  - `i`: Agad na ilipat ang focus ng cursor sa pangunahing text input field sa pahina.
  - `ESC`: Alisin ang focus sa mga input at ibalik ang focus ng keyboard sa navigation mode.

### 4.9 Subsystem ng Text Snippets na may mga Template Variable
Ang subsystem ng Text Snippets (`SnippetManager` sa `src/utils/hint/snippets.js` at `src/utils/snippet-panel.js`) ay nagpapabilis sa pagta-type sa pamamagitan ng pagpapalawak ng mga shortcut ng teksto sa anumang input, textarea, o rich editor:
- **Mga Paraan ng Pag-trigger**: I-type ang shortcut na sinusundan ng Space, o i-type ang `$$` upang ilabas ang interactive na popup sa paghahanap ng mga snippet.
- **Pagsasama sa Clipboard API**: Sumusuporta sa naka-format na HTML at paglalagay ng plain text sa pamamagitan ng Clipboard API, na tinitiyak ang 100% pagiging tugma sa mga kumplikadong editor tulad ng Google Docs, Notion, at Slack.
- **Mga Variable ng Template**: Dinamikong nireresolba ang mga variable sa sandali ng pagpapalawak:
  - `{{date}}` / `date`: Naka-format na petsa ng lokalidad (`toLocaleDateString`).
  - `{{isodate}}` / `isodate`: Petsa ng ISO 8601 (`YYYY-MM-DD`).
  - `{{longdate}}` / `longdate`: Mahabang petsa na may araw ng linggo, araw, buwan, at taon.
  - `{{time}}` / `time`: 2-digit na naka-format na oras (`HH:MM`).
  - `{{datetime}}` / `datetime`: Pinagsamang petsa at oras.
  - `{{weekday}}` / `weekday`: Buong pangalan ng araw (hal., Lunes).
  - `{{day}}` / `day`: Araw ng buwan (1-31).
  - `{{month}}` / `month`: Buong pangalan ng buwan (hal., Oktubre).
  - `{{year}}` / `year`: Buong 4-digit na taon.
  - `{{tomorrow}}` / `tomorrow`: Petsa sa susunod na araw (+1 araw).
  - `{{yesterday}}` / `yesterday`: Petsa sa nakaraang araw (-1 araw).
  - `{{nextweek}}` / `nextweek`: Petsa 7 araw mula ngayon (+7 araw).
  - `{{timestamp}}` / `timestamp`: Epoch millisecond timestamp (`Date.now()`).
  - `{{url}}` / `url`: URL ng aktibong webpage (`window.location.href`).
  - `{{domain}}` / `domain`: Aktibong domain hostname (`window.location.hostname`).
  - `{{pagetitle}}` / `pagetitle`: Pamagat ng aktibong dokumento (`document.title`).
  - `{{uuid}}` / `uuid`: Cryptographically secure na natatanging identifier (`crypto.randomUUID()`).
  - `{{random}}` / `random`: Random na integer sa pagitan ng 1 at 1000.
  - `{{clipboard}}` / `clipboard`: Teksto sa clipboard buffer ng system.

### 4.10 Mga Naka-embed na Tool sa Produktibidad
- **Allow Right Click Hook (`allowRightClickHook.js`)**:
  - Iniksyon sa `MAIN` execution world upang i-neutralize ang mga mapanirang web script na nagdi-disable sa mga right-click context menu, pagkopya, pag-cut, o pagpili ng teksto.
  - Humaharang sa `preventDefault()` at `stopPropagation()` sa `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown`, at `mouseup`.
  - Nililinis ang mga inline na handler na `oncontextmenu="return false"` sa pamamagitan ng isang persistent na `MutationObserver`.
  - Sinusuri ang mga payload ng clipboard upang maiwasan ang pagkasira ng mga lehitimong web editor (Google Docs, Telegram Web).
- **Editor ng Cookie**: In-page modal na nag-iinspeksyon, nag-e-edit, gumagawa, at nagtatanggal ng mga HTTP at HTTPS cookie para sa aktibong domain.
- **Tagabuo ng QR Code**: Bumubuo ng SVG/Canvas QR code para sa URL ng aktibong tab para sa mabilisang paglipat sa mobile.
- **Malinis na Pag-export sa PDF Print**: Niruruta ang mga target na pahina sa pamamagitan ng `print.html` nang inalis ang mga header, patalastas, at ingay sa pag-navigate para sa malinis na pag-archive ng dokumento.

### 4.11 Komprehensibong 3-Tier na Pagtanggal ng Duplicate at Matalinong Pag-discard
- **Komprehensibong 3-Tier na Pagtanggal ng Duplicate**:
  1. **Deduplication ng Tab (`removeDuplicateTabsCommand`)**: Ini-scan ang mga bukas na tab sa mga window o nakatutok na grupo, tinutukoy ang mga duplicate na URL, ibinubukod ang mga `Split` screen tab, at isinasara ang mga paulit-ulit na tab habang pinapanatili ang aktibo o pinakalumang tab. Nagpapakita ng buod na abiso sa desktop.
  2. **Deduplication ng Bookmark**: Malalimang ini-scan ang mga puno ng bookmark ng Chrome, hinahanap ang magkakaparehong duplicate na URL sa mga folder, at nagbibigay ng batch consolidation upang mapanatiling malinis ang mga bookmark.
  3. **Deduplication ng Panuntunan (`feature_v100_dedup_add_to_rule`)**: Awtomatikong inaalis ang mga duplicate na pattern ng URL kapag nagdaragdag ng mga URL sa mga kasalukuyang pasadyang panuntunan sa pagpapangkat, na pumipigil sa paglobo ng panuntunan.
- **Matalinong Pag-discard sa Memory (`suspendInactiveTabsIntelligently`)**:
  - Sinusuri bawat 1 minuto sa pamamagitan ng alarm na `itg-periodic-tasks`.
  - Nagdi-discard ng mga tab na hindi aktibo nang >= `discardingTimeMinutes` (default: 60 minuto).
  - May mga built-in na proteksyon sa resistensya: Hindi kailanman nagdi-discard ng mga aktibong tab, mga tab na nagpe-play ng audio, mga naka-pin na tab, o mga nasuspinde nang tab.

## 5. Seksyon 4: AI Assistant at Autonomous Agent (Asistente AI)

Isinasama ng AI Assistant ang malalaking language model sa browser upang magbigay ng pag-unawa sa konteksto, mga awtomatikong daloy ng trabaho, at direktang automation ng browser.

### 5.1 Arkitektura ng Dual Model Engine
1. **Google Gemini Cloud API (`gemini-api.js`)**:
   - Sumasama sa mga Google Generative Language REST endpoint (`v1beta/models/{model}:generateContent` at `:streamGenerateContent`).
   - Sumusuporta sa Gemini 2.5 Flash, Gemini 2.5 Pro, at mga pasadyang endpoint ng modelo.
   - **Multi-Key Rotation**: Namamahala ng mga pool ng key sa `geminiApiKeysList`. Ang obfuscation ng imbakan ay gumagamit ng mga prefix na `enc_`.
   - **Exponential Backoff**: Nangangasiwa sa pagkaubos ng quota ng HTTP 429 gamit ang awtomatikong retry ng backoff (1.5s -> 3s -> 6s).
   - **Search Grounding**: Pinapagana ang Google Search Grounding (`google_search: {}`). Kung maganap ang HTTP 403 dahil sa mga paghihigpit sa quota sa mga tool sa paghahanap, awtomatiko itong sumusubok muli nang walang grounding.
2. **Chrome Built-in AI / Prompt API (`localAiService.js`)**:
   - Pagsasama ng on-device Gemini Nano sa pamamagitan ng `window.LanguageModel`.
   - Sumusuporta sa zero-network na lokal na pagpapatupad. May kasamang pagsusuri sa availability ng modelo at live na pagsubaybay sa progreso ng pag-download.

### 5.2 Autonomous Browser Agent (`agent-backend.js`)
Ang autonomous agent ay nagbibigay ng buong kontrol sa browser sa pamamagitan ng 40+ structured tool:
- **Kontrol sa Tab at Grupo**: `getOpenTabs`, `switchToTab`, `createNewTab`, `closeTab`, `closeTabs`, `duplicateTab`, `findAndSwitchToTab`, `groupTabs`, `ungroupTabs`, `deleteTabGroup`, `collapseTabGroup`, `expandTabGroup`, `collapseAllGroups`, `expandAllGroups`, `setGroupColor`, `renameTabGroup`, `regroupAllTabs`, `removeDuplicateTabs`, `closeTabsWithSound`.
- **Pag-navigate at Paghahanap**: `openUrl`, `searchGoogle`, `getActiveTab`, `getActiveTabContent`.
- **Kaalaman at mga Bookmark**: `getBookmarks`, `searchBookmarks`, `createBookmark`, `getHistory`, `getRecentlyClosed`.
- **Mga Panuntunan at Hitsura**: `getRules`, `createRule`, `updateRule`, `deleteRule`, `getActiveTheme`, `getSavedThemes`, `applyTheme`.

### 5.3 Taint Tracking at Depensa sa Prompt Injection
Upang i-neutralize ang mga hindi direktang pag-atake ng prompt injection mula sa mga hindi pinagkakatiwalaang webpage, ang backend ng agent ay nagpapatupad ng mahigpit na taint tracking:
- **Pagmamarka ng Taint**: Ang pagtawag sa `getActiveTabContent` ay kumukuha ng teksto mula sa isang webpage at minamarkahan ang kasalukuyang pagtakbo ng pagpapatupad bilang tainted (`taintedAgentRuns.add(runId)`).
- **Bantay sa Egress**: Ang mga tainted na pagtakbo ay mahigpit na pinagbabawalan sa pagtawag ng mga egress tool (`AGENT_EGRESS_TOOLS`):
  * `openUrl`, `searchGoogle`, `createBookmark`, `createRule`, `addUrlToRule`, `createSiteShortcut`, `updateSiteShortcut`, `updateRule`.
- **Mekanismo ng Pagtanggi**: Sa halip na magtapon ng unhandled exception, ang engine ay nagbabalik ng isang structured na paliwanag sa seguridad. Pagkatapos ay ipinapaalam ng LLM sa user na ang panlabas na data ay hindi maaaring ilabas nang walang tahasang pahintulot ng user.

### 5.4 Subsystem ng Nakaiskedyul na mga Query sa Gemini (`GeminiScheduleModal.svelte`)
- **Engine ng Pagpapatupad sa Background**:
  - Ginagawang awtomatiko ang nakaiskedyul na pagpapatupad ng AI prompt nang direkta sa loob ng background service worker sa pamamagitan ng `chrome.alarms` (`gemini-scheduled-*`).
  - Sumusuporta sa hanggang 6 na nakaiskedyul na query bawat araw (`MAX_TIMES = 6`).
  - **Mga Mode ng Iskedyul**:
    - Paulit-ulit na Iskedyul: Paulit-ulit na tumatakbo sa mga napiling araw ng linggo (`selectedDays`).
    - Isahang Iskedyul: Tumatakbo sa isang partikular na target na petsa at oras (`formDate`).
  - **Mga Limitasyon sa Prompt**: Nagpapatupad ng mahigpit na 1,000-character na limitasyon sa prompt (`MAX_QUERY_CHARS = 1000`) na may mga real-time na counter ng character.
  - **Mga Abiso sa Background**: Nagpapadala ng abiso sa desktop na may snippet preview kapag natapos ang background query. Ang pag-click sa abiso ay agad na nagbubukas ng thread ng tugon sa loob ng chat sa sidepanel.

### 5.5 Pamamahala at Pag-export ng Pag-uusap sa Gemini

## 6. Seksyon 5: View ng Tala at Pamamahala ng Kaalaman (Ver Notas)

interface NoteRecord {

## 7. Seksyon 6: Media at Gallery View (Ver Galería)

Isang high-performance na pipeline para sa pagkuha ng media, anotasyon, at optical character recognition (OCR).

### 7.1 Mga Capture Mode at Inhenyeriya (Lahat ng 7 Uri ng Capture)
Ang extension ay nagpapatupad ng 7 espesyal na paraan ng pagkuha na sumasaklaw sa single-tab, cross-tab, na-crop, at mga operasyon sa palette:
1. **`visible` (Visible Viewport Capture - `cs`)**:
   - Kinukuha ang eksaktong nakikitang viewport ng aktibong tab gamit ang `chrome.tabs.captureVisibleTab`.

2. **`fullPage` (Seamless Full-Page Scrolling Canvas - `cp`)**:

3. **`fullPageParts` (Sequential Sliced Segments - `cpp` / `cP`)**:
   - Hinihiwa ang matataas na dokumento sa magkakasunod, indibidwal na mga bahagi ng imahe na kasingtaas ng viewport (`captureFullPageParts`), bumubuo ng hanggang 60 may bilang na piraso ng imahe para sa pagination.
4. **`area` (Interactive Rectangular Drag Crop - `ca`)**:

   - May mga nahihilang handle ng seleksyon, tooltip ng sukat, trigger ng kumpirmasyon, pagkansela gamit ang `Esc` key, at pagpipila ng pag-crop sa maraming tab (`handleCaptureAreaFromShortcut`).
5. **`groupTabs` (Batch Active Group Tab Walk - `Cs`, `Cp`, `CP`)**:
   - Sunod-sunod na nag-iiterate sa bawat tab sa loob ng aktibong pangkat ng tab (`handleCaptureGroupFromShortcut`).

6. **`omnibarPickedTabs` (Pasadyang Pagkuha ng Nakapilang Maraming Tab)**:
   - Sinisimulan sa pamamagitan ng mga command ng Omnibar na `cs:`, `cp:`, `cpp:`, o `ca:` (`handleCaptureTabs`).
   - Nagsasagawa ng magkakasunod na pagkuha sa lahat ng tab na sinala ng user, nagbibigay ng mga real-time na indicator ng progreso.
7. **`colorPickerCapture` (Fallback sa Eyedropper ng Background Screen)**:
   - Kumukuha ng screenshot sa background upang paganahin ang tool na pampalaki ng eyedropper para sa eksaktong hex sa mga operating system na walang katutubong suporta sa `window.EyeDropper` (hal., Linux).

### 7.2 Gallery UI at Persistence

## 8. Seksyon 7: Pomodoro at Suite ng Pagsukat ng Oras (Pomodoro)

Isang focus at timing suite na idinisenyo para sa ganap na katumpakan sa mga sleep cycle ng browser.

### 8.1 Timing Engine at Arkitektura sa Background
- **Zero-Drift Timestamp Math**: Ang estado ay naka-persist sa `chrome.storage.local` na may ganap na mga Unix timestamp (`startTime`, `pausedAt`). Ang mga paghinto ng service worker, pag-restart ng browser, at mga estado ng pagtulog ng operating system ay nagdudulot ng zero clock drift.
- **Dispatcher ng Alarma**:
  - High-resolution countdown ticker na pinapatakbo ng `chrome.alarms` (`pomodoroTick` 1s agwat).
  - Pagpapanatili sa background at pangmatagalang pagsusuri ng agwat na pinamamahalaan ng `itg-periodic-tasks` (1 minutong agwat).
- **Mga Tunog ng Audio sa Offscreen (`offscreen.html`)**: Ang mga tunog ng audio ay nabubuo sa pamamagitan ng isang nakalaang Chrome Offscreen document na ginawa nang may dahilang `AUDIO_PLAYBACK`. Awtomatiko itong nagsasara 3.5 segundo pagkatapos matapos ang tunog upang makatipid sa memory.

### 8.2 Kumpletong 4 na Timing Mode
1. **Pomodoro (`pomodoro`)**:
   - Tagal ng trabaho: 1 hanggang 180 minuto (default: 25 min).
   - Maikling pahinga: 1 hanggang 120 minuto (default: 5 min).
   - Mahabang pahinga: 1 hanggang 180 minuto (default: 15 min).
   - Mga cycle bago ang mahabang pahinga: 1 hanggang 12 cycle (default: 4).
   - Target na layunin ng cycle: 1 hanggang 99 na cycle (default: 8).
   - Nako-configure ang awtomatikong pagsisimula ng trabaho, awtomatikong pagsisimula ng pahinga, at mga abiso ng alarma.
2. **Stopwatch (`cronometro`)**: Progresibong timer na may pagtatala ng lap at kakayahang pause-as-stop.
3. **Countdown (`temporizador`)**: Pasadyang countdown timer na tumutukoy ng mga oras, minuto, at segundo.
4. **Alarma sa Target na Oras (`tiempo`)**: Calendar date picker at tagapili ng orasan na nagtatakda ng alarma para sa isang eksaktong timestamp sa hinaharap.

### 8.3 In-Page Floating Timer Widget
- Nahihila at minimal na overlay na nagpapakita ng real-time countdown, pag-pause/pagpapatuloy, at mga button ng paglaktaw nang direkta sa mga webpage.
- Nagbibigay-daan sa pagsubaybay sa mga sesyon ng pagtuon nang hindi lumilipat pabalik sa panel ng extension o popup.

### 8.4 Auto-Collapse Idle Timer ng Grupo
- Gumagana kasabay ng mga gawain sa pagtuon upang awtomatikong i-collapse ang mga hindi aktibong grupo pagkatapos ng 1 minuto ng kawalan ng aktibidad (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`) at ang aktibong grupo pagkatapos ng 15 minuto ng kawalan ng aktibidad (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`). Nako-configure mula 0 hanggang 1440 minuto.

### 8.5 Pag-tag ng Proyekto at Metadata
Ang bawat sesyon ay sumusuporta sa metadata ng pagkakategorya:
- Pangalan ng Proyekto (hanggang 18 character)
- Tag ng Proyekto (hal., `#research`, `#dev`)
- Folder ng Proyekto (hal., `/client/project`)

### 8.6 Analytics Engine at 19 na KPI Card
Ang buong dashboard (`dashboard.html` o Sidepanel `dashboard.html?context=sidepanel`) ay nagkakalkula ng 19 na key performance indicator mula sa mga na-deduplicate na sesyon (`dedupeSessions` ayon sa `sessionStarted`):

2. `sessions`: Kabuuang nakumpletong sesyon.
3. `cycles`: Kabuuang nakumpletong cycle ng trabaho.

13. `distractionRate`: Mga pagkaantala bawat oras ng pagtuon.
14. `bestDay`: Pinakaproduktibong araw ng linggo.

16. `projects`: Bilang ng mga natatanging proyektong nasubaybayan.
17. `avgIntDuration`: Karaniwang tagal ng bawat pagkaantala.
18. `topProject`: Proyekto na may pinakamataas na naipong oras ng pagtuon.
19. `focusIntensity`: Karaniwang oras ng pagtuon bawat aktibong araw.

## 9. Seksyon 8: Panel ng Aktibidad at Kasaysayan (Panel de Actividad)

Isang tracking, analytics, at web governance engine gamit ang Declarative Net Request (DNR).

### 9.1 Data Engine at Topolohiya ng Imbakan (`ITG_WEB_ACTIVITY`)
Pinamamahalaan sa ilalim ng `ITG_WEB_ACTIVITY`:
- `wa:day:YYYY-MM-DD`: Mga counter ng domain bawat araw (`{ domains: { host: { t: seconds, v: visits, s: sessions, h: { hour: seconds } } } }`).
- `wa:days`: Master index array ng mga naitalang key ng petsa.
- `wa:recent`: Ring buffer na nag-iimbak ng pinakabagong 400 entry sa timeline ng pagbisita.
- `wa:openSegment`: Aktibong timed segment sa `chrome.storage.session`, nilimitahan sa `WA_MAX_SEGMENT_SECONDS = 900s` (15 minuto) upang maiwasang mabaluktot ang mga istatistika kung matulog ang makina nang hindi nagti-trigger ng mga idle event.
- **Pagtukoy sa Kawalan ng Aktibidad (Idle Detection)**: Gumagamit ng `chrome.idle` (default: 300s / 5m). Pinapanatili ng pag-playback ng audio ang aktibong pagsubaybay kahit na hindi nakatutok ang mga window kung ang `countAudible = true`.
- **Pagpapanatili (Retention)**: Awtomatikong pinuputol ang mga tala ng araw na mas luma sa `retentionDays` (default: 180 araw).

### 9.2 Declarative Net Request (DNR) Site Blocker
- **Dinamikong Paglalaan ng Panuntunan**: Naglalaan ng mga dinamikong panuntunan sa hanay ng ID na `9000` hanggang `9999`.
- **Target ng Pag-redirect**: Ang mga na-block na kahilingan ay nagre-redirect sa `src/ui/pages/web-activity/blocked.html?d=<domain>&u=\1`.
- **Pagsusuri sa mga Bukas na Tab**: Kapag nag-expire ang limitasyon ng site, agad na sinusuri at inililipat ng background worker ang mga umiiral nang bukas na tab na tumutugma sa domain.
- **Pagsaklaw sa Magdamag na Iskedyul**: Ang mga iskedyul na lumalagpas sa hatinggabi (hal., `22:00` hanggang `02:00`) ay awtomatikong sinusuri sa mga hangganan ng araw.
- **Palugit / Panahon ng Pag-snooze (+5 min)**: Ang screen ng block ay nagbibigay-daan sa pansamantalang 5 minutong snooze pass, na sinusubaybayan sa `wa:snoozeUses`.

### 9.3 Asymmetric Security Lock (`blockLock.js`)
Maaaring protektahan ang mga limitasyon sa site gamit ang isang asymmetric na password lock:
- **Imbakan ng Hash**: Nag-iimbak ng random na 16-byte salt at SHA-256 hex digest (`wa:settings.blockPassword`).
- **Patakaran sa Asymmetric na Panuntunan**: Ang password ay **hindi kailanman hinihingi** kapag gumagawa ng mga bagong limitasyon o ginagawang mas mahigpit ang mga panuntunan (hal., pagbabawas ng mga allowance sa oras o pagdaragdag ng mga paghihigpit sa iskedyul).
- **Mga Binabantayang Aksyon**: Hinihingi lamang ang password kapag **nagpapaluwag ng mga panuntunan** (pagbura ng limitasyon, pagpapataas ng mga allowance sa oras, o pag-disable ng mga iskedyul) o kapag gumagamit ng snooze pagkatapos lumampas sa pang-araw-araw na libreng threshold (`snoozePasswordAfter`).

## 11. Mga Schema ng Imbakan at Persistence ng Data

Gumagamit ang extension ng multi-tier na modelo ng imbakan sa IndexedDB at Chrome Storage APIs:

### 11.1 IndexedDB Database: `Intelligent_Workspace` (Schema Version 8)
1. `screenshots`: keyPath: `'id'`, autoIncrement: true. Pangalawang index: `'createdAt'`. Naglalaman ng mga binary screenshot, canvas data URL, persistent flag, mga sukat, at mga index ng kabuuan ng segment.
2. `geminiConversations`: keyPath: `'id'`, autoIncrement: true. 0 pangalawang index (kinukuha/pinamamahalaan ayon sa ID). Nag-iimbak ng mga multi-turn chat thread, role ng mensahe, sukatan ng token, at metadata ng search grounding.
3. `notesStore`: keyPath: `'id'`, autoIncrement: false. 0 pangalawang index (sinasala sa memory ayon sa contextKey). Nag-iimbak ng rich text, mga checklist array, mga card ng Kanban board, mga detalye ng Mermaid, at mga KaTeX formula.
4. `backupsGroups`: keyPath: `'group.id'`. 0 pangalawang index (nag-iimbak ng mga backup group object na naka-key ayon sa nested `'group.id'`). Nag-iimbak ng mga compressed group structure, kulay, pamagat, at mga talaan ng isinarang tab.
5. `pomodoroStats`: keyPath: `'id'`, autoIncrement: true. Mga pangalawang index: `'projectName'` (keyPath `'projectName'`) at `'savedAt'` (keyPath `'savedAt'`) (walang index ng `date`). Naglalaman ng focus analytics, mga sukatan ng cycle, at mga log ng pagkaantala.

### 11.2 Chrome Storage Dual-Routing (`StorageService`)
- Dinamikong niruruta ang mga pagbasa at pagsusulat sa pagitan ng `chrome.storage.sync` (para sa mga portable na setting sa mga device ng user) at `chrome.storage.local` (para sa mabibigat na kagustuhan).
- Mga pangunahing modelo:
  - `customRules`: Array ng mga kahulugan ng panuntunan (`[{ name, color, active, urls }]`).
  - `clusterConfig`: Mga parameter ng auto-clustering (mga threshold, compact mode, mga espesyal na kategorya).
  - `userPrefixes`: Mga pagtatalaga ng emoji prefix (`{ lock, openKey, loupe, checked, warning }`).
  - `activeTheme`, `savedThemes`, & `themeSchedules`: Mga pagsasaayos ng kulay sa 9-palette at mga panuntunan ng nakaiskedyul na pag-ikot na isinaayos sa pamamagitan ng `ThemeScheduleModal.svelte`.
  - `pomodoroState`: Real-time na mga timestamp ng sesyon, tagal ng pagka-pause, at mga layunin ng cycle.
  - `wa:settings` & `wa:limits`: Mga kagustuhan sa pagsubaybay sa aktibidad sa web, mga limitasyon sa site, at mga window ng iskedyul.
  - `youtubeLoopEnabled`: Boolean flag na kumokontrol sa mga button ng loop sa YouTube at Shorts.

### 11.3 Chrome Storage Session (`chrome.storage.session`)
Ginagamit para sa napakabilis at panandaliang runtime coordination:
- `tabsEverActive`: Set ng mga tab ID na na-activate sa kasalukuyang sesyon ng browser.
- `groupExpandedEver`: Talaan ng mga grupong pinalawak sa kasalukuyang sesyon.
- `groupInfoMap`: Real-time na registry na nagmamapa ng mga group ID sa mga dinamikong pamagat at uri ng clustering.
- `splitScreenState`: Naka-cache na mga hangganan ng window para sa pagpapanumbalik ng orihinal na sukat ng screen.
- `contextMenusSignature`: Hash signature na pumipigil sa paulit-ulit na pagbuo ng context menu sa panahon ng mabilisang pagpapalit ng tab.
- `wa:openSegment`: Kasalukuyang aktibong time segment ng website.
- `hiddenYoutubeView`: Sanggunian sa naka-park na view ng YouTube player na nakadaong sa `HiddenGroupsBar.svelte`.

## 12. Depensibong Inhenyeriya at Pangangasiwa sa mga Edge Case

1. **Pag-unblock ng Header ng Declarative Net Request (`dnr.js`)**:
   - Binabago ang mga header ng tugon sa pamamagitan ng mga dinamikong panuntunan ng DNR upang alisin ang `X-Frame-Options` at mahigpit na mga `Content-Security-Policy` header, na nagpapahintulot sa mga panlabas na site na mag-render sa Side Panel at Picture-in-Picture iframe.
   - **Kaligtasan sa WhatsApp Web**: Tahasang pinapanatili ang `Cross-Origin-Opener-Policy` (COOP) at `Cross-Origin-Embedder-Policy` (COEP) sa `web.whatsapp.com` upang maiwasan ang pagkasira ng WebAssembly Signal cryptographic implementation nito.
2. **Tagapagtanggal ng Harang sa Right-Click at Seleksyon (`allowRightClickHook.js`)**:
   - Tinatalo ang mga mapanirang website na humaharang sa pagkopya, pag-paste, context menu, at pagpili ng teksto.
   - Tumatakbo sa `MAIN` world upang humarang sa `preventDefault()` at `stopPropagation()` sa `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown`, at `mouseup`.
   - Inaalis ang mga inline na handler na `oncontextmenu="return false"` sa pamamagitan ng `MutationObserver`.
   - Pinoprotektahan ang mga lehitimong web application (hal., Telegram Web, Google Docs) sa pamamagitan ng pagsusuri sa nilalaman ng clipboard bago muling i-inject ang mga nakanselang paste event.
3. **Pag-override sa Sapilitang Pag-mute ng Preview Audio sa Pag-hover sa YouTube (`youtubePreviewAudioHook.js`)**:
   - Tumatakbo sa `MAIN` world sa `ytd-video-preview #inline-preview-player`.
   - Ini-override ang `HTMLMediaElement.prototype.muted` property descriptor sa target na elementong `<video>` kapag nag-hover.
   - Inaalis ang panloob na race condition ng sapilitang pag-mute sa `volumechange` ng YouTube, pinapanatili ang naka-unmute na audio sa lahat ng pag-restart ng loop habang nagho-hover.
4. **Hook sa Pag-navigate ng Sequence sa Feed ng YouTube Shorts (`youtubeShortsFeedHook.js`)**:
   - Tumatakbo sa `MAIN` world sa `ytd-shorts`.
   - Humaharang sa property na `shortsProcessedSequence`, na hindi nakikita mula sa isolated world ng extension, at nagpapadala ng mga katutubong `yt-navigate` event sa `ytd-app` nang hindi muling nilo-load ang pahina o nawawala ang estado ng lumulutang na window.
5. **Proteksyon sa Canvas ng Infinite-Scroll**:
   - Nililimitahan ang mga full-page screenshot walk sa 60 segment (`MAX_FULL_PAGE_SEGMENTS`) at 30,000px na maximum taas ng canvas (`MAX_FULL_PAGE_CANVAS_PX`), iniiwasan ang pag-crash ng tab ng browser dahil sa pagkaubos ng memory.
6. **Fallback sa Eyedropper ng Screen Color Picker sa Linux**:
   - Kapag tumatakbo sa mga Linux environment na walang Chromium `window.EyeDropper` API, nag-i-inject ang extension ng `screen-color-picker.js`, nagre-render ng 9x magnified pixel lens na may kalkulasyon ng RGB/HEX/HSL.
7. **Pagkaantala sa Pag-aayos ng Sesyon sa Pagsisimula (Startup Session Settling Delay)**:
   - Inaantala ang paglilinis ng grupo nang 20 segundo (`groupsHaveSettledAfterStartup()`) sa paglunsad ng browser upang bigyang-daan ang mga tab ng sesyon at estado ng window na maayos bago suriin ang mga pagtatalaga ng grupo.
