# Intelligent Workspace

> Intelligent Workspace — это продвинутое браузерное расширение на базе Manifest V3 и продуктивная рабочая среда, разработанная с использованием Svelte, Vite и CRXJS. Оно обеспечивает интеллектуальную организацию вкладок, автоматическую кластеризацию и группировку по правилам, выполнение автономных AI-агентов (с поддержкой Google Gemini Cloud API и встроенного Chrome Prompt API), навигацию по ссылкам внутри страницы в стиле Vim, систему команд Omnibar с 41 префиксом, ведение заметок в различных форматах (форматированный текст, чек-листы, Kanban, диаграммы Mermaid, формулы KaTeX), захват медиа высокой четкости со встроенным распознаванием текста WASM OCR, таймер Pomodoro с оповещениями с нулевым дрейфом времени и воспроизведением звука в offscreen-режиме, а также измерение веб-активности, ограничение доменов и блокировку сайтов с помощью Declarative Net Request (DNR).

## 1. Архитектурный фундамент и жизненный цикл среды выполнения

Расширение функционирует в рамках архитектуры Google Chrome Manifest V3, разделяя персистентные процессы между фоновым Service Worker, изолированными панелями пользовательского интерфейса, offscreen-документами воспроизведения звука и оверлеями контентных скриптов на страницах:

1. **Конфигурация манифеста (`manifest.json`)**:
   - **Разрешения (21 пункт)**: `tabs`, `tabGroups`, `storage`, `favicon`, `contextMenus`, `notifications`, `sidePanel`, `scripting`, `downloads`, `downloads.open`, `system.display`, `declarativeNetRequestWithHostAccess`, `cookies`, `history`, `sessions`, `bookmarks`, `readingList`, `clipboardWrite`, `alarms`, `offscreen` и `idle`.
   - **Разрешения хостов (Host Permissions)**: `["<all_urls>"]`.
   - **Service Worker**: `src/core/background.js`, использующий синхронную модульную загрузку через `importScripts`.
   - **Действие на панели инструментов (Toolbar Action)**: Намеренно опускает `default_popup`. Среда выполнения принудительно задает `chrome.action.setPopup({ popup: '' })`, обеспечивая синхронное срабатывание `chrome.action.onClicked` и открытие `chrome.sidePanel` в закрепленном пользователем виде без задержек на инициализацию всплывающего окна.
   - **Ключевое слово Omnibox**: Зарегистрированное ключевое слово `"find"`.
   - **Команды (Commands)**: 24 системных клавиатурных сочетания, зарегистрированных в разделе `commands`.
   - **Политика безопасности контента (Content Security Policy)**: `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`.

2. **Безопасность межпроцессного взаимодействия**:
   - `src/core/background/messaging.js` фильтрует сообщения от контентных скриптов на основе явного белого списка (`ALLOWED_CONTENT_SCRIPT_ACTIONS`). Непривилегированные веб-фреймы не могут вызывать внутренние методы записи в хранилище, произвольные Chrome API или модификаторы правил.

3. **Двойные миры выполнения**:
   - Контентные скрипты работают как в мире `ISOLATED` (область видимости расширения), так и в мире `MAIN` (область видимости выполнения страницы). Скрипты, такие как `allowRightClickHook.js`, `videoPipHook.js`, `youtubePreviewAudioHook.js` и `youtubeShortsFeedHook.js`, выполняются в `MAIN` для перехвата методов прототипов, переопределения дескрипторов свойств и прямой обработки пользовательских событий.

## 2. Раздел 1: Управление правилами (Gestionar Reglas)

Подсистема управления правилами автоматизирует группировку вкладок на основе строгих детерминированных критериев, заданных пользователем.

### 2.1 Схема данных (`CustomRule`)
Каждое пользовательское правило соответствует следующему интерфейсу:
```typescript
interface CustomRule {
  name: string;        // От 1 до 16 символов. Не должно содержать пробельных символов.
  color: RuleColor;    // Один из 9 цветов: 'grey' | 'blue' | 'red' | 'yellow' | 'green' | 'pink' | 'purple' | 'cyan' | 'orange'
  urls: string[];      // Массив корректных URL, доменов или хостнеймов.
  active: boolean;     // Главный переключатель, включающий или отключающий применение правила.
  isStarred?: boolean; // Необязательный флаг, отмечающий правило как избранное для приоритетного отображения в интерфейсе.
}
```

### 2.2 Архитектура приоритетов
Когда вкладки обрабатываются функцией `groupTabs()` в `src/core/background/groupManager.js`, они оцениваются по уровням группировки в строгом иерархическом порядке:
1. **Пользовательские правила (`applyCustomRules`)**: Сопоставляются с активными пользовательскими правилами в порядке их расположения или приоритета пользователя. После группировки идентификаторы вкладок регистрируются в `groupedTabIds` и исключаются из последующих уровней.
2. **Специальные системные группы**: Системные URL перехватываются и кластеризуются в выделенные цветные группы:
   - `chrome://` и внутренние страницы браузера
   - `file:///` локальные файлы на диске
   - `chrome-extension://` страницы расширений
   - IP-адреса и Localhost (`localhost`, `127.0.0.1`, `[::1]`, IPv4/IPv6 хосты)
3. **Кластеризация по доменам**: Вкладки с одинаковым корневым доменом группируются, если их количество достигает или превышает `domainThreshold` (по умолчанию: 2 вкладки).
4. **Кластеризация по поддоменам**: Если включено, вкладки внутри доменов группируются по конкретным поддоменам (например, `docs.github.com` против `gist.github.com`).
5. **Разное («Misc»)**: Оставшиеся некластеризованные вкладки, не достигшие порогов группировки, помещаются в группу `Misc` (расположение настраивается: `start`, `end` или по алфавиту `alpha`).

### 2.3 Нормализация URL и семантика сопоставления
Движок сопоставления (`matchesRule(tabUrl, ruleUrl)` в `src/core/background/utils.js`) применяет строгую нормализацию:
- **Агностицизм к схеме**: Протоколы HTTP и HTTPS считаются взаимозаменяемыми (`http://example.com` совпадает с `https://example.com`). Несетевые протоколы (`file://`, `chrome://`) требуют точного совпадения схемы.
- **Нормализация хоста**: Начальные префиксы `www.` удаляются (`www.github.com` нормализуется в `github.com`). Имена хостов приводятся к нижнему регистру и поддерживают интернационализированные доменные имена (IDN) через punycode.
- **Чувствительность к порту**: Если правило указывает порт (например, `localhost:3000`), вкладка должна в точности соответствовать этому порту.
- **Сопоставление путей**: Замыкающие косые черты удаляются. Если правило указывает путь (например, `example.com/docs`), оно соответствует вкладкам с этим точным путем ИЛИ подпутями (`example.com/docs/api`), но не соответствует соседним путям (`example.com/blog`).
- **Сопоставление Query и Hash**: Если правило явно содержит строку запроса (`?page=1`) или хэш (`#section`), вкладка должна содержать эти параметры дословно.
- **Защита от числовых Dword (`ruleValidation.js`)**: Валидатор строго отклоняет чисто числовые входные данные (например, `3242342424`), которые парсеры WHATWG URL интерпретируют как допустимые целочисленные DWORD IPv4, предотвращая случайные искажения группировки.

### 2.4 Подробный разбор настроек управления правилами
Менеджер правил предоставляет исчерпывающий набор элементов управления поведением и настроек:
- **Выбор маршрутизации хранилища**: Пользователи могут направлять хранение правил либо в `chrome.storage.sync` (для синхронизации настроек между всеми устройствами под одним профилем Google с учетом лимитов квоты Chrome sync в 100 КБ суммарно и 8 КБ на элемент), либо в `chrome.storage.local` (для неограниченного локального объема, подходящего для больших наборов из сотен шаблонов).
- **Главный переключатель кластеризации и пороговые значения**:
  - `toggle-clustering`: Главное сочетание клавиш и переключатель интерфейса, включающий или отключающий автоматическую кластеризацию по доменам/поддоменам без отключения пользовательских правил.
  - `domainThreshold`: Минимальное количество вкладок с одного домена, необходимое для создания автоматической группы вкладок (по умолчанию: 2 вкладки). Настраивается в диапазоне от 1 до 50.
  - `subdomainThreshold`: Минимальное количество вкладок для поддоменов перед созданием отдельных подгрупп.
  - Переключатель поддоменов (`toggle-subdomain-grouping`): Разделяет независимые поддомены (например, `news.ycombinator.com` против `ycombinator.com`).
- **Автоматическая сортировка групп по алфавиту (`toggle-sort-alpha`)**: Движок сортировки в реальном времени, поддерживающий алфавитный порядок всех открытых групп на панели вкладок браузера (`Ctrl+Shift+S` / `Cmd+Shift+S`).
- **Визуальные префиксы статуса (`toggle-prefixes`)**: Эмодзи-маркеры, динамически добавляемые перед названиями групп для отображения состояния просмотра:
  - `🔒` (Замок): Группа содержит непосещенные, непрочитанные вкладки.
  - `🔍` (Лупа): Группа содержит частично просмотренные вкладки.
  - `🗝️` (Открытый ключ): Все вкладки в группе были открыты и просмотрены.
  - `⚠️` (Предупреждение): Обнаружен конфликт дублирования имени группы с группой в другом окне.
- **Автоматическое сворачивание неактивных групп (`toggle-collapse-timer`)**: Автоматически сворачивает группы при отсутствии активности для поддержания чистоты панели вкладок.
- **Главная пауза группировки (`feature_pauseGrouping`)**: Главный переключатель заморозки, временно приостанавливающий все операции автоматической группировки (как по правилам, так и по эвристической кластеризации) во время активных исследовательских сессий, когда вкладки должны оставаться в произвольном порядке.
- **Группировка одиночных вкладок (`featureSingleTabGrouping`)**: Позволяет пользовательским правилам немедленно создавать группу даже для одной подходящей вкладки в обход порогового значения минимального количества вкладок.
- **Компактный режим (`toggle-compact-mode`)**: Минимизирует ширину заголовков групп на панели вкладок браузера, отображая только бейджи из одной буквы вместо полных названий.
- **Приоритет Drag-and-Drop**: Изменение порядка правил в списке `Rules.svelte` мгновенно меняет приоритет их применения. Правила, находящиеся выше, оцениваются первыми.
- **Нечеткий поиск (Fuzzy Search)**: Фильтрация в реальном времени в Менеджере правил и Omnibar, позволяющая мгновенно находить правила по названию или подходящим шаблонам URL.
- **Импорт / Экспорт JSON**:
  - Режим `add`: Объединяет импортированные правила с существующей коллекцией, отсеивая дубликаты.
  - Режим `overwrite`: Полностью заменяет текущую коллекцию правил импортированными данными после валидации схемы.
- **Динамическое создание правил**: Создание пользовательских правил в один клик прямо из папок закладок Chrome или наборов доменов подгрупп.
- **Дедупликация правил (`feature_v100_dedup_add_to_rule`)**: Автоматически удаляет дублирующиеся шаблоны URL при добавлении URL или доменов в существующие правила, предотвращая раздувание правил и избыточные проверки.

### 2.5 Операции и персистентность (`mutateRulesAndSync`)
- **Централизованный мутатор**: Все изменения правил проходят через `mutateRulesAndSync(mutateFn, sendResponse)` в `src/core/background/handlers/rules.js`. Это гарантирует синхронизацию с хранилищем, обновление кэша в памяти (`extensionSettings.customRules`), уведомление интерфейса (`rulesUpdated`) и автоматическую перегруппировку вкладок (`groupTabs()`).
- **Валидация в реальном времени**: Проверка уникальности имени, длины (1–16 символов), допустимости символов и корректности синтаксиса URL в реальном времени перед сохранением.

### 2.6 Способы вызова
- **Страница Менеджера правил (`Rules.svelte`)**: Доступна во вкладке на весь экран или в боковой панели (`?view=rules` / `pg`). Предоставляет полноценное изменение порядка перетаскиванием, встроенный выбор цвета, теги-чипы URL и переключатели правил.
- **Команды Omnibar**:
  - `rl:` — Поиск правил и открытие связанных с ними URL.
  - `cr: <name> [, url1, url2]` — Создание нового правила прямо из командной строки.
  - `atcr:` — Добавление домена или URL активной вкладки в существующее правило.
  - `atr:` — Добавление выбранных открытых вкладок или введенных вручную URL в существующее правило.
  - `ccr:` — Изменение цвета пользовательского правила.
  - `dr:` — Удаление правил или отдельных URL из правила.
  - `er:` — Редактирование или переименование существующего правила.
- **Контекстное меню**:
  - Правый клик на странице -> «Crear Regla para esta Página» -> «Añadir Raíz del Sitio» / «Añadir URL Completa».
  - Правый клик на странице -> «Añadir a Regla Existente» -> Выбор правила -> «Añadir Raíz del Sitio» / «Añadir URL Completa».
  - Правый клик на странице -> «Reglas» -> Переключение активности, открытие всех URL правила или закрытие подходящих вкладок.
- **Сочетания клавиш**:
  - `Alt+R`: Открыть Менеджер правил.
  - `Alt+M`: Переключить активацию всех правил одновременно (`toggle-all-rules`).

## 3. Раздел 2: Список групп и операции (Listar Grupos)

Представление списка групп предоставляет интерактивную рабочую среду для инспекции, манипулирования и упорядочивания групп вкладок и отдельных вкладок браузера.

### 3.1 Архитектура пользовательского интерфейса
- **Стек компонентов**: Построен на `ListGroup.svelte`, `GroupCard.svelte`, `GroupActions.svelte`, `TabItem.svelte` и `TabActions.svelte`.
- **Возможности карточки**: Отображает название группы, цветовой бейдж, индикатор количества вкладок, переключатель аккордеона сворачивания/разворачивания, закрепление карточки и настраиваемые группы кнопок действий.
- **Элементы вкладок**: Отображают фавиконку вкладки с запасным цветным вариантом, заголовок, бейдж воспроизведения звука, индикатор отключения звука, индикатор активного состояния и действия для отдельной вкладки (закрыть, дублировать, закрепить, разделить, выгрузить из памяти).

### 3.2 Жизненный цикл и поведение групп
- **Управление аккордеоном**: Плавные состояния разворачивания и сворачивания. Опциональный режим авто-аккордеона автоматически сворачивает неактивные группы при разворачивании новой группы.
- **Таймер автосворачивания по неактивности**:
  - Автоматически сворачивает неактивные группы вкладок для уменьшения визуального шума.
  - Два раздельных порога: неактивные группы сворачиваются через 1 минуту бездействия (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`), тогда как активная группа сворачивается через 15 минут бездействия (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`). Настраивается от 0 до 1440 минут.
- **Встроенное переименование и льготный период (Grace Period)**:
  - Пользователи могут переименовывать группы прямо на панели вкладок браузера или в интерфейсе расширения.
  - `GROUP_NAMING_GRACE_MS` (5000 мс) приостанавливает автоматическую перегруппировку во время редактирования, предотвращая перезапись заголовка во время ввода.
  - Пробелы нулевой ширины (`\u200B`, `\u200C`, `\u200D`, `\u2060`, `\uFEFF`) удаляются при обработке.
  - Переименование автоматически созданной группы переводит ее в разряд именованных пользователем, обновляя соответствующее правило или делая ее постоянной.
- **Визуальные префиксы-индикаторы групп**:
  - Динамически добавляют символы статуса: `🔒` (не посещено), `🔍` (частично), `🗝️` (все просмотрены), `⚠️` (конфликт).
- **Изменение порядка через Drag-and-Drop**: Интеграция с `sortable.js` для изменения порядка вкладок внутри групп, перемещения вкладок между группами или упорядочивания карточек групп.
- **Функция скрытых групп**:
  - Добавляет префикс `_hidden_` к заголовку группы на панели вкладок браузера.
  - Скрывает карточки групп из основного списка, перемещая их в `HiddenGroupsBar.svelte`.
  - Пользователи могут отобразить или восстановить группы мгновенно в один клик.

### 3.3 Операции с группами и управление памятью
- **Разгруппировать (Ungroup)**: Распускает группу, оставляя вкладки открытыми в окне.
- **Закрыть группу**: Закрывает все вкладки в группе и освобождает идентификатор группы.
- **Закрыть другие группы**: Закрывает все группы вкладок, кроме текущей сфокусированной.
- **Перегруппировать все вкладки (`Alt+Shift+R`)**: Выполняет полный проход переоценки по пользовательским правилам, системным группам и доменным кластерам.
- **Пошаговый обход скриншотов группы**: Последовательно переключает и делает скриншоты каждой вкладки в группе (`Cs` видимая область, `Cp` вся страница, `CP` вся страница по частям).

### 3.4 Подсистема резервного копирования и восстановления групп
- **Хранилище IndexedDB `backupsGroups`**:
  - Создает резервные копии отдельных групп или слепков всех открытых групп рабочей среды в хранилище `backupsGroups` базы данных IndexedDB `Intelligent_Workspace`.
  - Сохраняет полную структуру групп: заголовок группы, цвет, состояние свернутости, заголовки вкладок, URL, фавиконки, статус закрепления и относительные позиции вкладок.
  - **Экономия памяти**: Вкладки, сохраненные в резервной копии, корректно закрываются для освобождения системной оперативной памяти и снижения нагрузки на процессор.
  - **Механизмы восстановления**:
    - Интерфейс резервных копий в `ListGroup.svelte` с восстановлением групп в один клик.
    - Сочетания клавиш `br` (восстановить) и `bg` (создать резервную копию всех).
    - Команды Omnibar `bgr:` (поиск и восстановление резервных копий групп) и `b:` (поиск по закладкам).
  - **Экспорт и импорт JSON**: Полный экспорт и импорт резервных копий в формате JSON для удобной миграции между компьютерами и долгосрочного автономного архивирования.

### 3.5 Припаркованный плеер YouTube в панели скрытых групп
- **Архитектура (`HiddenGroupsBar.svelte`)**:
  - Когда пользователь уходит из активного режима просмотра видео YouTube или запускает видео внутри боковой панели, плеер не закрывается и не теряется. Он автоматически закрепляется в `HiddenGroupsBar.svelte` как припаркованный индикатор YouTube (`.youtube-indicator`).
  - Реактивно управляется через хранилище `hiddenYoutubeView` в `src/ui/stores/appStore.svelte.js`.
  - **Действия в один клик**:
    - Нажатие на припаркованный индикатор вызывает `restoreYoutubeView()`, немедленно возвращая плеер в активный вид рабочей среды.
    - Нажатие на бейдж удаления вызывает `discardYoutubeView()`, корректно останавливая воспроизведение и освобождая ресурсы.
  - Бесшовно располагается рядом со скрытыми группами вкладок в верхней части представления ListGroup, не загромождая списки активных вкладок.

## 4. Раздел 3: Навигация и управление вкладками (Navegación)

Ускоренная навигация с клавиатуры и элементы управления рабочей средой позволяют бесшовно управлять множеством вкладок без использования мыши.

### 4.1 Жест быстрого перехода к вкладке
- **Синтаксис жеста**: `Alt + [groupPrefix] + [tabIndex] + Enter`
- **Выполнение**:
  - Удерживая `Alt`, введите название группы или начальные буквы префикса, затем нужный номер вкладки (начиная с 1) и нажмите `Enter`.
  - Пример: `Alt + git + 2 + Enter` переходит напрямую ко второй вкладке в группе «GitHub».
  - Индекс `0` служит шорткатом для *последней* вкладки в группе.
  - Пропуск индекса выполняет переход к *первой* вкладке в группе.
  - Диакритические знаки автоматически сглаживаются (`deaccent`), а сопоставление нормализует символы с ударениями.

### 4.2 Клавиши пошагового переключения, смены вкладок и управления жизненным циклом
- `s`: Мгновенный переход к предыдущей активной вкладке (`previousActiveTabId`).
- `h` / `l`: Шаг к предыдущей / следующей вкладке (или горизонтальная прокрутка, если страница позволяет).
- `H` / `L`: Навигация назад / вперед по истории браузера.
- `t`: Открыть новую пустую вкладку.
- `x`: Закрыть текущую активную вкладку.
- `yt`: Дублировать текущую вкладку.
- `r` / `R`: Перезагрузить страницу / Принудительно перезагрузить в обход кэша.
- `d` / `u`: Прокрутить в самый низ / верх страницы.
- `j` / `k`: Плавная прокрутка вниз / вверх (шаг 75px).
- `f`: Активировать подсказки ссылок Vim (над кликабельными элементами появляются буквы для нажатия).
- `cf`: Активировать подсказки ссылок Vim для копирования целевого URL в буфер обмена.

### Для продвинутых пользователей

Опытные пользователи могут перевести браузер в полноэкранный режим и перемещаться исключительно с клавиатуры, вообще не прикасаясь к мыши.

#### Полноэкранное погружение и серфинг без мыши
- **Переключение полноэкранного режима**: Нажмите `F11` (Windows/Linux) или `Command+Control+F` (macOS). Элементы интерфейса браузера, адресная строка, панель вкладок и панели операционной системы скрываются, отдавая 100% дисплея под контент.
- **Навигация по ссылкам Vim на странице (`f` / `cf`)**:
  - Нажмите `f`, чтобы сгенерировать высококонтрастные двухбуквенные желтые подсказки над каждым кликабельным элементом, кнопкой, полем ввода и ссылкой в DOM.
  - Наберите две буквы, соответствующие цели, чтобы сэмулировать прямой клик без помощи мыши.
  - Нажмите `cf`, чтобы отобразить подсказки, копирующие URL целевой ссылки прямо в системный буфер обмена.
  - Нажмите `vp`, чтобы открыть модальное окно предпросмотра целевой ссылки внутри страницы.
  - Нажмите `Esc` в любой момент, чтобы отменить подсказки и вернуться к обычной прокрутке.
- **Мгновенный переход и переключение вкладок**:
  - `Alt + [groupPrefix] + [tabIndex] + Enter`: Выполнить жест быстрого перехода к вкладке (например, `Alt + dev + 1 + Enter` переходит прямо к первой вкладке в группе «Dev»; индекс `0` выбирает последнюю вкладку в группе).
  - `s`: Мгновенно переключиться между текущей и ранее активной вкладкой (`previousActiveTabId`).
  - `h` / `l`: Последовательный переход к предыдущей / следующей вкладке на панели вкладок.
  - `H` / `L`: Перемещение назад / вперед по истории навигации браузера.
  - `t` / `x` / `yt`: Открыть новую вкладку (`t`), закрыть текущую вкладку (`x`) или дублировать вкладку (`yt`).
- **Плавающая командная подсистема Omnibar (`o`)**:
  - Нажмите `o` на любой странице, чтобы вызвать оверлей Omnibar по центру экрана.
  - Нажмите `@`, чтобы отобразить интерактивный справочник всех 41 командных префиксов.
  - Введите `f: <query>` для глубокого полнотекстового поиска по вкладкам во всех открытых окнах.
  - Введите `sp:`, чтобы направить навигацию напрямую в любое представление Sidepanel (`rules`, `listgroup`, `notes`, `gallery`, `gemini`, `activity`, `themes`, `hints`, `downloads`).
  - Введите `qai: <query>` или `qaia: <task>`, чтобы обратиться к Gemini или отдать команду автономному браузерному агенту, не снимая рук с клавиатуры.
  - Введите `ts:`, чтобы разделить открытые вкладки на два экрана рядом друг с другом.
- **Навигация и фокус на странице**:
  - `j` / `k`: Плавная прокрутка вниз / вверх (шаг 75px).
  - `d` / `u`: Прокрутка на полстраницы вниз / вверх.
  - `i`: Мгновенно переместить фокус курсора в основное поле ввода текста на странице.
  - `ESC`: Снять фокус с полей ввода и вернуть клавиатуру в режим навигации.

### 4.3 Управление звуком и аудио
- Вкладки, воспроизводящие звук, помечаются значком динамика в интерфейсе ListGroup.
- `st`: Переключить отключение звука на текущей активной вкладке.
- `so`: Заглушить все вкладки со звуком во всем браузере.
- Контекстное меню: «Silenciar Todas las Pestañas» / «Reactivar Sonido en Todas las Pestañas».

### 4.4 Сценарии разделенного экрана (Split Screen)
- **Триггер**: Подсказка Vim `ts` или префикс Omnibar `ts:`.
- **Поведение**: Использует `chrome.system.display` для расчета геометрии экрана. Разделяет две вкладки рядом в смежные окна, группируя их в выделенную группу вкладок `Split`.
- **Восстановление**: Закрытие разделенного окна или повторное переключение режима восстанавливает исходные размеры и координаты окон.

### 4.5 Подсистема зацикливания YouTube
Подсистема зацикливания YouTube предоставляет точные элементы управления повтором медиа, встроенные непосредственно в плеер YouTube:
- **Кнопка в плеере на десктопе (`#itg-yt-loop-button`)**: Внедряется в стандартную панель управления плеера YouTube (`.ytp-right-controls`), слева от кнопки Cast / Remote или кнопки запуска PiP. Имеет анимированные SVG-глифы зацикливания, подсветку активного состояния (`ytp-loop-active`, `var(--interactive-color, #ff4444)`) и состояния `aria-pressed`.
- **Кнопка в плеере Shorts (`#itg-yt-shorts-loop-button`)**: Внедряется внутрь `#itg-yt-shorts-loop-wrapper` в правую колонку управления YouTube Shorts (`ytd-shorts`), обеспечивая зацикливание вертикальных видео в один клик.
- **Меню цикла и всплывающее окно PiP (`#itg-yt-loop-menu` и `#itg-pip-loop-popup`)**: Наведение курсора или клик по кнопке цикла открывает подробное меню настроек:
  - **Зацикливание A-B**: Пользователи могут задавать произвольные точки начала (A) и конца (B) с точностью до миллисекунд с помощью интерактивных ползунков диапазона и ручных полей ввода времени.
  - **Режим циклов и повторы последовательности**: Установка количества повторений для определенных циклов или включение бесконечного режима (`itg-loop-seq-inf`).
  - **Список циклов и многосегментные последовательности**: Создание очереди из нескольких интервалов зацикливания A-B, которые воспроизводятся последовательно в соответствии с настроенным числом повторов.
  - **Отображение статуса и длительности**: Отображает текущую позицию воспроизведения в реальном времени внутри интервала зацикливания и общую продолжительность медиа (`00:00 / 00:00`).
  - **Главный переключатель (`youtubeLoopEnabled`)**: Сохраняется в `chrome.storage.sync` и `local`, позволяя пользователям включать или отключать кнопки зацикливания на YouTube и в YouTube Shorts через страницу настроек Customize Hints (`YoutubeLoopSection.svelte`).

### 4.6 Звук при предпросмотре YouTube Shorts
- **Хук включения звука (`youtubePreviewAudioHook.js`)**:
  - Выполняется в мире выполнения `MAIN` для доступа к свойству `#inline-preview-player` элементов `ytd-video-preview`.
  - **Преодоление принудительного отключения звука**: YouTube принудительно отключает звук при предпросмотре Shorts, убирая элементы управления аудио и восстанавливая `muted = true` через внутренние слушатели `volumechange`.
  - Расширение перехватывает дескриптор свойства `HTMLMediaElement.prototype.muted` целевого элемента `<video>` при наведении курсора. Оно блокирует принудительное повторное заглушение от YouTube, сохраняя возможность ручного включения звука пользователем, благодаря чему звук воспроизводится непрерывно и не прерывается при перезапусках цикла вплоть до ухода курсора.

### 4.7 Архитектура «Картинка в картинке» (PiP)
- **Document Picture-in-Picture (`wp`)**:
  - Использует современный API `documentPictureInPicture` для открытия веб-страницы целиком или текстового фрагмента в плавающем окне поверх всех окон.
  - Автоматически синхронизирует временные метки воспроизведения видео при переносе медиа.
  - Включает логику повторных попыток (`itgRetryIfPipFrameRefused`) и очищает заголовки iframe DNR при закрытии.
- **Video Picture-in-Picture (`wv`)**:
  - Перехватывает `HTMLVideoElement.prototype.requestPictureInPicture` через `videoPipHook.js`.
  - Перенаправляет видеоплееры в кастомные фреймы PiP с элементами управления зацикливанием и выбором скорости воспроизведения.
- **Auto-PiP**:
  - `as`: Переключить Auto-PiP при прокрутке (открывает видео в PiP, когда оно скрывается из области видимости).
  - `ah`: Переключить Auto-PiP при скрытии вкладки (открывает видео в PiP при переключении на другую вкладку).

### 4.8 Режимы чтения страниц и визуальные оверлеи
- **Темы на основе CSS-фильтров**: Внедряет недеструктивные стили в веб-страницы:
  - `mb` / `mB`: Черный (темный высококонтрастный) — область вкладки / глобально.
  - `ms` / `mS`: Сепия (теплая бумага) — область вкладки / глобально.
  - `mp` / `mP`: Бумага (монохромный серый) — область вкладки / глобально.
  - `ml` / `mL`: Светлый (мягкий белый) — область вкладки / глобально.
  - `me` / `mE`: Пользовательский CSS-фильтр — область вкладки / глобально.
  - `ESC`: Мгновенно удаляет активный фильтр страницы.
- **Режим чтения и голосовое чтение вслух (TTS)**:
  - `fetchContentForReaderView`: Извлекает чистый контент статьи, удаляя рекламу, сайдбары и навигационный шум.
  - Встроенный движок Text-to-Speech (TTS), читающий текст вслух предложение за предложением.
  - Управление навигацией с клавиатуры: `zp` (воспроизведение/пауза), `zn` (следующее предложение), `zb` (предыдущее предложение), `zq` (закрыть оверлей чтения).

### 4.9 Подсистема текстовых сниппетов с шаблонными переменными
Подсистема текстовых сниппетов (`SnippetManager` в `src/utils/hint/snippets.js` и `src/utils/snippet-panel.js`) ускоряет ввод текста путем разворачивания сокращений в любых полях ввода, textarea или rich-редакторах:
- **Способы активации**: Введите сокращение и нажмите Пробел, либо наберите `$$`, чтобы вызвать интерактивное всплывающее окно поиска сниппетов.
- **Интеграция с Clipboard API**: Поддерживает вставку форматированного HTML и простого текста через Clipboard API, обеспечивая 100% совместимость со сложными редакторами, такими как Google Docs, Notion и Slack.
- **Шаблонные переменные**: Динамически подставляются в момент разворачивания:
  - `{{date}}` / `date`: Локализованная дата (`toLocaleDateString`).
  - `{{isodate}}` / `isodate`: Дата по стандарту ISO 8601 (`YYYY-MM-DD`).
  - `{{longdate}}` / `longdate`: Полная дата с указанием дня недели, числа, месяца и года.
  - `{{time}}` / `time`: 2-значный формат времени (`HH:MM`).
  - `{{datetime}}` / `datetime`: Объединенные дата и время.
  - `{{weekday}}` / `weekday`: Полное название дня недели (например, Понедельник).
  - `{{day}}` / `day`: Число месяца (1–31).
  - `{{month}}` / `month`: Полное название месяца (например, Октябрь).
  - `{{year}}` / `year`: Полный 4-значный год.
  - `{{tomorrow}}` / `tomorrow`: Дата завтрашнего дня (+1 день).
  - `{{yesterday}}` / `yesterday`: Дата вчерашнего дня (-1 день).
  - `{{nextweek}}` / `nextweek`: Дата через 7 дней (+7 дней).
  - `{{timestamp}}` / `timestamp`: Метка времени в миллисекундах Unix Epoch (`Date.now()`).
  - `{{url}}` / `url`: URL активной веб-страницы (`window.location.href`).
  - `{{domain}}` / `domain`: Хост активного домена (`window.location.hostname`).
  - `{{pagetitle}}` / `pagetitle`: Заголовок активного документа (`document.title`).
  - `{{uuid}}` / `uuid`: Криптографически стойкий уникальный идентификатор (`crypto.randomUUID()`).
  - `{{random}}` / `random`: Случайное целое число от 1 до 1000.
  - `{{clipboard}}` / `clipboard`: Текст из системного буфера обмена.

### 4.10 Встроенные инструменты продуктивности
- **Хук разблокировки правого клика (`allowRightClickHook.js`)**:
  - Внедряется в мир выполнения `MAIN`, нейтрализуя вредоносные скрипты страниц, блокирующие контекстное меню по правому клику, копирование, вырезание или выделение текста.
  - Перехватывает вызовы `preventDefault()` и `stopPropagation()` для событий `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown` и `mouseup`.
  - Очищает встроенные обработчики `oncontextmenu="return false"` с помощью постоянного `MutationObserver`.
  - Проверяет данные буфера обмена, исключая нарушение работы легитимных веб-редакторов (Google Docs, Telegram Web).
- **Редактор Cookie**: Модальное окно внутри страницы для просмотра, редактирования, создания и удаления файлов cookie HTTP и HTTPS для текущего домена.
- **Генератор QR-кодов**: Генерирует QR-коды SVG/Canvas для URL активной вкладки для быстрой передачи на мобильные устройства.
- **Экспорт чистой печати в PDF**: Пропускает целевые страницы через `print.html` с удалением верхних и нижних колонтитулов, рекламы и навигационного шума для чистого архивирования документов.

### 4.11 Комплексное 3-уровневое удаление дубликатов и интеллектуальная выгрузка вкладок
- **Комплексное 3-уровневое удаление дубликатов**:
  1. **Дедупликация вкладок (`removeDuplicateTabsCommand`)**: Сканирует открытые вкладки по всем окнам или выбранным группам, находит дублирующиеся URL, исключает вкладки разделенного экрана `Split` и закрывает лишние вкладки, сохраняя активную или самую старую. Выводит сводное системное уведомление на рабочий стол.
  2. **Дедупликация закладок**: Глубоко сканирует деревья закладок Chrome, находит идентичные дубликаты URL по всем папкам и обеспечивает пакетную консолидацию для поддержания порядка в закладках.
  3. **Дедупликация правил (`feature_v100_dedup_add_to_rule`)**: Автоматически удаляет дублирующиеся шаблоны URL при добавлении адресов в существующие правила группировки, предотвращая их раздувание.
- **Интеллектуальная выгрузка из памяти (`suspendInactiveTabsIntelligently`)**:
  - Вычисляется каждую 1 минуту по сигналу таймера `itg-periodic-tasks`.
  - Выгружает из памяти вкладки, неактивные в течение >= `discardingTimeMinutes` (по умолчанию: 60 минут).
  - Встроенная защита от выгрузки: никогда не выгружает активные вкладки, вкладки со звуком, закрепленные вкладки или уже приостановленные вкладки.

## 5. Раздел 4: AI-ассистент и автономный агент (Asistente AI)

AI-ассистент интегрирует большие языковые модели в браузер для обеспечения контекстного понимания, автоматизации рабочих процессов и прямого управления браузером.

### 5.1 Архитектура с двумя движками моделей
1. **Google Gemini Cloud API (`gemini-api.js`)**:
   - Интегрируется с REST-эндпоинтами Google Generative Language (`v1beta/models/{model}:generateContent` и `:streamGenerateContent`).
   - Поддерживает Gemini 2.5 Flash, Gemini 2.5 Pro и пользовательские эндпоинты моделей.
   - **Ротация нескольких ключей**: Управляет пулами ключей в `geminiApiKeysList`. Маскирование в хранилище использует префиксы `enc_`.
   - **Экспоненциальная задержка (Exponential Backoff)**: Обрабатывает исчерпание квот HTTP 429 с автоматическими повторными попытками (1.5 с -> 3 с -> 6 с).
   - **Заземление на Google Поиск (Search Grounding)**: Включает Google Search Grounding (`google_search: {}`). При возникновении ошибки HTTP 403 из-за ограничений квоты на поисковые инструменты автоматически повторяет запрос без заземления.
2. **Встроенный Chrome AI / Prompt API (`localAiService.js`)**:
   - Интеграция с Gemini Nano на устройстве через `window.LanguageModel`.
   - Поддерживает локальное выполнение без доступа к сети. Включает проверку доступности модели и отслеживание прогресса ее загрузки в реальном времени.

### 5.2 Автономный браузерный агент (`agent-backend.js`)
Автономный агент предоставляет полный контроль над браузером с помощью более чем 40 структурированных инструментов:
- **Управление вкладками и группами**: `getOpenTabs`, `switchToTab`, `createNewTab`, `closeTab`, `closeTabs`, `duplicateTab`, `findAndSwitchToTab`, `groupTabs`, `ungroupTabs`, `deleteTabGroup`, `collapseTabGroup`, `expandTabGroup`, `collapseAllGroups`, `expandAllGroups`, `setGroupColor`, `renameTabGroup`, `regroupAllTabs`, `removeDuplicateTabs`, `closeTabsWithSound`.
- **Навигация и поиск**: `openUrl`, `searchGoogle`, `getActiveTab`, `getActiveTabContent`.
- **База знаний и закладки**: `getBookmarks`, `searchBookmarks`, `createBookmark`, `getHistory`, `getRecentlyClosed`.
- **Правила и внешний вид**: `getRules`, `createRule`, `updateRule`, `deleteRule`, `getActiveTheme`, `getSavedThemes`, `applyTheme`.

### 5.3 Отслеживание недоверенных данных (Taint Tracking) и защита от Prompt Injection
Для нейтрализации атак непрямой инъекции промпта (Indirect Prompt Injection) с недоверенных веб-страниц бэкенд агента реализует строгое отслеживание недоверенных данных:
- **Маркировка заражения (Taint Marking)**: Вызов `getActiveTabContent` извлекает текст с веб-страницы и помечает текущий сеанс выполнения как скомпрометированный (`taintedAgentRuns.add(runId)`).
- **Барьер на вывод данных (Egress Guard)**: Сеансам с меткой заражения строго запрещено вызывать инструменты вывода данных вовне (`AGENT_EGRESS_TOOLS`):
  * `openUrl`, `searchGoogle`, `createBookmark`, `createRule`, `addUrlToRule`, `createSiteShortcut`, `updateSiteShortcut`, `updateRule`.
- **Механизм отказа**: Вместо генерации необработанного исключения движок возвращает структурированное объяснение безопасности. Затем LLM информирует пользователя о том, что внешние данные не могут быть выгружены без его явного согласия.

### 5.4 Подсистема запланированных запросов Gemini (`GeminiScheduleModal.svelte`)
- **Движок фонового выполнения**:
  - Автоматизирует выполнение запланированных AI-промптов непосредственно внутри фонового сервис-воркера через `chrome.alarms` (`gemini-scheduled-*`).
  - Поддерживает до 6 запланированных запросов в день (`MAX_TIMES = 6`).
  - **Режимы расписания**:
    - Повторяющиеся расписания: Выполняются регулярно в выбранные дни недели (`selectedDays`).
    - Однократные расписания: Выполняются в определенную целевую дату и время (`formDate`).
  - **Лимиты промптов**: Применяет строгое ограничение длины промпта в 1000 символов (`MAX_QUERY_CHARS = 1000`) со счетчиком символов в реальном времени.
  - **Фоновые уведомления**: Отправляет уведомление на рабочий стол с фрагментом ответа по завершении фонового запроса. Клик по уведомлению мгновенно открывает тред с ответом в чате боковой панели.

### 5.5 Управление диалогами Gemini и экспорт
- **Персистентное хранилище IndexedDB (`geminiConversations`)**: Многоэтапные сессии чата сохраняются в хранилище `geminiConversations` базы IndexedDB `Intelligent_Workspace`.
- **Полнотекстовый поиск по истории**: Мгновенный поиск по всем прошлым диалогам и отдельным сообщениям с помощью команд Omnibar `lai:` (просмотр диалогов) и `laiq:` (поиск сообщений).
- **Четыре формата экспорта**:
  1. **Стилизованный HTML**: Оформленный автономный HTML-документ со стилизованными диалоговыми пузырями сообщений, бейджами ролей, временными метками и блоками кода с подсветкой синтаксиса.
  2. **Сырой JSON**: Полный структурированный дамп данных, включая массивы сообщений, использование токенов, конфигурацию модели и поисковые цитаты.
  3. **Markdown**: Стандартный Markdown-файл, отформатированный с заголовками, временными метками и блоками кода (` ``` `).
  4. **Простой текст**: Чистая текстовая расшифровка диалога без форматирования, подходящая для отправки по почте или заметок.
- **Отслеживание метаданных заземления**: Фиксирует идентификатор модели, статистику расхода токенов, временные метки выполнения и цитаты источников, возвращенные Google Search Grounding.

### 5.6 Мультимодальный ввод и файловые вложения (`feature_geminiAttachFiles`)
- **Мультимодальные вложения**: Переключатель `feature_geminiAttachFiles` позволяет прикреплять изображения и документы напрямую к промптам в чате:
  - Файлы изображений (JPEG, PNG, WebP, HEIC/HEIF).
  - Документы PDF и научные статьи.
  - Обычные текстовые файлы и файлы с исходным кодом.
  - Структурированные наборы данных CSV.
- **Поддержка голоса**:
  - Web Speech STT (Speech-to-Text) для надиктовки промптов голосом.
  - Web Speech TTS (Text-to-Speech) для озвучивания ответов вслух.

### 5.7 Способы вызова
- **Маршрут боковой панели**: `?view=gemini` или шорткат `pa`.
- **Префиксы Omnibar на странице**:
  - `qai: <query>` — Задать прямой вопрос настроенной модели Gemini.
  - `qaia: <prompt>` — Выполнить промпт через автономного агента с вызовом инструментов.
  - `lai:` — Просмотр истории прошлых диалогов с AI.
  - `laiq:` — Полнотекстовый поиск по сообщениям диалогов с AI.
- **Поиск вкладок через Omnibox с AI (`find <query>`)**:
  - Ключевое слово `find` в адресной строке запускает гибридный поиск.
  - Объединяет сопоставление границ слов регулярными выражениями с семантическим анализом Gemini для поиска и фокусировки открытых вкладок на основе запросов на естественном языке.

## 6. Раздел 5: Просмотр заметок и управление знаниями (Ver Notas)

Контекстно-ориентированный локальный движок заметок, привязанный к группам вкладок браузера и навигационным контекстам.

### 6.1 Архитектура хранилища (`notesStore`)
Хранится в базе данных IndexedDB `Intelligent_Workspace` (v8) внутри хранилища объектов `notesStore`:
```typescript
interface NoteRecord {
  id: string;          // Уникальный идентификатор заметки.
  title: string;       // Заголовок заметки.
  text: string;        // Форматированный HTML, Markdown или сериализованная полезная нагрузка задач.
  type: NoteType;      // 'text' | 'checklist' | 'kanban'
  url?: string;        // Исходный URL, где была создана заметка.
  contextKey: string;  // Ключ области видимости, привязывающий заметку к иерархии рабочей среды.
  createdAt: number;   // Временная метка создания.
  modifiedAt: number;  // Временная метка последнего редактирования.
  isPersistent: boolean; // Флаг закрепления, защищающий заметку от удаления при очистке группы.
}
```

### 6.2 Специализированные форматы заметок и расширенный рендеринг
1. **Текстовая заметка (`NoteTextEditor.svelte`)**:
   - Область форматированного текста `contenteditable`.
   - Прямое встраивание медиа: изображений, аудио, видео и документов PDF.
   - Встроенная санитизация HTML и подсчет слов и символов в реальном времени.
   - **Рендеринг диаграмм Mermaid**: Отрисовывает динамические блок-схемы, диаграммы последовательностей, диаграммы классов и конечные автоматы прямо из блоков Markdown (` ```mermaid `).
   - **Математический LaTeX KaTeX**: Отображает строчные формулы (`$...$`) и блочные уравнения (`$$...$$`) с высокой типографической точностью.
2. **Заметка-чеклист (`NoteChecklistEditor.svelte`)**:
   - Интерактивный список задач с отдельными чекбоксами выполнения.
   - Поддерживает изменение порядка элементов с клавиатуры и отслеживание прогресса.
3. **Заметка Kanban (`NoteKanbanEditor.svelte`)**:
   - Доска из 3 колонок: `To Do` -> `In Progress` -> `Done`.
   - Циклически переключаемые чипы статуса для быстрого перемещения задач.
- **Динамическое преобразование без потерь**: Заметки преобразуются между представлениями Text, Checklist и Kanban без потери данных.

### 6.3 Области видимости и контекстная иерархия
Заметки привязываются к контекстам просмотра через `contextKey`:
- **Область группы (`g_<groupId>` или `g_<groupKey>`)**: Прикреплена ко всей группе вкладок.
- **Область подгруппы (`s_<groupId>_<domain>`)**: Прикреплена к конкретному домену внутри группы вкладок.
- **Область вне групп (`g_ungrouped` / `s_ungrouped_<domain>`)**: Заметки, созданные на вкладках вне групп.
- **Pomodoro и общие области (`pomodoro`, `general`)**: Заметки уровня всей рабочей среды.
- **Детектор потерянных заметок (Orphan Detection Engine)**: При удалении групп вкладок или доменов связанные с ними незакрепленные заметки перехватываются детектором. Они остаются доступными в интерфейсе для переназначения или удаления.

### 6.4 Способы вызова
- **Элементы запуска в UI**: Кнопка «Просмотр заметок» на карточках групп и подгрупп; кнопка «Быстрые заметки» в заголовке всплывающего окна; маршрут боковой панели `?view=notes` (`pk`).
- **Вызов через контекстное меню**: Выделите текст на любой странице -> Правый клик -> «Crear Nota desde Selección» (`note-from-selection`). Автоматически извлекает выделенный текст и устанавливает ближайший заголовок `h1`-`h3` в качестве названия.
- **Подсказка Vim**: `ao` создает заметку из текущего выделения.
- **Omnibar**: `lnt:` открывает браузер заметок с мгновенным полнотекстовым поиском.
- **Озвучивание текста**: Кнопка TTS в редакторе читает содержимое заметки вслух с помощью Web Speech API.

## 7. Раздел 6: Медиа и просмотр галереи (Ver Galería)

Высокопроизводительный конвейер захвата медиа, аннотирования и оптического распознавания символов (OCR).

### 7.1 Режимы захвата и инженерия (все 7 типов захвата)
Расширение реализует 7 специализированных способов захвата, охватывающих работу с отдельными вкладками, несколькими вкладками, выделенными областями и палитрой:
1. **`visible` (Захват видимой области - `cs`)**:
   - Захватывает точную видимую область активной вкладки с помощью `chrome.tabs.captureVisibleTab`.
   - Автоматически сохраняет снимок в хранилище `screenshots` IndexedDB и копирует растровое изображение прямо в системный буфер обмена (`screenshotSavedAndCopied`).
2. **`fullPage` (Бесшовный холст всей страницы с прокруткой - `cp`)**:
   - Выполняет программную прокрутку страницы, рассчитывая полную высоту документа.
   - Скрывает полосы прокрутки и липкие/фиксированные панели навигации после первого сегмента для устранения визуальных артефактов.
   - Сшивает растровые фрагменты на `OffscreenCanvas` высотой до 30 000 пикселей (`captureFullPageDataUrl`), соблюдая совместимые с Chromium задержки в 600 мс между кадрами.
3. **`fullPageParts` (Последовательные нарезанные сегменты - `cpp` / `cP`)**:
   - Нарезает длинные документы на последовательные отдельные части высотой в область просмотра (`captureFullPageParts`), генерируя до 60 пронумерованных фрагментов изображений для постраничного просмотра.
4. **`area` (Интерактивная обрезка прямоугольной области перетаскиванием - `ca`)**:
   - Внедряет `area-selector.js`, накладывая холст с перекрестием и размерами области выделения в реальном времени.
   - Маркеры изменения размера, подсказка с габаритами, подтверждение, отмена по клавише `Esc` и очередь обрезки для нескольких вкладок (`handleCaptureAreaFromShortcut`).
5. **`groupTabs` (Пакетный обход вкладок активной группы - `Cs`, `Cp`, `CP`)**:
   - Последовательно перебирает каждую вкладку внутри активной группы (`handleCaptureGroupFromShortcut`).
   - Поддерживает пакетный захват в режимах видимой области, всей страницы или по частям, объединяя их в единую коллекцию.
6. **`omnibarPickedTabs` (Выборочный захват очереди вкладок через Omnibar)**:
   - Запускается командами Omnibar `cs:`, `cp:`, `cpp:` или `ca:` (`handleCaptureTabs`).
   - Выполняет последовательный захват по всем отфильтрованным пользователем вкладкам с индикаторами прогресса в реальном времени.
7. **`colorPickerCapture` (Фоновый снимок экрана для пипетки)**:
   - Делает фоновый снимок экрана для работы точной лупы с пипеткой цветов HEX в операционных системах, где отсутствует нативная поддержка `window.EyeDropper` (например, Linux).

### 7.2 Интерфейс галереи и персистентность
- **Интерфейс**: Адаптивная плиточная раскладка (masonry/grid) с просмотрщиком-лайтбоксом, функциями масштабирования, панорамирования и поворота.
- **Персистентность (Хранилище `screenshots`)**: Сохраняется в IndexedDB `Intelligent_Workspace`. Неотмеченные булавкой снимки автоматически удаляются во время обслуживания; нажатие на иконку булавки (`isPersistent = true`) сохраняет снимки бессрочно.

### 7.3 Экспорт, OCR в браузере и внешняя разметка
- **Форматы экспорта (`captureDownloadFormats`)**:
  - Высокоэффективные форматы: PNG, WebP, AVIF.
  - Экспорт многостраничных документов PDF с помощью `pdf.js`.
- **WASM OCR на устройстве**:
  - WebWorker с Tesseract.js внутри браузера, использующий предзагруженные языковые модели для испанского и английского языков (`spa+eng`).
  - Извлекает текст напрямую в буфер обмена без отправки данных изображений по сети.
- **Прямая интеграция отправки**:
  - Передача распознанного OCR текста или прикрепленных изображений в один клик в заметки (`notesStore`) или промпты Gemini AI (`feature_geminiAttachFiles`).
  - **Разметка в Excalidraw**: Экспорт в один клик отправляет сделанные снимки напрямую в `https://excalidraw.com/` для рисования от руки, добавления стрелок и векторных аннотаций.

### 7.4 Способы вызова
- **Пользовательский интерфейс**: Кнопка камеры на карточке группы, быстрое действие во всплывающем окне, маршрут галереи в боковой панели `?view=gallery` (`ps`).
- **Подсказки Vim**: `cs` (видимая часть), `cp` (вся страница), `cP` (по частям), `ca` (обрезка области), `Cs` (все вкладки группы - видимо), `Cp` (все вкладки группы - вся страница), `CP` (все вкладки группы - по частям).
- **Префиксы Omnibar**: `cs:`, `cp:`, `cpp:`, `ca:` и `limg:` (просмотр галереи).

## 8. Раздел 7: Набор инструментов Pomodoro и учета времени (Pomodoro)

Комплекс для концентрации и учета времени, спроектированный для абсолютной точности независимо от циклов сна браузера.

### 8.1 Движок тайминга и фоновая архитектура
- **Математика временных меток с нулевым дрейфом**: Состояние сохраняется в `chrome.storage.local` с абсолютными временными метками Unix (`startTime`, `pausedAt`). Завершение работы сервис-воркера, перезапуски браузера и переход операционной системы в спящий режим не вызывают рассинхронизации часов.
- **Диспетчер сигналов (Alarm Dispatcher)**:
  - Высокоточный таймер обратного отсчета на базе `chrome.alarms` (интервал `pomodoroTick` 1 с).
  - Фоновое обслуживание и периодические проверки интервалов через `itg-periodic-tasks` (интервал 1 мин).
- **Звуковые оповещения в Offscreen-режиме (`offscreen.html`)**: Звуковые сигналы генерируются через отдельный offscreen-документ Chrome, создаваемый с причиной `AUDIO_PLAYBACK`. Автоматически закрывается через 3.5 секунды после окончания звука для экономии памяти.

### 8.2 Исчерпывающие 4 режима тайминга
1. **Pomodoro (`pomodoro`)**:
   - Длительность работы: от 1 до 180 минут (по умолчанию: 25 мин).
   - Короткий перерыв: от 1 до 120 минут (по умолчанию: 5 мин).
   - Длинный перерыв: от 1 до 180 минут (по умолчанию: 15 мин).
   - Циклов до длинного перерыва: от 1 до 12 циклов (по умолчанию: 4).
   - Целевое количество циклов: от 1 до 99 циклов (по умолчанию: 8).
   - Настраиваемый автозапуск работы, автозапуск перерывов и системные уведомления.
2. **Секундомер (`cronometro`)**: Прямой отсчет времени с записью кругов и возможностью остановки по паузе.
3. **Обратный отсчет (`temporizador`)**: Пользовательский таймер обратного отсчета с указанием часов, минут и секунд.
4. **Будильник к целевому времени (`tiempo`)**: Выбор даты в календаре и времени на часах для установки сигнала на точный момент в будущем.

### 8.3 Плавающий виджет таймера на странице
- Минималистичный перемещаемый оверлей, отображающий обратный отсчет в реальном времени, кнопки паузы/возобновления и пропуска прямо поверх веб-страниц.
- Позволяет контролировать сессии концентрации, не переключаясь обратно на панель расширения или всплывающее окно.

### 8.4 Таймер бездействия для автосворачивания групп
- Работает в связке с режимами концентрации, автоматически сворачивая неактивные группы после 1 минуты бездействия (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`), а активную группу — после 15 минут бездействия (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`). Настраивается в пределах от 0 до 1440 минут.

### 8.5 Теги проектов и метаданные
Каждая сессия поддерживает метаданные для категоризации:
- Название проекта (до 18 символов)
- Тег проекта (например, `#research`, `#dev`)
- Папка проекта (например, `/client/project`)

### 8.6 Аналитический движок и 19 карточек KPI
Полный дашборд (`dashboard.html` или боковая панель `dashboard.html?context=sidepanel`) рассчитывает 19 ключевых показателей эффективности на основе дедуплицированных сессий (`dedupeSessions` по `sessionStarted`):
1. `focus`: Общее время фокуса.
2. `sessions`: Всего завершенных сессий.
3. `cycles`: Всего завершенных рабочих циклов.
4. `efficiency`: Средний процент эффективности (`Total Focus / Total Time * 100`).
5. `activeDays`: Количество уникальных активных дней.
6. `break`: Общая длительность перерывов.
7. `interruptions`: Общее количество ручных пауз/прерываний.
8. `interruptionTime`: Суммарное время, проведенное в состоянии паузы.
9. `bestSession`: Самая длинная непрерывная сессия концентрации.
10. `avgFocus`: Средняя продолжительность фокуса за завершенный цикл.
11. `totalTime`: Суммарное время работы и перерывов.
12. `workRest`: Соотношение времени работы и отдыха (`1 : X`).
13. `distractionRate`: Количество прерываний на один час фокуса.
14. `bestDay`: Самый продуктивный день недели.
15. `goldenHour`: Интервал пиковой продуктивности в течение дня (например, `10:00 - 11:00`).
16. `projects`: Количество отслеживаемых различных проектов.
17. `avgIntDuration`: Средняя продолжительность одного прерывания.
18. `topProject`: Проект с наибольшим накопленным временем фокуса.
19. `focusIntensity`: Среднее количество часов фокуса в активный день.

Дополнительная визуальная аналитика включает календарь-тепловую карту непрерывной серии дней (Day Streak Heatmap), гистограмму почасового распределения фокуса, распределение по проектам и полный импорт/экспорт данных в формате JSON.

## 9. Раздел 8: Панель активности и истории (Panel de Actividad)

Движок отслеживания, аналитики и контроля веб-активности на базе Declarative Net Request (DNR).

### 9.1 Движок данных и топология хранилища (`ITG_WEB_ACTIVITY`)
Управляется в рамках структуры `ITG_WEB_ACTIVITY`:
- `wa:day:YYYY-MM-DD`: Счетчики доменов по дням (`{ domains: { host: { t: seconds, v: visits, s: sessions, h: { hour: seconds } } } }`).
- `wa:days`: Массив главного индекса записанных ключей дат.
- `wa:recent`: Кольцевой буфер, хранящий последние 400 записей хронологии посещений.
- `wa:openSegment`: Активный интервал времени в `chrome.storage.session`, ограниченный значением `WA_MAX_SEGMENT_SECONDS = 900s` (15 минут) во избежание искажения статистики при уходе компьютера в сон без вызова событий простоя.
- **Определение простоя**: Использует `chrome.idle` (по умолчанию: 300 с / 5 мин). Воспроизведение звука сохраняет активное отслеживание даже при расфокусированных окнах, если включен параметр `countAudible = true`.
- **Хранение данных**: Автоматически удаляет записи дней старше `retentionDays` (по умолчанию: 180 дней).

### 9.2 Блокировщик сайтов на основе Declarative Net Request (DNR)
- **Динамическое выделение правил**: Назначает динамические правила в диапазоне идентификаторов от `9000` до `9999`.
- **Цель перенаправления**: Заблокированные запросы перенаправляются на страницу `src/ui/pages/web-activity/blocked.html?d=<domain>&u=\1`.
- **Очистка открытых вкладок**: Когда лимит для сайта исчерпан, фоновый воркер немедленно проверяет и перенаправляет существующие открытые вкладки с данным доменом.
- **Расписания, переходящие через полночь**: Расписания, пересекающие полночь (например, с `22:00` до `02:00`), автоматически обрабатываются с учетом смены суток.
- **Льготный период / Отсрочка (+5 мин)**: Экран блокировки позволяет временно отложить блокировку на 5 минут, что фиксируется в `wa:snoozeUses`.

### 9.3 Асимметричная блокировка безопасности (`blockLock.js`)
Лимиты сайтов можно защитить асимметричным паролем:
- **Хранение хэша**: Сохраняет случайную 16-байтную соль и шестнадцатеричный дайджест SHA-256 (`wa:settings.blockPassword`).
- **Политика асимметричных правил**: Пароль **никогда не запрашивается** при создании новых лимитов или ужесточении правил (например, при уменьшении разрешенного времени или добавлении ограничений по расписанию).
- **Защищенные действия**: Пароль требуется только при **смягчении правил** (удалении лимита, увеличении времени или отключении расписаний), а также при использовании отсрочки сверх дневного бесплатного лимита (`snoozePasswordAfter`).

### 9.4 Категоризация и визуальная аналитика
- **16 встроенных категорий**: `social`, `video`, `music`, `news`, `shopping`, `reading`, `entertainment`, `dev`, `work`, `education`, `games`, `finance`, `mail`, `ai`, `search`, `other`.
- **Пользовательские категории**: Поддерживает категории, заданные пользователем, с префиксом `custom:`.
- **Коэффициент фокуса**: Сопоставляет продуктивные категории (`dev`, `work`, `education`, `reading`, `finance`, `mail`) с отвлекающими (`social`, `video`, `games`, `shopping`, `entertainment`).
- **Визуализация**: Почасовое распределение активности Chart.js, круговая диаграмма категорий и списки рейтинга доменов.

### 9.5 Подсистема менеджера загрузок (`switchMainView('downloads')`)
- **Выделенный маршрут**: Доступен в боковой панели через `switchMainView('downloads')` (`?view=downloads`).
- **Прямая интеграция с Chrome API**: Перехватывает `chrome.downloads` для отслеживания, управления и проверки всех загрузок браузера в реальном времени.
- **Нечеткий поиск в реальном времени**: Мгновенный поиск по имени файла, пути к файлу или исходному URL загрузки.
- **Чипы фильтрации по статусу**: Быстрая фильтрация загрузок по состоянию: `All`, `In Progress`, `Complete`, `Paused` и `Interrupted`.
- **Фильтрация по диапазону дат**: Выборка загрузок по конкретным датам или интервалам времени через календарь.
- **Пакетный загрузчик из группы**: Извлекает все ссылки на скачивание из открытых вкладок активной группы и запускает синхронизированное пакетное скачивание с индикацией прогресса.
- **Управление файлами**: Открытие файла в один клик (`chrome.downloads.open`) и показ в папке (`chrome.downloads.show`).

### 9.6 Подсистема недавно закрытых вкладок и истории просмотров
- **Просмотр недавно закрытых вкладок**:
  - Прямая интеграция с `chrome.sessions.getRecentlyClosed`.
  - Поиск в реальном времени с автоматическим сглаживанием диакритики и ударений (`deaccent`).
  - Восстановление отдельной вкладки или сессии целого окна в один клик или через команду Omnibar `c:`.
- **Просмотр истории просмотров**:
  - Глубокий поиск с 10-секундным кэшированием TTL в памяти для исключения избыточных запросов `chrome.history.search`.
  - Фильтрация поиска по домену, ключевым словам и диапазонам дат в календаре.
  - Активация вкладки в один клик, если она уже открыта, или создание новой, с доступом через Omnibar `h:`.

### 9.7 Подсистема планирования тем (`ThemeScheduleModal.svelte`)
- **Автоматическое расписание тем**:
  - Управляется через `ThemeScheduleModal.svelte` внутри представления тем в боковой панели (`?view=themes` / `pt`).
  - Поддерживает автоматическое переключение тем в зависимости от времени суток (`HH:MM`) и активных дней недели (`[0..6]`).
  - Максимум 7 глобальных расписаний тем (`MAX_GLOBAL_SCHEDULES = 7`).
  - **Автовозврат**: Автоматический возврат к дневным или рабочим темам по умолчанию в заданные часы окончания.
  - **Оповещения на рабочем столе**: Выводит системные уведомления при автоматической смене тем (`chrome.notifications`).
  - **Двойная персистентность**: Сохраняется в `chrome.storage.sync` (синхронизируемые настройки) и `chrome.storage.local` под ключами `savedThemes` и `themeSchedules`.

### 9.8 Компактный вид боковой панели
- **Маршрут боковой панели (`?view=activity` / `pw`)**: 350-пиксельная колонка, оптимизированная для мониторинга в реальном времени, с чипами выбора периода (`Today`, `7d`, `30d`, `All`) и шкалами прогресса лимитов доменов.

### 10.6 Древовидная иерархия контекстного меню (все 5 групп и более 30 действий)
Контекстное меню представляет собой полную иерархическую структуру, разделенную на 5 функциональных групп команд:
1. **Группа 1: Подменю правил и URL**:
   - Главный чекбокс правил («Activar/Desactivar Todas las Reglas»).
   - Индивидуальные переключатели для быстрого включения/выключения отдельных правил.
   - «Abrir Todas las URLs»: открывает все целевые URL, зарегистрированные в выбранном правиле.
   - Подменю отдельных URL с динамическим счетчиком открытых вкладок `[N]`: отображает количество открытых вкладок, соответствующих адресу, обеспечивает переход к URL в один клик и предлагает пункт «Cerrar Pestañas para esta URL» для закрытия всех подходящих вкладок.
   - Быстрое создание правил: «Crear Regla para esta Página» -> «Añadir Raíz del Sitio» / «Añadir URL Completa».
   - Добавление в существующее правило: «Añadir a Regla Existente» -> Выбор правила -> «Añadir Raíz del Sitio» / «Añadir URL Completa».
2. **Группа 2: Очистка вкладок и управление звуком**:
   - «Eliminar Pestañas Duplicadas [N]»: показывает количество обнаруженных дубликатов и закрывает их во всех окнах.
   - «Eliminar Pestañas por Dominio»: динамическое подменю со списком всех доменов и количеством открытых вкладок `[N]`, позволяющее точечно закрывать вкладки по доменам.
   - «Cerrar Todos Excepto el Grupo Activo»: оставляет активную группу в фокусе и закрывает все остальные группы.
   - «Reagrupar Todas las Pestañas»: запускает полный фоновый проход перегруппировки по всем открытым вкладкам.
   - «Silenciar Todas las Pestañas» / «Reactivar Sonido en Todas las Pestañas»: глобальное отключение и включение звука.
3. **Группа 3: Чтение, выделение и заметки**:
   - «Leer Página en Voz Alta» (TTS): чтение всей страницы синтезатором речи с элементами управления в оверлее.
   - «Leer Selección en Voz Alta»: чтение выделенного фрагмента DOM вслух с помощью речевого синтеза.
   - «Crear Nota desde Selección»: извлекает выделенный текст, автоматически определяет название заметки из ближайшего заголовка (`h1`-`h3`) и сохраняет ее в `notesStore`.
4. **Группа 4: Открытие расширения, PiP и панели**:
   - «Abrir como PiP» / «Abrir como Ventana Emergente»: открытие целевой страницы, выделенного фрагмента или изображения в плавающем окне Picture-in-Picture или отдельном всплывающем окне.
   - «Abrir Extensión»: открывает всплывающее окно расширения или разворачивает боковую панель.
   - «Gestionar Reglas»: открывает полноразмерный Менеджер правил в отдельной вкладке браузера.
   - Прямой запуск боковой панели: переход в один клик к разделам List Groups (`?view=listgroup`), Themes (`?view=themes`), AI Assistant (`?view=gemini`) и Customize Hints (`?view=hints`).
5. **Группа 5: Настройки и параметры кластеризации**:
   - **Gestión de Grupos**: Alternar Grupo Actual (свернуть/развернуть текущую группу), Alternar Todos los Grupos (свернуть/развернуть все группы).
   - **Opciones de Agrupación**:
     - Agrupación Inteligente (переключить автоматическую эвристическую кластеризацию).
     - Modo Compacto (переключить компактный режим названий групп из одной буквы).
     - Dominio / Subdominio (переключить группировку по доменам и поддоменам).
     - Páginas Especiales: Páginas Chrome (`chrome://`), Archivos Locales (`file:///`), Extensiones (`chrome-extension://`), Miscelánea (`Misc`), Direcciones IP & Localhost.
   - **Opciones Generales**:
     - Ordenar Alfabéticamente (принудительная сортировка по алфавиту на панели вкладок).
     - Ubicación Miscelánea: Principio (`start`), Final (`end`), Alfabéticamente (`alpha`).
     - Temporizador de Auto-Colapso (переключить таймер автосворачивания неактивных групп).
     - Prefijos Visuales (переключить маркеры состояний `🔒`, `🔍`, `🗝️`, `⚠️`).
     - Vista Previa de Enlaces (переключить модальное окно предпросмотра ссылок на странице).

## 11. Схемы хранения и персистентность данных

Расширение использует многоуровневую модель хранения данных на основе IndexedDB и Chrome Storage API:

### 11.1 База данных IndexedDB: `Intelligent_Workspace` (версия схемы 8)
1. `screenshots`: keyPath: `'id'`, autoIncrement: true. Вторичный индекс: `'createdAt'`. Хранит бинарные скриншоты, data URL холста, флаги персистентности, размеры и общие индексы сегментов.
2. `geminiConversations`: keyPath: `'id'`, autoIncrement: true. 0 вторичных индексов (извлечение/управление по ID). Сохраняет многоэтапные треды чатов, роли сообщений, метрики токенов и метаданные поискового заземления.
3. `notesStore`: keyPath: `'id'`, autoIncrement: false. 0 вторичных индексов (фильтрация в памяти по contextKey). Сохраняет форматированный текст, массивы чеклистов, карточки досок Kanban, спецификации Mermaid и формулы KaTeX.
4. `backupsGroups`: keyPath: `'group.id'`. 0 вторичных индексов (сохраняет объекты резервных копий групп по вложенному ключу `'group.id'`). Хранит сжатые структуры групп, цвета, заголовки и записи закрытых вкладок.
5. `pomodoroStats`: keyPath: `'id'`, autoIncrement: true. Вторичные индексы: `'projectName'` (keyPath `'projectName'`) и `'savedAt'` (keyPath `'savedAt'`) (индекс `date` отсутствует). Содержит аналитику фокуса, метрики циклов и журналы прерываний.

### 11.2 Двойная маршрутизация Chrome Storage (`StorageService`)
- Динамически перенаправляет чтение и запись между `chrome.storage.sync` (для переносимых настроек между устройствами пользователя) и `chrome.storage.local` (для объемных параметров).
- Основные модели данных:
  - `customRules`: Массив определений правил (`[{ name, color, active, urls }]`).
  - `clusterConfig`: Параметры автокластеризации (пороговые значения, компактный режим, специальные категории).
  - `userPrefixes`: Назначения эмодзи-префиксов (`{ lock, openKey, loupe, checked, warning }`).
  - `activeTheme`, `savedThemes` и `themeSchedules`: Цветовые конфигурации из 9 палитр и правила запланированной ротации, настроенные через `ThemeScheduleModal.svelte`.
  - `pomodoroState`: Временные метки сессии в реальном времени, продолжительность паузы и цели по циклам.
  - `wa:settings` и `wa:limits`: Настройки отслеживания веб-активности, лимиты сайтов и окна расписаний.
  - `youtubeLoopEnabled`: Логический флаг, управляющий кнопками зацикливания на YouTube и в Shorts.

### 11.3 Сессионное хранилище Chrome Storage (`chrome.storage.session`)
Используется для сверхбыстрой временной координации в среде выполнения:
- `tabsEverActive`: Набор идентификаторов вкладок, активированных за текущую сессию браузера.
- `groupExpandedEver`: Запись групп, развернутых за текущую сессию.
- `groupInfoMap`: Реестр реального времени, сопоставляющий идентификаторы групп с динамическими заголовками и типами кластеризации.
- `splitScreenState`: Кэшированные границы окон для восстановления исходных размеров экрана.
- `contextMenusSignature`: Хэш-подпись, предотвращающая избыточные перестроения контекстного меню при быстрых переключениях вкладок.
- `wa:openSegment`: Текущий активный сегмент времени на сайте.
- `hiddenYoutubeView`: Ссылка на вид припаркованного плеера YouTube, закрепленный в `HiddenGroupsBar.svelte`.

## 12. Защитная инженерия и обработка пограничных случаев

1. **Разблокировка заголовков через Declarative Net Request (`dnr.js`)**:
   - Модифицирует заголовки ответов с помощью динамических правил DNR, удаляя `X-Frame-Options` и ограничительные заголовки `Content-Security-Policy`, что позволяет внешним сайтам отображаться внутри iframes в боковой панели и окнах «Картинка в картинке».
   - **Безопасность WhatsApp Web**: Явно сохраняет заголовки `Cross-Origin-Opener-Policy` (COOP) и `Cross-Origin-Embedder-Policy` (COEP) для `web.whatsapp.com`, предотвращая сбой криптографической реализации WebAssembly Signal.
2. **Разблокировщик правого клика и выделения (`allowRightClickHook.js`)**:
   - Нейтрализует враждебные скрипты веб-страниц, блокирующие копирование, вставку, контекстное меню и выделение текста.
   - Выполняется в мире `MAIN`, перехватывая `preventDefault()` и `stopPropagation()` для событий `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown` и `mouseup`.
   - Удаляет инлайновые обработчики `oncontextmenu="return false"` через `MutationObserver`.
   - Защищает легитимные веб-приложения (например, Telegram Web, Google Docs), проверяя содержимое буфера обмена перед повторной отправкой отмененных событий вставки.
3. **Переопределение принудительного отключения звука при предпросмотре YouTube (`youtubePreviewAudioHook.js`)**:
   - Выполняется в мире `MAIN` на элементе `ytd-video-preview #inline-preview-player`.
   - Переопределяет дескриптор свойства `HTMLMediaElement.prototype.muted` на целевом элементе `<video>` при наведении курсора.
   - Устраняет состояние гонки внутреннего принудительного заглушения `volumechange` в YouTube, сохраняя включенный звук при перезапусках цикла во время наведения мыши.
4. **Хук навигации по последовательности ленты YouTube Shorts (`youtubeShortsFeedHook.js`)**:
   - Выполняется в мире `MAIN` на элементе `ytd-shorts`.
   - Перехватывает свойство `shortsProcessedSequence`, невидимое из изолированного мира расширения, и отправляет нативные события `yt-navigate` на `ytd-app` без перезагрузки страницы и без потери состояния плавающего окна.
5. **Защита холста при бесконечной прокрутке**:
   - Ограничивает создание скриншотов всей страницы 60 сегментами (`MAX_FULL_PAGE_SEGMENTS`) и максимальной высотой холста в 30 000 пикселей (`MAX_FULL_PAGE_CANVAS_PX`), предотвращая падение вкладок браузера из-за нехватки памяти (OOM).
6. **Запасной вариант пипетки цветов экрана для Linux**:
   - При работе в среде Linux, где отсутствует Chromium API `window.EyeDropper`, расширение внедряет `screen-color-picker.js`, отображающий 9-кратную увеличительную пиксельную лупу с расчетом значений RGB/HEX/HSL.
7. **Задержка стабилизации сессии при запуске**:
   - Откладывает очистку групп на 20 секунд (`groupsHaveSettledAfterStartup()`) при запуске браузера, позволяя вкладкам сессии и состояниям окон стабилизироваться перед вычислением распределения по группам.
