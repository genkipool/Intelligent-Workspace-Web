# Intelligent Workspace

> Intelligent Workspace হলো Svelte, Vite এবং CRXJS দিয়ে নির্মিত একটি উন্নত Manifest V3 ব্রাউজার এক্সটেনশন এবং প্রোডাক্টিভ ওয়ার্কস্পেস এনভায়রনমেন্ট। এটি বুদ্ধিমান ট্যাব সংগঠন, স্বয়ংক্রিয় ও নিয়ম-ভিত্তিক ক্লাস্টারিং, স্বায়ত্তশাসিত এআই এজেন্ট এক্সিকিউশন (Google Gemini Cloud API এবং Chrome Built-in Prompt API সমর্থনকারী), পেজের অভ্যন্তরে Vim-স্টাইলের লিঙ্ক নেভিগেশন, একটি ৪১-উপসর্গযুক্ত Omnibar কমান্ড সিস্টেম, বহু-ফরম্যাটের নোট গ্রহণ (রিচ টেক্সট, চেকলিস্ট, Kanban, Mermaid ডায়াগ্রাম, KaTeX ফর্মুলা), উচ্চ-মানের মিডিয়া ক্যাপচার এবং ব্রাউজার-অভ্যন্তরীণ WASM OCR, জিরো-ড্রিফ্ট অ্যালার্ম ও অফস্ক্রিন অডিও প্লেব্যাকসহ Pomodoro টাইমিং, এবং Declarative Net Request (DNR) ওয়েব অ্যাক্টিভিটি পরিমাপ, ডোমেন সীমা ও সাইট ব্লকিং পরিচালনা করে।

## 1. Architectural Foundation & Runtime Lifecycle

এই এক্সটেনশনটি Google Chrome-এর Manifest V3 আর্কিটেকচারের অধীনে চলে, যা একটি ব্যাকগ্রাউন্ড Service Worker, স্যান্ডবক্সযুক্ত UI প্যানেল, অফস্ক্রিন অডিও ডকুমেন্ট এবং ইন-পেজ কনটেন্ট স্ক্রিপ্ট ওভারলে জুড়ে স্থায়ী প্রক্রিয়াগুলিকে আলাদা করে:

1. **ম্যানিফেস্ট কনফিগারেশন (`manifest.json`)**:
   - **পারমিশনসমূহ (২১টি আইটেম)**: `tabs`, `tabGroups`, `storage`, `favicon`, `contextMenus`, `notifications`, `sidePanel`, `scripting`, `downloads`, `downloads.open`, `system.display`, `declarativeNetRequestWithHostAccess`, `cookies`, `history`, `sessions`, `bookmarks`, `readingList`, `clipboardWrite`, `alarms`, `offscreen`, এবং `idle`।
   - **হোস্ট পারমিশনসমূহ**: `["<all_urls>"]`।
   - **Service Worker**: সিনক্রোনাস `importScripts` মডুলার লোডিং ব্যবহারকারী `src/core/background.js`।
   - **টুলবার অ্যাকশন**: ইচ্ছাকৃতভাবে `default_popup` বাদ দেওয়া হয়েছে। রানটাইম `chrome.action.setPopup({ popup: '' })` প্রয়োগ করে, যা নিশ্চিত করে যে `chrome.action.onClicked` সিনক্রোনাসভাবে কার্যকর হয় এবং কোনো পপআপ ইনিশিয়ালাইজেশন লেটেন্সি ছাড়াই ব্যবহারকারীর পিন করা ভিউতে `chrome.sidePanel` খোলে।
   - **Omnibox কীওয়ার্ড**: নিবন্ধিত কীওয়ার্ড `"find"`।
   - **কমান্ডসমূহ**: `commands`-এর অধীনে নিবন্ধিত ২৪টি সিস্টেম-লেভেল কীবোর্ড শর্টকাট।
   - **কনটেন্ট সিকিউরিটি পলিসি**: `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`।

2. **আন্তঃ-প্রক্রিয়া যোগাযোগ নিরাপত্তা (Inter-Process Communication Security)**:
   - `src/core/background/messaging.js` একটি সুস্পষ্ট অনুমোদিত তালিকা (`ALLOWED_CONTENT_SCRIPT_ACTIONS`) অনুযায়ী কনটেন্ট স্ক্রিপ্ট থেকে আসা বার্তাগুলি ফিল্টার করে। বিশেষাধিকারহীন ওয়েব ফ্রেমগুলি অভ্যন্তরীণ স্টোরেজ রাইটার, নির্বিচার Chrome API, বা রুল মিউটেটর আহ্বান করতে পারে না।

3. **ডুয়াল এক্সিকিউশন ওয়ার্ল্ডস (Dual Execution Worlds)**:
   - কনটেন্ট স্ক্রিপ্টগুলি `ISOLATED` (এক্সটেনশন স্কোপ) এবং `MAIN` (পেজ এক্সিকিউশন স্কোপ) উভয় জগতেই কাজ করে। `allowRightClickHook.js`, `videoPipHook.js`, `youtubePreviewAudioHook.js`, এবং `youtubeShortsFeedHook.js`-এর মতো স্ক্রিপ্টগুলি প্রোটোটাইপ পদ্ধতিগুলিকে ইন্টারসেপ্ট করতে, প্রপার্টি ডেসক্রিপ্টর ওভাররাইড করতে এবং সরাসরি কাস্টম ইভেন্টগুলি পরিচালনা করতে `MAIN`-এ চলে।

## 2. Section 1: Rules Management (Gestionar Reglas)

নিয়ম ব্যবস্থাপনা সাবসিস্টেম ব্যবহারকারীর সংজ্ঞায়িত কঠোর নিয়মতান্ত্রিক মানদণ্ডের ভিত্তিতে স্বয়ংক্রিয়ভাবে ট্যাব গ্রুপিং সম্পন্ন করে।

### 2.1 Data Schema (`CustomRule`)
প্রতিটি কাস্টম নিয়ম নিম্নলিখিত ইন্টারফেস মেনে চলে:
```typescript
interface CustomRule {
  name: string;        // 1 to 16 characters. Must contain no whitespace characters.
  color: RuleColor;    // One of 9 colors: 'grey' | 'blue' | 'red' | 'yellow' | 'green' | 'pink' | 'purple' | 'cyan' | 'orange'
  urls: string[];      // Array of valid URLs, domains, or hostnames.
  active: boolean;     // Master toggle enabling or disabling rule evaluation.
  isStarred?: boolean; // Optional flag marking rule as a favorite for prioritized UI ordering.
}
```

### 2.2 Precedence Architecture
যখন ট্যাবগুলি `src/core/background/groupManager.js`-এ `groupTabs()` দ্বারা প্রক্রিয়া করা হয়, তখন কঠোর শ্রেণিবিন্যাস ক্রমে গ্রুপিং স্তরগুলির বিপরীতে ট্যাবগুলি মূল্যায়ন করা হয়:
1. **কাস্টম নিয়ম (`applyCustomRules`)**: উপস্থিতি বা ব্যবহারকারীর অগ্রাধিকারের ভিত্তিতে সক্রিয় কাস্টম নিয়মের সাথে মেলায়। একবার গ্রুপ করা হলে, ট্যাব আইডিগুলি `groupedTabIds`-এ নিবন্ধিত হয় এবং পরবর্তী স্তরগুলি থেকে বাদ দেওয়া হয়।
2. **বিশেষ সিস্টেম গ্রুপ**: সিস্টেম URL-গুলি ইন্টারসেপ্ট করা হয় এবং নিবেদিত রঙিন গ্রুপে ক্লাস্টার করা হয়:
   - `chrome://` এবং অভ্যন্তরীণ ব্রাউজার পেজসমূহ
   - `file:///` স্থানীয় ডিস্ক ফাইলসমূহ
   - `chrome-extension://` এক্সটেনশন পেজসমূহ
   - IP ঠিকানা এবং Localhost (`localhost`, `127.0.0.1`, `[::1]`, IPv4/IPv6 হোস্ট)
3. **ডোমেন ক্লাস্টারিং**: একই রুট ডোমেন ভাগ করে নেওয়া ট্যাবগুলিকে গ্রুপ করা হয় যদি ট্যাবের সংখ্যা `domainThreshold` পূরণ করে বা অতিক্রম করে (ডিফল্ট: ২টি ট্যাব)।
4. **সাবডোমেন ক্লাস্টারিং**: সক্ষম করা থাকলে, ডোমেনের ভিতরের ট্যাবগুলিকে নির্দিষ্ট সাবডোমেন দ্বারা গ্রুপ করা হয় (যেমন, `docs.github.com` বনাম `gist.github.com`)।
5. **বিবিধ ("Misc") গ্রুপ**: অবশিষ্ট আনক্লাস্টার্ড ট্যাবগুলি যা গ্রুপিং থ্রেশহোল্ড পূরণ করে না সেগুলিকে `Misc` গ্রুপে রাখা হয় (প্লেসমেন্ট কনফিগারযোগ্য: `start`, `end`, বা বর্ণানুক্রমিক `alpha`)।

### 2.3 URL Normalization & Matching Semantics
ম্যাচিং ইঞ্জিন (`src/core/background/utils.js`-এ `matchesRule(tabUrl, ruleUrl)`) কঠোর স্বাভাবিকীকরণ প্রয়োগ করে:
- **স্কিম অজ্ঞেয়বাদী (Scheme Agnostic)**: HTTP এবং HTTPS প্রোটোকলকে পরস্পর বিনিময়যোগ্য হিসাবে গণ্য করা হয় (`http://example.com` মিলে যায় `https://example.com`-এর সাথে)। নন-ওয়েব প্রোটোকলগুলির (`file://`, `chrome://`) জন্য হুবহু স্কিম ম্যাচিং প্রয়োজন।
- **হোস্ট স্বাভাবিকীকরণ**: শুরুর `www.` উপসর্গগুলি বাদ দেওয়া হয় (`www.github.com` স্বাভাবিক হয়ে `github.com` হয়)। হোস্টনেমগুলি ছোট হাতের অক্ষরে রূপান্তরিত হয় এবং punycode-এর মাধ্যমে আন্তর্জাতিকীকৃত ডোমেন নামগুলি (IDNs) সমর্থন করে।
- **পোর্ট সংবেদনশীলতা**: যদি কোনো নিয়ম একটি পোর্ট নির্দিষ্ট করে (যেমন, `localhost:3000`), ট্যাবটিকে অবশ্যই সেই সঠিক পোর্টের সাথে মিলতে হবে।
- **পাথ ম্যাচিং**: ট্রেইলিং স্ল্যাশ বাদ দেওয়া হয়। যদি কোনো নিয়ম একটি পাথ নির্দিষ্ট করে (যেমন, `example.com/docs`), তবে এটি সেই সঠিক পাথ বা সাবপাথের (`example.com/docs/api`) ট্যাবগুলির সাথে মিলে যায়, কিন্তু সহোদর পাথের (`example.com/blog`) সাথে মেলে না।
- **কোয়েরি ও হ্যাশ ম্যাচিং**: যদি কোনো নিয়মে স্পষ্টভাবে একটি কোয়েরি স্ট্রিং (`?page=1`) বা হ্যাশ (`#section`) থাকে, তবে ট্যাবের সাথে সেই প্যারামিটারগুলি হুবহু মিলতে হবে।
- **সাংখ্যিক Dword সুরক্ষা (`ruleValidation.js`)**: যাচাইকারী খালি সাংখ্যিক ইনপুটগুলিকে (যেমন, `3242342424`) কঠোরভাবে প্রত্যাখ্যান করে যা WHATWG URL পার্সারগুলি বৈধ IPv4 ইন্টিজার DWORD হিসাবে বিবেচনা করে, যার ফলে দুর্ঘটনাজনিত গ্রুপিং বিকৃতি প্রতিরোধ হয়।

### 2.4 Rules Management Settings Breakdown
রুলস ম্যানেজার আচরণগত নিয়ন্ত্রণ এবং সেটিংসের একটি বিস্তৃত স্যুট প্রদান করে:
- **স্টোরেজ রাউটিং নির্বাচন**: ব্যবহারকারীরা `chrome.storage.sync` (Google প্রোফাইলে সাইন ইন করা সমস্ত ডিভাইস জুড়ে সিঙ্ক করা সেটিংসের জন্য, যা মোট ১০০ KB এবং প্রতি আইটেমে ৮ KB Chrome সিঙ্ক কোটার অধীন) এবং `chrome.storage.local`-এর (শত শত প্যাটার্ন সম্বলিত বড় নিয়ম সেটের জন্য উপযুক্ত সীমাহীন স্থানীয় ক্ষমতার জন্য) মধ্যে নিয়ম স্টোরেজ রুট করতে পারেন।
- **ক্লাস্টারিং মাস্টার টগল এবং থ্রেশহোল্ড**:
  - `toggle-clustering`: মাস্টার কীবোর্ড শর্টকাট এবং UI টগল যা ব্যবহারকারীর তৈরি কাস্টম নিয়মগুলি নিষ্ক্রিয় না করেই স্বয়ংক্রিয় ডোমেন/সাবডোমেন ক্লাস্টারিং সক্ষম বা নিষ্ক্রিয় করে।
  - `domainThreshold`: একটি স্বয়ংক্রিয় ট্যাব গ্রুপ ট্রিগার করার জন্য একই ডোমেন থেকে প্রয়োজনীয় সর্বনিম্ন ট্যাব সংখ্যা (ডিফল্ট: ২টি ট্যাব)। ১ থেকে ৫০ পর্যন্ত কনফিগারযোগ্য।
  - `subdomainThreshold`: পৃথক সাবগ্রুপ ক্লাস্টার তৈরি করার আগে সাবডোমেনের জন্য প্রয়োজনীয় সর্বনিম্ন ট্যাব সংখ্যা।
  - সাবডোমেন টগল (`toggle-subdomain-grouping`): স্বাধীন সাবডোমেনগুলির মধ্যে পার্থক্য করে (যেমন, `news.ycombinator.com` বনাম `ycombinator.com`)।
- **গ্রুপগুলি বর্ণানুক্রমিকভাবে স্বয়ংক্রিয়-সাজানো (`toggle-sort-alpha`)**: রিয়েল-টাইম সাজানোর ইঞ্জিন যা ব্রাউজার ট্যাব স্ট্রিপে সমস্ত খোলা ট্যাব গ্রুপ জুড়ে বর্ণানুক্রমিক ক্রম প্রয়োগ করে (`Ctrl+Shift+S` / `Cmd+Shift+S`)।
- **ভিজ্যুয়াল স্ট্যাটাস উপসর্গ (`toggle-prefixes`)**: পরিদর্শনের অবস্থা নির্দেশ করতে গ্রুপের শিরোনামের পূর্বে গতিশীলভাবে ইমোজি মার্কার যুক্ত করা হয়:
  - `🔒` (তালা): গ্রুপে অপঠিত বা না-দেখা ট্যাব রয়েছে।
  - `🔍` (ম্যাগনিফাইং গ্লাস): গ্রুপে আংশিকভাবে পরিদর্শন করা ট্যাব রয়েছে।
  - `🗝️` (খোলা চাবি): গ্রুপের সমস্ত ট্যাব খোলা হয়েছে এবং পর্যালোচনা করা হয়েছে।
  - `⚠️` (সতর্কতা): অন্য উইন্ডো গ্রুপের সাথে ডুপ্লিকেট গ্রুপের নামের দ্বন্দ্ব সনাক্ত হয়েছে।
- **নিষ্ক্রিয় গ্রুপ স্বয়ংক্রিয়-সংকোচন (`toggle-collapse-timer`)**: ট্যাব স্ট্রিপ পরিষ্কার রাখতে নিষ্ক্রিয় অবস্থায় গ্রুপগুলিকে স্বয়ংক্রিয়ভাবে সঙ্কুচিত করে।
- **মাস্টার পজ গ্রুপিং (`feature_pauseGrouping`)**: মাস্টার ফ্রিজ সুইচ যা সক্রিয় গবেষণা সেশনের সময় সমস্ত স্বয়ংক্রিয় গ্রুপিং ক্রিয়াকলাপ (নিয়ম ম্যাচ এবং হিউরিস্টিক ক্লাস্টারিং উভয়ই) সাময়িকভাবে স্থগিত করে, যেখানে ট্যাবগুলি ব্যবহারকারীর ইচ্ছামতো বিন্যাসে থাকা উচিত।
- **একক ট্যাব গ্রুপিং (`featureSingleTabGrouping`)**: কাস্টম নিয়মগুলিকে বহু-ট্যাব থ্রেশহোল্ড প্রয়োজনীয়তা বাইপাস করে একটি একক ম্যাচিং ট্যাবের জন্যই অবিলম্বে একটি ট্যাব গ্রুপ তৈরি করার অনুমতি দেয়।
- **কমপ্যাক্ট ভিউ (`toggle-compact-mode`)**: গ্রুপের শিরোনামের জন্য কেবল একক-অক্ষরের ব্যাজ রেন্ডার করে ব্রাউজার ট্যাব স্ট্রিপে ট্যাব হেডারের প্রস্থ হ্রাস করে।
- **ড্র্যাগ-অ্যান্ড-ড্রপ অগ্রাধিকার**: `Rules.svelte` তালিকায় নিয়মগুলির ক্রম পুনর্বিন্যাস করলে তাৎক্ষণিকভাবে তাদের মূল্যায়নের অগ্রাধিকার পরিবর্তিত হয়। শীর্ষের নিয়মগুলি প্রথমে মূল্যায়ন করা হয়।
- **ফাজি অনুসন্ধান**: রুলস ম্যানেজার এবং Omnibar-এ লাইভ ফিল্টারিং, যা শিরোনাম বা ম্যাচিং URL প্যাটার্ন দ্বারা নিয়মগুলির তাৎক্ষণিক অবস্থান সনাক্ত করতে দেয়।
- **JSON ইমপোর্ট / এক্সপোর্ট**:
  - মোড `add`: ডুপ্লিকেট বাদ দিয়ে বিদ্যমান সংগ্রহের সাথে ইমপোর্ট করা নিয়মগুলিকে একত্রিত করে।
  - মোড `overwrite`: স্কিমা যাচাইকরণের পরে সক্রিয় নিয়ম সংগ্রহকে ইমপোর্ট করা পেলোড দ্বারা সম্পূর্ণ প্রতিস্থাপন করে।
  - **গতিশীল নিয়ম তৈরি**: Chrome বুকমার্ক ফোল্ডার বা সাবগ্রুপ ডোমেন সংগ্রহ থেকে সরাসরি কাস্টম নিয়মের এক-ক্লিকে তৈরি।
- **নিয়ম ডুপ্লিকেশন অপসারণ (`feature_v100_dedup_add_to_rule`)**: বিদ্যমান কাস্টম নিয়মগুলিতে URL বা ডোমেন যোগ করার সময় স্বয়ংক্রিয়ভাবে ডুপ্লিকেট URL প্যাটার্নগুলি সরিয়ে দেয়, যা নিয়মের স্ফীতি এবং অপ্রয়োজনীয় মূল্যায়ন রোধ করে।

### 2.5 Operations & Persistence (`mutateRulesAndSync`)
- **কেন্দ্রীভূত মিউটেটর**: সমস্ত নিয়ম সংশোধন `src/core/background/handlers/rules.js`-এ `mutateRulesAndSync(mutateFn, sendResponse)`-এর মাধ্যমে পরিচালিত হয়। এটি স্টোরেজ সিঙ্ক্রোনাইজেশন, ইন-মেমরি ক্যাশ রিফ্রেশমেন্ট (`extensionSettings.customRules`), UI বিজ্ঞপ্তি (`rulesUpdated`), এবং স্বয়ংক্রিয় ট্যাব পুনরায় গ্রুপিং (`groupTabs()`) নিশ্চিত করে।
- **লাইভ যাচাইকরণ**: সংরক্ষণের আগে নামের অনন্যতা, দৈর্ঘ্য (১-১৬ অক্ষর), অক্ষর সীমাবদ্ধতা এবং বৈধ URL সিনট্যাক্সের জন্য রিয়েল-টাইম যাচাইকরণ পরীক্ষা করে।

### 2.6 Invocation Modalities
- **নিয়ম ব্যবস্থাপনা পেজ (`Rules.svelte`)**: ফুল-ট্যাব ভিউ বা সাইড প্যানেলে অ্যাক্সেসযোগ্য (`?view=rules` / `pg`)। সম্পূর্ণ ড্র্যাগ-অ্যান্ড-ড্রপ পুনর্বিন্যাস, ইনলাইন কালার পিকার, URL ট্যাগ চিপস এবং নিয়ম টগল সরবরাহ করে।
- **Omnibar কমান্ডসমূহ**:
  - `rl:` — নিয়ম অনুসন্ধান করুন এবং সংশ্লিষ্ট URL-গুলি খুলুন।
  - `cr: <name> [, url1, url2]` — কমান্ড বার থেকে সরাসরি একটি নতুন নিয়ম তৈরি করুন।
  - `atcr:` — একটি বিদ্যমান নিয়মে সক্রিয় ট্যাবের ডোমেন বা URL যোগ করুন।
  - `atr:` — একটি বিদ্যমান নিয়মে নির্বাচিত খোলা ট্যাব বা ম্যানুয়াল URL যোগ করুন।
  - `ccr:` — একটি কাস্টম নিয়মের রঙ পরিবর্তন করুন।
  - `dr:` — নিয়ম বা নিয়ম থেকে পৃথক URL মুছুন।
  - `er:` — একটি বিদ্যমান নিয়ম সম্পাদনা বা পুনঃনামকরণ করুন।
- **কনটেক্সট মেনুসমূহ**:
  - পেজে রাইট-ক্লিক -> "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa"।
  - পেজে রাইট-ক্লিক -> "Añadir a Regla Existente" -> নিয়ম নির্বাচন -> "Añadir Raíz del Sitio" / "Añadir URL Completa"।
  - পেজে রাইট-ক্লিক -> "Reglas" -> সক্রিয় অবস্থা টগল করুন, সমস্ত নিয়মের URL খুলুন, বা ম্যাচিং ট্যাবগুলি বন্ধ করুন।
- **কীবোর্ড শর্টকাটসমূহ**:
  - `Alt+R`: রুলস ম্যানেজার খুলুন।
  - `Alt+M`: একসাথে সমস্ত নিয়মের সক্রিয়করণ টগল করুন (`toggle-all-rules`)।

## 3. Section 2: Group Listing & Operations (Listar Grupos)

গ্রুপ তালিকা ভিউ ব্রাউজার ট্যাব গ্রুপ এবং পৃথক ট্যাবগুলি পরিদর্শন, ম্যানিপুলেট এবং পুনর্বিন্যাস করার জন্য একটি ইন্টারেক্টিভ ওয়ার্কস্পেস সরবরাহ করে।

### 3.1 UI Architecture
- **কম্পোনেন্ট স্ট্যাক**: `ListGroup.svelte`, `GroupCard.svelte`, `GroupActions.svelte`, `TabItem.svelte`, এবং `TabActions.svelte` দিয়ে নির্মিত।
- **কার্ড বৈশিষ্ট্য**: গ্রুপের শিরোনাম, রঙের ব্যাজ, ট্যাব সংখ্যা পিল, অ্যাকর্ডিয়ন সংকোচন/প্রসারণ টগল, কার্ড পিনিং এবং কাস্টমাইজযোগ্য অ্যাকশন বোতাম গ্রুপ প্রদর্শন করে।
- **ট্যাব আইটেম**: ট্যাবের ফ্যাভিকন (রঙিন ফলব্যাকসহ), শিরোনাম, শব্দযোগ্য অডিও ব্যাজ, মিউট নির্দেশক, সক্রিয় অবস্থা নির্দেশক এবং ট্যাব-ভিত্তিক অ্যাকশন (বন্ধ, ডুপ্লিকেট, পিন, স্প্লিট, ডিসকার্ড) প্রদর্শন করে।

### 3.2 Group Lifecycle & Behaviors
- **অ্যাকর্ডিয়ন নিয়ন্ত্রণ**: মসৃণ প্রসারণ এবং সংকোচন অবস্থা। ঐচ্ছিক স্বয়ংক্রিয়-অ্যাকর্ডিয়ন মোড একটি নতুন গ্রুপ প্রসারিত হলে নিষ্ক্রিয় গ্রুপগুলিকে স্বয়ংক্রিয়ভাবে সঙ্কুচিত করে।
- **নিষ্ক্রিয়তা অটো-সংকোচন আইডল টাইমার**:
  - ভিজ্যুয়াল বিশৃঙ্খলা কমাতে নিষ্ক্রিয় ট্যাব গ্রুপগুলিকে স্বয়ংক্রিয়ভাবে সঙ্কুচিত করে।
  - দুটি পৃথক থ্রেশহোল্ড: নিষ্ক্রিয় গ্রুপগুলি ১ মিনিট নিষ্ক্রিয়তার পরে সঙ্কুচিত হয় (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`), আর সক্রিয় গ্রুপটি ১৫ মিনিট নিষ্ক্রিয়তার পরে সঙ্কুচিত হয় (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`)। ০ থেকে ১৪৪০ মিনিট পর্যন্ত কনফিগারযোগ্য।
- **ইনলাইন পুনঃনামকরণ এবং গ্রেস পিরিয়ড**:
  - ব্যবহারকারীরা ব্রাউজার ট্যাব স্ট্রিপ বা UI-তে সরাসরি গ্রুপগুলির নাম পরিবর্তন করতে পারেন।
  - `GROUP_NAMING_GRACE_MS` (5000ms) ব্যবহারকারী সম্পাদনা করার সময় স্বয়ংক্রিয় পুনরায় গ্রুপিং বিরতি দেয়, যা টাইপ করার মাঝে শিরোনাম ওভাররাইট হওয়া প্রতিরোধ করে।
  - মূল্যায়নের সময় জিরো-উইডথ স্পেস (`\u200B`, `\u200C`, `\u200D`, `\u2060`, `\uFEFF`) বাদ দেওয়া হয়।
  - একটি স্বয়ংক্রিয়ভাবে তৈরি গ্রুপের নাম পরিবর্তন করলে তা ব্যবহারকারী-নামাঙ্কিত গ্রুপে রূপান্তরিত হয়, সংশ্লিষ্ট কাস্টম নিয়ম আপডেট হয় বা এটি স্থায়ী হিসেবে চিহ্নিত হয়।
- **ভিজ্যুয়াল গ্রুপ প্রিফিক্স নির্দেশক**:
  - গতিশীলভাবে স্ট্যাটাস প্রতীকগুলি সামনে যুক্ত করে: `🔒` (অপঠিত), `🔍` (আংশিক), `🗝️` (সব দেখা হয়েছে), `⚠️` (দ্বন্দ্ব)।
- **ড্র্যাগ-অ্যান্ড-ড্রপ পুনর্বিন্যাস**: গ্রুপের মধ্যে ট্যাব পুনর্বিন্যাস, গ্রুপগুলির মধ্যে ট্যাব স্থানান্তর বা গ্রুপ কার্ড পুনর্বিন্যাসের জন্য `sortable.js`-এর সাথে একীভূত।
- **হিডেন গ্রুপ বৈশিষ্ট্য**:
  - ব্রাউজার ট্যাব স্ট্রিপে গ্রুপের শিরোনামের আগে `_hidden_` যুক্ত করে।
  - প্রধান তালিকা ভিউ থেকে গ্রুপ কার্ডগুলি লুকিয়ে রাখে এবং সেগুলিকে `HiddenGroupsBar.svelte`-এ স্থানান্তর করে।
  - ব্যবহারকারীরা এক ক্লিকেই অবিলম্বে গ্রুপগুলি দৃশ্যমান বা পুনরুদ্ধার করতে পারেন।

### 3.3 Group Operations & Memory Management
- **Ungroup**: গ্রুপ ভেঙে দেয়, উইন্ডোতে ট্যাবগুলি খোলা রেখে।
- **Close Group**: গ্রুপের সমস্ত ট্যাব বন্ধ করে এবং গ্রুপ আইডি ছেড়ে দেয়।
- **Close Other Groups**: বর্তমানে ফোকাস করা গ্রুপ ব্যতীত অন্য সমস্ত ট্যাব গ্রুপ বন্ধ করে।
- **Regroup All Tabs (`Alt+Shift+R`)**: কাস্টম নিয়ম, সিস্টেম গ্রুপ এবং ডোমেন ক্লাস্টার জুড়ে একটি ব্যাপক পুনর্মূল্যায়ন চালায়।
- **Group Screenshot Walk**: ক্রমানুসারে গ্রুপের প্রতিটি ট্যাব ব্রাউজ করে এবং ক্যাপচার করে (`Cs` দৃশ্যমান, `Cp` সম্পূর্ণ পেজ, `CP` সম্পূর্ণ পেজের অংশসমূহ)।

### 3.4 Group Backups & Restore Subsystem
- **IndexedDB `backupsGroups` স্টোর**:
  - একক ট্যাব গ্রুপ বা সমস্ত খোলা গ্রুপের ওয়ার্কস্পেস-ব্যাপী স্ন্যাপশট IndexedDB `Intelligent_Workspace` স্টোর `backupsGroups`-এ ব্যাকআপ করে।
  - সম্পূর্ণ গ্রুপ কাঠামো ক্যাপচার করে: গ্রুপের শিরোনাম, রঙ, সংকুচিত অবস্থা, ট্যাবের শিরোনাম, URL, ফ্যাভিকন, পিন করা অবস্থা এবং আপেক্ষিক ট্যাব অবস্থান।
  - **মেমরি সংরক্ষণ**: সিস্টেম RAM পুনরুদ্ধার করতে এবং CPU ওভারহেড কমাতে ব্যাকআপ করা ট্যাবগুলি পরিষ্কারভাবে বন্ধ করা হয়।
  - **পুনরুদ্ধার প্রক্রিয়া**:
    - `ListGroup.svelte`-এ এক-ক্লিক গ্রুপ পুনরুদ্ধারের ব্যাকআপ UI ভিউ।
    - কীবোর্ড শর্টকাট `br` (পুনরুদ্ধার) এবং `bg` (সব ব্যাকআপ)।
    - Omnibar কমান্ড `bgr:` (ব্যাকআপ করা গ্রুপ অনুসন্ধান ও পুনরুদ্ধার) এবং `b:` (বুকমার্ক অনুসন্ধান)।
  - **JSON এক্সপোর্ট ও ইমপোর্ট**: মেশিনগুলির মধ্যে বিরামহীন স্থানান্তর এবং দীর্ঘমেয়াদী অফলাইন সংরক্ষণের জন্য সম্পূর্ণ JSON ব্যাকআপ এক্সপোর্ট ও ইমপোর্ট।

### 3.5 Parked YouTube Player in Hidden Groups Bar
- **আর্কিটেকচার (`HiddenGroupsBar.svelte`)**:
  - যখন কোনো ব্যবহারকারী একটি সক্রিয় YouTube ভিডিও ভিউ থেকে দূরে সরে যান বা সাইড প্যানেলের ভিতরে ভিডিও কনটেন্ট চালু করেন, প্লেয়ারটি বন্ধ বা হারিয়ে যায় না। এটি একটি পার্ক করা YouTube নির্দেশক (`.youtube-indicator`) হিসেবে স্বয়ংক্রিয়ভাবে `HiddenGroupsBar.svelte`-এ ডক করা হয়।
  - `src/ui/stores/appStore.svelte.js`-এ `hiddenYoutubeView` স্টোরের মাধ্যমে প্রতিক্রিয়াশীলভাবে পরিচালিত হয়।
  - **এক-ক্লিক অ্যাকশনসমূহ**:
    - পার্ক করা নির্দেশকে ক্লিক করলে `restoreYoutubeView()` কার্যকর হয়, যা প্লেয়ারটিকে অবিলম্বে সক্রিয় ওয়ার্কস্পেস ভিউতে ফিরিয়ে আনে।
    - ডিলিট ব্যাজে ক্লিক করলে `discardYoutubeView()` কার্যকর হয়, যা পরিষ্কারভাবে প্লেব্যাক বন্ধ করে এবং রিসোর্স মুক্ত করে।
  - সক্রিয় ট্যাবের তালিকাকে বিশৃঙ্খল না করে ListGroup ভিউয়ের শীর্ষে লুকানো ট্যাব গ্রুপগুলির পাশে নির্বিঘ্নে অবস্থান করে।

## 4. Section 3: Navigation & Tab Management (Navegación)

দ্রুত কীবোর্ড নেভিগেশন এবং ওয়ার্কস্পেস নিয়ন্ত্রণ মাউসের মিথস্ক্রিয়া ছাড়াই নির্বিঘ্নে বহু-ট্যাব নিয়ন্ত্রণের অনুমতি দেয়।

### 4.1 Fast Tab Jump Gesture
- **জেসচার সিনট্যাক্স**: `Alt + [groupPrefix] + [tabIndex] + Enter`
- **এক্সিকিউশন**:
  - `Alt` চেপে ধরে গ্রুপের নাম বা প্রিফিক্স অক্ষর টাইপ করুন, তারপরে কাঙ্ক্ষিত ১-ভিত্তিক ট্যাব ইনডেক্স লিখুন, তারপর `Enter` চাপুন।
  - উদাহরণ: `Alt + git + 2 + Enter` সরাসরি "GitHub" গ্রুপের দ্বিতীয় ট্যাবে চলে যায়।
  - ইনডেক্স `0` গ্রুপের *শেষ* ট্যাবের শর্টকাট হিসেবে কাজ করে।
  - ইনডেক্স বাদ দিলে গ্রুপের *প্রথম* ট্যাবে চলে যায়।
  - অ্যাকসেন্টগুলি স্বয়ংক্রিয়ভাবে সরলীকৃত হয় (`deaccent`) এবং ম্যাচিং ডায়াক্রিটিক্স স্বাভাবিক করে।

### 4.2 Stepping, Swapping & Lifecycle Keys
- `s`: অবিলম্বে পূর্বে সক্রিয় ট্যাবে অদলবদল করুন (`previousActiveTabId`)।
- `h` / `l`: পূর্ববর্তী / পরবর্তী ট্যাবে যান (অথবা পেজ অনুমতি দিলে অনুভূমিকভাবে স্ক্রোল করুন)।
- `H` / `L`: ব্রাউজার হিস্ট্রিতে পিছনে / সামনে নেভিগেট করুন।
- `t`: একটি নতুন ফাঁকা ট্যাব খুলুন।
- `x`: বর্তমান সক্রিয় ট্যাব বন্ধ করুন।
- `yt`: বর্তমান ট্যাবটি ডুপ্লিকেট করুন।
- `r` / `R`: পেজ রিলোড করুন / ক্যাশ বাইপাস করে ফোর্স রিলোড করুন।
- `d` / `u`: পেজের নিচে / উপরে স্ক্রোল করুন।
- `j` / `k`: মসৃণভাবে নিচে / উপরে স্ক্রোল করুন (75px ধাপ)।
- `f`: Vim লিঙ্ক হিন্ট সক্রিয় করুন (ক্লিকযোগ্য উপাদানগুলির উপর ক্লিক করার জন্য অক্ষর প্রদর্শিত হয়)।
- `cf`: ক্লিপবোর্ডে লক্ষ্য URL কপি করতে Vim লিঙ্ক হিন্ট সক্রিয় করুন।

### For power users

উন্নত ব্যবহারকারীরা ব্রাউজারটিকে ফুল-স্ক্রিন মোডে রাখতে পারেন এবং মাউস একেবারেই ব্যবহার না করে পুরোপুরি কীবোর্ড দিয়ে নেভিগেট করতে পারেন।

#### Full-Screen Immersion & Mouse-Free Browsing
- **ফুল-স্ক্রিন টগল করুন**: `F11` (Windows/Linux) বা `Command+Control+F` (macOS) চাপুন। ব্রাউজারের ক্রোম, অ্যাড্রেস বার, ট্যাব স্ট্রিপ এবং অপারেটিং সিস্টেম প্যানেলগুলি লুকিয়ে যায়, যা ডিসপ্লের ১০০% কনটেন্টের জন্য নিবেদিত করে।
- **ইন-পেজ Vim লিঙ্ক নেভিগেশন (`f` / `cf`)**:
  - DOM-এর প্রতিটি ক্লিকযোগ্য উপাদান, বোতাম, ইনপুট এবং লিঙ্কের উপর উচ্চ-কন্ট্রাস্টের দুই অক্ষরের হলুদ লিঙ্ক হিন্ট তৈরি করতে `f` চাপুন।
  - মাউস ছাড়া সরাসরি ক্লিক সিমুলেট করতে আপনার লক্ষ্যের সাথে মিলে যাওয়া দুটি অক্ষর টাইপ করুন।
  - লক্ষ্য লিঙ্কের URL সরাসরি আপনার সিস্টেম ক্লিপবোর্ডে কপি করতে হিন্ট ব্যাজ ট্রিগার করতে `cf` চাপুন।
  - লক্ষ্য লিঙ্কের একটি ইন-পেজ প্রিভিউ মোডাল খুলতে `vp` চাপুন।
  - লিঙ্ক হিন্ট বাতিল করতে এবং সাধারণ স্ক্রোলিংয়ে ফিরে যেতে যে কোনো সময় `Esc` চাপুন।
- **তাৎক্ষণিক ট্যাব জাম্পিং ও স্যুইচিং**:
  - `Alt + [groupPrefix] + [tabIndex] + Enter`: Fast Tab Jump জেসচার কার্যকর করুন (যেমন, `Alt + dev + 1 + Enter` সরাসরি "Dev" গ্রুপের প্রথম ট্যাবে চলে যায়; ইনডেক্স `0` গ্রুপের শেষ ট্যাবটি নির্বাচন করে)।
  - `s`: বর্তমান ট্যাব এবং পূর্বে সক্রিয় ট্যাবের মধ্যে তাৎক্ষণিকভাবে অদলবদল করুন (`previousActiveTabId`)।
  - `h` / `l`: ট্যাব স্ট্রিপে ক্রমানুসারে পূর্ববর্তী / পরবর্তী ট্যাবে যান।
  - `H` / `L`: ব্রাউজার নেভিগেশন হিস্ট্রির মাধ্যমে পিছনে / সামনে যান।
  - `t` / `x` / `yt`: নতুন ট্যাব খুলুন (`t`), বর্তমান ট্যাব বন্ধ করুন (`x`), বা ট্যাব ডুপ্লিকেট করুন (`yt`)।
- **ভাসমান Omnibar কমান্ড সাবসিস্টেম (`o`)**:
  - কেন্দ্রস্থলে অবস্থিত Omnibar ওভারলে আহ্বান করতে যে কোনো পেজে `o` চাপুন।
  - সমস্ত ৪১টি কমান্ড উপসর্গের ইন্টারেক্টিভ ডিরেক্টরি প্রদর্শন করতে `@` চাপুন।
  - সমস্ত খোলা উইন্ডো জুড়ে গভীর ফুল-টেক্সট ট্যাব অনুসন্ধান চালাতে `f: <query>` টাইপ করুন।
  - যে কোনো সাইডপ্যানেল ভিউতে (`rules`, `listgroup`, `notes`, `gallery`, `gemini`, `activity`, `themes`, `hints`, `downloads`) সরাসরি নেভিগেশন রুট করতে `sp:` টাইপ করুন।
  - কীবোর্ড থেকে হাত না সরিয়েই Gemini-কে প্রশ্ন করতে বা স্বায়ত্তশাসিত ব্রাউজার এজেন্টকে নির্দেশ দিতে `qai: <query>` বা `qaia: <task>` টাইপ করুন।
  - খোলা ট্যাবগুলিকে পাশাপাশি স্প্লিট স্ক্রিনে ভাগ করতে `ts:` টাইপ করুন।
- **ইন-পেজ নেভিগেশন ও ফোকাস**:
  - `j` / `k`: মসৃণভাবে নিচে / উপরে স্ক্রোল করুন (75px বৃদ্ধি)।
  - `d` / `u`: অর্ধ-পৃষ্ঠা নিচে / উপরে স্ক্রোল করুন।
  - `i`: কার্সার ফোকাস অবিলম্বে পেজের প্রাথমিক টেক্সট ইনপুট ফিল্ডে নিয়ে যান।
  - `ESC`: ইনপুট আনফোকাস করুন এবং কীবোর্ড ফোকাস নেভিগেশন মোডে ফিরিয়ে আনুন।

### 4.3 Audio & Sound Management
- অডিও বাজানো ট্যাবগুলি ListGroup UI-তে একটি স্পিকার ব্যাজ প্রদর্শন করে।
- `st`: বর্তমান সক্রিয় ট্যাবে নিঃশব্দ (মিউট) টগল করুন।
- `so`: সমগ্র ব্রাউজার জুড়ে সমস্ত শব্দযুক্ত ট্যাব মিউট করুন।
- কনটেক্সট মেনু: "Silenciar Todas las Pestañas" / "Reactivar Sonido en Todas las Pestañas"।

### 4.4 Split Screen Workflows
- **ট্রিগার**: Vim হিন্ট `ts` বা Omnibar প্রিফিক্স `ts:`।
- **আচরণ**: স্ক্রিন জ্যামিতি গণনা করতে `chrome.system.display` ব্যবহার করে। দুটি ট্যাবকে পাশাপাশি সংলগ্ন উইন্ডোতে বিভক্ত করে, সেগুলিকে একটি নিবেদিত `Split` ট্যাব গ্রুপের অধীনে রাখে।
- **পুনরুদ্ধার**: বিভক্ত উইন্ডো বন্ধ করা বা স্প্লিট স্ক্রিন টগল করা মূল উইন্ডোর মাত্রা এবং স্থানাঙ্ক পুনরুদ্ধার করে।

### 4.5 YouTube Looping Subsystem
YouTube লুপিং সাবসিস্টেম সরাসরি YouTube প্লেয়ারে সমন্বিত সুনির্দিষ্ট মিডিয়া লুপিং নিয়ন্ত্রণ সরবরাহ করে:
- **ডেস্কটপ প্লেয়ার বোতাম (`#itg-yt-loop-button`)**: স্ট্যান্ডার্ড YouTube প্লেয়ার কন্ট্রোল বারে (`.ytp-right-controls`) ইনজেক্ট করা হয়, যা Cast / Remote বোতাম বা PiP লঞ্চারের বাম দিকে অবস্থান করে। অ্যানিমেটেড SVG লুপিং গ্লিফ, টগল হাইলাইট স্টাইলিং (`ytp-loop-active`, `var(--interactive-color, #ff4444)`), এবং `aria-pressed` বৈশিষ্ট্যযুক্ত।
- **Shorts প্লেয়ার বোতাম (`#itg-yt-shorts-loop-button`)**: YouTube Shorts ডানদিকের নিয়ন্ত্রণ কলামে (`ytd-shorts`) `#itg-yt-shorts-loop-wrapper`-এর ভিতরে ইনজেক্ট করা হয়, যা উল্লম্ব ভিডিও কনটেন্টের জন্য এক-ক্লিক লুপিং সরবরাহ করে।
- **লুপ মেনু ও PiP পপআপ (`#itg-yt-loop-menu` ও `#itg-pip-loop-popup`)**: লুপ বোতামে হোভার বা ক্লিক করলে ব্যাপক লুপ সেটিংস মেনু খোলে:
  - **A-B লুপিং**: ব্যবহারকারীরা ইন্টারেক্টিভ রেঞ্জ স্লাইডার এবং ম্যানুয়াল সময় ফিল্ডের সাহায্যে মিলিসেকেন্ড নির্ভুলতায় কাস্টম শুরুর বিন্দু (A) এবং শেষ বিন্দু (B) সেট করতে পারেন।
  - **সাইকেল মোড ও সিকোয়েন্স পুনরাবৃত্তি**: নির্দিষ্ট লুপের জন্য পুনরাবৃত্তির সংখ্যা সেট করুন বা অসীম লুপ মোড টগল করুন (`itg-loop-seq-inf`)।
  - **লুপ তালিকা ও বহু-সেগমেন্ট সিকোয়েন্স**: একাধিক A-B লুপ ব্যবধান সারিবদ্ধ করুন যা কনফিগার করা পুনরাবৃত্তি অনুসারে পর্যায়ক্রমে প্লে হয়।
  - **স্ট্যাটাস ও সময়কাল প্রদর্শন**: বর্তমান লুপ ব্যবধানের মধ্যে রিয়েল-টাইম প্লেব্যাক অবস্থান এবং মোট মিডিয়া সময়কাল প্রদর্শন করে (`00:00 / 00:00`)।
  - **মাস্টার টগল (`youtubeLoopEnabled`)**: `chrome.storage.sync` এবং `local`-এ সংরক্ষিত থাকে, যা ব্যবহারকারীদের কাস্টমাইজ হিন্টস সেটিংস পেজের (`YoutubeLoopSection.svelte`) মাধ্যমে YouTube এবং YouTube Shorts জুড়ে লুপ বোতামগুলি সক্ষম বা নিষ্ক্রিয় করতে দেয়।

### 4.6 YouTube Shorts Preview Audio
- **অডিও আনমিউট হুক (`youtubePreviewAudioHook.js`)**:
  - `ytd-video-preview` উপাদানগুলির `#inline-preview-player` বৈশিষ্ট্য অ্যাক্সেস করতে `MAIN` এক্সিকিউশন ওয়ার্ল্ডে চলে।
  - **জোরপূর্বক মিউট অতিক্রম করা**: YouTube অডিও নিয়ন্ত্রণ মুছে ফেলে এবং অভ্যন্তরীণ `volumechange` লিসেনারের মাধ্যমে `muted = true` পুনরুদ্ধার করে Shorts প্রিভিউতে জোরপূর্বক মিউট প্রয়োগ করে।
  - এক্সটেনশনটি হোভার করার সময় লক্ষ্য `<video>` উপাদানে `HTMLMediaElement.prototype.muted` প্রপার্টি ডেসক্রিপ্টর হুক করে। এটি ব্যবহারকারীর আনমিউটিং অনুমোদন করার সাথে সাথে YouTube-এর জোরপূর্বক পুনরায় মিউট করাকে বাতিল করে, যার ফলে মাউস সরিয়ে না নেওয়া পর্যন্ত লুপ পুনরায় শুরুর পরেও কোনো বাধা ছাড়াই অডিও একটানা বাজতে পারে।

### 4.7 Picture-in-Picture (PiP) Architecture
- **ডকুমেন্ট পিকচার-ইন-পিকচার (`wp`)**:
  - সর্বদা শীর্ষে থাকা একটি ভাসমান উইন্ডোর ভিতরে সম্পূর্ণ ওয়েবপেজ বা টেক্সট স্নিপেট খুলতে আধুনিক `documentPictureInPicture` API ব্যবহার করে।
  - মিডিয়া স্থানান্তর করার সময় স্বয়ংক্রিয়ভাবে ভিডিও প্লেব্যাক টাইমস্ট্যাম্প সিঙ্ক করে।
  - পুনরায় চেষ্টা করার যুক্তি (`itgRetryIfPipFrameRefused`) অন্তর্ভুক্ত এবং বন্ধ করার সময় DNR আইফ্রেম হেডারগুলি পরিষ্কার করে।
- **ভিডিও পিকচার-ইন-পিকচার (`wv`)**:
  - `videoPipHook.js`-এর মাধ্যমে `HTMLVideoElement.prototype.requestPictureInPicture` হুক করে।
  - লুপ কন্ট্রোল এবং প্লেব্যাক স্পিড সিলেক্টর সহ কাস্টম PiP ফ্রেমে ভিডিও প্লেয়ারগুলিকে পুনঃনির্দেশিত করে।
- **Auto-PiP**:
  - `as`: স্ক্রোল করার সময় Auto-PiP টগল করুন (ভিউোর্টের বাইরে স্ক্রোল করলে ভিডিও PiP-তে চালু হয়)।
  - `ah`: ট্যাব লুকানোর সময় Auto-PiP টগল করুন (অন্য ট্যাবে স্যুইচ করার সময় ভিডিও PiP-তে চালু হয়)।

### 4.8 Page Reading Modes & Visual Overlays
- **CSS ফিল্টার থিম**: ওয়েব পেজে অবিনাশী স্টাইল ইনজেক্ট করে:
  - `mb` / `mB`: কালো (ডার্ক হাই-কন্ট্রাস্ট) — ট্যাব স্কোপ / গ্লোবাল স্কোপ।
  - `ms` / `mS`: সেপিয়া (উষ্ণ কাগজ) — ট্যাব স্কোপ / গ্লোবাল স্কোপ।
  - `mp` / `mP`: কাগজ (মনোক্রোম গ্রেস্কেল) — ট্যাব স্কোপ / গ্লোবাল স্কোপ।
  - `ml` / `mL`: হালকা (নরম সাদা) — ট্যাব স্কোপ / গ্লোবাল স্কোপ।
  - `me` / `mE`: কাস্টম ব্যবহারকারী-সংজ্ঞায়িত CSS ফিল্টার — ট্যাব স্কোপ / গ্লোবাল স্কোপ।
  - `ESC`: সক্রিয় পেজ ফিল্টার অবিলম্বে সরিয়ে দেয়।
- **রিডার মোড ও TTS রিড অ্যালাউড**:
  - `fetchContentForReaderView`: বিজ্ঞাপন, সাইডবার এবং অপ্রয়োজনীয় নেভিগেশন সরিয়ে পরিষ্কার নিবন্ধ বিষয়বস্তু বের করে আনে।
  - বাক্য ধরে ধরে উচ্চস্বরে টেক্সট পাঠ করার জন্য অন্তর্নির্মিত টেক্সট-টু-স্পিচ (TTS) ইঞ্জিন।
  - কীবোর্ড নেভিগেশন নিয়ন্ত্রণ: `zp` (প্লে/পজ), `zn` (পরবর্তী বাক্য), `zb` (পূর্ববর্তী বাক্য), `zq` (রিডার ওভারলে বন্ধ)।

### 4.9 Text Snippets Subsystem with Template Variables
টেক্সট স্নিপেট সাবসিস্টেম (`src/utils/hint/snippets.js` এবং `src/utils/snippet-panel.js`-এ `SnippetManager`) যে কোনো ইনপুট, টেক্সটএরিয়া বা রিচ এডিটরে টেক্সট শর্টকাট প্রসারিত করে টাইপিং ত্বরান্বিত করে:
- **ট্রিগার মোডালিটি**: শর্টকাট টাইপ করে স্পেস চাপুন, অথবা ইন্টারেক্টিভ স্নিপেট সার্চ পপআপ কল করতে `$$` টাইপ করুন।
- **ক্লিপবোর্ড API ইন্টিগ্রেশন**: ক্লিপবোর্ড API-এর মাধ্যমে ফরম্যাট করা HTML এবং প্লেইন টেক্সট সন্নিবেশ সমর্থন করে, যা Google Docs, Notion এবং Slack-এর মতো জটিল এডিটরগুলির সাথে শতভাগ সামঞ্জস্য নিশ্চিত করে।
- **টেমপ্লেট ভেরিয়েবলসমূহ**: সম্প্রসারণের মুহূর্তে গতিশীলভাবে ভেরিয়েবল সমাধান করে:
  - `{{date}}` / `date`: ফরম্যাট করা স্থানীয় তারিখ (`toLocaleDateString`)।
  - `{{isodate}}` / `isodate`: ISO 8601 তারিখ (`YYYY-MM-DD`)।
  - `{{longdate}}` / `longdate`: বার, দিন, মাস এবং বছরসহ দীর্ঘ তারিখ।
  - `{{time}}` / `time`: ২-সংখ্যার ফরম্যাট করা সময় (`HH:MM`)।
  - `{{datetime}}` / `datetime`: তারিখ এবং সময় একত্রিত।
  - `{{weekday}}` / `weekday`: বারের পুরো নাম (যেমন, Monday)।
  - `{{day}}` / `day`: মাসের দিন (১-৩১)।
  - `{{month}}` / `month`: মাসের পুরো নাম (যেমন, October)।
  - `{{year}}` / `year`: সম্পূর্ণ ৪-সংখ্যার বছর।
  - `{{tomorrow}}` / `tomorrow`: পরবর্তী দিনের তারিখ (+১ দিন)।
  - `{{yesterday}}` / `yesterday`: পূর্ববর্তী দিনের তারিখ (-১ দিন)।
  - `{{nextweek}}` / `nextweek`: ৭ দিন পরের তারিখ (+৭ দিন)।
  - `{{timestamp}}` / `timestamp`: ইপোক মিলিসেকেন্ড টাইমস্ট্যাম্প (`Date.now()`)।
  - `{{url}}` / `url`: সক্রিয় ওয়েবপেজের URL (`window.location.href`)।
  - `{{domain}}` / `domain`: সক্রিয় ডোমেন হোস্টনেম (`window.location.hostname`)।
  - `{{pagetitle}}` / `pagetitle`: সক্রিয় ডকুমেন্টের শিরোনাম (`document.title`)।
  - `{{uuid}}` / `uuid`: ক্রিপ্টোগ্রাফিকভাবে সুরক্ষিত অনন্য শনাক্তকারী (`crypto.randomUUID()`)।
  - `{{random}}` / `random`: ১ থেকে ১০০০ এর মধ্যে দৈব পূর্ণসংখ্যা।
  - `{{clipboard}}` / `clipboard`: সিস্টেম ক্লিপবোর্ড বাফার টেক্সট।

### 4.10 Embedded Productivity Tools
- **অ্যালো রাইট ক্লিক হুক (`allowRightClickHook.js`)**:
  - রাইট-ক্লিক কনটেক্সট মেনু, কপি, কাট বা টেক্সট নির্বাচন নিষ্ক্রিয় করে এমন প্রতিকূল ওয়েব স্ক্রিপ্টগুলিকে নিরপেক্ষ করতে `MAIN` এক্সিকিউশন ওয়ার্ল্ডে ইনজেক্ট করা হয়।
  - `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown`, এবং `mouseup`-এ `preventDefault()` এবং `stopPropagation()` ইন্টারসেপ্ট করে।
  - একটি স্থায়ী `MutationObserver`-এর মাধ্যমে ইনলাইন `oncontextmenu="return false"` হ্যান্ডলারগুলি মুছে ফেলে।
  - বৈধ ওয়েব এডিটরদের (Google Docs, Telegram Web) নষ্ট হওয়া রোধ করতে ক্লিপবোর্ড পেলোড যাচাই করে।
- **কুকি এডিটর**: সক্রিয় ডোমেনের জন্য HTTP এবং HTTPS কুকিজ পরিদর্শন, সম্পাদনা, তৈরি এবং মুছে ফেলার ইন-পেজ মোডাল।
- **QR কোড জেনারেটর**: দ্রুত মোবাইল স্থানান্তরের জন্য সক্রিয় ট্যাব URL-এর জন্য SVG/Canvas QR কোড তৈরি করে।
- **পরিচ্ছন্ন PDF প্রিন্ট এক্সপোর্ট**: পরিষ্কার ডকুমেন্ট সংরক্ষণের জন্য হেডার, বিজ্ঞাপন এবং নেভিগেশনাল নয়েজ সরিয়ে `print.html`-এর মাধ্যমে লক্ষ্য পেজগুলিকে রুট করে।

### 4.11 Comprehensive 3-Tier Duplicate Removal & Intelligent Discarding
- **সর্বাঙ্গীণ ৩-স্তরবিশিষ্ট ডুপ্লিকেট অপসারণ**:
  1. **ট্যাব ডুপ্লিকেট অপসারণ (`removeDuplicateTabsCommand`)**: উইন্ডো বা ফোকাস করা গ্রুপ জুড়ে খোলা ট্যাবগুলি স্ক্যান করে, ডুপ্লিকেট URL শনাক্ত করে, `Split` স্ক্রিন ট্যাবগুলিকে অব্যাহতি দেয় এবং সক্রিয় বা প্রাচীনতম ট্যাবটি রেখে অপ্রয়োজনীয় ট্যাবগুলি বন্ধ করে। একটি ডেস্কটপ সংক্ষিপ্ত বিজ্ঞপ্তি প্রদর্শন করে।
  2. **বুকমার্ক ডুপ্লিকেট অপসারণ**: Chrome বুকমার্ক ট্রি গভীরভাবে স্ক্যান করে, ফোল্ডার জুড়ে অভিন্ন URL ডুপ্লিকেট শনাক্ত করে এবং বুকমার্ক পরিষ্কার রাখতে ব্যাচ একত্রীকরণ প্রদান করে।
  3. **নিয়ম ডুপ্লিকেট অপসারণ (`feature_v100_dedup_add_to_rule`)**: বিদ্যমান কাস্টম গ্রুপিং নিয়মগুলিতে URL যোগ করার সময় স্বয়ংক্রিয়ভাবে ডুপ্লিকেট URL প্যাটার্নগুলি সরিয়ে দেয়, যা নিয়মের অযাচিত বৃদ্ধি রোধ করে।
- **বুদ্ধিমান মেমরি ডিসকার্ডিং (`suspendInactiveTabsIntelligently`)**:
  - অ্যালার্ম `itg-periodic-tasks`-এর মাধ্যমে প্রতি ১ মিনিটে মূল্যায়ন করা হয়।
  - `>= discardingTimeMinutes` (ডিফল্ট: ৬০ মিনিট) নিষ্ক্রিয় থাকা ট্যাবগুলি বাতিল (ডিসকার্ড) করে।
  - অন্তর্নির্মিত অনাক্রম্যতা সুরক্ষা: সক্রিয় ট্যাব, অডিও বাজানো ট্যাব, পিন করা ট্যাব বা ইতিমধ্যে স্থগিত ট্যাবগুলিকে কখনই বাতিল করে না।

## 5. Section 4: AI Assistant & Autonomous Agent (Asistente AI)

এআই অ্যাসিস্ট্যান্ট প্রাসঙ্গিক বোধগম্যতা, স্বয়ংক্রিয় ওয়ার্কফ্লো এবং সরাসরি ব্রাউজার অটোমেশন সরবরাহ করতে ব্রাউজারে লার্জ ল্যাঙ্গুয়েজ মডেলগুলিকে সংহত করে।

### 5.1 Dual Model Engine Architecture
1. **Google Gemini Cloud API (`gemini-api.js`)**:
   - Google Generative Language REST এন্ডপয়েন্টগুলির সাথে সংহত (`v1beta/models/{model}:generateContent` এবং `:streamGenerateContent`)।
   - Gemini 2.5 Flash, Gemini 2.5 Pro, এবং কাস্টম মডেল এন্ডপয়েন্ট সমর্থন করে।
   - **মাল্টি-কি রোটেশন**: `geminiApiKeysList`-এ কি পুল পরিচালনা করে। স্টোরেজ অস্পষ্টকরণ `enc_` উপসর্গ ব্যবহার করে।
   - **এক্সপোনেনশিয়াল ব্যাকঅফ**: স্বয়ংক্রিয় ব্যাকঅফ পুনরায় চেষ্টার মাধ্যমে HTTP 429 কোটা সমাপ্তি পরিচালনা করে (১.৫ সেকেন্ড -> ৩ সেকেন্ড -> ৬ সেকেন্ড)।
   - **সার্চ গ্রাউন্ডিং**: Google Search Grounding সক্ষম করে (`google_search: {}`)। সার্চ টুলে কোটা সীমাবদ্ধতার কারণে HTTP 403 ঘটলে এটি স্বয়ংক্রিয়ভাবে গ্রাউন্ডিং ছাড়াই পুনরায় চেষ্টা করে।
2. **Chrome Built-in AI / Prompt API (`localAiService.js`)**:
   - `window.LanguageModel`-এর মাধ্যমে অন-ডিভাইস Gemini Nano ইন্টিগ্রেশন।
   - নেটওয়ার্কবিহীন শূন্য-সংযোগ স্থানীয় সম্পাদন সমর্থন করে। মডেলের প্রাপ্যতা পরীক্ষা এবং লাইভ ডাউনলোড অগ্রগতি ট্র্যাকিং অন্তর্ভুক্ত।

### 5.2 Autonomous Browser Agent (`agent-backend.js`)
স্বায়ত্তশাসিত এজেন্টটি ৪০টিরও বেশি কাঠামোগত টুলের মাধ্যমে সম্পূর্ণ ব্রাউজার নিয়ন্ত্রণ প্রদান করে:
- **ট্যাব ও গ্রুপ নিয়ন্ত্রণ**: `getOpenTabs`, `switchToTab`, `createNewTab`, `closeTab`, `closeTabs`, `duplicateTab`, `findAndSwitchToTab`, `groupTabs`, `ungroupTabs`, `deleteTabGroup`, `collapseTabGroup`, `expandTabGroup`, `collapseAllGroups`, `expandAllGroups`, `setGroupColor`, `renameTabGroup`, `regroupAllTabs`, `removeDuplicateTabs`, `closeTabsWithSound`।
- **নেভিগেশন ও অনুসন্ধান**: `openUrl`, `searchGoogle`, `getActiveTab`, `getActiveTabContent`।
- **জ্ঞান ও বুকমার্ক**: `getBookmarks`, `searchBookmarks`, `createBookmark`, `getHistory`, `getRecentlyClosed`।
- **নিয়ম ও রূপ**: `getRules`, `createRule`, `updateRule`, `deleteRule`, `getActiveTheme`, `getSavedThemes`, `applyTheme`।

### 5.3 Taint Tracking & Prompt Injection Defense
অবিশ্বস্ত ওয়েব পেজ থেকে পরোক্ষ প্রম্পট ইনজেকশন আক্রমণ নিষ্ক্রিয় করতে এজেন্ট ব্যাকএন্ড কঠোর টেইন্ট ট্র্যাকিং প্রয়োগ করে:
- **টেইন্ট চিহ্নিতকরণ**: `getActiveTabContent` কল করলে একটি ওয়েব পেজ থেকে টেক্সট বের করা হয় এবং বর্তমান এক্সিকিউশন রানকে টেইন্টেড বা কলুষিত হিসেবে চিহ্নিত করা হয় (`taintedAgentRuns.add(runId)`)।
- **ইগ্রেস গার্ড**: কলুষিত রানগুলিকে বহির্গমন টুল (`AGENT_EGRESS_TOOLS`) আহ্বান করা থেকে কঠোরভাবে নিষিদ্ধ করা হয়:
  * `openUrl`, `searchGoogle`, `createBookmark`, `createRule`, `addUrlToRule`, `createSiteShortcut`, `updateSiteShortcut`, `updateRule`।
- **প্রত্যাখ্যান প্রক্রিয়া**: একটি অনির্ধারিত ব্যতিক্রম নিক্ষেপ করার পরিবর্তে ইঞ্জিন একটি কাঠামোগত নিরাপত্তা ব্যাখ্যা প্রদান করে। এলএলএম তখন ব্যবহারকারীকে জানায় যে স্পষ্ট ব্যবহারকারীর সম্মতি ছাড়া বাহ্যিক ডেটা পাচার করা যাবে না।

### 5.4 Scheduled Gemini Queries Subsystem (`GeminiScheduleModal.svelte`)
- **ব্যাকগ্রাউন্ড এক্সিকিউশন ইঞ্জিন**:
  - `chrome.alarms` (`gemini-scheduled-*`)-এর মাধ্যমে ব্যাকগ্রাউন্ড সার্ভিস ওয়ার্কারের মধ্যে সরাসরি নির্ধারিত এআই প্রম্পট সম্পাদন স্বয়ংক্রিয় করে।
  - প্রতিদিন ৬টি পর্যন্ত নির্ধারিত কোয়েরি সমর্থন করে (`MAX_TIMES = 6`)।
  - **শিডিউল মোডসমূহ**:
    - পুনরাবৃত্তিমূলক শিডিউল: সপ্তাহের নির্বাচিত দিনগুলিতে বারবার কার্যকর হয় (`selectedDays`)।
    - এককালীন শিডিউল: একটি নির্দিষ্ট লক্ষ্য তারিখ এবং সময়ে কার্যকর হয় (`formDate`)।
  - **প্রম্পট সীমাবদ্ধতা**: রিয়েল-টাইম অক্ষর কাউন্টার সহ একটি কঠোর ১,০০০-অক্ষরের প্রম্পট সীমা প্রয়োগ করে (`MAX_QUERY_CHARS = 1000`)।
  - **ব্যাকগ্রাউন্ড নোটিফিকেশন**: ব্যাকগ্রাউন্ড কোয়েরি শেষ হলে একটি স্নিপেট প্রিভিউ সহ একটি ডেস্কটপ বিজ্ঞপ্তি পাঠায়। বিজ্ঞপ্তিতে ক্লিক করলে সাইডপ্যানেল চ্যাটের ভিতরে তাৎক্ষণিকভাবে রেসপন্স থ্রেডটি খুলে যায়।

### 5.5 Gemini Conversation Management & Export
- **স্থায়ী IndexedDB স্টোরেজ (`geminiConversations`)**: বহু-ধাপের চ্যাট সেশনগুলি IndexedDB `Intelligent_Workspace` স্টোর `geminiConversations`-এ সংরক্ষিত হয়।
- **ফুল-টেক্সট হিস্ট্রি অনুসন্ধান**: Omnibar কমান্ড `lai:` (কথোপকথন ব্রাউজ) এবং `laiq:` (বার্তা অনুসন্ধান)-এর মাধ্যমে অতীতের সমস্ত কথোপকথন এবং পৃথক বার্তা জুড়ে তাৎক্ষণিক অনুসন্ধান।
- **চারটি এক্সপোর্ট ফরম্যাট**:
  1. **স্টাইলযুক্ত HTML**: স্টাইলযুক্ত কথোপকথন বাবল, ভূমিকা ব্যাজ, টাইমস্ট্যাম্প এবং সিনট্যাক্স-হাইলাইট করা কোড ব্লক সহ ফরম্যাট করা স্বতন্ত্র HTML ডকুমেন্ট।
  2. **র JSON**: বার্তা অ্যারে, টোকেন ব্যবহার, মডেল কনফিগারেশন এবং অনুসন্ধান উদ্ধৃতি সহ সম্পূর্ণ কাঠামোগত ডেটা ডাম্প।
  3. **Markdown**: হেডার, টাইমস্ট্যাম্প এবং ফেন্সড কোড ব্লক (` ``` `) সহ ফরম্যাট করা স্ট্যান্ডার্ড Markdown ফাইল।
  4. **প্লেইন টেক্সট**: ইমেল বা নোটের জন্য উপযুক্ত পরিষ্কার, আনফরম্যাট করা কথোপকথনের প্রতিলিপি।
- **গ্রাউন্ডিং মেটাডেটা ট্র্যাকিং**: মডেল আইডি, টোকেন ব্যবহারের পরিসংখ্যান, সম্পাদনের টাইমস্ট্যাম্প এবং Google Search Grounding দ্বারা প্রত্যাবর্তিত উৎস উদ্ধৃতি ট্র্যাক করে।

### 5.6 Multimodal Inputs & File Attachments (`feature_geminiAttachFiles`)
- **মাল্টিমোডাল সংযুক্তি**: টগল `feature_geminiAttachFiles` চ্যাট প্রম্পটে সরাসরি ছবি এবং ডকুমেন্ট সংযুক্তি সক্ষম করে:
  - ইমেজ ফাইল (JPEG, PNG, WebP, HEIC/HEIF)।
  - PDF ডকুমেন্ট এবং গবেষণাপত্র।
  - প্লেইন টেক্সট ফাইল এবং কোড ফাইল।
  - CSV কাঠামোগত ডেটাসেট।
- **ভয়েস সাপোর্ট**:
  - হাত ব্যবহার না করে প্রম্পট ডিক্টেট করার জন্য Web Speech STT (স্পিচ-টু-টেক্সট)।
  - প্রতিক্রিয়া উচ্চস্বরে পড়ার জন্য Web Speech TTS (টেক্সট-টু-স্পিচ)।

### 5.7 Invocation Modalities
- **সাইডপ্যানেল রুট**: `?view=gemini` বা শর্টকাট `pa`।
- **ইন-পেজ Omnibar প্রিফিক্স**:
  - `qai: <query>` — কনফিগার করা Gemini মডেলকে সরাসরি প্রশ্ন জিজ্ঞাসা করুন।
  - `qaia: <prompt>` — টুল এক্সিকিউশন সহ স্বায়ত্তশাসিত এজেন্টের মাধ্যমে প্রম্পট কার্যকর করুন।
  - `lai:` — অতীতের এআই কথোপকথন ব্রাউজ করুন।
  - `laiq:` — এআই কথোপকথনের সমস্ত বার্তার মধ্যে সম্পূর্ণ টেক্সট অনুসন্ধান করুন।
- **Omnibox এআই ট্যাব অনুসন্ধান (`find <query>`)**:
  - URL বার কীওয়ার্ড `find` হাইব্রিড অনুসন্ধান শুরু করে।
  - প্রাকৃতিক ভাষার কোয়েরির ভিত্তিতে খোলা ট্যাবগুলি সনাক্ত এবং ফোকাস করতে Gemini শব্দার্থিক সমাধানের সাথে রেজেক্স শব্দ-সীমানা স্কোরিংকে একত্রিত করে।

## 6. Section 5: Notes View & Knowledge Management (Ver Notas)

ব্রাউজার ট্যাব গ্রুপ এবং নেভিগেশন প্রসঙ্গের সাথে সংযুক্ত একটি স্থানীয়-প্রথম, প্রসঙ্গ-সচেতন নোট গ্রহণ ইঞ্জিন।

### 6.1 Storage Architecture (`notesStore`)
IndexedDB ডাটাবেস `Intelligent_Workspace` (v8)-এর অবজেক্ট স্টোর `notesStore`-এ সংরক্ষিত:
```typescript
interface NoteRecord {
  id: string;          // Unique note identifier.
  title: string;       // Note title.
  text: string;        // Rich text HTML, Markdown, or serialized task payload.
  type: NoteType;      // 'text' | 'checklist' | 'kanban'
  url?: string;        // Origin URL where note was created.
  contextKey: string;  // Scoping key binding note to workspace hierarchy.
  createdAt: number;   // Creation timestamp.
  modifiedAt: number;  // Last edit timestamp.
  isPersistent: boolean; // Pin flag protecting note from group deletion cleanup.
}
```

### 6.2 Specialized Note Formats & Advanced Rendering
1. **টেক্সট নোট (`NoteTextEditor.svelte`)**:
   - রিচ টেক্সট `contenteditable` সারফেস।
   - সরাসরি মিডিয়া এম্বেড করে: ছবি, অডিও, ভিডিও এবং PDF ডকুমেন্ট।
   - অন্তর্নির্মিত HTML স্যানিটাইজেশন এবং রিয়েল-টাইম শব্দ ও অক্ষর কাউন্টার।
   - **Mermaid ডায়াগ্রাম রেন্ডারিং**: Markdown ফেন্স (` ```mermaid `) থেকে সরাসরি ডায়নামিক ফ্লোচার্ট, সিকোয়েন্স ডায়াগ্রাম, ক্লাস ডায়াগ্রাম এবং স্টেট মেশিন রেন্ডার করে।
   - **KaTeX গাণিতিক LaTeX**: উচ্চ নির্ভুলতার টাইপোগ্রাফি সহ ইনলাইন সমীকরণ (`$...$`) এবং ব্লক সমীকরণ (`$$...$$`) রেন্ডার করে।
2. **চেকলিস্ট নোট (`NoteChecklistEditor.svelte`)**:
   - স্বতন্ত্র সমাপ্তি চেকবক্স সহ ইন্টারেক্টিভ টাস্ক তালিকা।
   - কীবোর্ড-চালিত আইটেম পুনর্বিন্যাস এবং অগ্রগতি ট্র্যাকিং সমর্থন করে।
3. **Kanban নোট (`NoteKanbanEditor.svelte`)**:
   - ৩-কলামের ওয়ার্কফ্লো বোর্ড: `To Do` -> `In Progress` -> `Done`।
   - দ্রুত টাস্ক ট্রানজিশনের জন্য সাইক্লিং স্ট্যাটাস চিপস।
- **গতিশীল ক্ষয়হীন রূপান্তর**: নোটগুলি টেক্সট, চেকলিস্ট এবং Kanban উপস্থাপনার মধ্যে কোনো ক্ষতি ছাড়াই রূপান্তরিত হয়।

### 6.3 Scoping & Context Hierarchy
নোটগুলি `contextKey`-এর মাধ্যমে ব্রাউজিং প্রসঙ্গের সাথে আবদ্ধ হয়:
- **গ্রুপ স্কোপ (`g_<groupId>` বা `g_<groupKey>`)**: একটি সম্পূর্ণ ট্যাব গ্রুপের সাথে সংযুক্ত।
- **সাবগ্রুপ স্কোপ (`s_<groupId>_<domain>`)**: একটি ট্যাব গ্রুপের মধ্যে একটি নির্দিষ্ট ডোমেনের সাথে সংযুক্ত।
- **আনগ্রুপড স্কোপ (`g_ungrouped` / `s_ungrouped_<domain>`)**: ট্যাব গ্রুপের বাইরের ট্যাবে তৈরি নোট।
- **Pomodoro ও সাধারণ স্কোপ (`pomodoro`, `general`)**: সমগ্র ওয়ার্কস্পেস-ব্যাপী নোট।
- **অরফান সনাক্তকরণ ইঞ্জিন**: যখন ট্যাব গ্রুপ বা ডোমেন মুছে ফেলা হয়, তখন সংশ্লিষ্ট অস্থায়ী নোটগুলি অরফান ডিটেক্টর দ্বারা সংরক্ষিত হয়। নোটগুলি পুনরায় বরাদ্দ বা মুছে ফেলার জন্য UI-তে অ্যাক্সেসযোগ্য থাকে।

### 6.4 Invocation Modalities
- **UI লঞ্চারসমূহ**: গ্রুপ কার্ড এবং সাবগ্রুপ কার্ডে "View Notes" বোতাম; পপআপ হেডারে "Quick Notes" বোতাম; সাইডপ্যানেল রুট `?view=notes` (`pk`)।
- **কনটেক্সট মেনু ট্রিগার**: যে কোনো ওয়েব পেজে টেক্সট নির্বাচন করুন -> রাইট-ক্লিক -> "Crear Nota desde Selección" (`note-from-selection`)। স্বয়ংক্রিয়ভাবে নির্বাচিত টেক্সট বের করে এবং নিকটতম `h1`-`h3` শিরোনামকে শিরোনাম হিসেবে সেট করে।
- **Vim হিন্ট**: `ao` বর্তমান নির্বাচন থেকে একটি নোট তৈরি করে।
- **Omnibar**: `lnt:` তাৎক্ষণিক সম্পূর্ণ টেক্সট অনুসন্ধান সহ নোট ব্রাউজার খোলে।
- **অডিও রিডআউট**: এডিটরের অভ্যন্তরীণ TTS বোতাম Web Speech API ব্যবহার করে উচ্চস্বরে নোটের বিষয়বস্তু পাঠ করে।

## 7. Section 6: Media & Gallery View (Ver Galería)

একটি উচ্চ-কার্যক্ষমতাসম্পন্ন মিডিয়া ক্যাপচার, টীকা (অ্যানোটেশন) এবং অপটিক্যাল ক্যারেক্টার রিকগনিশন (OCR) পাইপলাইন।

### 7.1 Capture Modes & Engineering (All 7 Capture Types)
এক্সটেনশনটি একক-ট্যাব, ক্রস-ট্যাব, ক্রপ করা এবং প্যালেট অপারেশন কভার করে ৭টি বিশেষায়িত ক্যাপচার মোডালিটি প্রয়োগ করে:
1. **`visible` (দৃশ্যমান ভিউপোর্ট ক্যাপচার - `cs`)**:
   - `chrome.tabs.captureVisibleTab` ব্যবহার করে সক্রিয় ট্যাবের সঠিক দৃশ্যমান ভিউপোর্ট ক্যাপচার করে।
   - স্বয়ংক্রিয়ভাবে ক্যাপচারটিকে IndexedDB `screenshots` স্টোরে জমা দেয় এবং ইমেজ বিটম্যাপ সরাসরি সিস্টেম ক্লিপবোর্ডে কপি করে (`screenshotSavedAndCopied`)।
2. **`fullPage` (বিরামহীন পূর্ণ-পৃষ্ঠা স্ক্রোলিং ক্যানভাস - `cp`)**:
   - মোট ডকুমেন্ট স্ক্রোল উচ্চতা গণনা করে প্রোগ্রাম্যাটিক পেজ স্ক্রোলিং চালায়।
   - ভিজ্যুয়াল ত্রুটি দূর করতে স্ক্রোলবার দমন করে এবং প্রাথমিক সেগমেন্টের পরে স্টিকি/স্থির নেভিগেশন বার লুকিয়ে রাখে।
   - ফ্রেম ক্যাপচারের মধ্যে Chromium-অনুমোদিত 600ms বিলম্ব প্রয়োগ করে ৩০,০০০ পিক্সেল পর্যন্ত উচ্চতার একটি `OffscreenCanvas`-এ বিটম্যাপ স্লাইস সংযুক্ত করে (`captureFullPageDataUrl`)।
3. **`fullPageParts` (ধারাবাহিক স্লাইস করা অংশসমূহ - `cpp` / `cP`)**:
   - লম্বা ডকুমেন্টগুলিকে অনুক্রমিক, পৃথক ভিউপোর্ট-উচ্চতার ইমেজ অংশে ভাগ করে (`captureFullPageParts`), পেজিনেশনের জন্য ৬০টি পর্যন্ত সংখ্যাযুক্ত ইমেজ খণ্ড তৈরি করে।
4. **`area` (ইন্টারেক্টিভ আয়তক্ষেত্রাকার ড্র্যাগ ক্রপ - `ca`)**:
   - `area-selector.js` ইনজেক্ট করে, রিয়েল-টাইম বাউন্ডিং বক্স মাত্রা সহ একটি ক্রসহেয়ার ক্যানভাস ওভারলে করে।
   - ড্র্যাগেবল সিলেকশন হ্যান্ডেল, ডাইমেনশন টুলটিপ, কনফার্মেশন ট্রিগার, `Esc` কি বাতিলকরণ এবং বহু-ট্যাব ক্রপ কিউয়িং (`handleCaptureAreaFromShortcut`)।
5. **`groupTabs` (ব্যাচ সক্রিয় গ্রুপ ট্যাব ওয়াক - `Cs`, `Cp`, `CP`)**:
   - সক্রিয় ট্যাব গ্রুপের প্রতিটি ট্যাবের মধ্য দিয়ে ক্রমানুসারে পুনরাবৃত্তি করে (`handleCaptureGroupFromShortcut`)।
   - দৃশ্যমান, পূর্ণ-পৃষ্ঠা বা খণ্ডিত অংশ মোডে ব্যাচ ক্যাপচার সমর্থন করে, সেগুলিকে একটি ইউনিফাইড সংগ্রহে সংকলন করে।
6. **`omnibarPickedTabs` (কাস্টম মাল্টি-ট্যাব কিউ ক্যাপচার)**:
   - Omnibar কমান্ড `cs:`, `cp:`, `cpp:`, বা `ca:`-এর মাধ্যমে সূচিত হয় (`handleCaptureTabs`)।
   - সমস্ত ব্যবহারকারী-ফিল্টার করা ট্যাব জুড়ে ধারাবাহিক ক্যাপচার চালায়, রিয়েল-টাইম অগ্রগতি নির্দেশক সরবরাহ করে।
7. **`colorPickerCapture` (ব্যাকগ্রাউন্ড স্ক্রিন আইড্রপার ফলব্যাক)**:
   - স্থানীয় `window.EyeDropper` সমর্থনহীন অপারেটিং সিস্টেমে (যেমন, Linux) নির্ভুল হেক্স আইড্রপার ম্যাগনিফায়ার টুল পরিচালনা করতে একটি ব্যাকগ্রাউন্ড স্ক্রিন ক্যাপচার নেয়।

### 7.2 Gallery UI & Persistence
- **ইন্টারফেস**: লাইটবক্স জুম, প্যান এবং রোটেট টুল সহ প্রতিক্রিয়াশীল ম্যাসনরি/গ্রিড লেআউট।
- **স্থায়িত্ব (`screenshots` স্টোর)**: IndexedDB `Intelligent_Workspace`-এ সংরক্ষিত। আনপিন করা ক্যাপচারগুলি রক্ষণাবেক্ষণের সময় স্বয়ংক্রিয়ভাবে মুছে ফেলা হয়; পিন আইকনে ক্লিক করলে (`isPersistent = true`) ক্যাপচারগুলি অনির্দিষ্টকালের জন্য সংরক্ষিত থাকে।

### 7.3 Export, In-Browser OCR & External Markup
- **এক্সপোর্ট ফরম্যাট (`captureDownloadFormats`)**:
  - উচ্চ দক্ষতার ফরম্যাট: PNG, WebP, AVIF।
  - `pdf.js`-এর মাধ্যমে বহু-পৃষ্ঠার সংকলিত PDF ডকুমেন্ট এক্সপোর্ট।
- **অন-ডিভাইস WASM OCR**:
  - ব্রাউজার-অভ্যন্তরীণ Tesseract.js WebWorker যা প্রিলোড করা স্প্যানিশ এবং ইংরেজি (`spa+eng`) ভাষা মডেল ব্যবহার করে।
  - নেটওয়ার্কের মাধ্যমে ইমেজ ডেটা না পাঠিয়ে সরাসরি ক্লিপবোর্ডে টেক্সট বের করে নেয়।
- **সরাসরি পাঠানোর ইন্টিগ্রেশন**:
  - এক্সট্র্যাক্ট করা OCR টেক্সট বা ইমেজ সংযুক্তি এক-ক্লিকে Notes (`notesStore`) বা Gemini AI প্রম্পটে (`feature_geminiAttachFiles`) স্থানান্তর।
- **Excalidraw মার্কআপ**: ফ্রিহ্যান্ড অঙ্কন, তীর এবং ভেক্টর টীকাগুলির জন্য এক-ক্লিকে ক্যাপচার করা ছবি সরাসরি `https://excalidraw.com/`-এ পাঠায়।

### 7.4 Invocation Modalities
- **UI**: গ্রুপ কার্ড ক্যামেরা বোতাম, পপআপ দ্রুত অ্যাকশন, সাইডপ্যানেল গ্যালারি রুট `?view=gallery` (`ps`)।
- **Vim হিন্টসমূহ**: `cs` (দৃশ্যমান), `cp` (সম্পূর্ণ পেজ), `cP` (অংশসমূহ), `ca` (অঞ্চল ক্রপ), `Cs` (গ্রুপ দৃশ্যমান), `Cp` (গ্রুপ সম্পূর্ণ পেজ), `CP` (গ্রুপ অংশসমূহ)।
- **Omnibar প্রিফিক্সসমূহ**: `cs:`, `cp:`, `cpp:`, `ca:`, এবং `limg:` (গ্যালারি ব্রাউজ)।

## 8. Section 7: Pomodoro & Timing Suite (Pomodoro)

ব্রাউজার স্লিপ চক্র জুড়ে নিখুঁত নির্ভুলতার জন্য প্রকৌশলিত একটি ফোকাস এবং টাইমিং স্যুট।

### 8.1 Timing Engine & Background Architecture
- **জিরো-ড্রিফ্ট টাইমস্ট্যাম্প ম্যাথ**: স্টেটটি পরম ইউনিক্স টাইমস্ট্যাম্প সহ `chrome.storage.local`-এ স্থায়ী থাকে (`startTime`, `pausedAt`)। সার্ভিস ওয়ার্কার সমাপ্তি, ব্রাউজার রিস্টার্ট এবং অপারেটিং সিস্টেম স্লিপ অবস্থার কারণে ঘড়ির কোনো বিচ্যুতি (ড্রিফ্ট) ঘটে না।
- **অ্যালার্ম প্রেরক (Alarm Dispatcher)**:
  - `chrome.alarms` দ্বারা চালিত উচ্চ-রেজোলিউশনের কাউন্টডাউন টিকার (`pomodoroTick` ১ সেকেন্ডের ব্যবধান)।
  - ব্যাকগ্রাউন্ড রক্ষণাবেক্ষণ এবং দীর্ঘমেয়াদী ব্যবধান সুইপ `itg-periodic-tasks` দ্বারা পরিচালিত হয় (১ মিনিটের ব্যবধান)।
- **অফস্ক্রিন অডিও চাইমস (`offscreen.html`)**: `AUDIO_PLAYBACK` কারণ সহ তৈরি একটি নিবেদিত Chrome অফস্ক্রিন ডকুমেন্টের মাধ্যমে অডিও চাইমস তৈরি হয়। মেমরি সংরক্ষণের জন্য শব্দ শেষ হওয়ার ৩.৫ সেকেন্ড পরে স্বয়ংক্রিয়ভাবে বন্ধ হয়ে যায়।

### 8.2 Exhaustive 4 Timing Modes
1. **Pomodoro (`pomodoro`)**:
   - কাজের সময়কাল: ১ থেকে ১৮০ মিনিট (ডিফল্ট: ২৫ মিনিট)।
   - ছোট বিরতি: ১ থেকে ১২০ মিনিট (ডিফল্ট: ৫ মিনিট)।
   - দীর্ঘ বিরতি: ১ থেকে ১৮০ মিনিট (ডিফল্ট: ১৫ মিনিট)।
   - দীর্ঘ বিরতির আগের চক্র: ১ থেকে ১২ চক্র (ডিফল্ট: ৪)।
   - লক্ষ্য চক্র লক্ষ্য: ১ থেকে ৯৯ চক্র (ডিফল্ট: ৮)।
   - কনফিগারযোগ্য স্বয়ংক্রিয় কাজ শুরু, স্বয়ংক্রিয় বিরতি শুরু এবং বিজ্ঞপ্তি সতর্কতা।
2. **স্টপওয়াচ (`cronometro`)**: ল্যাপ রেকর্ডিং এবং পজ-অ্যাজ-স্টপ ক্ষমতা সহ প্রগ্রেসিভ টাইমার।
3. **কাউন্টডাউন (`temporizador`)**: ঘন্টা, মিনিট এবং সেকেন্ড নির্দিষ্ট করে কাস্টম কাউন্টডাউন টাইমার।
4. **টার্গেট টাইম অ্যালার্ম (`tiempo`)**: একটি সঠিক ভবিষ্যৎ টাইমস্ট্যাম্পের জন্য অ্যালার্ম সেট করতে ক্যালেন্ডার তারিখ পিকার এবং ঘড়ি নির্বাচক।

### 8.3 In-Page Floating Timer Widget
- সরাসরি ওয়েব পেজের উপর রিয়েল-টাইম কাউন্টডাউন, পজ/রিজিউম এবং স্কিপ বোতাম প্রদর্শনকারী ড্র্যাগেবল, ন্যূনতম ওভারলে।
- এক্সটেনশন প্যানেল বা পপআপে ফিরে না গিয়ে ফোকাস সেশন নিরীক্ষণ করার অনুমতি দেয়।

### 8.4 Group Auto-Collapse Idle Timer
- ১ মিনিট নিষ্ক্রিয়তার পরে নিষ্ক্রিয় গ্রুপগুলিকে (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`) এবং ১৫ মিনিট নিষ্ক্রিয়তার পরে সক্রিয় গ্রুপকে (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`) স্বয়ংক্রিয়ভাবে সঙ্কুচিত করতে ফোকাস রুটিনের সাথে সমন্বয় করে কাজ করে। ০ থেকে ১৪৪০ মিনিট পর্যন্ত কনফিগারযোগ্য।

প্রতিটি সেশন শ্রেণিবিন্যাস মেটাডেটা সমর্থন করে:

- প্রজেক্ট ফোল্ডার (যেমন, `/client/project`)

### 8.6 Analytics Engine & 19 KPI Cards
সম্পূর্ণ ড্যাশবোর্ড (`dashboard.html` বা সাইডপ্যানেল `dashboard.html?context=sidepanel`) ডুপ্লিকেট-মুক্ত সেশনগুলি থেকে (`sessionStarted` দ্বারা `dedupeSessions`) ১৯টি মূল কর্মক্ষমতা সূচক (KPI) গণনা করে:
1. `focus`: মোট ফোকাস সময়।
2. `sessions`: মোট সম্পন্ন সেশন।
3. `cycles`: মোট সম্পন্ন কাজের চক্র।
4. `efficiency`: গড় দক্ষতার শতাংশ (`Total Focus / Total Time * 100`)।
5. `activeDays`: অনন্য সক্রিয় দিনের সংখ্যা।
6. `break`: মোট বিরতির সময়কাল।
7. `interruptions`: ম্যানুয়াল বিরতি/বাধার মোট সংখ্যা।
8. `interruptionTime`: বিরতি অবস্থায় কাটানো পুঞ্জীভূত সময়কাল।
9. `bestSession`: দীর্ঘতম একক নিরবচ্ছিন্ন ফোকাস সেশন।
10. `avgFocus`: সম্পন্ন চক্র প্রতি গড় ফোকাস সময়কাল।
11. `totalTime`: কাজ এবং বিরতিতে কাটানো মোট পুঞ্জীভূত সময়।
12. `workRest`: কাজের সময়কাল এবং বিশ্রামের সময়কালের অনুপাত (`1 : X`)।
13. `distractionRate`: প্রতি ফোকাস ঘন্টায় বাধা।
14. `bestDay`: সপ্তাহের সবচেয়ে ফলপ্রসূ দিন।
15. `goldenHour`: দিনের সর্বোচ্চ ফোকাস ঘন্টার ব্যবধান (যেমন, `10:00 - 11:00`)।
16. `projects`: ট্র্যাক করা স্বতন্ত্র প্রজেক্টের সংখ্যা।
17. `avgIntDuration`: প্রতিটি বাধার গড় সময়কাল।
18. `topProject`: সর্বোচ্চ জমে থাকা ফোকাস সময় সহ প্রজেক্ট।
19. `focusIntensity`: প্রতি সক্রিয় দিনে গড় ফোকাস ঘন্টা।

অতিরিক্ত ভিজ্যুয়াল অ্যানালিটিক্সের মধ্যে রয়েছে একটি ডে স্ট্রিক হিটম্যাপ ক্যালেন্ডার, একটি প্রতি ঘন্টার ফোকাস বিতরণ বার চার্ট, একটি প্রজেক্ট বৈচিত্র্যের ব্রেকডাউন এবং সম্পূর্ণ JSON ডেটা ইমপোর্ট/এক্সপোর্ট।

## 9. Section 8: Activity & History Panel (Panel de Actividad)

একটি Declarative Net Request (DNR) ট্র্যাকিং, অ্যানালিটিক্স এবং ওয়েব গভর্নেন্স ইঞ্জিন।

### 9.1 Data Engine & Storage Topology (`ITG_WEB_ACTIVITY`)
`ITG_WEB_ACTIVITY`-এর অধীনে পরিচালিত:
- `wa:day:YYYY-MM-DD`: প্রতিদিনের ডোমেন কাউন্টার (`{ domains: { host: { t: seconds, v: visits, s: sessions, h: { hour: seconds } } } }`)।
- `wa:days`: রেকর্ড করা তারিখ কীগুলির মাস্টার ইনডেক্স অ্যারে।
- `wa:recent`: সাম্প্রতিক ৪০০টি ভিজিট টাইমলাইন এন্ট্রি সংরক্ষণকারী রিং বাফার।
- `wa:openSegment`: `chrome.storage.session`-এ সক্রিয় সময়োপযোগী সেগমেন্ট, যা `WA_MAX_SEGMENT_SECONDS = 900s` (১৫ মিনিট) এ সীমাবদ্ধ, যাতে মেশিন আইডল ইভেন্ট ফায়ার না করে স্লিপে গেলে পরিসংখ্যান বিকৃত না হয়।
- **আইডল সনাক্তকরণ**: `chrome.idle` ব্যবহার করে (ডিফল্ট: 300s / 5m)। উইন্ডো আনফোকাসড থাকলেও `countAudible = true` হলে অডিও প্লেব্যাক সক্রিয় ট্র্যাকিং বজায় রাখে।
- **সংরক্ষণকাল (Retention)**: `retentionDays` (ডিফল্ট: ১৮০ দিন)-এর চেয়ে পুরানো দিনের রেকর্ড স্বয়ংক্রিয়ভাবে ছাঁটাই করে।

### 9.2 Declarative Net Request (DNR) Site Blocker
- **ডায়নামিক রুল বরাদ্দকরণ**: `9000` থেকে `9999` আইডি রেঞ্জে ডায়নামিক রুল বরাদ্দ করে।
- **রিডাইরেক্ট টার্গেট**: অবরুদ্ধ অনুরোধগুলি `src/ui/pages/web-activity/blocked.html?d=<domain>&u=\1`-এ পুনঃনির্দেশিত হয়।
- **খোলা ট্যাব সুইপ**: যখন একটি সাইটের সীমা শেষ হয়ে যায়, ব্যাকগ্রাউন্ড ওয়ার্কার অবিলম্বে ডোমেনের সাথে মিলে যাওয়া বিদ্যমান খোলা ট্যাবগুলি সুইপ এবং পুনঃনির্দেশ করে।
- **ওভারনাইট শিডিউল স্প্যানিং**: মধ্যরাত অতিক্রমকারী শিডিউলগুলি (যেমন, `22:00` থেকে `02:00`) দিনের সীমানা জুড়ে স্বয়ংক্রিয়ভাবে মূল্যায়ন করা হয়।
- **গ্রেস / স্নুজ পিরিয়ড (+৫ মিনিট)**: ব্লক স্ক্রিন অস্থায়ী ৫-মিনিটের স্নুজ পাসের অনুমতি দেয়, যা `wa:snoozeUses`-এ ট্র্যাক করা হয়।

### 9.3 Asymmetric Security Lock (`blockLock.js`)
সাইটের সীমাগুলি একটি অসমমিত পাসওয়ার্ড লক দিয়ে সুরক্ষিত করা যেতে পারে:
- **হ্যাশ স্টোরেজ**: এলোমেলো ১৬-বাইট সল্ট এবং SHA-256 হেক্স ডাইজেস্ট সংরক্ষণ করে (`wa:settings.blockPassword`)।
- **অসমমিত রুল পলিসি**: নতুন সীমা তৈরি করার সময় বা নিয়মগুলি কঠোর করার সময় (যেমন, অনুমোদিত সময় কমানো বা শিডিউল সীমাবদ্ধতা যোগ করা) পাসওয়ার্ড **কখনই চাওয়া হয় না**।
- **সুরক্ষিত অ্যাকশনসমূহ**: পাসওয়ার্ড কেবল তখনই চাওয়া হয় যখন **নিয়ম শিথিল করা হয়** (একটি সীমা মুছে ফেলা, সময় বৃদ্ধি করা বা শিডিউল নিষ্ক্রিয় করা) অথবা দৈনিক বিনামূল্যে সীমা অতিক্রম করার পরে স্নুজ আহ্বান করার সময় (`snoozePasswordAfter`)।

### 9.4 Categorization & Visual Analytics
- **১৬টি অন্তর্নির্মিত বিভাগ**: `social`, `video`, `music`, `news`, `shopping`, `reading`, `entertainment`, `dev`, `work`, `education`, `games`, `finance`, `mail`, `ai`, `search`, `other`।
- **কাস্টম বিভাগ**: `custom:` উপসর্গযুক্ত ব্যবহারকারী-সংজ্ঞায়িত বিভাগ সমর্থন করে।
- **ফোকাস অনুপাত**: বিভ্রান্তিকর বিভাগের (`social`, `video`, `games`, `shopping`, `entertainment`) বিপরীতে উত্পাদনশীল বিভাগগুলিকে (`dev`, `work`, `education`, `reading`, `finance`, `mail`) তুলনা করে।
- **ভিজ্যুয়ালসমূহ**: Chart.js প্রতি ঘন্টার কার্যকলাপ বিতরণ, বিভাগ ডোনাট ব্রেকডাউন এবং ডোমেন র‌্যাঙ্কিং তালিকা।

### 9.5 Downloads Manager Subsystem (`switchMainView('downloads')`)
- **নিবেদিত রুট**: সাইড প্যানেলে `switchMainView('downloads')` (`?view=downloads`)-এর মাধ্যমে অ্যাক্সেস করা হয়।
- **সরাসরি Chrome API ইন্টিগ্রেশন**: রিয়েল-টাইমে সমস্ত ব্রাউজার ডাউনলোড ট্র্যাক, পরিচালনা এবং পরিদর্শন করতে `chrome.downloads` হুক করে।
- **রিয়েল-টাইম ফাজি অনুসন্ধান**: ফাইলের নাম, ফাইলের পাথ বা ডাউনলোড সোর্স URL দ্বারা তাত্ক্ষণিক অনুসন্ধান।
- **স্ট্যাটাস ফিল্টার চিপস**: স্থিতি অনুসারে দ্রুত ডাউনলোড ফিল্টার করুন: `All`, `In Progress`, `Complete`, `Paused`, এবং `Interrupted`।
- **ক্যালেন্ডার তারিখ পরিসীমা ফিল্টারিং**: নির্দিষ্ট তারিখ বা সময় ব্যবধান অনুসারে ডাউনলোড সংকীর্ণ করুন।
- **ব্যাচ গ্রুপ ডাউনলোডার**: সক্রিয় গ্রুপের খোলা ট্যাব থেকে সমস্ত ডাউনলোড লিঙ্ক বের করে এবং অগ্রগতি ট্র্যাকিং সহ সিঙ্ক্রোনাইজড ব্যাচ ডাউনলোড শুরু করে।
- **ফাইল ব্যবস্থাপনা**: সরাসরি এক-ক্লিকে ফাইল খোলা (`chrome.downloads.open`) এবং ফোল্ডার প্রদর্শন (`chrome.downloads.show`)।

### 9.6 Recently Closed Tabs & Browsing History Subsystem
- **সম্প্রতি বন্ধ করা ট্যাব ভিউ**:
  - সরাসরি `chrome.sessions.getRecentlyClosed`-এর সাথে সংহত।
  - স্বয়ংক্রিয় ডায়াক্রিটিক এবং অ্যাকসেন্ট সরলীকরণ (`deaccent`) সহ রিয়েল-টাইম অনুসন্ধান।
  - এক ক্লিকে বা Omnibar কমান্ড `c:` দিয়ে একক ট্যাব পুনরুদ্ধার এবং সম্পূর্ণ উইন্ডো সেশন পুনরুদ্ধার।
- **ব্রাউজিং হিস্ট্রি ভিউ**:
  - অপ্রয়োজনীয় `chrome.history.search` কোয়েরি চার্ন দূর করতে ১০-সেকেন্ডের TTL ইন-মেমরি ক্যাশিং সহ গভীর অনুসন্ধান।
  - ডোমেন, কীওয়ার্ড এবং ক্যালেন্ডার তারিখের ব্যাপ্তি দ্বারা ফিল্টারযোগ্য অনুসন্ধান।
  - ইতিমধ্যে খোলা থাকলে এক-ক্লিকে ট্যাব সক্রিয়করণ, অথবা নতুন ট্যাব তৈরি, যা Omnibar `h:`-এর মাধ্যমে অ্যাক্সেসযোগ্য।

### 9.7 Theme Scheduling Subsystem (`ThemeScheduleModal.svelte`)
- **স্বয়ংক্রিয় থিম শিডিউলিং**:
  - থিম সাইড প্যানেল ভিউয়ের (`?view=themes` / `pt`) ভিতরে `ThemeScheduleModal.svelte`-এর মাধ্যমে পরিচালিত।
  - দিনের সময় (`HH:MM`) এবং সপ্তাহের সক্রিয় দিনের (`[0..6]`) ভিত্তিতে স্বয়ংক্রিয় থিম পরিবর্তন সমর্থন করে।
  - সর্বাধিক ৭টি বৈশ্বিক থিম শিডিউল (`MAX_GLOBAL_SCHEDULES = 7`)।
  - **অটো-রিভার্ট**: নির্ধারিত সমাপ্তির সময় স্বয়ংক্রিয়ভাবে ডিফল্ট দিনের বেলা বা কর্মক্ষেত্রের থিমে ফিরে আসে।
  - **ডেস্কটপ সতর্কতা**: স্বয়ংক্রিয় থিম পরিবর্তন ঘটলে ডেস্কটপ বিজ্ঞপ্তি পাঠায় (`chrome.notifications`)।
  - **দ্বৈত স্থায়িত্ব**: `savedThemes` এবং `themeSchedules`-এর অধীনে `chrome.storage.sync` (রোমিং পছন্দ) এবং `chrome.storage.local`-এ সংরক্ষিত।

### 9.8 Compact Sidepanel View
- **সাইডপ্যানেল রুট (`?view=activity` / `pw`)**: রিয়েল-টাইম পর্যবেক্ষণের জন্য অপ্টিমাইজ করা ৩৫০px কলাম, যাতে পিরিয়ড সিলেক্টর চিপস (`Today`, `7d`, `30d`, `All`) এবং ডোমেন সীমা প্রগ্রেস বার রয়েছে।

## 10. Multi-Modal Invocation Matrix

### 10.1 Popup UI Interface
- **Rules ট্যাব**: দ্রুত নিয়ম টগল, সক্রিয় স্থিতি নির্দেশক এবং নিয়ম URL লঞ্চার।
- **Groups ট্যাব**: ট্যাব স্যুইচিং এবং গ্রুপ ক্লিনআপ সহ কমপ্যাক্ট অ্যাকর্ডিয়ন তালিকা।
- **AI লঞ্চার**: সাইড প্যানেলে প্রশ্ন পাঠানোর জন্য সরাসরি চ্যাট ইনপুট বক্স।
- **কুইক অ্যাকশন টুলবার**: এরিয়া স্ক্রিনশট, ফুল-পেজ ক্যাপচার, কুইক নোটস, Pomodoro স্টার্ট/পজ এবং সাইডপ্যানেল প্রসারণের জন্য এক-ক্লিক বোতাম।

### 10.2 Sidepanel Navigation Routes (`?view=...`)
- `?view=rules` — ব্যাপক নিয়ম ম্যানেজার এবং URL প্যাটার্ন এডিটর (`pg`)।
- `?view=listgroup` — ড্র্যাগ-অ্যান্ড-ড্রপ পুনর্বিন্যাস সহ সম্পূর্ণ গ্রুপ এবং ট্যাব ওয়ার্কস্পেস (`pl`)।
- `?view=notes` — নোট ওয়ার্কস্পেস (Text, Checklist, Kanban, Mermaid, KaTeX) (`pk`)।

- `?view=gemini` — মাল্টিমোডাল এআই অ্যাসিস্ট্যান্ট এবং স্বায়ত্তশাসিত এজেন্ট ইন্টারফেস (`pa`)।

- `?view=downloads` — ডাউনলোড ম্যানেজার এবং ব্যাচ লিঙ্ক ডাউনলোডার (`switchMainView('downloads')`)।

26. `atr:` — একটি বিদ্যমান নিয়মে খোলা ট্যাব বা ম্যানুয়াল URL যোগ করুন।

28. `cr:` — একটি নতুন নিয়ম তৈরি করুন (`cr: name` বা `cr: name, url1, url2`)।
29. `ccr:` — একটি কাস্টম নিয়মের রঙ পরিবর্তন করুন।
30. `ccg:` — একটি সক্রিয় ট্যাব গ্রুপের রঙ পরিবর্তন করুন।
31. `dr:` — নিয়ম বা নিয়ম থেকে পৃথক URL মুছুন।
32. `er:` — একটি বিদ্যমান নিয়ম পুনঃনামকরণ বা সম্পাদনা করুন।
33. `st:` — Omnibar ইন্টারেক্টিভ টিউটোরিয়াল খুলুন।
34. `g:` — Google অনুসন্ধান করুন (`g: <query>`)।
35. `y:` — YouTube অনুসন্ধান করুন (`y: <query>`)।
36. `d:` — DuckDuckGo অনুসন্ধান করুন (`d: <query>`)।
37. `w:` — Wikipedia অনুসন্ধান করুন (`w: <query>`)।
38. `gm:` — Google Maps অনুসন্ধান করুন (`gm: <query>`)।
39. `x:` — X / Twitter অনুসন্ধান করুন (`x: <query>`)।
40. `am:` — Amazon অনুসন্ধান করুন (`am: <query>`)।
41. `ams:` — Amazon Spain অনুসন্ধান করুন (`ams: <query>`)।

### 10.6 Context Menu Tree Hierarchy (All 5 Groups & 30+ Actions)
কনটেক্সট মেনুটি ৫টি কার্যকরী কমান্ড গ্রুপে সংগঠিত একটি সম্পূর্ণ হায়ারার্কিকাল ট্রি সরবরাহ করে:
1. **Group 1: Rules & URL Submenu**:
   - মাস্টার রুল চেকবক্স টগল ("Activar/Desactivar Todas las Reglas")।
   - তাৎক্ষণিকভাবে পৃথক কাস্টম নিয়মগুলি সক্ষম বা নিষ্ক্রিয় করার জন্য নিয়ম-ভিত্তিক টগল।
   - "Abrir Todas las URLs": নির্বাচিত নিয়মে নিবন্ধিত সমস্ত লক্ষ্য URL খোলে।
   - গতিশীল খোলা ট্যাবের সংখ্যা সহ পৃথক URL সাবমেনু `[N]`: URL-এর সাথে মিলে যাওয়া বর্তমানে খোলা ট্যাবের সংখ্যা প্রদর্শন করে, URL-এ এক-ক্লিক নেভিগেশন প্রদান করে এবং সমস্ত ম্যাচিং ট্যাব বন্ধ করতে "Cerrar Pestañas para esta URL" অফার করে।
   - কুইক রুল তৈরি: "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa"।
   - বিদ্যমান নিয়মে যোগ করুন: "Añadir a Regla Existente" -> নিয়ম নির্বাচন -> "Añadir Raíz del Sitio" / "Añadir URL Completa"।
2. **Group 2: Tab Cleanup & Audio Controls**:
   - "Eliminar Pestañas Duplicadas [N]": সনাক্ত করা অপ্রয়োজনীয় ট্যাবের সংখ্যা দেখায় এবং উইন্ডো জুড়ে সেগুলি বন্ধ করে।
   - "Eliminar Pestañas por Dominio": খোলা ট্যাবের সংখ্যা `[N]` সহ সমস্ত ডোমেন তালিকাভুক্ত গতিশীল সাবমেনু, যা ডোমেন দ্বারা সুনির্দিষ্টভাবে ট্যাব বন্ধ করার অনুমতি দেয়।
   - "Cerrar Todos Excepto el Grupo Activo": সক্রিয় ফোকাস করা গ্রুপটি রাখে এবং অন্য সমস্ত গ্রুপ বন্ধ করে।
   - "Reagrupar Todas las Pestañas": সমস্ত খোলা ট্যাব জুড়ে সম্পূর্ণ ব্যাকগ্রাউন্ড পুনর্গ্রুপিং পাস ট্রিগার করে।
   - "Silenciar Todas las Pestañas" / "Reactivar Sonido en Todas las Pestañas": গ্লোবাল অডিও মিউট এবং আনমিউট নিয়ন্ত্রণ।
3. **Group 3: Reading, Selection & Notes**:
   - "Leer Página en Voz Alta" (TTS): ওভারলে নিয়ন্ত্রণ সহ পূর্ণ-পৃষ্ঠা টেক্সট-টু-স্পিচ রিডার।
   - "Leer Selección en Voz Alta": স্পিচ সিন্থেসিস ব্যবহার করে হাইলাইট করা DOM নির্বাচন উচ্চস্বরে পাঠ করে।
   - "Crear Nota desde Selección": টেক্সট সিলেকশন বের করে, স্বয়ংক্রিয়ভাবে নিকটতম শিরোনাম (`h1`-`h3`) থেকে নোটের শিরোনাম তৈরি করে এবং এটি `notesStore`-এ সংরক্ষণ করে।
4. **Group 4: Open Extension, PiP & Panels**:
   - "Abrir como PiP" / "Abrir como Ventana Emergente": টার্গেট পেজ, হাইলাইট করা নির্বাচন বা টার্গেট ছবি ভাসমান Picture-in-Picture বা স্বতন্ত্র পপআপ উইন্ডোতে চালু করুন।
   - "Abrir Extensión": এক্সটেনশন পপআপ খোলে বা সাইড প্যানেল প্রসারিত করে।
   - "Gestionar Reglas": একটি নিবেদিত ব্রাউজার ট্যাবে সম্পূর্ণ Rules Manager খোলে।
   - সরাসরি সাইডপ্যানেল লঞ্চারসমূহ: List Groups (`?view=listgroup`), Themes (`?view=themes`), AI Assistant (`?view=gemini`), এবং Customize Hints (`?view=hints`)-এ এক-ক্লিকে রাউটিং।
5. **Group 5: Settings & Clustering Options**:
   - **Gestión de Grupos**: Alternar Grupo Actual (সক্রিয় গ্রুপের সংকোচন টগল করুন), Alternar Todos los Grupos (সমস্ত গ্রুপের সংকোচন টগল করুন)।
   - **Opciones de Agrupación**:
     - Agrupación Inteligente (স্বয়ংক্রিয় হিউরিস্টিক ক্লাস্টারিং টগল করুন)।
     - Modo Compacto (একক-অক্ষরের গ্রুপ শিরোনাম মোড টগল করুন)।
     - Dominio / Subdominio (ডোমেন এবং সাবডোমেন গ্রুপিং টগল করুন)।
     - Páginas Especiales: Páginas Chrome (`chrome://`), Archivos Locales (`file:///`), Extensiones (`chrome-extension://`), Miscelánea (`Misc`), Direcciones IP & Localhost।
   - **Opciones Generales**:
     - Ordenar Alfabéticamente (ট্যাব স্ট্রিপ জুড়ে বর্ণানুক্রমিক সাজানো প্রয়োগ করুন)।
     - Ubicación Miscelánea: Principio (`start`), Final (`end`), Alfabéticamente (`alpha`)।
     - Temporizador de Auto-Colapso (নিষ্ক্রিয় গ্রুপ সংকোচন টাইমার টগল করুন)।
     - Prefijos Visuales (`🔒`, `🔍`, `🗝️`, `⚠️` অবস্থা মার্কার টগল করুন)।
     - Vista Previa de Enlaces (ইন-পেজ লিঙ্ক প্রিভিউ মোডাল টগল করুন)।

## 11. Storage Schemas & Data Persistence

এক্সটেনশনটি IndexedDB এবং Chrome Storage API জুড়ে একটি বহু-স্তরবিশিষ্ট স্টোরেজ মডেল ব্যবহার করে:

### 11.1 IndexedDB Database: `Intelligent_Workspace` (Schema Version 8)
1. `screenshots`: keyPath: `'id'`, autoIncrement: true। সেকেন্ডারি ইনডেক্স: `'createdAt'`। বাইনারি স্ক্রিনশট, ক্যানভাস ডেটা URL, স্থায়ী ফ্ল্যাগ, মাত্রা এবং সেগমেন্ট মোট সূচক ধারণ করে।
2. `geminiConversations`: keyPath: `'id'`, autoIncrement: true। ০ সেকেন্ডারি ইনডেক্স (আইডি দ্বারা পুনরুদ্ধার/পরিচালিত)। বহু-ধাপের চ্যাট থ্রেড, বার্তার ভূমিকা, টোকেন মেট্রিক্স এবং অনুসন্ধান গ্রাউন্ডিং মেটাডেটা সংরক্ষণ করে।
3. `notesStore`: keyPath: `'id'`, autoIncrement: false। ০ সেকেন্ডারি ইনডেক্স (contextKey দ্বারা মেমরিতে ফিল্টার করা হয়)। রিচ টেক্সট, চেকলিস্ট অ্যারে, Kanban বোর্ড কার্ড, Mermaid স্পেসিফিকেশন এবং KaTeX ফর্মুলা সংরক্ষণ করে।
4. `backupsGroups`: keyPath: `'group.id'`। ০ সেকেন্ডারি ইনডেক্স (নেস্টেড `'group.id'` দ্বারা কী করা ব্যাকআপ গ্রুপ অবজেক্ট সংরক্ষণ করে)। সংকুচিত গ্রুপ কাঠামো, রঙ, শিরোনাম এবং বন্ধ ট্যাবের রেকর্ড সংরক্ষণ করে।
5. `pomodoroStats`: keyPath: `'id'`, autoIncrement: true। সেকেন্ডারি ইনডেক্সসমূহ: `'projectName'` (keyPath `'projectName'`) এবং `'savedAt'` (keyPath `'savedAt'`) (কোনো `date` ইনডেক্স নেই)। ফোকাস অ্যানালিটিক্স, চক্র মেট্রিক্স এবং বাধার লগ ধারণ করে।

### 11.2 Chrome Storage Dual-Routing (`StorageService`)
- `chrome.storage.sync` (ব্যবহারকারীর ডিভাইস জুড়ে বহনযোগ্য সেটিংসের জন্য) এবং `chrome.storage.local`-এর (ভারী পছন্দের জন্য) মধ্যে গতিশীলভাবে পড়া এবং লেখা রুট করে।
- মূল মডেলসমূহ:
  - `customRules`: নিয়মের সংজ্ঞার অ্যারে (`[{ name, color, active, urls }]`)।
  - `clusterConfig`: স্বয়ংক্রিয় ক্লাস্টারিং প্যারামিটার (থ্রেশহোল্ড, কমপ্যাক্ট মোড, বিশেষ বিভাগ)।
  - `userPrefixes`: ইমোজি প্রিফিক্স বরাদ্দকরণ (`{ lock, openKey, loupe, checked, warning }`)।
  - `activeTheme`, `savedThemes`, ও `themeSchedules`: ৯-প্যালেট রঙের কনফিগারেশন এবং `ThemeScheduleModal.svelte`-এর মাধ্যমে কনফিগার করা নির্ধারিত ঘূর্ণন নিয়ম।
  - `pomodoroState`: রিয়েল-টাইম সেশন টাইমস্ট্যাম্প, বিরতির সময়কাল এবং চক্র লক্ষ্য।
  - `wa:settings` ও `wa:limits`: ওয়েব কার্যকলাপ ট্র্যাকিং পছন্দ, সাইট সীমা এবং সময়সূচী উইন্ডো।
  - `youtubeLoopEnabled`: YouTube এবং Shorts লুপ বোতাম নিয়ন্ত্রণকারী বুলিয়ান ফ্ল্যাগ।

### 11.3 Chrome Storage Session (`chrome.storage.session`)
আল্ট্রা-ফাস্ট, ক্ষণস্থায়ী রানটাইম সমন্বয়ের জন্য ব্যবহৃত হয়:
- `tabsEverActive`: বর্তমান ব্রাউজার সেশনের সময় সক্রিয় হওয়া ট্যাব আইডিগুলির সেট।
- `groupExpandedEver`: বর্তমান সেশনের সময় প্রসারিত হওয়া গ্রুপগুলির রেকর্ড।
- `groupInfoMap`: গতিশীল শিরোনাম এবং ক্লাস্টারিং টাইপের সাথে গ্রুপ আইডি ম্যাপিংয়ের রিয়েল-টাইম রেজিস্ট্রি।
- `splitScreenState`: মূল স্ক্রিন মাত্রা পুনরুদ্ধারের জন্য ক্যাশ করা উইন্ডো বাউন্ডস।
- `contextMenusSignature`: দ্রুত ট্যাব স্যুইচের সময় অপ্রয়োজনীয় কনটেক্সট মেনু পুনর্নির্মাণ চার্ন প্রতিরোধকারী হ্যাশ স্বাক্ষর।
- `wa:openSegment`: বর্তমান সক্রিয় ওয়েবসাইটের সময় সেগমেন্ট।
- `hiddenYoutubeView`: `HiddenGroupsBar.svelte`-এ ডক করা পার্ক করা YouTube প্লেয়ার ভিউয়ের রেফারেন্স।

## 12. Defensive Engineering & Edge Case Handling

1. **Declarative Net Request Header Unblocking (`dnr.js`)**:
   - `X-Frame-Options` এবং সীমাবদ্ধ `Content-Security-Policy` হেডারগুলি সরিয়ে ফেলার জন্য ডায়নামিক DNR নিয়মের মাধ্যমে রেসপন্স হেডার পরিবর্তন করে, যা সাইড প্যানেল এবং Picture-in-Picture আইফ্রেমে বাহ্যিক সাইটগুলিকে রেন্ডার করার অনুমতি দেয়।
   - **WhatsApp Web নিরাপত্তা**: `web.whatsapp.com`-এ স্পষ্টভাবে `Cross-Origin-Opener-Policy` (COOP) এবং `Cross-Origin-Embedder-Policy` (COEP) সংরক্ষণ করে যাতে এর WebAssembly Signal ক্রিপ্টোগ্রাফিক বাস্তবায়ন ভেঙে না যায়।
2. **Right-Click & Selection Unblocker (`allowRightClickHook.js`)**:
   - কপি, পেস্ট, কনটেক্সট মেনু এবং টেক্সট নির্বাচন ব্লক করে এমন প্রতিকূল ওয়েবসাইটগুলিকে পরাস্ত করে।
   - `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown`, এবং `mouseup`-এ `preventDefault()` এবং `stopPropagation()` আটকাতে `MAIN` ওয়ার্ল্ডে চলে।
   - `MutationObserver`-এর মাধ্যমে ইনলাইন `oncontextmenu="return false"` হ্যান্ডলারগুলি সরিয়ে দেয়।
   - বাতিল করা পেস্ট ইভেন্টগুলি পুনরায় ইনজেক্ট করার আগে ক্লিপবোর্ড বিষয়বস্তু যাচাই করে বৈধ ওয়েব অ্যাপ্লিকেশনগুলিকে (যেমন, Telegram Web, Google Docs) সুরক্ষিত করে।
3. **YouTube Hover Preview Audio Forced-Mute Override (`youtubePreviewAudioHook.js`)**:
   - `ytd-video-preview #inline-preview-player`-এ `MAIN` ওয়ার্ল্ডে চলে।
   - হোভার করার সময় লক্ষ্য `<video>` উপাদানে `HTMLMediaElement.prototype.muted` প্রপার্টি ডেসক্রিপ্টর ওভাররাইড করে।
   - YouTube-এর অভ্যন্তরীণ `volumechange` জোরপূর্বক মিউট রেস কন্ডিশন দূর করে, যা হোভার করার সময় লুপ রিস্টার্টের পরেও নিরবচ্ছিন্ন অডিও বজায় রাখে।
4. **YouTube Shorts Feed Sequence Navigation Hook (`youtubeShortsFeedHook.js`)**:
   - `ytd-shorts`-এ `MAIN` ওয়ার্ল্ডে চলে।
   - `shortsProcessedSequence` প্রপার্টি ইন্টারসেপ্ট করে, যা এক্সটেনশনের আইসোলেটেড ওয়ার্ল্ড থেকে অদৃশ্য, এবং পেজ রিলোড না করে বা ভাসমান উইন্ডো অবস্থা না হারিয়ে `ytd-app`-এ নেটিভ `yt-navigate` ইভেন্ট প্রেরণ করে।
5. **Infinite-Scroll Canvas Protection**:
   - ফুল-পেজ স্ক্রিনশট ওয়াককে ৬০টি সেগমেন্ট (`MAX_FULL_PAGE_SEGMENTS`) এবং ৩০,০০০ পিক্সেল সর্বোচ্চ ক্যানভাস উচ্চতায় (`MAX_FULL_PAGE_CANVAS_PX`) সীমাবদ্ধ করে, যা ব্রাউজার ট্যাবের মেমরি শেষ হয়ে ক্র্যাশ হওয়া এড়ায়।
6. **Linux Screen Color Picker Eyedropper Fallback**:
   - Chromium-এর `window.EyeDropper` API বিহীন Linux পরিবেশে চলার সময়, এক্সটেনশনটি `screen-color-picker.js` ইনজেক্ট করে, যা RGB/HEX/HSL গণনা সহ একটি ৯x ম্যাগনিফাইড পিক্সেল লেন্স রেন্ডার করে।
7. **Startup Session Settling Delay**:
   - ব্রাউজার চালু করার সময় গ্রুপ অ্যাসাইনমেন্ট মূল্যায়ন করার আগে সেশন ট্যাব এবং উইন্ডো অবস্থা স্থিতিশীল হতে দেওয়ার জন্য গ্রুপ প্রুনিং ২০ সেকেন্ডের জন্য বিলম্বিত করে (`groupsHaveSettledAfterStartup()`)।
