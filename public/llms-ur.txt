# Intelligent Workspace

> Intelligent Workspace ایک جدید Manifest V3 براؤزر ایکسٹینشن اور پیداواری ورک اسپیس ماحول ہے جسے Svelte، Vite، اور CRXJS کی مدد سے تیار کیا گیا ہے۔ یہ ٹیبز کی ذہین تنظیم، خودکار اور قواعد پر مبنی کلسٹرنگ، خود مختار AI ایجنٹ پر عمل درآمد (بشمول Google Gemini Cloud API اور Chrome Built-in Prompt API کی معاونت)، صفحے کے اندر Vim اسٹائل لنک نیویگیشن، 41 پریفکسز پر مشتمل Omnibar کمانڈ سسٹم، کثیر فارمیٹ نوٹ بندی (رچ ٹیکسٹ، چیک لسٹس، Kanban، Mermaid ڈایاگرامز، KaTeX فارمولے)، اعلیٰ کوالٹی میڈیا کیپچر اور براؤزر میں WASM OCR، زیرو-ڈرفٹ الارمز اور آف اسکرین آڈیو پلے بیک کے ساتھ Pomodoro ٹائمنگ، اور Declarative Net Request (DNR) کے تحت ویب سرگرمی کی پیمائش، ڈومین کی حدود اور سائٹ بلاکنگ کا انتظام و انصرام کرتا ہے۔

## 1. Architectural Foundation & Runtime Lifecycle

یہ ایکسٹینشن Google Chrome کے Manifest V3 آرکیٹیکچر کے تحت کام کرتی ہے، جو مستقل عمل کو پس منظر کے Service Worker، سینڈ باکسڈ UI پینلز، آف اسکرین آڈیو دستاویزات، اور صفحے کے اندر مواد کے اسکرپٹ اوورلیز کے درمیان غیر مربوط (decouple) کرتی ہے:

1. **Manifest Configuration (`manifest.json`)**:
   - **اجازتیں (21 اشیاء)**: `tabs`، `tabGroups`، `storage`، `favicon`، `contextMenus`، `notifications`، `sidePanel`، `scripting`، `downloads`، `downloads.open`، `system.display`، `declarativeNetRequestWithHostAccess`، `cookies`، `history`، `sessions`، `bookmarks`، `readingList`، `clipboardWrite`، `alarms`، `offscreen`، اور `idle`۔
   - **ہوسٹ کی اجازتیں**: `["<all_urls>"]`۔
   - **Service Worker**: `src/core/background.js` جو ہم وقت ساز (synchronous) `importScripts` ماڈیولر لوڈنگ کا استعمال کرتا ہے۔
   - **ٹول بار ایکشن**: جان بوجھ کر `default_popup` کو خارج کرتا ہے۔ رن ٹائم `chrome.action.setPopup({ popup: '' })` کو لاگو کرتا ہے، جس سے یہ یقینی بنتا ہے کہ `chrome.action.onClicked` ہم وقت ساز طریقے سے فائر ہو اور بغیر کسی پاپ اپ کی تاخیر کے صارف کے پن کیے گئے ویو میں `chrome.sidePanel` کو کھولے۔
   - **Omnibox کلیدی لفظ**: رجسٹرڈ کلیدی لفظ `"find"`۔
   - **کمانڈز**: `commands` کے تحت 24 سسٹم لیول کے کی بورڈ شارٹ کٹس رجسٹرڈ ہیں۔
   - **Content Security Policy**: `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`۔

2. **انٹر پروسیس کمیونیکیشن سیکیورٹی**:
   - `src/core/background/messaging.js` مواد کے اسکرپٹس کے پیغامات کو ایک واضح وائٹ لسٹ (`ALLOWED_CONTENT_SCRIPT_ACTIONS`) کے مطابق فلٹر کرتا ہے۔ غیر مراعات یافتہ ویب فریمز اندرونی اسٹوریج رائٹرز، من مانی Chrome APIs، یا رول میوٹیٹرز کو کال نہیں کر سکتے۔

3. **دوہری عمل درآمدی دنیایں (Dual Execution Worlds)**:
   - مواد کے اسکرپٹس `ISOLATED` (ایکسٹینشن کا دائرہ کار) اور `MAIN` (صفحہ کے عمل درآمد کا دائرہ کار) دونوں جہانوں میں کام کرتے ہیں۔ اسکرپٹس جیسے کہ `allowRightClickHook.js`، `videoPipHook.js`، `youtubePreviewAudioHook.js`، اور `youtubeShortsFeedHook.js` پروٹوٹائپ طریقوں کو روکنے، پراپرٹی ڈسکرپٹرز کو اوور رائیڈ کرنے اور کسٹم ایونٹس کو براہ راست سنبھالنے کے لیے `MAIN` میں چلتے ہیں۔

## 2. Section 1: Rules Management (Gestionar Reglas)

قواعد کے انتظام کا ذیلی نظام صارف کے طے کردہ سخت اور قطعی معیارات کی بنیاد پر ٹیبز کی گروپ بندی کو خودکار بناتا ہے۔

### 2.1 Data Schema (`CustomRule`)
ہر کسٹم رول درج ذیل انٹرفیس پر عمل پیرا ہوتا ہے:
```typescript
interface CustomRule {
  name: string;        // 1 to 16 characters. Must contain no whitespace characters.
  color: RuleColor;    // One of 9 colors: 'grey' | 'blue' | 'red' | 'yellow' | 'green' | 'pink' | 'purple' | 'cyan' | 'orange'
  urls: string[];      // Array of valid URLs, domains, or hostnames.
  active: boolean;     // Master toggle enabling or disabling rule evaluation.
  isStarred?: boolean; // Optional flag marking rule as a favorite for prioritized UI ordering.
}
```

### 2.2 Precedence Architecture
جب ٹیبز پر `src/core/background/groupManager.js` میں `groupTabs()` کے ذریعے کارروائی کی جاتی ہے، تو ٹیبز کی جانچ سخت درجہ بندی کی ترتیب میں گروپ بندی کی تہوں کے خلاف کی جاتی ہے:
1. **کسٹم قواعد (`applyCustomRules`)**: ظاہری ترتیب یا صارف کی ترجیح کے مطابق فعال کسٹم قواعد سے مطابقت رکھتا ہے۔ ایک بار گروپ بن جانے کے بعد، ٹیب IDs `groupedTabIds` میں رجسٹر ہو جاتے ہیں اور بعد کی تہوں سے خارج کر دیے جاتے ہیں۔
2. **خصوصی سسٹم گروپس**: سسٹم URLs کو روک کر مخصوص رنگین گروپس میں اکٹھا کیا جاتا ہے:
   - `chrome://` اور براؤزر کے اندرونی صفحات
   - `file:///` مقامی ڈسک کی فائلیں
   - `chrome-extension://` ایکسٹینشن کے صفحات
   - IP ایڈریسز اور لوکل ہوسٹ (`localhost`, `127.0.0.1`, `[::1]`, IPv4/IPv6 ہوسٹس)
3. **ڈومین کلسٹرنگ**: ایک ہی روٹ ڈومین رکھنے والے ٹیبز کو اس وقت گروپ کیا جاتا ہے جب ٹیبز کی تعداد `domainThreshold` (ڈیفالٹ: 2 ٹیبز) تک پہنچ جائے یا اس سے تجاوز کر جائے۔
4. **ذیلی ڈومین کلسٹرنگ**: اگر فعال ہو، تو ڈومینز کے اندر موجود ٹیبز کو مخصوص ذیلی ڈومینز کے مطابق گروپ کیا جاتا ہے (مثلاً `docs.github.com` بمقابلہ `gist.github.com`)۔
5. **متفرق ("Misc") گروپ**: باقی ماندہ غیر کلسٹر شدہ ٹیبز جو گروپ بندی کی حد کو پورا نہیں کرتے ہیں انہیں `Misc` گروپ میں رکھا جاتا ہے (اس کی جگہ کو ترتیب دیا جا سکتا ہے: `start`، `end`، یا حروف تہجی کے اعتبار سے `alpha`)۔

### 2.3 URL Normalization & Matching Semantics
میچنگ انجن (`src/core/background/utils.js` میں `matchesRule(tabUrl, ruleUrl)`) سخت اصولوں کے تحت نارملائزیشن کا اطلاق کرتا ہے:
- **اسکیم سے غیر جانبدار**: HTTP اور HTTPS پروٹوکولز کو ایک جیسا سمجھا جاتا ہے (`http://example.com`، `https://example.com` سے میل کھاتا ہے)۔ غیر ویب پروٹوکولز (`file://`، `chrome://`) کے لیے پروٹوکول کا ہو بہو یکساں ہونا لازمی ہے۔
- **ہوسٹ نارملائزیشن**: شروع میں موجود `www.` کو ہٹا دیا جاتا ہے (`www.github.com` نارملائز ہو کر `github.com` بن جاتا ہے)۔ ہوسٹ کے نام چھوٹے حروف (lowercase) میں کر دیے جاتے ہیں اور punycode کے ذریعے بین الاقوامی ڈومین ناموں (IDNs) کو سپورٹ کرتے ہیں۔
- **پورٹ کی حساسیت**: اگر کوئی اصول پورٹ کی وضاحت کرتا ہے (مثلاً `localhost:3000`)، تو ٹیب کے لیے اس مخصوص پورٹ سے میل کھانا ضروری ہے۔
- **راستہ (Path) میچنگ**: آخر میں موجود سلیشز کو ہٹا دیا جاتا ہے۔ اگر کوئی اصول کسی راستے کی وضاحت کرتا ہے (مثلاً `example.com/docs`)، تو یہ بالکل اسی راستے والے ٹیبز یا اس کے ذیلی راستوں (`example.com/docs/api`) سے میل کھاتا ہے، لیکن یہ ایک جیسے متوازی راستوں (`example.com/blog`) سے میل نہیں کھاتا۔
- **کیوری اور ہیش میچنگ**: اگر کسی اصول میں واضح طور پر کیوری اسٹرنگ (`?page=1`) یا ہیش (`#section`) شامل ہے، تو ٹیب کا ان پیرامیٹرز سے ہو بہو میل کھانا لازمی ہے۔
- **عددی Dword تحفظ (`ruleValidation.js`)**: توثیق کار صرف عددی ان پٹس (مثلاً `3242342424`) کو سختی سے مسترد کرتا ہے جنہیں WHATWG URL پارسرز درست IPv4 انٹیجر DWORDs کے طور پر سمجھتے ہیں، جس سے گروپ بندی میں غیر ارادی بگاڑ کو روکا جا سکتا ہے۔

### 2.4 Rules Management Settings Breakdown
رولز مینیجر طرز عمل کے کنٹرولز اور ترتیبات کا ایک جامع مجموعہ فراہم کرتا ہے:
- **اسٹوریج روٹنگ کا انتخاب**: صارفین رول اسٹوریج کو `chrome.storage.sync` (گوگل پروفائل میں سائن ان تمام آلات پر مطابقت پذیر ترتیبات کے لیے، جو Chrome کے ہم وقتی کوٹہ کل 100 KB اور فی آئٹم 8 KB کے تابع ہے) اور `chrome.storage.local` (سینکڑوں پیٹرنز پر مشتمل بڑے رولز سیٹس کے لیے موزوں لامحدود مقامی گنجائش) کے درمیان روٹ کر سکتے ہیں۔
- **کلسٹرنگ ماسٹر ٹوگل اور حدیں**:
  - `toggle-clustering`: ماسٹر کی بورڈ شارٹ کٹ اور UI ٹوگل جو صارف کے بنائے ہوئے کسٹم قواعد کو غیر فعال کیے بغیر خودکار ڈومین/ذیلی ڈومین کلسٹرنگ کو فعال یا غیر فعال کرتا ہے۔
  - `domainThreshold`: خودکار ٹیب گروپ بنانے کے لیے ایک ہی ڈومین سے مطلوبہ ٹیبز کی کم از کم تعداد (ڈیفالٹ: 2 ٹیبز)۔ اسے 1 سے 50 تک ترتیب دیا جا سکتا ہے۔
  - `subdomainThreshold`: الگ الگ ذیلی گروپس کے کلسٹرز بنانے سے پہلے ذیلی ڈومینز کے لیے ٹیبز کی کم از کم تعداد۔
  - ذیلی ڈومین ٹوگل (`toggle-subdomain-grouping`): خود مختار ذیلی ڈومینز میں فرق کرتا ہے (مثلاً `news.ycombinator.com` بمقابلہ `ycombinator.com`)۔
- **گروپس کی حروف تہجی کے لحاظ سے خودکار ترتیب (`toggle-sort-alpha`)**: ریئل ٹائم سارٹنگ انجن جو براؤزر ٹیب کی پٹی میں تمام کھلے ہوئے ٹیب گروپس پر حروف تہجی کی ترتیب کو لاگو کرتا ہے (`Ctrl+Shift+S` / `Cmd+Shift+S`)۔
- **بصری اسٹیٹس پریفکسز (`toggle-prefixes`)**: گروپ ٹائٹلز کے ساتھ متحرک طور پر ایموجی مارکرز شامل کیے جاتے ہیں تاکہ معائنے کی حالت ظاہر کی جا سکے:
  - `🔒` (لاک): گروپ میں ایسے ٹیبز ہیں جن کا ابھی تک دورہ نہیں کیا گیا، یعنی وہ ان پڑھ ہیں۔
  - `🔍` (میگنیفائنگ گلاس): گروپ میں جزوی طور پر وزٹ کیے گئے ٹیبز شامل ہیں۔
  - `🗝️` (کھلی چابی): گروپ کے تمام ٹیبز کھولے اور دیکھے جا چکے ہیں۔
  - `⚠️` (انتباہ): کسی دوسری ونڈو کے گروپ کے ساتھ ایک ہی نام کا تصادم پایا گیا ہے۔
- **غیر فعال گروپس کا خودکار سمٹاؤ (`toggle-collapse-timer`)**: ٹیب کی پٹی کو منظم رکھنے کے لیے غیر فعال ہونے پر گروپس کو خود بخود سمیٹ دیتا ہے۔
- **ماسٹر پاز گروپنگ (`feature_pauseGrouping`)**: ماسٹر فریز سوئچ جو تحقیقی سیشنز کے دوران تمام خودکار گروپ بندی کی کارروائیوں (رول میچز اور ہیورسٹک کلسٹرنگ دونوں) کو عارضی طور پر معطل کر دیتا ہے جہاں ٹیبز کو صارف کی مرضی کے مطابق ترتیب میں رہنا چاہیے۔
- **واحد ٹیب کی گروپ بندی (`featureSingleTabGrouping`)**: کسٹم رولز کو ایک ہی مماثل ٹیب کے لیے فوری طور پر ٹیب گروپ بنانے کی اجازت دیتا ہے، کثیر ٹیب کی حد کی شرط کو نظرانداز کرتے ہوئے۔
- **کمپیکٹ ویو (`toggle-compact-mode`)**: گروپ کے ناموں کے لیے صرف ایک حرف کے بیجز دکھا کر براؤزر کی ٹیب کی پٹی میں ٹیب ہیڈر کی چوڑائی کو کم کرتا ہے۔
- **ڈریگ اینڈ ڈراپ ترجیح**: `Rules.svelte` کی فہرست میں قواعد کو دوبارہ ترتیب دینے سے ان کی جانچ کی ترجیح فوری طور پر بدل جاتی ہے۔ اوپر والے قواعد پہلے جانچے جاتے ہیں۔
- **فزی تلاش (Fuzzy Search)**: رولز مینیجر اور Omnibar میں لائیو فلٹرنگ جو عنوان یا مماثل URL پیٹرنز کے ذریعے قواعد کی فوری تلاش کی اجازت دیتی ہے۔
- **JSON درآمد / برآمد**:
  - موڈ `add`: درآمد شدہ قواعد کو موجودہ مجموعے میں ضم کرتا ہے، اور ایک جیسے ڈپلیکیٹس کو ضائع کر دیتا ہے۔
  - موڈ `overwrite`: اسکیما کی توثیق کے بعد فعال رول کے مجموعے کو درآمد شدہ ڈیٹا سے مکمل طور پر تبدیل کر دیتا ہے۔
- **متحرک رول تخلیق**: Chrome بک مارک فولڈرز یا ذیلی گروپ ڈومین کے مجموعوں سے براہ راست کسٹم رولز کی ایک کلک پر تخلیق۔
- **رول ڈپلیکیٹ کا خاتمہ (`feature_v100_dedup_add_to_rule`)**: موجودہ کسٹم قواعد میں URLs یا ڈومینز شامل کرتے وقت ڈپلیکیٹ URL پیٹرنز کو خود بخود ہٹا دیتا ہے، جس سے قواعد میں غیر ضروری پھیلاؤ اور دہرائے جانے والے جائزوں کو روکا جاتا ہے۔

### 2.5 Operations & Persistence (`mutateRulesAndSync`)
- **مرکزی میوٹیٹر**: تمام رول کی تبدیلیاں `src/core/background/handlers/rules.js` میں `mutateRulesAndSync(mutateFn, sendResponse)` کے ذریعے انجام پاتی ہیں۔ یہ اسٹوریج کی ہم آہنگی، ان میموری کیشے کی تجدید (`extensionSettings.customRules`)، UI نوٹیفکیشن (`rulesUpdated`)، اور ٹیبز کی خودکار دوبارہ گروپ بندی (`groupTabs()`) کی ضمانت دیتا ہے۔
- **لائیو توثیق**: محفوظ کرنے سے پہلے نام کی انفرادیت، لمبائی (1-16 حروف)، حروف کی پابندیاں، اور درست URL نحو کی ریئل ٹائم توثیق۔

### 2.6 Invocation Modalities
- **رولز مینیجر کا صفحہ (`Rules.svelte`)**: پورے ٹیب ویو یا سائیڈ پینل (`?view=rules` / `pg`) میں قابل رسائی۔ ڈریگ اینڈ ڈراپ کے ذریعے مکمل تنظیم نو، ان لائن کلر سلیکٹر، URL ٹیگ چپس اور رول ٹوگلز فراہم کرتا ہے۔
- **Omnibar کمانڈز**:
  - `rl:` — قواعد تلاش کریں اور متعلقہ URLs کھولیں۔
  - `cr: <name> [, url1, url2]` — کمانڈ بار سے براہ راست نیا رول بنائیں۔
  - `atcr:` — فعال ٹیب کا ڈومین یا URL کسی موجودہ رول میں شامل کریں۔
  - `atr:` — منتخب کھلے ٹیبز یا دستی URLs کو کسی موجودہ رول میں شامل کریں۔
  - `ccr:` — کسی کسٹم رول کا رنگ تبدیل کریں۔
  - `dr:` — قواعد یا کسی رول سے انفرادی URLs کو حذف کریں۔
  - `er:` — کسی موجودہ رول میں ترمیم کریں یا اس کا نام بدلیں۔
- **کانٹیکسٹ مینیوز**:
  - صفحہ پر دائیں کلک کریں -> "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa"۔
  - صفحہ پر دائیں کلک کریں -> "Añadir a Regla Existente" -> رول منتخب کریں -> "Añadir Raíz del Sitio" / "Añadir URL Completa"۔
  - صفحہ پر دائیں کلک کریں -> "Reglas" -> فعال حالت کو ٹوگل کریں، رول کے تمام URLs کھولیں، یا مماثل ٹیبز کو بند کریں۔
- **کی بورڈ شارٹ کٹس**:
  - `Alt+R`: رولز مینیجر کھولیں۔
  - `Alt+M`: تمام قواعد کے نفاذ کو بیک وقت ٹوگل کریں (`toggle-all-rules`)۔

## 3. Section 2: Group Listing & Operations (Listar Grupos)

گروپ لسٹنگ ویو براؤزر ٹیب کے گروپس اور انفرادی ٹیبز کے معائنے، ہیرا پھیری اور ان کی دوبارہ ترتیب کے لیے ایک انٹرایکٹو ورک اسپیس فراہم کرتا ہے۔

### 3.1 UI Architecture
- **کمپوننٹ اسٹیک**: `ListGroup.svelte`، `GroupCard.svelte`، `GroupActions.svelte`، `TabItem.svelte`، اور `TabActions.svelte` کے ساتھ بنایا گیا ہے۔
- **کارڈ کی خصوصیات**: گروپ کا عنوان، رنگین بیج، ٹیب کاؤنٹ پل، اکارڈین ٹوگل کو سمیٹنا/پھیلانا، کارڈ کو پن کرنا، اور حسب ضرورت ایکشن بٹن گروپس دکھاتا ہے۔
- **ٹیب آئٹمز**: ٹیب کا فیو آئیکون رنگین فال بیک کے ساتھ، عنوان، قابل سماعت آواز کا بیج، میوٹ انڈیکیٹر، فعال حالت کا اشارہ، اور فی ٹیب اقدامات (بند کرنا، ڈپلیکیٹ کرنا، پن کرنا، تقسیم کرنا، خارج کرنا) دکھاتا ہے۔

### 3.2 Group Lifecycle & Behaviors
- **اکارڈین کنٹرول**: پھیلانے اور سمیٹنے کی ہموار حالتیں۔ اختیاری آٹو اکارڈین موڈ نیا گروپ پھیلانے پر غیر فعال گروپس کو خود بخود سمیٹ دیتا ہے۔
- **غیر فعالیت پر خودکار سمٹاؤ کا ٹائمر**:
  - بصری الجھن کو کم کرنے کے لیے غیر فعال ٹیب گروپس کو خود بخود سمیٹ دیتا ہے۔
  - دو الگ الگ حدیں: غیر فعال گروپس 1 منٹ کی غیر سرگرمی کے بعد سمٹ جاتے ہیں (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`)، جبکہ فعال گروپ 15 منٹ کی غیر سرگرمی کے بعد سمٹ جاتا ہے (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`)۔ 0 سے 1440 منٹ تک قابل ترتیب۔
- **ان لائن نام بدلنا اور رعایتی مدت (Grace Period)**:
  - صارفین براؤزر کی ٹیب کی پٹی یا UI میں براہ راست گروپس کا نام بدل سکتے ہیں۔
  - `GROUP_NAMING_GRACE_MS` (5000ms) صارف کی ترمیم کے دوران خودکار دوبارہ گروپ بندی کو روکتا ہے، جس سے ٹائپنگ کے دوران ٹائٹل کے اوور رائٹ ہونے سے بچاؤ ہوتا ہے۔
  - جانچ کے دوران زیرو چوڑائی کی اسپیسز (`\u200B`, `\u200C`, `\u200D`, `\u2060`, `\uFEFF`) کو ہٹا دیا جاتا ہے۔
  - خودکار طور پر تیار کردہ گروپ کا نام تبدیل کرنے سے یہ صارف کے نام والے گروپ میں تبدیل ہو جاتا ہے، جس سے متعلقہ کسٹم رول اپ ڈیٹ ہو جاتا ہے یا اسے مستقل قرار دیا جاتا ہے۔
- **بصری گروپ پریفکس انڈیکیٹرز**:
  - متحرک طور پر اسٹیٹس کی علامات لگاتا ہے: `🔒` (غیر دورہ شدہ)، `🔍` (جزوی دورہ شدہ)، `🗝️` (تمام دیکھے گئے)، `⚠️` (تصادم)۔
- **ڈریگ اینڈ ڈراپ کے ذریعے دوبارہ ترتیب**: گروپس کے اندر ٹیبز کو دوبارہ ترتیب دینے، گروپس کے درمیان ٹیبز کو منتقل کرنے، یا گروپ کارڈز کو دوبارہ ترتیب دینے کے لیے `sortable.js` کے ساتھ مربوط ہے۔
- **پوشیدہ گروپس کی خصوصیت**:
  - براؤزر کی ٹیب کی پٹی میں گروپ ٹائٹل سے پہلے `_hidden_` کا اضافہ کرتا ہے۔
  - گروپ کارڈز کو مرکزی فہرست کے منظر سے چھپاتا ہے، اور انہیں `HiddenGroupsBar.svelte` میں منتقل کرتا ہے۔
  - صارفین ایک کلک کے ساتھ فوری طور پر گروپس کو ظاہر یا بحال کر سکتے ہیں۔

### 3.3 Group Operations & Memory Management
- **Ungroup**: گروپ کو ختم کرتا ہے، اور ٹیبز ونڈو میں کھلے رہتے ہیں۔
- **Close Group**: گروپ کے تمام ٹیبز کو بند کرتا ہے اور گروپ ID کو آزاد کرتا ہے۔
- **Close Other Groups**: فی الوقت فوکس شدہ گروپ کے علاوہ باقی تمام ٹیب گروپس کو بند کر دیتا ہے۔
- **تمام ٹیبز کو دوبارہ گروپ کرنا (`Alt+Shift+R`)**: کسٹم رولز، سسٹم گروپس، اور ڈومین کلسٹرز میں جامع دوبارہ جانچ کا عمل انجام دیتا ہے۔
- **گروپ اسکرین شاٹ واک**: گروپ میں موجود ہر ٹیب کو ترتیب وار کھول کر اس کا اسکرین شاٹ لیتا ہے (`Cs` نظر آنے والا حصہ، `Cp` مکمل صفحہ، `CP` مکمل صفحے کے حصے)۔

### 3.4 Group Backups & Restore Subsystem
- **IndexedDB `backupsGroups` اسٹور**:
  - انفرادی ٹیب گروپس یا تمام کھلے گروپس کے ورک اسپیس کے اسنیپ شاٹس کا IndexedDB `Intelligent_Workspace` کے اسٹور `backupsGroups` میں بیک اپ لیتا ہے۔
  - مکمل گروپ ڈھانچے کو محفوظ کرتا ہے: گروپ کا عنوان، رنگ، سمٹی ہوئی حالت، ٹیب کے عنوانات، URLs، فیو آئیکونز، پن کی گئی حیثیت، اور ٹیب کی متعلقہ پوزیشنز۔
  - **میموری کا تحفظ**: سسٹم کی RAM حاصل کرنے اور CPU پر بوجھ کم کرنے کے لیے بیک اپ کیے گئے ٹیبز کو باقاعدہ طور پر بند کر دیا جاتا ہے۔
  - **بحالی کے میکانزم**:
    - `ListGroup.svelte` میں بیک اپ UI منظر ایک کلک کے ساتھ گروپ کی بحالی کے ساتھ۔
    - کی بورڈ شارٹ کٹ `br` (بحالی) اور `bg` (سب کا بیک اپ)۔
    - Omnibar کمانڈ `bgr:` (بیک اپ گروپس تلاش اور بحال کریں) اور `b:` (بک مارک تلاش)۔
  - **JSON برآمد اور درآمد**: کمپیوٹرز کے درمیان ہموار منتقلی اور طویل مدتی آف لائن آرکائیو کرنے کے لیے مکمل JSON بیک اپ کی برآمد اور درآمد۔

### 3.5 Parked YouTube Player in Hidden Groups Bar
- **آرکیٹیکچر (`HiddenGroupsBar.svelte`)**:
  - جب کوئی صارف یوٹیوب ویڈیو کے فعال منظر سے ہٹ جاتا ہے یا سائیڈ پینل کے اندر ویڈیو کا مواد چلاتا ہے، تو پلیئر بند یا گم نہیں ہوتا۔ یہ خود بخود `HiddenGroupsBar.svelte` میں پارک شدہ یوٹیوب انڈیکیٹر (`.youtube-indicator`) کے طور پر محفوظ ہو جاتا ہے۔
  - `src/ui/stores/appStore.svelte.js` میں `hiddenYoutubeView` اسٹور کے ذریعے ری ایکٹیو انداز میں منظم ہوتا ہے۔
  - **ایک کلک کے اقدامات**:
    - پارک شدہ انڈیکیٹر پر کلک کرنے سے `restoreYoutubeView()` متحرک ہوتا ہے، جو پلیئر کو فوری طور پر فعال ورک اسپیس ویو میں واپس لے آتا ہے۔
    - ڈیلیٹ بیج پر کلک کرنے سے `discardYoutubeView()` متحرک ہوتا ہے، جو پلے بیک کو صاف طور پر ختم کرتا ہے اور وسائل کو آزاد کرتا ہے۔
    - فعال ٹیب کی فہرستوں میں گڑبڑ کیے بغیر ListGroup ویو کے اوپری حصے میں پوشیدہ ٹیب گروپس کے ساتھ آسانی سے موجود رہتا ہے۔

## 4. Section 3: Navigation & Tab Management (Navegación)

تیز رفتار کی بورڈ نیویگیشن اور ورک اسپیس کے کنٹرولز ماؤس کی مداخلت کے بغیر متعدد ٹیبز کو کنٹرول کرنے کی سہولت دیتے ہیں۔

### 4.1 Fast Tab Jump Gesture
- **اشارہ کی ساخت (Gesture Syntax)**: `Alt + [groupPrefix] + [tabIndex] + Enter`
- **طریقہ کار**:
  - `Alt` کو دبائے رکھیں اور گروپ کا نام یا پریفکس کے حروف ٹائپ کریں، اس کے بعد مطلوبہ 1-بیسڈ ٹیب انڈیکس لکھیں، پھر `Enter` دبائیں۔
  - مثال: `Alt + git + 2 + Enter` براہ راست "GitHub" گروپ کے دوسرے ٹیب پر لے جاتا ہے۔
  - انڈیکس `0` گروپ کے *آخری* ٹیب کے شارٹ کٹ کے طور پر کام کرتا ہے۔
  - انڈیکس چھوڑ دینے سے گروپ کے *پہلے* ٹیب پر رسائی ہوتی ہے۔
  - اعراب خود بخود نارملائز ہو جاتے ہیں (`deaccent`) اور مماثلت کے عمل میں علامات کو یکساں کر دیا جاتا ہے۔

### 4.2 Stepping, Swapping & Lifecycle Keys
- `s`: فوری طور پر پچھلے فعال ٹیب پر جائیں (`previousActiveTabId`)۔
- `h` / `l`: پچھلے / اگلے ٹیب پر جائیں (یا اگر صفحہ اجازت دے تو افقی طور پر اسکرول کریں)۔
- `H` / `L`: براؤزر کی ہسٹری میں پیچھے / آگے جائیں۔
- `t`: نیا خالی ٹیب کھولیں۔
- `x`: موجودہ فعال ٹیب کو بند کریں۔
- `yt`: موجودہ ٹیب کی نقل (duplicate) بنائیں۔
- `r` / `R`: صفحہ دوبارہ لوڈ کریں / کیشے کو نظرانداز کرتے ہوئے زبردستی دوبارہ لوڈ کریں۔
- `d` / `u`: صفحے کے بالکل نیچے / اوپر اسکرول کریں۔
- `j` / `k`: نیچے / اوپر ہموار اسکرول کریں (75px کا مرحلہ)۔
- `f`: Vim لنک ہنٹس کو فعال کریں (کلک کرنے کے لیے عناصر پر حروف نمودار ہوتے ہیں)۔
- `cf`: ٹارگٹ URL کو کلپ بورڈ پر کاپی کرنے کے لیے Vim لنک ہنٹس فعال کریں۔

### For power users

ماہر صارفین براؤزر کو فل اسکرین موڈ میں ڈال سکتے ہیں اور ماؤس کا بالکل استعمال کیے بغیر، مکمل طور پر کی بورڈ کے ساتھ نیویگیٹ کر سکتے ہیں۔

#### Full-Screen Immersion & Mouse-Free Browsing
- **فل اسکرین کو ٹوگل کریں**: `F11` (Windows/Linux) یا `Command+Control+F` (macOS) دبائیں۔ براؤزر کا بیرونی فریم، ایڈریس بار، ٹیبز کی پٹی، اور آپریٹنگ سسٹم کے پینلز چھپ جاتے ہیں، جس سے ڈسپلے کا 100% حصہ مواد کے لیے مخصوص ہو جاتا ہے۔
- **صفحے کے اندر Vim لنک نیویگیشن (`f` / `cf`)**:
  - DOM میں موجود ہر کلک کے قابل عنصر، بٹن، ان پٹ، اور لنک پر نمایاں دو حرفی پیلے رنگ کے لنک ہنٹس بنانے کے لیے `f` دبائیں۔
  - ماؤس کے استعمال کے بغیر براہ راست کلک کرنے کے لیے اپنے مطلوبہ ہدف کے مطابق دو حروف ٹائپ کریں۔
  - ٹارگٹ لنک کا URL براہ راست اپنے سسٹم کلپ بورڈ پر کاپی کرنے والے اشارے حاصل کرنے کے لیے `cf` دبائیں۔
  - ٹارگٹ لنک کا صفحے کے اندر پریویو ماڈل کھولنے کے لیے `vp` دبائیں۔
  - لنک ہنٹس کو منسوخ کرنے اور عام اسکرولنگ پر واپس آنے کے لیے کسی بھی وقت `Esc` دبائیں۔
- **فوری ٹیب پر جانا اور تبدیلی**:
  - `Alt + [groupPrefix] + [tabIndex] + Enter`: Fast Tab Jump اشارے پر عمل کریں (مثلاً، `Alt + dev + 1 + Enter` براہ راست "Dev" گروپ کے پہلے ٹیب پر چلا جاتا ہے؛ انڈیکس `0` گروپ کے آخری ٹیب کو منتخب کرتا ہے)۔
  - `s`: موجودہ ٹیب اور پہلے فعال ٹیب (`previousActiveTabId`) کے درمیان فوری تبادلہ کریں۔
  - `h` / `l`: ٹیب کی پٹی میں پچھلے / اگلے ٹیب پر ترتیب وار جائیں۔
  - `H` / `L`: براؤزر کی نیویگیشن ہسٹری میں پیچھے / آگے بڑھیں۔
  - `t` / `x` / `yt`: نیا ٹیب کھولیں (`t`)، موجودہ ٹیب بند کریں (`x`)، یا ٹیب کی نقل بنائیں (`yt`)۔
- **فلوٹنگ Omnibar کمانڈ کا ذیلی نظام (`o`)**:
  - کسی بھی صفحے پر درمیان میں موجود Omnibar اوورلے کو ظاہر کرنے کے لیے `o` دبائیں۔
  - تمام 41 کمانڈ پریفکسز کی انٹرایکٹو ڈائرکٹری دیکھنے کے لیے `@` دبائیں۔
  - تمام کھلی ہوئی ونڈوز میں گہری فل ٹیکسٹ ٹیب تلاش کرنے کے لیے `f: <query>` ٹائپ کریں۔
  - کسی بھی Sidepanel منظر (`rules`، `listgroup`، `notes`، `gallery`، `gemini`، `activity`، `themes`، `hints`، `downloads`) میں نیویگیشن کے لیے `sp:` ٹائپ کریں۔
  - کی بورڈ سے ہاتھ اٹھائے بغیر Gemini سے سوال کرنے یا خود مختار براؤزر ایجنٹ کو ہدایات دینے کے لیے `qai: <query>` یا `qaia: <task>` ٹائپ کریں۔
  - کھلے ٹیبز کو ساتھ ساتھ اسپلٹ اسکرین میں تقسیم کرنے کے لیے `ts:` ٹائپ کریں۔
- **صفحے کے اندر نیویگیشن اور فوکس**:
  - `j` / `k`: نیچے / اوپر ہموار اسکرول کریں (75px کا اضافہ)۔
  - `d` / `u`: آدھا صفحہ نیچے / اوپر اسکرول کریں۔
  - `i`: کرسر کا فوکس فوری طور پر صفحے کے بنیادی ٹیکسٹ ان پٹ فیلڈ میں منتقل کریں۔
  - `ESC`: ان پٹ فیلڈ سے فوکس ہٹا کر کی بورڈ کو نیویگیشن موڈ پر واپس لائیں۔

### 4.4 Split Screen Workflows
- **محرک (Trigger)**: Vim ہنٹ `ts` یا Omnibar پریفکس `ts:`۔
- **طرز عمل**: اسکرین کی جیومیٹری کا حساب لگانے کے لیے `chrome.system.display` کا استعمال کرتا ہے۔ دو ٹیبز کو ساتھ ساتھ متصل ونڈوز میں تقسیم کرتا ہے، اور انہیں ایک مخصوص `Split` ٹیب گروپ کے تحت رکھتا ہے۔
- **بحالی**: تقسیم شدہ ونڈو کو بند کرنا یا اسپلٹ اسکرین کو ٹوگل کرنا ونڈو کی اصل پیمائش اور نقاط کو بحال کر دیتا ہے۔

### 4.5 YouTube Looping Subsystem
یوٹیوب لوپنگ سب سسٹم میڈیا کو بار بار چلانے کے لیے درست کنٹرول فراہم کرتا ہے جو براہ راست یوٹیوب پلیئر میں مربوط ہیں:
- **ڈیسک ٹاپ پلیئر بٹن (`#itg-yt-loop-button`)**: یوٹیوب پلیئر کے معیاری کنٹرول بار (`.ytp-right-controls`) میں، Cast / Remote بٹن یا PiP لانچر کے بائیں جانب شامل کیا گیا ہے۔ اس میں متحرک SVG لوپنگ گلفس، ٹوگل ہائی لائٹ اسٹائلنگ (`ytp-loop-active`، `var(--interactive-color, #ff4444)`)، اور `aria-pressed` کی کیفیات شامل ہیں۔
- **شارٹس پلیئر بٹن (`#itg-yt-shorts-loop-button`)**: ورٹیکل ویڈیو مواد کو ایک کلک سے بار بار چلانے کے لیے یوٹیوب شارٹس کے دائیں جانب والے کنٹرول کالم (`ytd-shorts`) میں `#itg-yt-shorts-loop-wrapper` کے اندر شامل کیا گیا ہے۔
- **لوپ مینو اور PiP پاپ اپ (`#itg-yt-loop-menu` اور `#itg-pip-loop-popup`)**: لوپ بٹن پر ہوور کرنے یا کلک کرنے سے جامع لوپ ترتیبات کا مینو کھل جاتا ہے:
  - **A-B لوپنگ**: صارفین انٹرایکٹو رینج سلائیڈرز اور دستی ٹائم فیلڈز کے ساتھ ملی سیکنڈ کی درستگی تک مخصوص آغاز کا نقطہ (A) اور اختتامی نقطہ (B) مقرر کر سکتے ہیں۔
  - **سائیکل موڈ اور ترتیب کا اعادہ**: مخصوص لوپس کے لیے تکرار کی تعداد مقرر کریں یا لامحدود لوپ موڈ (`itg-loop-seq-inf`) کو ٹوگل کریں۔
  - **لوپ لسٹ اور کثیر حصوں کی ترتیب**: متعدد A-B لوپ وقفوں کو قطار میں لگائیں جو ترتیب شدہ تکرار کے مطابق ایک کے بعد ایک چلتے ہیں۔
  - **اسٹیٹس اور دورانیہ کا ڈسپلے**: موجودہ لوپ کے وقفے میں ریئل ٹائم پلے بیک کی پوزیشن اور میڈیا کا کل دورانیہ (`00:00 / 00:00`) دکھاتا ہے۔
  - **ماسٹر ٹوگل (`youtubeLoopEnabled`)**: `chrome.storage.sync` اور `local` میں محفوظ ہوتا ہے، جس سے صارفین Customize Hints ترتیبات کے صفحے (`YoutubeLoopSection.svelte`) کے ذریعے یوٹیوب اور یوٹیوب شارٹس پر لوپ بٹنوں کو فعال یا غیر فعال کر سکتے ہیں۔

### 4.6 YouTube Shorts Preview Audio
- **آڈیو ان میوٹ ہک (`youtubePreviewAudioHook.js`)**:
  - `ytd-video-preview` عناصر پر `#inline-preview-player` پراپرٹی تک رسائی حاصل کرنے کے لیے `MAIN` ایگزیکیوشن ورلڈ میں چلتا ہے۔
  - **زبردستی میوٹ پر قابو پانا**: یوٹیوب آڈیو کنٹرولز کو صاف کر کے اور اندرونی `volumechange` سننے والوں کے ذریعے `muted = true` بحال کر کے شارٹس کے پیش نظارہ پر زبردستی میوٹ نافذ کرتا ہے۔
  - یہ ایکسٹینشن ہوور کرنے پر مطلوبہ `<video>` عنصر پر `HTMLMediaElement.prototype.muted` پراپرٹی ڈسکرپٹر کو ہک کرتی ہے۔ یہ یوٹیوب کے زبردستی دوبارہ میوٹ کرنے کو ختم کر دیتی ہے جبکہ صارف کو ان میوٹ کرنے کی اجازت دیتی ہے، جس سے یہ یقینی بنتا ہے کہ ماؤس ہٹانے تک لوپ دوبارہ شروع ہونے پر بھی آواز بغیر کسی رکاوٹ کے مسلسل چلتی رہے۔

### 4.7 Picture-in-Picture (PiP) Architecture
- **Document Picture-in-Picture (`wp`)**:
  - ایک تیرتی ہوئی، ہمیشہ اوپر رہنے والی ونڈو کے اندر پورا ویب صفحہ یا ٹیکسٹ اسنیپٹ کھولنے کے لیے جدید `documentPictureInPicture` API کا استعمال کرتا ہے۔
  - میڈیا کو منتقل کرتے وقت ویڈیو پلے بیک کے ٹائم اسٹیمپ کو خود بخود سنکرونائز کرتا ہے۔
  - دوبارہ کوشش کی منطق (`itgRetryIfPipFrameRefused`) پر مشتمل ہے اور بند ہونے پر DNR آئی فریم ہیڈرز کو صاف کرتا ہے۔
- **Video Picture-in-Picture (`wv`)**:
  - `videoPipHook.js` کے ذریعے `HTMLVideoElement.prototype.requestPictureInPicture` کو ہک کرتا ہے۔
  - ویڈیو پلیئرز کو لوپ کنٹرولز اور پلے بیک اسپیڈ سلیکٹرز کے ساتھ حسب ضرورت PiP فریموں میں ری ڈائریکٹ کرتا ہے۔
- **Auto-PiP**:
  - `as`: اسکرول پر Auto-PiP کو ٹوگل کریں (ویو پورٹ سے باہر اسکرول کرنے پر ویڈیو کو PiP میں چلاتا ہے)۔
  - `ah`: ٹیب چھپانے پر Auto-PiP کو ٹوگل کریں (دوسرے ٹیب پر سوئچ کرتے وقت ویڈیو کو PiP میں لانچ کرتا ہے)۔

### 4.8 Page Reading Modes & Visual Overlays
- **CSS فلٹر تھیمز**: ویب صفحات میں غیر تخریبی اسٹائلز داخل کرتا ہے:
  - `mb` / `mB`: سیاہ (ڈارک ہائی کنٹراسٹ) — ٹیب کا دائرہ کار / عالمی دائرہ کار۔
  - `ms` / `mS`: سیپیا (گرم کاغذ) — ٹیب کا دائرہ کار / عالمی دائرہ کار۔
  - `mp` / `mP`: کاغذ (مونوکروم گرے اسکیل) — ٹیب کا دائرہ کار / عالمی دائرہ کار۔
  - `ml` / `mL`: ہلکا (ہلکا سفید) — ٹیب کا دائرہ کار / عالمی دائرہ کار۔
  - `me` / `mE`: کسٹم صارف کا وضع کردہ CSS فلٹر — ٹیب کا دائرہ کار / عالمی دائرہ کار۔
  - `ESC`: فعال صفحے کے فلٹر کو فوری طور پر ہٹاتا ہے۔
- **ریڈر موڈ اور TTS باآواز بلند پڑھنا**:
  - `fetchContentForReaderView`: مضامین کا صاف ستھرا مواد نکالتا ہے، اشتہارات، سائیڈ بارز اور نیویگیشن کی رکاوٹوں کو دور کرتا ہے۔
  - بلٹ ان ٹیکسٹ ٹو اسپیچ (TTS) انجن جو جملہ بہ جملہ متن کو باآواز بلند پڑھتا ہے۔
  - کی بورڈ نیویگیشن کنٹرولز: `zp` (چلائیں/روکیں)، `zn` (اگلا جملہ)، `zb` (پچھلا جملہ)، `zq` (ریڈر اوورلے بند کریں)۔

### 4.9 Text Snippets Subsystem with Template Variables
ٹیکسٹ اسنیپٹس کا ذیلی نظام (`src/utils/hint/snippets.js` اور `src/utils/snippet-panel.js` میں `SnippetManager`) کسی بھی ان پٹ، ٹیکسٹ ایریا یا رچ ایڈیٹر میں ٹیکسٹ شارٹ کٹس کو وسعت دے کر ٹائپنگ کو تیز کرتا ہے:
- **محرک کے طریقے**: شارٹ کٹ کے بعد اسپیس ٹائپ کریں، یا انٹرایکٹو اسنیپٹس سرچ پاپ اپ کو لانے کے لیے `$$` ٹائپ کریں۔
- **Clipboard API انضمام**: Clipboard API کے ذریعے فارمیٹ شدہ HTML اور سادہ متن داخل کرنے کی معاونت کرتا ہے، جو Google Docs، Notion، اور Slack جیسے پیچیدہ ایڈیٹرز کے ساتھ 100% مطابقت کو یقینی بناتا ہے۔
- **ٹیمپلیٹ متغیرات (Template Variables)**: وسعت کے وقت متغیرات کو متحرک طور پر حل کرتا ہے:
  - `{{date}}` / `date`: فارمیٹ شدہ مقامی تاریخ (`toLocaleDateString`)۔
  - `{{isodate}}` / `isodate`: ISO 8601 تاریخ (`YYYY-MM-DD`)۔
  - `{{longdate}}` / `longdate`: ہفتے کے دن، تاریخ، مہینے اور سال کے ساتھ لمبی تاریخ۔
  - `{{time}}` / `time`: 2 ہندسوں کا فارمیٹ شدہ وقت (`HH:MM`)۔
  - `{{datetime}}` / `datetime`: تاریخ اور وقت یکجا۔
  - `{{weekday}}` / `weekday`: دن کا مکمل نام (مثلاً Monday)۔
  - `{{day}}` / `day`: مہینے کا دن (1-31)۔
  - `{{month}}` / `month`: مہینے کا مکمل نام (مثلاً October)۔
  - `{{year}}` / `year`: مکمل 4 ہندسوں کا سال۔
  - `{{tomorrow}}` / `tomorrow`: اگلے دن کی تاریخ (+1 دن)۔
  - `{{yesterday}}` / `yesterday`: پچھلے دن کی تاریخ (-1 دن)۔
  - `{{nextweek}}` / `nextweek`: 7 دن بعد کی تاریخ (+7 دن)۔
  - `{{timestamp}}` / `timestamp`: دور کا ملی سیکنڈ ٹائم اسٹیمپ (`Date.now()`)۔
  - `{{url}}` / `url`: فعال ویب پیج کا URL (`window.location.href`)۔
  - `{{domain}}` / `domain`: فعال ڈومین ہوسٹ نام (`window.location.hostname`)۔
  - `{{pagetitle}}` / `pagetitle`: فعال دستاویز کا عنوان (`document.title`)۔
  - `{{uuid}}` / `uuid`: کرپٹوگرافی کے لحاظ سے محفوظ منفرد شناخت کنندہ (`crypto.randomUUID()`)۔
  - `{{random}}` / `random`: 1 اور 1000 کے درمیان بے ترتیب عدد۔
  - `{{clipboard}}` / `clipboard`: سسٹم کے کلپ بورڈ بفر کا متن۔

### 4.10 Embedded Productivity Tools
- **رائٹ کلک کی اجازت دینے والا ہک (`allowRightClickHook.js`)**:
  - رائٹ کلک کانٹیکسٹ مینیوز، کاپی، کٹ یا ٹیکسٹ کے انتخاب کو روکنے والے ویب اسکرپٹس کو ناکارہ بنانے کے لیے `MAIN` ایگزیکیوشن ورلڈ میں داخل کیا جاتا ہے۔
  - `contextmenu`، `copy`، `cut`، `selectstart`، `mousedown`، اور `mouseup` پر `preventDefault()` اور `stopPropagation()` کو روکتا ہے۔
  - ایک مستقل `MutationObserver` کے ذریعے ان لائن `oncontextmenu="return false"` ہینڈلرز کو صاف کرتا ہے۔
  - کلپ بورڈ ڈیٹا کی تصدیق کرتا ہے تاکہ قانونی ویب ایڈیٹرز (Google Docs، Telegram Web) میں خرابی پیدا نہ ہو۔
- **کوکی ایڈیٹر**: صفحے کے اندر موجود ماڈل جو فعال ڈومین کے لیے HTTP اور HTTPS کوکیز کی جانچ، ترمیم، تخلیق اور حذف کرتا ہے۔
- **کیو آر کوڈ جنریٹر**: فوری موبائل منتقلی کے لیے فعال ٹیب کے URL سے SVG/Canvas QR کوڈز بناتا ہے۔
- **صاف پی ڈی ایف پرنٹ ایکسپورٹ**: صاف دستاویز آرکائیو کرنے کے لیے ہیڈرز، اشتہارات اور نیویگیشن کی فالتو چیزوں سے پاک صفحات کو `print.html` کے ذریعے روٹ کرتا ہے۔

### 4.11 Comprehensive 3-Tier Duplicate Removal & Intelligent Discarding
- **ڈپلیکیٹس کا جامع 3 سطحی خاتمہ**:
  1. **ٹیبز کے ڈپلیکیٹ کا خاتمہ (`removeDuplicateTabsCommand`)**: تمام ونڈوز یا مخصوص گروپس میں کھلے ہوئے ٹیبز کو اسکین کرتا ہے، ایک جیسے URLs کی شناخت کرتا ہے، `Split` اسکرین ٹیبز کو مستثنیٰ رکھتا ہے، اور فعال یا قدیم ترین ٹیب کو برقرار رکھتے ہوئے فالتو ٹیبز کو بند کرتا ہے۔ ڈیسک ٹاپ پر خلاصہ کا نوٹیفکیشن دکھاتا ہے۔
  2. **بک مارکس کے ڈپلیکیٹ کا خاتمہ**: Chrome کے بک مارک ٹریز کو گہرائی سے اسکین کرتا ہے، تمام فولڈرز میں بالکل یکساں URLs تلاش کرتا ہے، اور بک مارکس کو صاف رکھنے کے لیے بیچ میں یکجا کرنے کی سہولت فراہم کرتا ہے۔
  3. **قواعد کے ڈپلیکیٹ کا خاتمہ (`feature_v100_dedup_add_to_rule`)**: موجودہ کسٹم گروپنگ قواعد میں URLs شامل کرتے وقت یکساں URL پیٹرنز کو خود بخود خارج کرتا ہے، جس سے قواعد میں غیر ضروری اضافے کی روک تھام ہوتی ہے۔
- **میموری کا ذہین اخراج (`suspendInactiveTabsIntelligently`)**:
  - `itg-periodic-tasks` الارم کے ذریعے ہر 1 منٹ بعد جانچا جاتا ہے۔
  - ان ٹیبز کو خارج کر دیتا ہے جو `>= discardingTimeMinutes` (ڈیفالٹ: 60 منٹ) تک غیر فعال رہتے ہیں۔
  - بلٹ ان تحفظات: کبھی بھی فعال ٹیبز، آواز چلانے والے ٹیبز، پن کیے گئے ٹیبز، یا پہلے سے معطل شدہ ٹیبز کو خارج نہیں کرتا۔

## 5. Section 4: AI Assistant & Autonomous Agent (Asistente AI)

AI اسسٹنٹ براؤزر کے اندر بڑے لینگویج ماڈلز کو مربوط کرتا ہے تاکہ سیاق و سباق کی تفہیم، خودکار ورک فلوز، اور براؤزر کے براہ راست خودکار کنٹرول کو ممکن بنایا جا سکے۔

### 5.1 Dual Model Engine Architecture
1. **Google Gemini Cloud API (`gemini-api.js`)**:
   - Google Generative Language REST اینڈ پوائنٹس (`v1beta/models/{model}:generateContent` اور `:streamGenerateContent`) کے ساتھ ضم ہوتا ہے۔
   - Gemini 2.5 Flash، Gemini 2.5 Pro، اور حسب ضرورت ماڈل اینڈ پوائنٹس کو سپورٹ کرتا ہے۔
   - **ملٹی کی روٹیشن**: `geminiApiKeysList` میں کلیدی پولز کا انتظام کرتا ہے۔ اسٹوریج کی حفاظت کے لیے `enc_` پریفکسز کا استعمال ہوتا ہے۔
   - **ایکسپونینشل بیک آف**: HTTP 429 کوٹہ ختم ہونے پر خودکار دوبارہ کوشش (1.5s -> 3s -> 6s) کے ساتھ نمٹتا ہے۔
   - **تلاش کی بنیاد (Search Grounding)**: Google Search Grounding (`google_search: {}`) کو فعال کرتا ہے۔ اگر تلاش کے ٹولز پر کوٹہ کی پابندیوں کی وجہ سے HTTP 403 کی خرابی پیش آئے، تو یہ خود بخود گراؤنڈنگ کے بغیر دوبارہ کوشش کرتا ہے۔
2. **Chrome کا بلٹ ان AI / Prompt API (`localAiService.js`)**:
   - `window.LanguageModel` کے ذریعے آن ڈیوائس Gemini Nano انضمام۔
   - بغیر نیٹ ورک کے مقامی عمل درآمد کو سپورٹ کرتا ہے۔ ماڈل کی دستیابی کی جانچ اور ڈاؤن لوڈ کی لائیو پیش رفت سے باخبر رہتا ہے۔

### 5.2 Autonomous Browser Agent (`agent-backend.js`)
خود مختار ایجنٹ 40 سے زیادہ منظم ٹولز کے ذریعے براؤزر پر مکمل کنٹرول فراہم کرتا ہے:
- **ٹیب اور گروپ کنٹرول**: `getOpenTabs`, `switchToTab`, `createNewTab`, `closeTab`, `closeTabs`, `duplicateTab`, `findAndSwitchToTab`, `groupTabs`, `ungroupTabs`, `deleteTabGroup`, `collapseTabGroup`, `expandTabGroup`, `collapseAllGroups`, `expandAllGroups`, `setGroupColor`, `renameTabGroup`, `regroupAllTabs`, `removeDuplicateTabs`, `closeTabsWithSound`۔
- **نیویگیشن اور تلاش**: `openUrl`, `searchGoogle`, `getActiveTab`, `getActiveTabContent`۔
- **علم اور بک مارکس**: `getBookmarks`, `searchBookmarks`, `createBookmark`, `getHistory`, `getRecentlyClosed`۔
- **قواعد اور ظاہری شکل**: `getRules`, `createRule`, `updateRule`, `deleteRule`, `getActiveTheme`, `getSavedThemes`, `applyTheme`۔

### 5.3 Taint Tracking & Prompt Injection Defense
غیر معتبر ویب صفحات سے بالواسطہ پرامپٹ انجیکشن حملوں کو بے اثر کرنے کے لیے، ایجنٹ کا بیک اینڈ سخت ٹینٹ ٹریکنگ (Taint Tracking) لاگو کرتا ہے:
- **ٹینٹ کی نشاندہی**: `getActiveTabContent` کو کال کرنے سے ویب صفحہ سے متن نکلتا ہے اور موجودہ عمل درآمد کو آلودہ (tainted) کے طور پر نشان زد کیا جاتا ہے (`taintedAgentRuns.add(runId)`)۔
- **اخراج پر پہرہ (Egress Guard)**: آلودہ رنز کے لیے بیرونی ٹولز (`AGENT_EGRESS_TOOLS`) کے استعمال پر سخت پابندی عائد ہوتی ہے:
  * `openUrl`, `searchGoogle`, `createBookmark`, `createRule`, `addUrlToRule`, `createSiteShortcut`, `updateSiteShortcut`, `updateRule`۔
- **انکار کا طریقہ کار**: غیر ہینڈل شدہ خرابی دینے کے بجائے، انجن ایک منظم حفاظتی وضاحت واپس کرتا ہے۔ اس کے بعد LLM صارف کو مطلع کرتا ہے کہ صارف کی واضح رضامندی کے بغیر بیرونی ڈیٹا باہر نہیں بھیجا جا سکتا۔

### 5.4 Scheduled Gemini Queries Subsystem (`GeminiScheduleModal.svelte`)
- **پس منظر کا ایگزیکیوشن انجن**:
  - `chrome.alarms` (`gemini-scheduled-*`) کے ذریعے بیک گراؤنڈ سروس ورکر میں طے شدہ AI پرامپٹس کے عمل درآمد کو خودکار بناتا ہے۔
  - روزانہ 6 طے شدہ استفسارات تک کی اجازت دیتا ہے (`MAX_TIMES = 6`)۔
  - **شیڈولنگ موڈز**:
    - بار بار ہونے والے شیڈولز: ہفتے کے منتخب دنوں میں بار بار انجام پاتے ہیں (`selectedDays`)۔
    - ایک بار کے شیڈولز: ایک مخصوص ہدف کی تاریخ اور وقت پر چلتے ہیں (`formDate`)۔
    - **پرامپٹ کی حدیں**: ریئل ٹائم کیریکٹر کاؤنٹرز کے ساتھ 1,000 حروف کی سخت حد نافذ کرتا ہے (`MAX_QUERY_CHARS = 1000`)۔
    - **بیک گراؤنڈ نوٹیفیکیشنز**: جب بیک گراؤنڈ استفسار مکمل ہو جاتا ہے تو اسنیپٹ کے پیش نظارہ کے ساتھ ڈیسک ٹاپ نوٹیفکیشن بھیجتا ہے۔ نوٹیفکیشن پر کلک کرنے سے سائیڈ پینل چیٹ کے اندر فوری طور پر جواب کی گفتگو کھل جاتی ہے۔

### 5.5 Gemini Conversation Management & Export
- **مستقل IndexedDB اسٹوریج (`geminiConversations`)**: بات چیت کے سیشنز کو IndexedDB کے `Intelligent_Workspace` اسٹور `geminiConversations` میں محفوظ کیا جاتا ہے۔
- **مکمل ٹیکسٹ ہسٹری کی تلاش**: Omnibar کمانڈز `lai:` (گفتگو براؤز کریں) اور `laiq:` (پیغامات تلاش کریں) کے ذریعے تمام ماضی کی گفتگوؤں اور انفرادی پیغامات میں فوری تلاش۔
- **برآمد کے چار فارمیٹس**:
  1. **اسٹائل شدہ HTML**: اسٹائلش چیٹ بلبلز، کردار کے بیجز، ٹائم اسٹیمپ اور سنٹیکس ہائی لائٹڈ کوڈ بلاکس کے ساتھ فارمیٹ شدہ خود مختار HTML دستاویز۔
  2. **خام JSON**: میسج اریز، ٹوکن کے استعمال، ماڈل کنفیگریشن اور سرچ کے حوالہ جات سمیت مکمل منظم ڈیٹا ڈمپ۔
  3. **Markdown**: ہیڈرز، ٹائم اسٹیمپس اور باؤنڈ کوڈ بلاکس (` ``` `) کے ساتھ فارمیٹ شدہ معیاری Markdown فائل۔
  4. **سادہ متن**: ای میل یا نوٹس کے لیے موزوں صاف، غیر فارمیٹ شدہ گفتگو کا مسودہ۔
- **گراؤنڈنگ میٹا ڈیٹا ٹریکنگ**: ماڈل ID، ٹوکن کے استعمال کے اعدادوشمار، ایگزیکیوشن ٹائم اسٹیمپس اور Google Search Grounding سے واپس آنے والے سورس کے حوالہ جات کا سراغ لگاتا ہے۔

### 5.6 Multimodal Inputs & File Attachments (`feature_geminiAttachFiles`)
- **ملٹی موڈل منسلکات**: ٹوگل `feature_geminiAttachFiles` چیٹ پرامپٹس میں تصاویر اور دستاویزات کی براہ راست شمولیت کو ممکن بناتا ہے:
  - تصویری فائلیں (JPEG, PNG, WebP, HEIC/HEIF)۔
  - پی ڈی ایف دستاویزات اور تحقیقی مقالے۔
  - سادہ ٹیکسٹ فائلیں اور کوڈ فائلیں۔
  - CSV ساختہ ڈیٹا سیٹس۔
- **آواز کی معاونت**:
  - بغیر ہاتھوں کے پرامپٹس بولنے کے لیے Web Speech STT (Speech-to-Text)۔
  - جوابات کو باآواز بلند سننے کے لیے Web Speech TTS (Text-to-Speech)۔

### 5.7 Invocation Modalities
- **Sidepanel روٹ**: `?view=gemini` یا شارٹ کٹ `pa`۔
- **صفحے کے اندر Omnibar پریفکسز**:
  - `qai: <query>` — تشکیل شدہ Gemini ماڈل سے براہ راست سوال پوچھیں۔
  - `qaia: <prompt>` — ٹول پر عمل درآمد کے ساتھ خود مختار ایجنٹ کے ذریعے پرامپٹ پر عمل کریں۔
  - `lai:` — ماضی کی AI گفتگو کی ہسٹری براؤز کریں۔
  - `laiq:` — AI پیغامات کے اندر مکمل ٹیکسٹ تلاش کریں۔
- **Omnibox AI ٹیب تلاش (`find <query>`)**:
  - URL بار کا کلیدی لفظ `find` ہائبرڈ تلاش شروع کرتا ہے۔
  - قدرتی زبان کے سوالات کی بنیاد پر کھلے ہوئے ٹیبز کو تلاش کرنے اور فوکس کرنے کے لیے regex ورڈ باؤنڈری اسکورنگ کو Gemini معنوی تفہیم کے ساتھ یکجا کرتا ہے۔

## 6. Section 5: Notes View & Knowledge Management (Ver Notas)

ایک مقامی ترجیحی (local-first)، سیاق و سباق سے آگاہ نوٹ لینے والا انجن جو براؤزر ٹیب گروپس اور نیویگیشن سیاق و سباق سے جڑا ہوا ہے۔

### 6.1 Storage Architecture (`notesStore`)
IndexedDB ڈیٹا بیس `Intelligent_Workspace` (v8) کے اندر آبجیکٹ اسٹور `notesStore` میں محفوظ ہے:
```typescript
interface NoteRecord {
  id: string;          // Unique note identifier.
  title: string;       // Note title.
  text: string;        // Rich text HTML, Markdown, or serialized task payload.
  type: NoteType;      // 'text' | 'checklist' | 'kanban'
  url?: string;        // Origin URL where note was created.
  contextKey: string;  // Scoping key binding note to workspace hierarchy.
  createdAt: number;   // Creation timestamp.
  modifiedAt: number;  // Last edit timestamp.
  isPersistent: boolean; // Pin flag protecting note from group deletion cleanup.
}
```

### 6.2 Specialized Note Formats & Advanced Rendering
1. **ٹیکسٹ نوٹ (`NoteTextEditor.svelte`)**:
   - رچ ٹیکسٹ `contenteditable` سطح۔
   - میڈیا کو براہ راست شامل کرتا ہے: تصاویر، آڈیو، ویڈیو اور پی ڈی ایف دستاویزات۔
   - بلٹ ان HTML صفائی اور حقیقی وقت کے الفاظ اور حروف کے کاؤنٹرز۔
   - **Mermaid ڈایاگرام رینڈرنگ**: Markdown فینسز (` ```mermaid `) سے براہ راست متحرک فلو چارٹس، سیکوئنس ڈایاگرامز، کلاس ڈایاگرامز اور اسٹیٹ مشینیں تیار کرتا ہے۔
   - **KaTeX ریاضیاتی LaTeX**: انتہائی درست ٹائپوگرافی کے ساتھ ان لائن مساوات (`$...$`) اور بلاک مساوات (`$$...$$`) کو رینڈر کرتا ہے۔
2. **چیک لسٹ نوٹ (`NoteChecklistEditor.svelte`)**:
   - انفرادی تکمیل کے چیک باکسز کے ساتھ انٹرایکٹو ٹاسک لسٹ۔
   - کی بورڈ سے آئٹمز کی دوبارہ ترتیب اور پیش رفت کی نگرانی کی سہولت۔
3. **Kanban نوٹ (`NoteKanbanEditor.svelte`)**:
   - 3 کالموں پر مشتمل ورک فلو بورڈ: `To Do` -> `In Progress` -> `Done`۔
   - کاموں کی فوری منتقلی کے لیے سائیکلنگ اسٹیٹس چپس۔
- **متحرک بغیر نقصان کے تبدیلی**: نوٹس ٹیکسٹ، چیک لسٹ اور Kanban کی شکلوں کے درمیان بغیر کسی ڈیٹا کے نقصان کے تبدیل ہو جاتے ہیں۔

### 6.3 Scoping & Context Hierarchy
نوٹس `contextKey` کے ذریعے براؤزنگ کے سیاق و سباق سے منسلک ہوتے ہیں:
- **گروپ کا دائرہ کار (`g_<groupId>` یا `g_<groupKey>`)**: پورے ٹیب گروپ کے ساتھ منسلک۔
- **ذیلی گروپ کا دائرہ کار (`s_<groupId>_<domain>`)**: ٹیب گروپ کے اندر ایک مخصوص ڈومین کے ساتھ منسلک۔
- **غیر گروپ شدہ دائرہ کار (`g_ungrouped` / `s_ungrouped_<domain>`)**: ٹیب گروپس سے باہر کے ٹیبز پر بنائے گئے نوٹس۔
- **Pomodoro اور عمومی دائرہ کار (`pomodoro`, `general`)**: ورک اسپیس پر محیط نوٹس۔
- **یتیم نوٹس کا پتہ لگانے والا انجن (Orphan Detection Engine)**: جب ٹیب گروپس یا ڈومینز حذف ہو جاتے ہیں، تو متعلقہ غیر مستقل نوٹس کو Orphan Detector محفوظ کر لیتا ہے۔ نوٹس UI میں دوبارہ تفویض کرنے یا حذف کرنے کے لیے دستیاب رہتے ہیں۔

### 6.4 Invocation Modalities
- **UI لانچرز**: گروپ کارڈز اور سب گروپ کارڈز پر "View Notes" کا بٹن؛ پاپ اپ ہیڈر میں "Quick Notes" کا بٹن؛ سائیڈ پینل روٹ `?view=notes` (`pk`)۔
- **کانٹیکسٹ مینو ٹرگر**: کسی بھی ویب پیج پر متن منتخب کریں -> رائٹ کلک کریں -> "Crear Nota desde Selección" (`note-from-selection`)۔ منتخب متن کو خود بخود نکالتا ہے اور قریب ترین `h1`-`h3` ہیڈنگ کو عنوان بنا دیتا ہے۔
- **Vim ہنٹ**: `ao` موجودہ انتخاب سے ایک نوٹ بناتا ہے۔
- **Omnibar**: `lnt:` فوری فل ٹیکسٹ تلاش کے ساتھ نوٹس براؤزر کھولتا ہے۔
- **آڈیو پڑھنا**: ایڈیٹر کے اندر موجود TTS بٹن Web Speech API کا استعمال کرتے ہوئے نوٹ کے مواد کو باآواز بلند پڑھتا ہے۔

## 7. Section 6: Media & Gallery View (Ver Galería)

ایک اعلیٰ کارکردگی کا میڈیا کیپچر، اینوٹیشن اور آپٹیکل کریکٹر ریکگنیشن (OCR) پائپ لائن۔

### 7.1 Capture Modes & Engineering (All 7 Capture Types)
ایکسٹینشن سنگل ٹیب، کراس ٹیب، کراپ شدہ اور پیلیٹ کے کاموں کا احاطہ کرنے والے 7 مخصوص کیپچر طریقے فراہم کرتی ہے:
1. **`visible` (Visible Viewport Capture - `cs`)**:
   - `chrome.tabs.captureVisibleTab` کا استعمال کرتے ہوئے فعال ٹیب کے بالکل نظر آنے والے حصے کو قید کرتا ہے۔
   - کیپچر کو خود بخود IndexedDB `screenshots` اسٹور میں محفوظ کرتا ہے اور تصویر کے بٹ میپ کو براہ راست سسٹم کلپ بورڈ پر کاپی کرتا ہے (`screenshotSavedAndCopied`)۔
2. **`fullPage` (Seamless Full-Page Scrolling Canvas - `cp`)**:
   - دستاویز کے اسکرول کی کل اونچائی کا حساب لگاتے ہوئے، پروگرام کے مطابق صفحہ کو اسکرول کرتا ہے۔
   - بصری جھٹکوں کو ختم کرنے کے لیے اسکرول بارز کو دبا دیتا ہے اور ابتدائی حصے کے بعد اسٹکی/فکسڈ نیویگیشن بارز کو چھپا دیتا ہے۔
   - بٹ میپ کے ٹکڑوں کو `OffscreenCanvas` پر 30,000px اونچائی تک جوڑتا ہے (`captureFullPageDataUrl`)، جو فریم کیپچرز کے درمیان Chromium کے مطابق 600ms کی تاخیر کو نافذ کرتا ہے۔
3. **`fullPageParts` (Sequential Sliced Segments - `cpp` / `cP`)**:
   - لمبی دستاویزات کو پےجینیشن کے لیے 60 تک نمبر والے امیج چنکس تیار کرتے ہوئے، انفرادی ویو پورٹ اونچائی کے تصویری حصوں میں کاٹتا ہے (`captureFullPageParts`)۔
4. **`area` (Interactive Rectangular Drag Crop - `ca`)**:
   - `area-selector.js` کو شامل کرتا ہے، جو باؤنڈنگ باکس کی ریئل ٹائم پیمائش کے ساتھ ایک کراس ہیئر کینوس چڑھاتا ہے۔
   - ڈریگ کے قابل سلیکشن ہینڈلز، پیمائش کا ٹول ٹِپ، تصدیقی محرک، `Esc` کلید کے ذریعے منسوخی اور ملٹی ٹیب کراپ قطار (`handleCaptureAreaFromShortcut`)۔
5. **`groupTabs` (Batch Active Group Tab Walk - `Cs`, `Cp`, `CP`)**:
   - فعال ٹیب گروپ کے اندر موجود ہر ٹیب کو ترتیب وار کھولتا ہے (`handleCaptureGroupFromShortcut`)۔
   - نظر آنے والے، مکمل صفحے یا کٹے ہوئے حصوں کے موڈ میں بیچ کیپچر کی حمایت کرتا ہے، اور انہیں ایک مجموعے میں مرتب کرتا ہے۔
6. **`omnibarPickedTabs` (Custom Multi-Tab Queue Capture)**:
   - Omnibar کمانڈز `cs:`، `cp:`، `cpp:`، یا `ca:` کے ذریعے شروع کیا جاتا ہے (`handleCaptureTabs`)۔
   - صارف کے فلٹر کردہ تمام ٹیبز پر حقیقی وقت کے پروگریس انڈیکیٹرز کے ساتھ ترتیب وار کیپچرز انجام دیتا ہے۔
7. **`colorPickerCapture` (Background Screen Eyedropper Fallback)**:
   - ان آپریٹنگ سسٹمز پر جن میں مقامی `window.EyeDropper` سپورٹ کا فقدان ہے (مثلاً Linux)، پریسجن ہیکس آئی ڈراپر میگنیفائر ٹول کو چلانے کے لیے بیک گراؤنڈ اسکرین کیپچر لیتا ہے۔

### 7.2 Gallery UI & Persistence
- **انٹرفیس**: لائٹ باکس زوم، پین اور روٹیٹ ٹولز کے ساتھ ریسپانسو میسنری/گرڈ لے آؤٹ۔
- **استحکام (`screenshots` اسٹور)**: IndexedDB `Intelligent_Workspace` میں محفوظ ہے۔ ان پن شدہ کیپچرز دیکھ بھال کے دوران خود بخود حذف ہو جاتے ہیں؛ پن آئیکون پر کلک کرنے سے (`isPersistent = true`) کیپچرز غیر معینہ مدت تک محفوظ رہتے ہیں۔

### 7.3 Export, In-Browser OCR & External Markup
- **برآمدی فارمیٹس (`captureDownloadFormats`)**:
  - اعلی کارکردگی والے فارمیٹس: PNG, WebP, AVIF۔
  - `pdf.js` کے ذریعے کثیر صفحات پر مشتمل مرتب کردہ PDF دستاویز کی برآمد۔
- **آن ڈیوائس WASM OCR**:
  - براؤزر میں Tesseract.js WebWorker جو پہلے سے لوڈ کردہ ہسپانوی اور انگریزی (`spa+eng`) لینگویج ماڈلز کو استعمال کرتا ہے۔
  - نیٹ ورک پر تصویری ڈیٹا بھیجے بغیر متن کو براہ راست کلپ بورڈ پر نکالتا ہے۔
- **براہ راست بھیجنے کا انضمام**:
  - نکالے گئے OCR ٹیکسٹ یا تصویری منسلکات کو ایک کلک سے نوٹس (`notesStore`) یا Gemini AI پرامپٹس (`feature_geminiAttachFiles`) میں منتقل کرنا۔
- **Excalidraw مارک اپ**: ایک کلک کے ساتھ برآمد، فری ہینڈ ڈرائنگ، تیروں اور ویکٹر اینوٹیشنز کے لیے کیپچر کی گئی تصاویر کو براہ راست `https://excalidraw.com/` پر بھیجتی ہے۔

### 7.4 Invocation Modalities
- **UI**: گروپ کارڈ کیمرہ بٹن، پاپ اپ فوری کارروائی، سائیڈ پینل گیلری روٹ `?view=gallery` (`ps`)۔
- **Vim ہنٹس**: `cs` (نظر آنے والا)، `cp` (مکمل صفحہ)، `cP` (حصے)، `ca` (کراپ ایریا)، `Cs` (گروپ کا نظر آنے والا)، `Cp` (گروپ کا مکمل صفحہ)، `CP` (گروپ کے حصے۔
- **Omnibar پریفکسز**: `cs:`، `cp:`، `cpp:`، `ca:`، اور `limg:` (گیلری براؤز کریں)۔

## 8. Section 7: Pomodoro & Timing Suite (Pomodoro)

براؤزر کے سلیپ سائیکلوں کے دوران مطلق درستگی کے لیے بنایا گیا ایک فوکس اور ٹائمنگ کا نظام۔

### 8.1 Timing Engine & Background Architecture
- **زیرو ڈرفٹ ٹائم اسٹیمپ کا حساب**: اسٹیٹس کو `chrome.storage.local` میں مطلق یونکس ٹائم اسٹیمپ (`startTime`، `pausedAt`) کے ساتھ محفوظ کیا جاتا ہے۔ سروس ورکر کا خاتمہ، براؤزر کا دوبارہ آغاز، اور آپریٹنگ سسٹم کے سلیپ موڈز کلاک میں صفر کا فرق پیدا کرتے ہیں۔
- **الارم ڈسپیچر**:
  - `chrome.alarms` کے ذریعے چلنے والا ہائی ریزولوشن کاؤنٹ ڈاؤن ٹکر (`pomodoroTick` 1 سیکنڈ کا وقفہ)۔
  - پس منظر کی دیکھ بھال اور طویل مدتی وقفے کی جانچ `itg-periodic-tasks` (1 منٹ کا وقفہ) کے ذریعے کی جاتی ہے۔
- **آف اسکرین آڈیو چائمز (`offscreen.html`)**: آڈیو چائمز ایک مخصوص Chrome آف اسکرین دستاویز کے ذریعے پیدا کی جاتی ہیں جو `AUDIO_PLAYBACK` کی وجہ سے بنائی گئی ہے۔ میموری کو بچانے کے لیے آواز مکمل ہونے کے 3.5 سیکنڈ بعد خود بخود بند ہو جاتی ہے۔

### 8.2 Exhaustive 4 Timing Modes
1. **Pomodoro (`pomodoro`)**:
   - کام کا دورانیہ: 1 سے 180 منٹ (ڈیفالٹ: 25 منٹ)۔
   - مختصر وقفہ: 1 سے 120 منٹ (ڈیفالٹ: 5 منٹ)۔
   - طویل وقفہ: 1 سے 180 منٹ (ڈیفالٹ: 15 منٹ)۔
   - طویل وقفے سے پہلے سائیکلز: 1 سے 12 سائیکلز (ڈیفالٹ: 4)۔
   - ہدف کا سائیکل گول: 1 سے 99 سائیکلز (ڈیفالٹ: 8)۔
   - خودکار کام شروع کرنے، بریک خودکار شروع کرنے، اور نوٹیفکیشن الرٹس کی سہولت۔
2. **اسٹاپ واچ (`cronometro`)**: لیپ ریکارڈنگ اور توقف کو اسٹاپ کے طور پر استعمال کرنے کی صلاحیت کے ساتھ پروگریسو ٹائمر۔
3. **الٹی گنتی (`temporizador`)**: گھنٹے، منٹ اور سیکنڈ کی وضاحت کرنے والا کسٹم کاؤنٹ ڈاؤن ٹائمر۔
4. **ہدف کے وقت کا الارم (`tiempo`)**: مستقبل کے کسی درست وقت کے لیے الارم لگانے والا کیلنڈر اور کلاک سلیکٹر۔

### 8.3 In-Page Floating Timer Widget
- گھسیٹنے کے قابل، کم سے کم اوورلے جو ویب صفحات پر براہ راست ریئل ٹائم کاؤنٹ ڈاؤن، روکنے/دوبارہ شروع کرنے اور چھوڑنے کے بٹن دکھاتا ہے۔
- ایکسٹینشن پینل یا پاپ اپ پر واپس جائے بغیر فوکس سیشنز کی نگرانی کی اجازت دیتا ہے۔

### 8.4 Group Auto-Collapse Idle Timer
- غیر فعال گروپس کو 1 منٹ کی غیر سرگرمی کے بعد (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`) اور فعال گروپ کو 15 منٹ کی غیر سرگرمی کے بعد (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`) خود بخود سمیٹنے کے لیے فوکس روٹینز کے ساتھ مل کر کام کرتا ہے۔ 0 سے 1440 منٹ تک قابل ترتیب۔

### 8.5 Project Tagging & Metadata
ہر سیشن زمرہ بندی کے میٹا ڈیٹا کو سپورٹ کرتا ہے:
- پروجیکٹ کا نام (18 حروف تک)
- پروجیکٹ ٹیگ (مثلاً `#research`، `#dev`)
- پروجیکٹ فولڈر (مثلاً `/client/project`)

### 8.6 Analytics Engine & 19 KPI Cards
مکمل ڈیش بورڈ (`dashboard.html` یا سائیڈ پینل `dashboard.html?context=sidepanel`) بغیر کسی ڈپلیکیٹ سیشنز کے (`dedupeSessions` بذریعہ `sessionStarted`) 19 اہم کارکردگی کے اشارے (KPIs) کا حساب لگاتا ہے:
1. `focus`: کل فوکس کا وقت۔
2. `sessions`: کل مکمل شدہ سیشنز۔
3. `cycles`: کل مکمل شدہ کام کے چکر۔
4. `efficiency`: اوسط کارکردگی کا فیصد (`Total Focus / Total Time * 100`)۔
5. `activeDays`: منفرد فعال دنوں کی تعداد۔
6. `break`: وقفے کا کل دورانیہ۔
7. `interruptions`: دستی رکاوٹوں/توقفات کی کل تعداد۔
8. `interruptionTime`: رکی ہوئی حالت میں گزارا گیا مجموعی وقت۔
9. `bestSession`: طویل ترین بلا تعطل فوکس سیشن۔
10. `avgFocus`: فی مکمل سائیکل کا اوسط فوکس دورانیہ۔
11. `totalTime`: کام اور وقفوں میں گزارا گیا مجموعی وقت۔
12. `workRest`: کام اور آرام کے دورانیے کا تناسب (`1 : X`)۔
13. `distractionRate`: فی فوکس گھنٹہ رکاوٹوں کی شرح۔
14. `bestDay`: ہفتے کا سب سے زیادہ پیداواری دن۔
15. `goldenHour`: دن کا عروج کا فوکس گھنٹہ (مثلاً `10:00 - 11:00`)۔
16. `projects`: ٹریک کیے گئے مختلف پروجیکٹس کی تعداد۔
17. `avgIntDuration`: ہر رکاوٹ کا اوسط دورانیہ۔
18. `topProject`: سب سے زیادہ جمع شدہ فوکس ٹائم والا پروجیکٹ۔
19. `focusIntensity`: فی فعال دن اوسط فوکس کے گھنٹے۔

اضافی بصری تجزیات میں ڈے اسٹریک ہیٹ میپ کیلنڈر، فی گھنٹہ فوکس ڈسٹری بیوشن بار چارٹ، پروجیکٹ ورائٹی کا بریک ڈاؤن، اور مکمل JSON ڈیٹا درآمد/برآمد شامل ہیں۔

## 9. Section 8: Activity & History Panel (Panel de Actividad)

ایک Declarative Net Request (DNR) ٹریکنگ، تجزیات اور ویب گورننس انجن۔

### 9.1 Data Engine & Storage Topology (`ITG_WEB_ACTIVITY`)
`ITG_WEB_ACTIVITY` کے تحت زیر انتظام:
- `wa:day:YYYY-MM-DD`: فی دن ڈومین کاؤنٹرز (`{ domains: { host: { t: seconds, v: visits, s: sessions, h: { hour: seconds } } } }`)۔
- `wa:days`: ریکارڈ شدہ تاریخ کی چابیاں کی ماسٹر انڈیکس سرنی۔
- `wa:recent`: رنگ بفر جو تازہ ترین 400 وزٹ ٹائم لائن اندراجات کو محفوظ کرتا ہے۔
- `wa:openSegment`: `chrome.storage.session` میں فعال وقتی طبقہ، جو `WA_MAX_SEGMENT_SECONDS = 900s` (15 منٹ) تک محدود ہے تاکہ اگر مشین بغیر بیکار واقعات کے سو جائے تو اعدادوشمار کو خراب ہونے سے بچایا جا سکے۔
- **بیکار رہنے کا پتہ لگانا**: `chrome.idle` استعمال کرتا ہے (ڈیفالٹ: 300s / 5m)۔ آڈیو پلے بیک فعال ٹریکنگ کو برقرار رکھتا ہے یہاں تک کہ جب ونڈوز غیر فوکسڈ ہوں اگر `countAudible = true` ہو۔
- **برقراری (Retention)**: `retentionDays` (ڈیفالٹ: 180 دن) سے پرانے دن کے ریکارڈز کو خود بخود صاف کرتا ہے۔

### 9.2 Declarative Net Request (DNR) Site Blocker
- **متحرک رول کی تخصیص**: ID کی حد `9000` سے `9999` میں متحرک قواعد مختص کرتا ہے۔
- **ری ڈائریکٹ ہدف**: بلاک کی گئی درخواستیں `src/ui/pages/web-activity/blocked.html?d=<domain>&u=\1` پر ری ڈائریکٹ ہوتی ہیں۔
- **کھلے ٹیبز کی صفائی**: جب سائٹ کی حد ختم ہو جاتی ہے، تو بیک گراؤنڈ ورکر فوری طور پر ڈومین سے ملنے والے موجودہ کھلے ٹیبز کو ری ڈائریکٹ کر دیتا ہے۔
- **رات کے شیڈول کا دورانیہ**: آدھی رات کو عبور کرنے والے نظام الاوقات (مثلاً `22:00` سے `02:00`) کا خود بخود جائزہ لیا جاتا ہے۔
- **رعایتی / اسنوز کی مدت (+5 منٹ)**: بلاک اسکرین عارضی 5 منٹ کے اسنوز پاسز کی اجازت دیتی ہے، جو `wa:snoozeUses` میں ٹریک کیے جاتے ہیں۔

### 9.3 Asymmetric Security Lock (`blockLock.js`)
سائٹ کی حدود کو غیر متناسب پاس ورڈ لاک سے محفوظ کیا جا سکتا ہے:
- **ہیش اسٹوریج**: بے ترتیب 16 بائٹ نمک اور SHA-256 ہیکس ڈائجسٹ محفوظ کرتا ہے (`wa:settings.blockPassword`)۔
- **غیر متناسب اصول کی پالیسی**: نئی حدود بناتے وقت یا قواعد کو سخت بناتے وقت (مثلاً وقت کی الاؤنس کو کم کرنا یا شیڈول کی پابندیاں شامل کرنا) پاس ورڈ **کبھی نہیں مانگا جاتا**۔
- **محفوظ کارروائیاں**: پاس ورڈ صرف اس وقت مانگا جاتا ہے جب **قواعد میں نرمی کی جائے** (حد کو حذف کرنا، وقت کا الاؤنس بڑھانا، یا نظام الاوقات کو غیر فعال کرنا) یا روزانہ کی مفت حد سے تجاوز کرنے کے بعد اسنوز کا استعمال کرتے ہوئے (`snoozePasswordAfter`)۔

### 9.4 Categorization & Visual Analytics
- **16 بلٹ ان زمرے**: `social`، `video`، `music`، `news`، `shopping`، `reading`، `entertainment`، `dev`، `work`، `education`، `games`، `finance`، `mail`، `ai`، `search`، `other`۔
- **کسٹم زمرے**: صارف کے طے کردہ زمروں کو سپورٹ کرتا ہے جن کے شروع میں `custom:` ہوتا ہے۔
- **فوکس کا تناسب**: پیداواری زمروں (`dev`، `work`، `education`، `reading`، `finance`، `mail`) کا غیر پیداواری زمروں (`social`، `video`، `games`، `shopping`، `entertainment`) سے موازنہ کرتا ہے۔
- **بصری تجزیات**: Chart.js کے فی گھنٹہ سرگرمی کے گراف، زمرہ کے ڈونٹ چارٹس، اور ڈومین کی درجہ بندی کی فہرستیں۔

### 9.5 Downloads Manager Subsystem (`switchMainView('downloads')`)
- **مخصوص روٹ**: سائیڈ پینل میں `switchMainView('downloads')` (`?view=downloads`) کے ذریعے رسائی حاصل کی جاتی ہے۔
- **براہ راست Chrome API انضمام**: حقیقی وقت میں براؤزر کے تمام ڈاؤن لوڈز کو ٹریک کرنے، منظم کرنے اور جانچنے کے لیے `chrome.downloads` کو ہک کرتا ہے۔
- **ریئل ٹائم فزی تلاش**: فائل کے نام، فائل کے راستے، یا ڈاؤن لوڈ سورس کے URL کے ذریعے فوری تلاش۔
- **اسٹیٹس فلٹر چپس**: حالت کے لحاظ سے ڈاؤن لوڈز کو تیزی سے فلٹر کریں: `All`، `In Progress`، `Complete`، `Paused`، اور `Interrupted`۔
- **کیلنڈر تاریخ کی حد کا فلٹر**: مخصوص تاریخوں یا وقت کے وقفوں کے لحاظ سے ڈاؤن لوڈز کو محدود کریں۔
- **بیچ گروپ ڈاؤنلوڈر**: فعال گروپ میں کھلے ٹیبز سے تمام ڈاؤن لوڈ لنکس نکالتا ہے اور پیش رفت سے باخبر رہتے ہوئے بیچ ڈاؤن لوڈز شروع کرتا ہے۔
- **فائل کا انتظام**: ایک کلک کے ساتھ فائل کو کھولنا (`chrome.downloads.open`) اور فولڈر کو ظاہر کرنا (`chrome.downloads.show`)۔

### 9.6 Recently Closed Tabs & Browsing History Subsystem
- **حال ہی میں بند کیے گئے ٹیبز کا ویو**:
  - `chrome.sessions.getRecentlyClosed` کے ساتھ براہ راست مربوط۔
  - خودکار اعراب کو ہٹانے کے ساتھ حقیقی وقت کی تلاش (`deaccent`)۔
  - ایک کلک یا Omnibar کمانڈ `c:` کے ساتھ سنگل ٹیب کی بحالی اور ونڈو کے پورے سیشن کی بحالی۔
- **براؤزنگ ہسٹری ویو**:
  - ضرورت سے زیادہ `chrome.history.search` کوئری سے بچنے کے لیے 10 سیکنڈ کے TTL ان میموری کیشے کے ساتھ گہری تلاش۔
  - ڈومین، کلیدی لفظ اور کیلنڈر کی تاریخ کی حدود کے لحاظ سے تلاش کو فلٹر کیا جا سکتا ہے۔
  - اگر پہلے سے کھلا ہو تو ایک کلک پر ٹیب کو فعال کرنا، یا نیا ٹیب بنانا، جو Omnibar `h:` کے ذریعے دستیاب ہے۔

### 9.7 Theme Scheduling Subsystem (`ThemeScheduleModal.svelte`)
- **خودکار تھیم شیڈولنگ**:
  - تھیمز سائیڈ پینل ویو (`?view=themes` / `pt`) کے اندر `ThemeScheduleModal.svelte` کے ذریعے منظم۔
  - دن کے وقت (`HH:MM`) اور ہفتے کے فعال دنوں (`[0..6]`) کی بنیاد پر خودکار تھیم سوئچنگ کو سپورٹ کرتا ہے۔
  - زیادہ سے زیادہ 7 عالمی تھیم شیڈولز (`MAX_GLOBAL_SCHEDULES = 7`)۔
  - **خودکار واپسی**: نامزد تکمیلی گھنٹوں پر خود بخود پہلے سے طے شدہ دن یا کام کی جگہ کے تھیمز پر واپس آجاتا ہے۔
  - **ڈیسک ٹاپ الرٹس**: تھیم کے خودکار تبدیل ہونے پر ڈیسک ٹاپ اطلاعات جاری کرتا ہے (`chrome.notifications`)۔
  - **دوہرا استحکام**: `savedThemes` اور `themeSchedules` کے تحت `chrome.storage.sync` (رومنگ ترجیحات) اور `chrome.storage.local` میں محفوظ۔

### 9.8 Compact Sidepanel View
- **Sidepanel روٹ (`?view=activity` / `pw`)**: 350px کا کالم جو ریئل ٹائم مانیٹرنگ کے لیے بہترین ہے، جس میں مدت کے سلیکٹر چپس (`Today`، `7d`، `30d`، `All`) اور ڈومین کی حد کے پروگریس بارز شامل ہیں۔

## 10. Multi-Modal Invocation Matrix

### 10.1 Popup UI Interface
- **Rules ٹیب**: فوری رول ٹوگلز، فعال اسٹیٹس انڈیکیٹرز، اور رول URL لانچر۔

- **AI لانچر**: سائیڈ پینل پر استفسارات بھیجنے والا براہ راست چیٹ ان پٹ باکس۔

### 10.2 Sidepanel Navigation Routes (`?view=...`)
- `?view=rules` — جامع رولز مینیجر اور URL پیٹرن ایڈیٹر (`pg`)۔
- `?view=listgroup` — ڈریگ اینڈ ڈراپ ری آرڈرنگ کے ساتھ مکمل گروپ اور ٹیب ورک اسپیس (`pl`)۔

- `?view=gemini` — ملٹی ماڈل AI اسسٹنٹ اور خود مختار ایجنٹ انٹرفیس (`pa`)۔
- `?view=activity` — ویب سرگرمی ٹریکر، حدود، اور کیٹیگری میٹرکس (`pw`)۔

- `?view=downloads` — ڈاؤن لوڈز مینیجر اور بیچ لنک ڈاؤنلوڈر (`switchMainView('downloads')`)۔

29. `ccr:` — کسٹم رول کا رنگ تبدیل کریں۔
30. `ccg:` — فعال ٹیب گروپ کا رنگ تبدیل کریں۔
31. `dr:` — قواعد یا قواعد سے انفرادی URLs کو حذف کریں۔
32. `er:` — کسی موجودہ رول کا نام بدلیں یا ترمیم کریں۔
33. `st:` — Omnibar کا انٹرایکٹو ٹیوٹوریل کھولیں۔
34. `g:` — گوگل پر تلاش کریں (`g: <query>`)۔
35. `y:` — یوٹیوب پر تلاش کریں (`y: <query>`)۔
36. `d:` — DuckDuckGo پر تلاش کریں (`d: <query>`)۔
37. `w:` — ویکیپیڈیا پر تلاش کریں (`w: <query>`)۔
38. `gm:` — گوگل میپس پر تلاش کریں (`gm: <query>`)۔
39. `x:` — X / Twitter پر تلاش کریں (`x: <query>`)۔
40. `am:` — ایمیزون پر تلاش کریں (`am: <query>`)۔
41. `ams:` — ایمیزون اسپین پر تلاش کریں (`ams: <query>`)۔

### 10.6 Context Menu Tree Hierarchy (All 5 Groups & 30+ Actions)
کانٹیکسٹ مینو ایک مکمل درجہ بندی کا درخت فراہم کرتا ہے جو 5 فنکشنل کمانڈ گروپس میں منظم ہے:
1. **گروپ 1: قواعد اور URL سب مینو**:
   - ماسٹر رولز چیک باکس ٹوگل ("Activar/Desactivar Todas las Reglas")۔
   - انفرادی کسٹم قواعد کو موقع پر ہی فعال یا غیر فعال کرنے والے فی رول ٹوگلز۔
   - "Abrir Todas las URLs": منتخب رول میں رجسٹرڈ تمام مطلوبہ URLs کو کھولتا ہے۔
   - کھلے ہوئے ٹیبز کی متحرک گنتی کے ساتھ انفرادی URL سب مینیوز `[N]`: URL سے مماثل موجودہ کھلے ٹیبز کی تعداد دکھاتا ہے، URL پر ایک کلک سے نیویگیشن فراہم کرتا ہے، اور تمام مماثل ٹیبز کو بند کرنے کے لیے "Cerrar Pestañas para esta URL" کی پیشکش کرتا ہے۔
   - فوری رول تخلیق: "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa"۔
   - موجودہ رول میں اضافہ: "Añadir a Regla Existente" -> رول منتخب کریں -> "Añadir Raíz del Sitio" / "Añadir URL Completa"۔
2. **گروپ 2: ٹیب کی صفائی اور آڈیو کنٹرولز**:
   - "Eliminar Pestañas Duplicadas [N]": شناخت شدہ فالتو ٹیبز کی گنتی دکھاتا ہے اور انہیں ونڈوز سے بند کر دیتا ہے۔
   - "Eliminar Pestañas por Dominio": تمام ڈومینز کو کھلے ٹیبز کی گنتی `[N]` کے ساتھ دکھانے والا سب مینو، جس سے ڈومین کے لحاظ سے ٹیبز کو چن چن کر بند کیا جا سکتا ہے۔
   - "Cerrar Todos Excepto el Grupo Activo": فعال فوکسڈ گروپ کو برقرار رکھتا ہے اور باقی تمام گروپس کو بند کر دیتا ہے۔
   - "Reagrupar Todas las Pestañas": تمام کھلے ٹیبز پر بیک گراؤنڈ میں دوبارہ گروپ بندی کا مکمل عمل شروع کرتا ہے۔
   - "Silenciar Todas las Pestañas" / "Reactivar Sonido en Todas las Pestañas": عالمی سطح پر آڈیو کو میوٹ اور ان میوٹ کرنے کے کنٹرولز۔
3. **گروپ 3: پڑھنا، انتخاب اور نوٹس**:
   - "Leer Página en Voz Alta" (TTS): اوورلے کنٹرولز کے ساتھ پورے صفحے کو پڑھنے والا ٹیکسٹ ٹو اسپیچ ریڈر۔
   - "Leer Selección en Voz Alta": اسپیچ سنتھیسز کا استعمال کرتے ہوئے منتخب کردہ DOM عبارت کو باآواز بلند پڑھتا ہے۔
   - "Crear Nota desde Selección": متن کے انتخاب کو نکالتا ہے، خود بخود قریب ترین ہیڈنگ (`h1`-`h3`) سے نوٹ کا عنوان بناتا ہے، اور اسے `notesStore` میں محفوظ کرتا ہے۔
4. **گروپ 4: ایکسٹینشن، PiP اور پینلز کھولیں**:
   - "Abrir como PiP" / "Abrir como Ventana Emergente": مطلوبہ صفحہ، منتخب کردہ متن، یا مطلوبہ تصویر کو تیرتی ہوئی Picture-in-Picture یا الگ پاپ اپ ونڈو میں لانچ کریں۔
   - "Abrir Extensión": ایکسٹینشن کا پاپ اپ کھولتا ہے یا سائیڈ پینل کو پھیلاتا ہے۔
   - "Gestionar Reglas": براؤزر کے ایک مخصوص ٹیب میں مکمل رولز مینیجر کھولتا ہے۔
   - سائیڈ پینل کے براہ راست لانچرز: List Groups (`?view=listgroup`)، Themes (`?view=themes`)، AI Assistant (`?view=gemini`)، اور Customize Hints (`?view=hints`) تک ایک کلک کے ساتھ رسائی۔
5. **گروپ 5: ترتیبات اور کلسٹرنگ کے اختیارات**:
   - **Gestión de Grupos**: Alternar Grupo Actual (فعال گروپ کے سمٹاؤ کو ٹوگل کریں)، Alternar Todos los Grupos (تمام گروپس کے سمٹاؤ کو ٹوگل کریں)۔
   - **Opciones de Agrupación**:
     - Agrupación Inteligente (خودکار ہیورسٹک کلسٹرنگ کو ٹوگل کریں)۔
     - Modo Compacto (سنگل لیٹر گروپ ٹائٹل موڈ کو ٹوگل کریں)۔
     - Dominio / Subdominio (ڈومین اور ذیلی ڈومین کی گروپ بندی کو ٹوگل کریں)۔
     - Páginas Especiales: Páginas Chrome (`chrome://`), Archivos Locales (`file:///`), Extensiones (`chrome-extension://`), Miscelánea (`Misc`), Direcciones IP & Localhost.
   - **Opciones Generales**:
     - Ordenar Alfabéticamente (ٹیب پٹی پر حروف تہجی کی ترتیب نافذ کریں)۔
     - Ubicación Miscelánea: Principio (`start`), Final (`end`), Alfabéticamente (`alpha`).
     - Temporizador de Auto-Colapso (غیر فعال گروپ کے سمٹاؤ کے ٹائمر کو ٹوگل کریں)۔
     - Prefijos Visuales (`🔒`, `🔍`, `🗝️`, `⚠️` اسٹیٹس مارکرز کو ٹوگل کریں)۔
     - Vista Previa de Enlaces (صفحے کے اندر لنک کے پیش نظارہ ماڈل کو ٹوگل کریں)۔

## 11. Storage Schemas & Data Persistence

ایکسٹینشن IndexedDB اور Chrome Storage APIs کے درمیان ایک ملٹی ٹائر اسٹوریج ماڈل استعمال کرتی ہے:

### 11.1 IndexedDB Database: `Intelligent_Workspace` (Schema Version 8)
1. `screenshots`: keyPath: `'id'`, autoIncrement: true. Secondary index: `'createdAt'`. بائنری اسکرین شاٹس، کینوس ڈیٹا URLs، مستقل جھنڈے، پیمائش، اور سیگمنٹ کے کل اشاریہ جات رکھتا ہے۔
2. `geminiConversations`: keyPath: `'id'`, autoIncrement: true. 0 سیکنڈری انڈیکسز (ID کے ذریعے حاصل/منظم کیا جاتا ہے)۔ ملٹی ٹرن چیٹ تھریڈز، میسج کے کردار، ٹوکن میٹرکس اور سرچ گراؤنڈنگ میٹا ڈیٹا کو محفوظ کرتا ہے۔
3. `notesStore`: keyPath: `'id'`, autoIncrement: false. 0 سیکنڈری انڈیکسز (contextKey کے ذریعے میموری میں فلٹر کیا جاتا ہے)۔ رچ ٹیکسٹ، چیک لسٹ اریز، Kanban بورڈ کارڈز، Mermaid وضاحتیں اور KaTeX فارمولے محفوظ کرتا ہے۔
4. `backupsGroups`: keyPath: `'group.id'`. 0 سیکنڈری انڈیکسز (نیسٹڈ `'group.id'` کے ذریعے بیک اپ گروپ آبجیکٹس کو اسٹور کرتا ہے)۔ کمپریسڈ گروپ ڈھانچے، رنگ، عنوانات، اور بند ٹیب کے ریکارڈز کو محفوظ کرتا ہے۔
5. `pomodoroStats`: keyPath: `'id'`, autoIncrement: true. Secondary indexes: `'projectName'` (keyPath `'projectName'`) اور `'savedAt'` (keyPath `'savedAt'`) (کوئی `date` انڈیکس نہیں)۔ فوکس کے تجزیات، سائیکل میٹرکس اور رکاوٹوں کے لاگز رکھتا ہے۔

### 11.2 Chrome Storage Dual-Routing (`StorageService`)
- `chrome.storage.sync` (صارف کے تمام آلات پر ترتیبات منتقل کرنے کے لیے) اور `chrome.storage.local` (بھاری ڈیٹا کی ترجیحات کے لیے) کے درمیان ریڈ اور رائٹ کو متحرک طور پر روٹ کرتا ہے۔
- کلیدی ماڈلز:
  - `customRules`: رول کی تعریفوں کی ارے (`[{ name, color, active, urls }]`)۔
  - `clusterConfig`: آٹو کلسٹرنگ پیرامیٹرز (حدیں، کمپیکٹ موڈ، خصوصی زمرے)۔
  - `userPrefixes`: ایموجی پریفکس اسائنمنٹس (`{ lock, openKey, loupe, checked, warning }`)۔
  - `activeTheme`، `savedThemes`، اور `themeSchedules`: 9 پیلیٹ کلر کنفیگریشنز اور `ThemeScheduleModal.svelte` کے ذریعے ترتیب دی گئی شیڈول گردش کے قواعد۔
  - `pomodoroState`: ریئل ٹائم سیشن کے ٹائم اسٹیمپس، رکا ہوا دورانیہ، اور سائیکل کے اہداف۔
  - `wa:settings` اور `wa:limits`: ویب سرگرمی سے باخبر رہنے کی ترجیحات، سائٹ کی حدود، اور شیڈول کے ونڈوز۔
  - `youtubeLoopEnabled`: یوٹیوب اور شارٹس لوپ بٹنوں کو کنٹرول کرنے والا بولین فلیگ۔

### 11.3 Chrome Storage Session (`chrome.storage.session`)
انتہائی تیز، عارضی رن ٹائم کوآرڈینیشن کے لیے استعمال ہوتا ہے:
- `tabsEverActive`: موجودہ براؤزر سیشن کے دوران فعال ہونے والے ٹیب IDs کا سیٹ۔
- `groupExpandedEver`: موجودہ سیشن کے دوران پھیلائے گئے گروپس کا ریکارڈ۔
- `groupInfoMap`: ریئل ٹائم رجسٹری جو گروپ IDs کو متحرک عنوانات اور کلسٹرنگ کی اقسام سے مربوط کرتی ہے۔
- `splitScreenState`: اسکرین کی اصل پیمائش کو بحال کرنے کے لیے کیش شدہ ونڈو باؤنڈز۔
- `contextMenusSignature`: ہیش سگنیچر جو ٹیبز کی تیز رفتاری سے تبدیلی کے دوران کانٹیکسٹ مینیو کی غیر ضروری دوبارہ تعمیر کو روکتا ہے۔
- `wa:openSegment`: موجودہ فعال ویب سائٹ کے وقت کا طبقہ۔
- `hiddenYoutubeView`: `HiddenGroupsBar.svelte` میں موجود پارک شدہ یوٹیوب پلیئر ویو کا حوالہ۔

## 12. Defensive Engineering & Edge Case Handling

1. **Declarative Net Request Header Unblocking (`dnr.js`)**:
   - `X-Frame-Options` اور سخت `Content-Security-Policy` ہیڈرز کو ہٹانے کے لیے متحرک DNR قواعد کے ذریعے جوابی ہیڈرز میں ترمیم کرتا ہے، جس سے بیرونی سائٹس کو سائیڈ پینل اور Picture-in-Picture iframes میں رینڈر ہونے کی اجازت ملتی ہے۔
   - **WhatsApp Web Safety**: `web.whatsapp.com` پر واضح طور پر `Cross-Origin-Opener-Policy` (COOP) اور `Cross-Origin-Embedder-Policy` (COEP) کو برقرار رکھتا ہے تاکہ اس کے WebAssembly Signal کرپٹوگرافک نفاذ کو ٹوٹنے سے بچایا جا سکے۔
2. **Right-Click & Selection Unblocker (`allowRightClickHook.js`)**:
   - کاپی، پیسٹ، کانٹیکسٹ مینو اور ٹیکسٹ سلیکشن کو روکنے والی مخالف ویب سائٹس کے اثرات کو زائل کرتا ہے۔
   - `contextmenu`، `copy`، `cut`، `selectstart`، `mousedown` اور `mouseup` پر `preventDefault()` اور `stopPropagation()` کو روکنے کے لیے `MAIN` ورلڈ میں چلتا ہے۔
   - `MutationObserver` کے ذریعے ان لائن `oncontextmenu="return false"` ہینڈلرز کو ہٹاتا ہے۔
   - منسوخ شدہ پیسٹ ایونٹس کو دوبارہ انجیکٹ کرنے سے پہلے کلپ بورڈ کے مواد کی توثیق کر کے قانونی ویب ایپلیکیشنز (مثلاً Telegram Web, Google Docs) کی حفاظت کرتا ہے۔
3. **YouTube Hover Preview Audio Forced-Mute Override (`youtubePreviewAudioHook.js`)**:
   - `ytd-video-preview #inline-preview-player` پر `MAIN` ورلڈ میں چلتا ہے۔
   - ماؤس اوپر لے جانے پر ٹارگٹ `<video>` عنصر پر `HTMLMediaElement.prototype.muted` پراپرٹی ڈسکرپٹر کو اوور رائیڈ کرتا ہے۔
   - یوٹیوب کی اندرونی `volumechange` جبری خاموشی کی دوڑ کے مقابلے (race condition) کو ختم کرتا ہے، اور ماؤس اوپر رہنے تک لوپ کے دوبارہ شروع ہونے پر بھی بغیر میوٹ کے آڈیو کو برقرار رکھتا ہے۔
4. **YouTube Shorts Feed Sequence Navigation Hook (`youtubeShortsFeedHook.js`)**:
   - `ytd-shorts` پر `MAIN` ورلڈ میں چلتا ہے۔
   - `shortsProcessedSequence` پراپرٹی کو پکڑتا ہے، جو ایکسٹینشن کی الگ تھلگ دنیا سے نظر نہیں آتی، اور صفحہ کو دوبارہ لوڈ کیے بغیر یا فلوٹنگ ونڈو کی حالت کھوئے بغیر `ytd-app` پر مقامی `yt-navigate` ایونٹس بھیجتا ہے۔
5. **لامحدود اسکرول کینوس کا تحفظ (Infinite-Scroll Canvas Protection)**:
   - پورے صفحے کے اسکرین شاٹ واک کو 60 سیگمنٹس (`MAX_FULL_PAGE_SEGMENTS`) اور زیادہ سے زیادہ 30,000px کینوس کی اونچائی (`MAX_FULL_PAGE_CANVAS_PX`) تک محدود کرتا ہے، جس سے براؤزر ٹیب کے آؤٹ آف میموری کریش ہونے سے بچاؤ ہوتا ہے۔
6. **Linux Screen Color Picker Eyedropper Fallback**:
   - لینکس کے ایسے ماحول پر چلتے وقت جن میں Chromium کا `window.EyeDropper` API موجود نہیں ہوتا، ایکسٹینشن `screen-color-picker.js` کو انجیکٹ کرتی ہے، جو RGB/HEX/HSL کیلکولیشن کے ساتھ 9 گنا بڑا پکسل لینس رینڈر کرتا ہے۔
7. **اسٹارٹ اپ سیشن کے استحکام کی تاخیر (Startup Session Settling Delay)**:
   - گروپ اسائنمنٹس کا جائزہ لینے سے پہلے سیشن ٹیبز اور ونڈو کی حالت کو مستحکم ہونے دینے کے لیے براؤزر کے آغاز پر گروپس کی صفائی میں 20 سیکنڈ کی تاخیر کرتا ہے (`groupsHaveSettledAfterStartup()`)۔
