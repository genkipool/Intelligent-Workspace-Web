# Intelligent Workspace

> Intelligent Workspace என்பது Svelte, Vite மற்றும் CRXJS கொண்டு உருவாக்கப்பட்ட ஒரு மேம்பட்ட Manifest V3 உலாவி நீட்டிப்பு (browser extension) மற்றும் பயனுள்ள பணிச்சூழலாகும் (productive workspace environment). இது அறிவார்ந்த தாவல் ஒழுங்கமைவு (tab organization), தானியங்கி மற்றும் விதி சார்ந்த கிளஸ்டரிங் (clustering), தன்னாட்சி AI ஏஜென்ட் இயக்கம் (Google Gemini Cloud API மற்றும் Chrome Built-in Prompt API ஆதரவுடன்), பக்கத்திற்குள்ளான Vim-பாணி இணைப்பு வழிசெலுத்தல் (Vim-style link navigation), 41 முன்னொட்டுகளைக் கொண்ட Omnibar கட்டளை அமைப்பு, பல வடிவ குறிப்பெடுத்தல் (rich text, சரிபார்ப்புப் பட்டியல்கள், Kanban, Mermaid வரைபடங்கள், KaTeX சூத்திரங்கள்), உயர் துல்லிய ஊடகப் பிடிப்பு (media capture) மற்றும் உலாவிக்குள்ளான WASM OCR, பூஜ்ஜிய-விலகல் அலாரங்கள் (zero-drift alarms) மற்றும் ஆஃப்ஸ்கிரீன் ஆடியோ பிளேபேக்குடன் கூடிய Pomodoro நேரக் கண்காணிப்பு, மற்றும் Declarative Net Request (DNR) இணைய செயல்பாட்டுக் கண்காணிப்பு, டொமைன் வரம்புகள் மற்றும் தள முடக்கம் (site blocking) ஆகியவற்றை ஒருங்கிணைக்கிறது.

## 1. கட்டமைப்பு அடித்தளம் & இயக்கநேர வாழ்க்கைச் சுழற்சி (Architectural Foundation & Runtime Lifecycle)

இந்த நீட்டிப்பு Google Chrome இன் Manifest V3 கட்டமைப்பின் கீழ் இயங்குகிறது; இது தொடர்ச்சியான செயல்முறைகளை பின்னணி Service Worker, சாண்ட்பாக்ஸ் செய்யப்பட்ட UI பேனல்கள், ஆஃப்ஸ்கிரீன் ஆடியோ ஆவணங்கள் மற்றும் பக்கத்திற்குள்ளான content script மேலடுக்குகளுக்கு இடையே பிரிக்கிறது:

1. **Manifest கட்டமைப்பு (`manifest.json`)**:
   - **அனுமதிகள் (21 உருப்படிகள்)**: `tabs`, `tabGroups`, `storage`, `favicon`, `contextMenus`, `notifications`, `sidePanel`, `scripting`, `downloads`, `downloads.open`, `system.display`, `declarativeNetRequestWithHostAccess`, `cookies`, `history`, `sessions`, `bookmarks`, `readingList`, `clipboardWrite`, `alarms`, `offscreen`, மற்றும் `idle`.
   - **ஹோஸ்ட் அனுமதிகள்**: `["<all_urls>"]`.
   - **Service Worker**: ஒத்திசைவான `importScripts` மாடுலர் ஏற்றுதலைப் பயன்படுத்தும் `src/core/background.js`.
   - **டூல்பார் செயல் (Toolbar Action)**: வேண்டுமென்றே `default_popup` தவிர்க்கப்பட்டுள்ளது. இயக்கநேரம் `chrome.action.setPopup({ popup: '' })` என்பதை செயல்படுத்துகிறது; இது `chrome.action.onClicked` ஒத்திசைவாக இயங்குவதை உறுதிசெய்து, பாப்அப் துவக்க தாமதமின்றி பயனரின் பொருத்தப்பட்ட பார்வைக்கு `chrome.sidePanel` ஐத் திறக்கிறது.
   - **Omnibox முக்கிய சொல்**: பதிவுசெய்யப்பட்ட முக்கிய சொல் `"find"`.
   - **கட்டளைகள்**: `commands` இன் கீழ் பதிவுசெய்யப்பட்ட 24 கணினி அளவிலான விசைப்பலகை குறுக்குவழிகள்.
   - **உள்ளடக்கப் பாதுகாப்புக் கொள்கை (Content Security Policy)**: `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`.

2. **செயல்முறைகளுக்கு இடையேயான தொடர்புப் பாதுகாப்பு (Inter-Process Communication Security)**:
   - `src/core/background/messaging.js` ஆனது உள்ளடக்க ஸ்கிரிப்ட்களிலிருந்து வரும் செய்திகளை வெளிப்படையான அனுமதிப்பட்டியலுடன் (`ALLOWED_CONTENT_SCRIPT_ACTIONS`) ஒப்பிட்டு வடிகட்டுகிறது. சலுகையற்ற வலை பிரேம்களால் உள் சேமிப்பக மாற்றிகள், தன்னிச்சையான Chrome API-கள் அல்லது விதி மாற்றிகளை இயக்க முடியாது.

3. **இரட்டை இயக்க உலகங்கள் (Dual Execution Worlds)**:
   - உள்ளடக்க ஸ்கிரிப்ட்கள் `ISOLATED` (நீட்டிப்பு வரம்பு) மற்றும் `MAIN` (பக்க இயக்க வரம்பு) ஆகிய இரண்டு உலகங்களிலும் செயல்படுகின்றன. `allowRightClickHook.js`, `videoPipHook.js`, `youtubePreviewAudioHook.js`, மற்றும் `youtubeShortsFeedHook.js` போன்ற ஸ்கிரிப்ட்கள் முன்மாதிரி முறைகளை (prototype methods) இடைமறிக்கவும், பண்புக்கூறு விளக்கங்களை மாற்றியமைக்கவும், தனிப்பயன் நிகழ்வுகளை நேரடியாகக் கையாளவும் `MAIN` இல் இயங்குகின்றன.

## 2. பிரிவு 1: விதிகள் மேலாண்மை (Gestionar Reglas)

விதிகள் மேலாண்மை துணை அமைப்பானது, பயனரால் வரையறுக்கப்பட்ட கடுமையான நிபந்தனைகளின் அடிப்படையில் தாவல்களைத் தானாகக் குழுவாக்குகிறது.

### 2.1 தரவு திட்டம் (`CustomRule`)
ஒவ்வொரு தனிப்பயன் விதியும் பின்வரும் இடைமுகத்தைக் கடைப்பிடிக்கிறது:
```typescript
interface CustomRule {
  name: string;        // 1 to 16 characters. Must contain no whitespace characters.
  color: RuleColor;    // One of 9 colors: 'grey' | 'blue' | 'red' | 'yellow' | 'green' | 'pink' | 'purple' | 'cyan' | 'orange'
  urls: string[];      // Array of valid URLs, domains, or hostnames.
  active: boolean;     // Master toggle enabling or disabling rule evaluation.
  isStarred?: boolean; // Optional flag marking rule as a favorite for prioritized UI ordering.
}
```

### 2.2 முன்னுரிமை கட்டமைப்பு (Precedence Architecture)
`src/core/background/groupManager.js` இல் உள்ள `groupTabs()` மூலம் தாவல்கள் செயலாக்கப்படும்போது, அவை கண்டிப்பான படிநிலை வரிசையில் மதிப்பீடு செய்யப்படுகின்றன:
1. **தனிப்பயன் விதிகள் (`applyCustomRules`)**: செயலில் உள்ள தனிப்பயன் விதிகளை தோன்றும் வரிசையிலோ அல்லது பயனர் முன்னுரிமையிலோ பொருத்துகிறது. குழுவாக்கப்பட்டவுடன், தாவல் ஐடிகள் `groupedTabIds` இல் பதிவு செய்யப்பட்டு அடுத்தடுத்த அடுக்குகளிலிருந்து விலக்கப்படும்.
2. **சிறப்பு கணினி குழுக்கள்**: கணினி URL-கள் இடைமறிக்கப்பட்டு பிரத்யேக வண்ணக் குழுக்களாகப் பிரிக்கப்படுகின்றன:
   - `chrome://` மற்றும் உள் உலாவிப் பக்கங்கள்
   - `file:///` உள்ளூர் வட்டு கோப்புகள்
   - `chrome-extension://` நீட்டிப்பு பக்கங்கள்
   - IP முகவரிகள் & Localhost (`localhost`, `127.0.0.1`, `[::1]`, IPv4/IPv6 ஹோஸ்ட்கள்)
3. **டொமைன் கிளஸ்டரிங்**: தாவல்களின் எண்ணிக்கை `domainThreshold` (இயல்புநிலை: 2 தாவல்கள்) வரம்பை எட்டினால் அல்லது தாண்டினால், அதே ரூட் டொமைனைப் பகிரும் தாவல்கள் குழுவாக்கப்படும்.
4. **துணை டொமைன் கிளஸ்டரிங்**: இயக்கப்பட்டிருந்தால், டொமைன்களுக்குள் உள்ள தாவல்கள் குறிப்பிட்ட துணை டொமைன்களால் குழுவாக்கப்படும் (எ.கா., `docs.github.com` vs `gist.github.com`).
5. **இதர ("Misc") குழு**: கிளஸ்டரிங் வரம்புகளை பூர்த்தி செய்யாத எஞ்சிய குழுவாக்கப்படாத தாவல்கள் `Misc` குழுவில் வைக்கப்படுகின்றன (அமைவிடம் மாற்றியமைக்கத்தக்கது: `start`, `end`, அல்லது அகரவரிசை `alpha`).

### 2.3 URL இயல்பாக்கம் & பொருத்த சொற்பொருளியல் (URL Normalization & Matching Semantics)
பொருத்த எஞ்சின் (`src/core/background/utils.js` இல் உள்ள `matchesRule(tabUrl, ruleUrl)`) கடுமையான இயல்பாக்கத்தைப் பயன்படுத்துகிறது:
- **திட்ட சார்பின்மை (Scheme Agnostic)**: HTTP மற்றும் HTTPS நெறிமுறைகள் ஒன்றுக்கொன்று மாற்றத்தக்கவையாகக் கருதப்படுகின்றன (`http://example.com` என்பது `https://example.com` உடன் பொருந்தும்). இணையம் அல்லாத நெறிமுறைகளுக்கு (`file://`, `chrome://`) சரியான திட்டப் பொருத்தம் தேவை.
- **ஹோஸ்ட் இயல்பாக்கம்**: முன்னொட்டு `www.` நீக்கப்படுகிறது (`www.github.com` என்பது `github.com` என இயல்பாக்கப்படுகிறது). ஹோஸ்ட் பெயர்கள் சிறிய எழுத்துகளாக மாற்றப்பட்டு, punycode வழியாக சர்வதேச டொமைன் பெயர்களை (IDN) ஆதரிக்கின்றன.
- **போர்ட் உணர்திறன் (Port Sensitivity)**: ஒரு விதி ஒரு போர்ட்டைக் குறிப்பிட்டால் (எ.கா., `localhost:3000`), தாவல் அதே சரியான போர்ட்டுடன் பொருந்த வேண்டும்.
- **பாதை பொருத்தம் (Path Matching)**: பின்வரும் சாய்வுக்கோடுகள் (trailing slashes) நீக்கப்படுகின்றன. ஒரு விதி ஒரு பாதையைக் குறிப்பிட்டால் (எ.கா., `example.com/docs`), அது அந்த சரியான பாதை அல்லது துணைப் பாதைகளைக் கொண்ட தாவல்களுடன் (`example.com/docs/api`) பொருந்தும், ஆனால் உடன்பிறப்பு பாதைகளுடன் (`example.com/blog`) பொருந்தாது.
- **வினவல் & ஹாஷ் பொருத்தம்**: ஒரு விதி வெளிப்படையாக வினவல் சரம் (`?page=1`) அல்லது ஹாஷ் (`#section`) கொண்டிருந்தால், தாவல் அந்த அளவுருக்களுடன் துல்லியமாகப் பொருந்த வேண்டும்.
- **எண் சார்ந்த Dword பாதுகாப்பு (`ruleValidation.js`)**: WHATWG URL பாகுபடுத்திகள் சரியான IPv4 முழு எண் DWORD-களாகக் கருதும் வெறும் எண் உள்ளீடுகளை (எ.கா., `3242342424`) சரிபார்ப்பான் கண்டிப்பாக நிராகரிக்கிறது, இது எதிர்பாராத குழுவாக்கப் பிழைகளைத் தடுக்கிறது.

### 2.4 விதிகள் மேலாண்மை அமைப்புகளின் விவரக்குறிப்பு
விதிகள் மேலாளர் பல நடத்தை கட்டுப்பாடுகள் மற்றும் அமைப்புகளை வழங்குகிறது:
- **சேமிப்பக வழித்தடத் தேர்வு**: பயனர்கள் விதி சேமிப்பகத்தை `chrome.storage.sync` (Google சுயவிவரத்தில் உள்நுழைந்துள்ள அனைத்து சாதனங்களிலும் ஒத்திசைக்கப்படும் அமைப்புகளுக்கு, Chrome ஒத்திசைவு வரம்புகளான மொத்தம் 100 KB மற்றும் உருப்படிக்கு 8 KB உட்பட்டது) மற்றும் `chrome.storage.local` (நூற்றுக்கணக்கான வடிவங்களைக் கொண்ட பெரிய விதித் தொகுப்புகளுக்கு ஏற்ற வரம்பற்ற உள்ளூர் திறன்) ஆகியவற்றிற்கு இடையே தேர்ந்தெடுக்கலாம்.
- **கிளஸ்டரிங் முதன்மை நிலைமாற்றி & வரம்புகள்**:
  - `toggle-clustering`: பயனரால் உருவாக்கப்பட்ட தனிப்பயன் விதிகளை முடக்காமல், தானியங்கி டொமைன்/துணை டொமைன் கிளஸ்டரிங்கை இயக்கும் அல்லது முடக்கும் முதன்மை விசைப்பலகை குறுக்குவழி மற்றும் UI மாற்றி.
  - `domainThreshold`: தானியங்கி தாவல் குழுவைத் தூண்டுவதற்கு ஒரே டொமைனிலிருந்து தேவைப்படும் குறைந்தபட்ச தாவல்களின் எண்ணிக்கை (இயல்புநிலை: 2 தாவல்கள்). 1 முதல் 50 வரை மாற்றியமைக்கலாம்.
  - `subdomainThreshold`: பிரிக்கப்பட்ட துணைக் குழு கிளஸ்டர்களை உருவாக்குவதற்கு முன் துணை டொமைன்களுக்கான குறைந்தபட்ச தாவல் எண்ணிக்கை.
  - துணை டொமைன் மாற்றி (`toggle-subdomain-grouping`): சுயாதீன துணை டொமைன்களை வேறுபடுத்துகிறது (எ.கா., `news.ycombinator.com` vs `ycombinator.com`).
- **அகரவரிசைப்படி குழுக்களைத் தானாக வரிசைப்படுத்துதல் (`toggle-sort-alpha`)**: உலாவி தாவல் பட்டியில் உள்ள அனைத்து திறந்த தாவல் குழுக்களிலும் அகரவரிசையை செயல்படுத்தும் நிகழ்நேர வரிசைப்படுத்தல் எஞ்சின் (`Ctrl+Shift+S` / `Cmd+Shift+S`).
- **காட்சி நிலை முன்னொட்டுகள் (`toggle-prefixes`)**: ஆய்வு நிலையைக் குறிக்க குழு தலைப்புகளுக்கு முன் மாறும் எமோஜி குறிகள் சேர்க்கப்படுகின்றன:
  - `🔒` (பூட்டு): குழுவில் பார்வையிடப்படாத, படிக்கப்படாத தாவல்கள் உள்ளன.
  - `🔍` (பூதக்கண்ணாடி): குழுவில் ஓரளவு பார்வையிடப்பட்ட தாவல்கள் உள்ளன.
  - `🗝️` (திறந்த சாவி): குழுவில் உள்ள அனைத்து தாவல்களும் திறக்கப்பட்டு மதிப்பாய்வு செய்யப்பட்டுள்ளன.
  - `⚠️` (எச்சரிக்கை): மற்றொரு சாளரக் குழுவுடன் நகல் குழு பெயர் முரண்பாடு கண்டறியப்பட்டுள்ளது.
- **செயலற்ற குழுக்களைத் தானாக மடக்குதல் (`toggle-collapse-timer`)**: தாவல் பட்டியை நேர்த்தியாகப் பராமரிக்க, செயலற்ற நிலையில் இருக்கும் குழுக்களைத் தானாகவே மடக்கச்செய்கிறது.
- **முழுமையான குழுவாக்க இடைநிறுத்தம் (`feature_pauseGrouping`)**: தாவல்கள் தன்னிச்சையான பயனர் அமைப்புகளில் இருக்க வேண்டிய சுறுசுறுப்பான ஆராய்ச்சி அமர்வுகளின் போது அனைத்து தானியங்கி குழுவாக்க செயல்பாடுகளையும் (விதி பொருத்தங்கள் மற்றும் கிளஸ்டரிங் இரண்டும்) தற்காலிகமாக நிறுத்திவைக்கும் முதன்மை முடக்குதல் சுவிட்ச்.
- **ஒற்றைத் தாவல் குழுவாக்கம் (`featureSingleTabGrouping`)**: பல தாவல்கள் வரம்பு தேவையைத் தவிர்த்து, பொருந்திய ஒற்றைத் தாவலுக்கு உடனடியாக ஒரு தாவல் குழுவை உருவாக்க தனிப்பயன் விதிகளை அனுமதிக்கிறது.
- **சுருக்கமான பார்வை (`toggle-compact-mode`)**: குழு தலைப்புகளுக்கு ஒற்றை எழுத்து பேட்ஜ்களை மட்டும் காண்பிப்பதன் மூலம் உலாவி தாவல் பட்டியில் தாவல் தலைப்பு அகலத்தைக் குறைக்கிறது.
- **இழுத்துப் போடும் முன்னுரிமை (Drag-and-Drop Priority)**: `Rules.svelte` பட்டியலில் விதிகளை மறுவரிசைப்படுத்துவது அவற்றின் மதிப்பீட்டு முன்னுரிமையை உடனடியாக மாற்றுகிறது. மேலே உள்ள விதிகள் முதலில் மதிப்பீடு செய்யப்படும்.
- **தெளிவற்ற தேடல் (Fuzzy Search)**: விதிகள் மேலாளர் மற்றும் Omnibar-இல் நேரடி வடிகட்டல், தலைப்பு அல்லது பொருந்தும் URL வடிவங்கள் மூலம் விதிகளை உடனடியாகக் கண்டறிய அனுமதிக்கிறது.
- **JSON இறக்குமதி / ஏற்றுமதி**:
  - பயன்முறை `add`: இறக்குமதி செய்யப்பட்ட விதிகளை ஏற்கனவே உள்ள சேகரிப்பில் இணைக்கிறது, நகல்களை நிராகரிக்கிறது.
  - பயன்முறை `overwrite`: திட்ட சரிபார்ப்புக்குப் பிறகு செயலில் உள்ள விதி சேகரிப்பை இறக்குமதி செய்யப்பட்ட தரவுகளுடன் முழுமையாக மாற்றுகிறது.
- **டைனமிக் விதி உருவாக்கம்**: Chrome புக்மார்க் கோப்புறைகள் அல்லது துணைக் குழு டொமைன் சேகரிப்புகளிலிருந்து நேரடியாக தனிப்பயன் விதிகளை ஒரே கிளிக்கில் உருவாக்குதல்.
- **விதி நகல் நீக்கம் (`feature_v100_dedup_add_to_rule`)**: ஏற்கனவே உள்ள தனிப்பயன் விதிகளில் URL-கள் அல்லது டொமைன்களைச் சேர்க்கும்போது நகல் URL வடிவங்களைத் தானாகவே நீக்குகிறது, இது விதி பெருக்கம் மற்றும் தேவையற்ற மதிப்பீடுகளைத் தடுக்கிறது.

### 2.5 செயல்பாடுகள் & நிலைத்தன்மை (`mutateRulesAndSync`)
- **மையப்படுத்தப்பட்ட மாற்றி**: அனைத்து விதி மாற்றங்களும் `src/core/background/handlers/rules.js` இல் உள்ள `mutateRulesAndSync(mutateFn, sendResponse)` வழியாக வழிநடத்தப்படுகின்றன. இது சேமிப்பக ஒத்திசைவு, நினைவக தற்காலிக சேமிப்பு புதுப்பிப்பு (`extensionSettings.customRules`), UI அறிவிப்பு (`rulesUpdated`) மற்றும் தானியங்கி தாவல் மறுசீரமைப்பு (`groupTabs()`) ஆகியவற்றை உறுதி செய்கிறது.
- **நேரடி சரிபார்ப்பு**: சேமிப்பதற்கு முன் பெயர் தனித்துவம், நீளம் (1-16 எழுத்துகள்), எழுத்து கட்டுப்பாடுகள் மற்றும் சரியான URL தொடரியல் ஆகியவற்றை நிகழ்நேரத்தில் சரிபார்க்கிறது.

### 2.6 செயல்படுத்தும் முறைகள் (Invocation Modalities)
- **விதிகள் மேலாளர் பக்கம் (`Rules.svelte`)**: முழு தாவல் பார்வையில் அல்லது பக்கப் பலகத்தில் (`?view=rules` / `pg`) அணுகலாம். முழு இழுத்துப் போடும் மறுவரிசைப்படுத்தல், இன்லைன் வண்ணத் தேர்வு, URL குறிச்சொற்கள் மற்றும் விதி மாற்றிகளை வழங்குகிறது.
- **Omnibar கட்டளைகள்**:
  - `rl:` — விதிகளைத் தேடி தொடர்புடைய URL-களைத் திறக்கவும்.
  - `cr: <name> [, url1, url2]` — கட்டளைப் பட்டியில் இருந்து நேரடியாக ஒரு புதிய விதியை உருவாக்கவும்.
  - `atcr:` — செயலில் உள்ள தாவலின் டொமைன் அல்லது URL-ஐ ஏற்கனவே உள்ள விதியில் சேர்க்கவும்.
  - `atr:` — தேர்ந்தெடுக்கப்பட்ட திறந்த தாவல்கள் அல்லது கைமுறை URL-களை ஏற்கனவே உள்ள விதியில் சேர்க்கவும்.
  - `ccr:` — தனிப்பயன் விதியின் நிறத்தை மாற்றவும்.
  - `dr:` — ஒரு விதியிலிருந்து விதிகள் அல்லது தனிப்பட்ட URL-களை நீக்கவும்.
  - `er:` — ஏற்கனவே உள்ள விதியைத் திருத்தவும் அல்லது மறுபெயரிடவும்.
- **சூழல் மெனுக்கள் (Context Menus)**:
  - பக்கத்தில் வலது கிளிக் -> "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa".
  - பக்கத்தில் வலது கிளிக் -> "Añadir a Regla Existente" -> விதியைத் தேர்ந்தெடுக்கவும் -> "Añadir Raíz del Sitio" / "Añadir URL Completa".
  - பக்கத்தில் வலது கிளிக் -> "Reglas" -> செயலில் உள்ள நிலையை மாற்றவும், அனைத்து விதி URL-களையும் திறக்கவும் அல்லது பொருந்தும் தாவல்களை மூடவும்.
- **விசைப்பலகை குறுக்குவழிகள்**:
  - `Alt+R`: விதிகள் மேலாளரைத் திறக்கவும்.
  - `Alt+M`: அனைத்து விதிகளின் செயல்பாட்டையும் ஒரே நேரத்தில் மாற்றவும் (`toggle-all-rules`).

## 3. பிரிவு 2: குழு பட்டியல் & செயல்பாடுகள் (Listar Grupos)

குழு பட்டியல் பார்வையானது உலாவி தாவல் குழுக்கள் மற்றும் தனிப்பட்ட தாவல்களை ஆய்வு செய்வதற்கும், கையாளுவதற்கும் மற்றும் மறுவரிசைப்படுத்துவதற்கும் ஒரு ஊடாடும் பணிச்சூழலை வழங்குகிறது.

### 3.1 பயனர் இடைமுகக் கட்டமைப்பு (UI Architecture)
- **கூறு அடுக்கு (Component Stack)**: `ListGroup.svelte`, `GroupCard.svelte`, `GroupActions.svelte`, `TabItem.svelte`, மற்றும் `TabActions.svelte` கொண்டு உருவாக்கப்பட்டது.
- **அட்டை அம்சங்கள்**: குழு தலைப்பு, வண்ண பேட்ஜ், தாவல் எண்ணிக்கை, அக்கார்டியன் மடிப்பு/விரிவாக்க மாற்றி, அட்டை பொருத்துதல் மற்றும் தனிப்பயனாக்கக்கூடிய செயல் பொத்தான் குழுக்களைக் காட்டுகிறது.
- **தாவல் உருப்படிகள்**: வண்ண பின்னணியுடன் கூடிய தாவல் favicon, தலைப்பு, ஒலி பேட்ஜ், மியூட் காட்டி, செயலில் உள்ள நிலை காட்டி மற்றும் தனிப்பட்ட தாவல் செயல்களைக் காட்டுகிறது (மூடு, நகலெடு, பின் செய், பிரி, நிராகரி).

### 3.2 குழு வாழ்க்கைச் சுழற்சி & நடத்தைகள்
- **அக்கார்டியன் கட்டுப்பாடு**: சீரான விரிவாக்கம் மற்றும் மடிப்பு நிலைகள். விருப்பத் தானியங்கி-அக்கார்டியன் பயன்முறையானது ஒரு புதிய குழு விரிவடையும் போது செயலற்ற குழுக்களைத் தானாகவே மடக்கச்செய்கிறது.
- **செயலற்ற குழு தானியங்கி-மடங்கல் டைமர்**:
  - காட்சி ஒழுங்கீனத்தைக் குறைக்க செயலற்ற தாவல் குழுக்களைத் தானாகவே மடக்கச்செய்கிறது.
  - இரண்டு தனித்துவமான வரம்புகள்: செயலற்ற குழுக்கள் 1 நிமிடம் செயலற்ற நிலைக்குப் பிறகு மடிகின்றன (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`), அதே நேரத்தில் செயலில் உள்ள குழு 15 நிமிடங்கள் செயலற்ற நிலைக்குப் பிறகு மடிகிறது (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`). 0 முதல் 1440 நிமிடங்கள் வரை மாற்றியமைக்கலாம்.
- **உடனடி மறுபெயரிடுதல் & சலுகைக் காலம்**:
  - பயனர்கள் உலாவி தாவல் பட்டியில் அல்லது UI-இல் நேரடியாக குழுக்களை மறுபெயரிடலாம்.
  - `GROUP_NAMING_GRACE_MS` (5000ms) பயனர் திருத்தும் போது தானியங்கி மறுசீரமைப்பை இடைநிறுத்துகிறது, இது தட்டச்சு செய்யும் போது தலைப்பு மேலெழுதப்படுவதைத் தடுக்கிறது.
  - மதிப்பீட்டின் போது பூஜ்ஜிய-அகல இடைவெளிகள் (`\u200B`, `\u200C`, `\u200D`, `\u2060`, `\uFEFF`) நீக்கப்படுகின்றன.
  - தானாக உருவாக்கப்பட்ட குழுவை மறுபெயரிடுவது, அதைப் பயனரால் பெயரிடப்பட்ட குழுவாக மாற்றுகிறது, இது தொடர்புடைய தனிப்பயன் விதியைப் புதுப்பிக்கிறது அல்லது அதை நிரந்தரமானது எனக் குறிக்கிறது.
- **காட்சிக் குழு முன்னொட்டு குறிகாட்டிகள்**:
  - நிலை சின்னங்களை மாறும் வகையில் முன்னொட்டாகச் சேர்க்கிறது: `🔒` (பார்வையிடப்படாதது), `🔍` (பகுதி), `🗝️` (அனைத்தும் பார்க்கப்பட்டது), `⚠️` (முரண்பாடு).
- **இழுத்துப் போடும் மறுவரிசைப்படுத்தல்**: குழுக்களுக்குள் தாவல்களை மறுவரிசைப்படுத்துவதற்கும், குழுக்களுக்கு இடையே தாவல்களை நகர்த்துவதற்கும் அல்லது குழு அட்டைகளை மறுவரிசைப்படுத்துவதற்கும் `sortable.js` உடன் ஒருங்கிணைக்கப்பட்டுள்ளது.
- **மறைக்கப்பட்ட குழுக்கள் அம்சம்**:
  - உலாவி தாவல் பட்டியில் குழு தலைப்பை `_hidden_` உடன் முன்னொட்டாக வைக்கிறது.
  - முக்கிய பட்டியல் பார்வையில் இருந்து குழு அட்டைகளை மறைத்து, அவற்றை `HiddenGroupsBar.svelte` க்கு மாற்றுகிறது.
  - பயனர்கள் ஒரே கிளிக்கில் குழுக்களை உடனடியாக வெளிப்படுத்தலாம் அல்லது மீட்டெடுக்கலாம்.

### 3.3 குழு செயல்பாடுகள் & நினைவக மேலாண்மை
- **குழு நீக்கு (Ungroup)**: குழுவைக் கலைத்து, சாளரத்தில் தாவல்களைத் திறந்து வைக்கிறது.
- **குழுவை மூடு (Close Group)**: குழுவில் உள்ள அனைத்து தாவல்களையும் மூடி, குழு ஐடியை விடுவிக்கிறது.
- **பிற குழுக்களை மூடு (Close Other Groups)**: தற்போது கவனம் செலுத்தப்பட்டுள்ள குழுவைத் தவிர மற்ற அனைத்து தாவல் குழுக்களையும் மூடுகிறது.
- **அனைத்து தாவல்களையும் மீண்டும் குழுவாக்கு (`Alt+Shift+R`)**: தனிப்பயன் விதிகள், கணினி குழுக்கள் மற்றும் டொமைன் கிளஸ்டர்களில் ஒரு விரிவான மறுமதிப்பீட்டைச் செயல்படுத்துகிறது.
- **குழு ஸ்கிரீன்ஷாட் உலாவுதல்**: குழுவில் உள்ள ஒவ்வொரு தாவலையும் வரிசையாகச் சுழற்சி செய்து படம்பிடிக்கிறது (`Cs` தெரியும் பகுதி, `Cp` முழுப் பக்கம், `CP` முழுப் பக்க பாகங்கள்).

### 3.4 குழு காப்புநகல் & மீட்டெடுப்பு துணை அமைப்பு (Group Backups & Restore Subsystem)
- **IndexedDB `backupsGroups` சேமிப்பகம்**:
  - ஒற்றைத் தாவல் குழுக்கள் அல்லது அனைத்து திறந்த குழுக்களின் பணிச்சூழல் அளவிலான ஸ்னாப்ஷாட்களை IndexedDB `Intelligent_Workspace` இன் `backupsGroups` சேமிப்பகத்தில் காப்புப் பிரதி எடுக்கிறது.
  - முழுமையான குழு கட்டமைப்புகளைப் படம்பிடிக்கிறது: குழு தலைப்பு, நிறம், மடிந்த நிலை, தாவல் தலைப்புகள், URL-கள், favicons, பின் செய்யப்பட்ட நிலை மற்றும் தொடர்புடைய தாவல் நிலைகள்.
  - **நினைவகப் பாதுகாப்பு**: கணினி ரேமை மீட்டெடுக்கவும் CPU சுமையைக் குறைக்கவும் காப்புப் பிரதி எடுக்கப்பட்ட தாவல்கள் நேர்த்தியாக மூடப்படுகின்றன.
  - **மீட்டெடுப்பு வழிமுறைகள்**:
    - ஒரே கிளிக்கில் குழுவை மீட்டெடுக்கும் வசதியுடன் `ListGroup.svelte` இல் காப்புநகல் UI பார்வை.
    - விசைப்பலகை குறுக்குவழி `br` (மீட்டெடுப்பு) மற்றும் `bg` (அனைத்தையும் காப்புநகல் செய்).
    - Omnibar கட்டளை `bgr:` (காப்புப் பிரதி எடுக்கப்பட்ட குழுக்களைத் தேடி மீட்டெடுப்பது) மற்றும் `b:` (புக்மார்க் தேடல்).
  - **JSON ஏற்றுமதி & இறக்குமதி**: கணினிகளுக்கு இடையே தடையற்ற இடமாற்றம் மற்றும் நீண்ட கால ஆஃப்லைன் காப்பகப்படுத்துதலுக்கான முழுமையான JSON காப்புப்பிரதி ஏற்றுமதி மற்றும் இறக்குமதி.

### 3.5 மறைக்கப்பட்ட குழுக்கள் பட்டியில் நிறுத்தப்பட்ட YouTube பிளேயர்
- **கட்டமைப்பு (`HiddenGroupsBar.svelte`)**:
  - ஒரு பயனர் செயலில் உள்ள YouTube வீடியோ பார்வையில் இருந்து விலகிச் செல்லும்போது அல்லது பக்கப் பலகத்திற்குள் வீடியோ உள்ளடக்கத்தைத் தொடங்கும்போது, பிளேயர் மூடப்படுவதோ அல்லது இழக்கப்படுவதோ இல்லை. இது தானாகவே `HiddenGroupsBar.svelte` இல் நிறுத்தப்பட்ட YouTube குறிகாட்டியாக (`.youtube-indicator`) நிறுத்தப்படுகிறது.
  - `src/ui/stores/appStore.svelte.js` இல் உள்ள `hiddenYoutubeView` சேமிப்பகம் மூலம் எதிர்வினையாற்றும் வகையில் நிர்வகிக்கப்படுகிறது.
  - **ஒரே கிளிக்கில் செயல்கள்**:
    - நிறுத்தப்பட்ட குறிகாட்டியை கிளிக் செய்வது `restoreYoutubeView()` ஐ அழைத்து, பிளேயரை உடனடியாக செயலில் உள்ள பணிச்சூழல் பார்வைக்குத் திருப்புகிறது.
    - நீக்கு பேட்ஜைக் கிளிக் செய்வது `discardYoutubeView()` ஐ அழைத்து, பிளேபேக்கை நேர்த்தியாக நிறுத்தி வளங்களை மீட்டெடுக்கிறது.
  - செயலில் உள்ள தாவல் பட்டியல்களைக் குழப்பாமல் ListGroup பார்வையின் மேற்புறத்தில் மறைக்கப்பட்ட தாவல் குழுக்களுடன் தடையின்றி அமர்ந்திருக்கிறது.

## 4. பிரிவு 3: வழிசெலுத்தல் & தாவல் மேலாண்மை (Navegación)

துரிதப்படுத்தப்பட்ட விசைப்பலகை வழிசெலுத்தல் மற்றும் பணிச்சூழல் கட்டுப்பாடுகள் மவுஸ் பயன்பாடு இல்லாமல் பல தாவல் கட்டுப்பாட்டை அனுமதிக்கின்றன.

### 4.1 விரைவு தாவல் தாவல் அசைவு (Fast Tab Jump Gesture)
- **தொடரியல்**: `Alt + [groupPrefix] + [tabIndex] + Enter`
- **செயல்பாடு**:
  - `Alt` விசையை அழுத்திப் பிடித்து குழுவின் பெயர் அல்லது முன்னொட்டு எழுத்துக்களைத் தட்டச்சு செய்து, அதைத் தொடர்ந்து விரும்பிய 1-அடிப்படையிலான தாவல் குறியீட்டைத் தட்டச்சு செய்து, பின்னர் `Enter` ஐ அழுத்தவும்.
  - எடுத்துக்காட்டு: `Alt + git + 2 + Enter` என்பது "GitHub" குழுவில் உள்ள இரண்டாவது தாவலுக்கு நேரடியாகத் தாவுகிறது.
  - குறியீடு `0` என்பது குழுவின் *கடைசி* தாவலுக்கான குறுக்குவழியாக செயல்படுகிறது.
  - குறியீட்டைத் தவிர்ப்பது குழுவின் *முதல்* தாவலுக்குத் தாவுகிறது.
  - உச்சரிப்புகள் தானாகவே மடக்கப்பட்டு (`deaccent`) பொருத்தமானது குறியீடுகளை இயல்பாக்குகிறது.

### 4.2 நகர்த்தல், இடமாற்றம் & வாழ்க்கைச் சுழற்சி விசைகள்
- `s`: முன்னர் செயலில் இருந்த தாவலுக்கு உடனடியாக இடமாறவும் (`previousActiveTabId`).
- `h` / `l`: முந்தைய / அடுத்த தாவலுக்கு நகரவும் (அல்லது பக்கம் அனுமதித்தால் கிடைமட்டமாக உருட்டவும்).
- `H` / `L`: உலாவி வரலாற்றில் பின்னோக்கி / முன்னோக்கி செல்லவும்.
- `t`: புதிய வெற்று தாவலைத் திறக்கவும்.
- `x`: தற்போதைய செயலில் உள்ள தாவலை மூடவும்.
- `yt`: தற்போதைய தாவலை நகலெடுக்கவும்.
- `r` / `R`: பக்கத்தை மீண்டும் ஏற்றவும் / கேச்-ஐத் தவிர்த்து கட்டாயமாக மீண்டும் ஏற்றவும்.
- `d` / `u`: பக்கத்தின் கீழே / மேலே உருட்டவும்.
- `j` / `k`: சீராக கீழே / மேலே உருட்டவும் (75px படி).
- `f`: Vim இணைப்பு குறிப்புகளை இயக்கவும் (கிளிக் செய்யக்கூடிய கூறுகளின் மேல் கிளிக் செய்வதற்கான எழுத்துக்கள் தோன்றும்).
- `cf`: இலக்கு URL-ஐ கிளிப்போர்டுக்கு நகலெடுக்க Vim இணைப்பு குறிப்புகளை இயக்கவும்.

### ஆற்றல் பயனர்களுக்கு (For power users)

மேம்பட்ட பயனர்கள் உலாவியை முழுத்திரை பயன்முறையில் வைத்து, மவுஸைப் பயன்படுத்தாமல் விசைப்பலகை மூலம் மட்டுமே முழுமையாக வழிசெலுத்த முடியும்.

#### முழுத்திரை மூழ்கிப்பார்த்தல் & மவுஸ் இல்லா உலாவல்
- **முழுத்திரையை மாற்றவும்**: `F11` (Windows/Linux) அல்லது `Command+Control+F` (macOS) ஐ அழுத்தவும். உலாவி குரோம், முகவரிப் பட்டி, தாவல்கள் பட்டி மற்றும் இயக்க முறைமை பேனல்கள் மறைக்கப்பட்டு, காட்சியின் 100% உள்ளடக்கத்திற்காக ஒதுக்கப்படுகிறது.
- **பக்கத்திற்குள்ளான Vim இணைப்பு வழிசெலுத்தல் (`f` / `cf`)**:
  - DOM இல் உள்ள ஒவ்வொரு கிளிக் செய்யக்கூடிய கூறு, பொத்தான், உள்ளீடு மற்றும் இணைப்பின் மீதும் உயர்-மாறுபட்ட இரண்டு எழுத்து மஞ்சள் இணைப்பு குறிப்புகளை உருவாக்க `f` ஐ அழுத்தவும்.
  - மவுஸ் தொடர்பு இல்லாமல் நேரடி கிளிக்கை உருவகப்படுத்த உங்கள் இலக்குடன் பொருந்தக்கூடிய இரண்டு எழுத்துக்களைத் தட்டச்சு செய்யவும்.
  - இலக்கு இணைப்பின் URL-ஐ உங்கள் கணினி கிளிப்போர்டுக்கு நேரடியாக நகலெடுக்கும் குறிப்பு பேட்ஜ்களைத் தூண்ட `cf` ஐ அழுத்தவும்.
  - இலக்கு இணைப்பின் பக்க முன்னோட்ட மாதிரியைத் திறக்க `vp` ஐ அழுத்தவும்.
  - இணைப்பு குறிப்புகளை ரத்து செய்து இயல்பான உருட்டலுக்குத் திரும்ப எந்த நேரத்திலும் `Esc` ஐ அழுத்தவும்.
- **உடனடி தாவல் தாவுதல் & மாறுதல்**:
  - `Alt + [groupPrefix] + [tabIndex] + Enter`: விரைவு தாவல் தாவல் அசைவை இயக்கவும் (எ.கா., `Alt + dev + 1 + Enter` நேரடியாக "Dev" குழுவில் உள்ள முதல் தாவலுக்குத் தாவுகிறது; குறியீடு `0` குழுவில் உள்ள கடைசி தாவலைத் தேர்ந்தெடுக்கிறது).
  - `s`: தற்போதைய தாவலுக்கும் முந்தைய செயலில் உள்ள தாவலுக்கும் இடையே உடனடியாக மாறவும் (`previousActiveTabId`).
  - `h` / `l`: தாவல் பட்டியில் முந்தைய / அடுத்த தாவலுக்கு வரிசையாக நகரவும்.
  - `H` / `L`: உலாவி வழிசெலுத்தல் வரலாற்றில் பின்னோக்கி / முன்னோக்கி செல்லவும்.
  - `t` / `x` / `yt`: புதிய தாவலைத் திறக்கவும் (`t`), தற்போதைய தாவலை மூடவும் (`x`), அல்லது தாவலை நகலெடுக்கவும் (`yt`).
- **மிதக்கும் Omnibar கட்டளை துணை அமைப்பு (`o`)**:
  - மையப்படுத்தப்பட்ட Omnibar மேலடுக்கை அழைக்க எந்தப் பக்கத்திலும் `o` ஐ அழுத்தவும்.
  - அனைத்து 41 கட்டளை முன்னொட்டுகளின் ஊடாடும் கோப்பகத்தைக் காட்ட `@` ஐ அழுத்தவும்.
  - திறந்துள்ள அனைத்து சாளரங்களிலும் ஆழமான முழு உரை தாவல் தேடலை இயக்க `f: <query>` எனத் தட்டச்சு செய்யவும்.
  - எந்த பக்கப் பலகப் பார்வைக்கும் (`rules`, `listgroup`, `notes`, `gallery`, `gemini`, `activity`, `themes`, `hints`, `downloads`) நேரடியாகச் செல்ல `sp:` எனத் தட்டச்சு செய்யவும்.
  - விசைப்பலகையிலிருந்து கைகளை எடுக்காமல் Gemini-ஐ வினவ அல்லது தன்னாட்சி உலாவி ஏஜென்டிற்கு அறிவுறுத்த `qai: <query>` அல்லது `qaia: <task>` எனத் தட்டச்சு செய்யவும்.
  - திறந்த தாவல்களை அருகருகே திரை பிரிப்பில் பிரிக்க `ts:` எனத் தட்டச்சு செய்யவும்.
- **பக்கத்திற்குள்ளான வழிசெலுத்தல் & கவனம்**:
  - `j` / `k`: சீராக கீழே / மேலே உருட்டவும் (75px அதிகரிப்பு).
  - `d` / `u`: அரைப் பக்கம் கீழே / மேலே உருட்டவும்.
  - `i`: கர்சர் கவனத்தை உடனடியாகப் பக்கத்தின் முதன்மை உரை உள்ளீட்டுப் புலத்திற்கு நகர்த்தவும்.
  - `ESC`: உள்ளீடுகளிலிருந்து கவனத்தை அகற்றி, விசைப்பலகை கவனத்தை வழிசெலுத்தல் பயன்முறைக்குத் திருப்பவும்.

### 4.3 ஆடியோ & ஒலி மேலாண்மை
- ஆடியோவை இயக்கும் தாவல்கள் ListGroup UI-இல் ஸ்பீக்கர் பேட்ஜைக் காட்டுகின்றன.
- `st`: தற்போதைய செயலில் உள்ள தாவலில் ஒலியை முடக்கவும்/இயக்கவும்.
- `so`: முழு உலாவியிலும் கேட்கக்கூடிய அனைத்து தாவல்களையும் முடக்கவும்.
- சூழல் மெனு: "Silenciar Todas las Pestañas" / "Reactivar Sonido en Todas las Pestañas".

### 4.4 திரை பிரிப்பு பணிப்பாய்வுகள் (Split Screen Workflows)
- **தூண்டுதல்**: Vim குறிப்பு `ts` அல்லது Omnibar முன்னொட்டு `ts:`.
- **நடத்தை**: திரை அளவைக் கணக்கிட `chrome.system.display` ஐப் பயன்படுத்துகிறது. இரண்டு தாவல்களை அருகருகே அடுத்தடுத்த சாளரங்களாகப் பிரித்து, அவற்றை பிரத்யேக `Split` தாவல் குழுவின் கீழ் குழுவாக்குகிறது.
- **மீட்டமைத்தல்**: பிரிக்கப்பட்ட சாளரத்தை மூடுவது அல்லது திரை பிரிப்பை மாற்றுவது அசல் சாளர பரிமாணங்களையும் ஆயத்தொலைவுகளையும் மீட்டெடுக்கிறது.

### 4.5 YouTube சுழற்சி துணை அமைப்பு (YouTube Looping Subsystem)
YouTube சுழற்சி துணை அமைப்பானது YouTube பிளேயரில் நேரடியாக ஒருங்கிணைக்கப்பட்ட துல்லியமான மீடியா சுழற்சிக் கட்டுப்பாடுகளை வழங்குகிறது:
- **டெஸ்க்டாப் பிளேயர் பொத்தான் (`#itg-yt-loop-button`)**: Cast / Remote பொத்தான் அல்லது PiP துவக்கிக்கு இடதுபுறத்தில் நிலையான YouTube பிளேயர் கட்டுப்பாட்டுப் பட்டியில் (`.ytp-right-controls`) செலுத்தப்படுகிறது. அனிமேஷன் செய்யப்பட்ட SVG சுழற்சி சின்னங்கள், நிலைமாற்றி சிறப்பம்ச பாணி (`ytp-loop-active`, `var(--interactive-color, #ff4444)`), மற்றும் `aria-pressed` நிலைகளைக் கொண்டுள்ளது.
- **Shorts பிளேயர் பொத்தான் (`#itg-yt-shorts-loop-button`)**: YouTube Shorts வலது பக்கக் கட்டுப்பாட்டு நெடுவரிசையில் (`ytd-shorts`) உள்ள `#itg-yt-shorts-loop-wrapper` க்குள் செலுத்தப்பட்டு, செங்குத்து வீடியோ உள்ளடக்கத்திற்கு ஒரே கிளிக்கில் சுழற்சியை வழங்குகிறது.
- **சுழற்சி மெனு & PiP பாப்அப் (`#itg-yt-loop-menu` & `#itg-pip-loop-popup`)**: லூப் பொத்தானின் மீது நகர்த்துவது அல்லது கிளிக் செய்வது விரிவான லூப் அமைப்புகள் மெனுவைத் திறக்கும்:
  - **A-B சுழற்சி**: பயனர்கள் ஊடாடும் வரம்பு ஸ்லைடர்கள் மற்றும் கைமுறை நேரப் புலங்களுடன் மில்லி விநாடி துல்லியத்துடன் தனிப்பயன் தொடக்கப் புள்ளி (A) மற்றும் முடிவுப் புள்ளியை (B) அமைக்கலாம்.
  - **சுழற்சி முறை & வரிசை மறுநிகழ்வுகள்**: குறிப்பிட்ட சுழற்சிகளுக்கான மறுநிகழ்வு எண்ணிக்கையை அமைக்கலாம் அல்லது எல்லையற்ற சுழற்சி பயன்முறையை மாற்றலாம் (`itg-loop-seq-inf`).
  - **சுழற்சி பட்டியல் & பல-பிரிவு வரிசைகள்**: உள்ளமைக்கப்பட்ட மறுநிகழ்வுகளுக்கு ஏற்ப அடுத்தடுத்து இயங்கும் பல A-B லூப் இடைவெளிகளை வரிசைப்படுத்தலாம்.
  - **நிலை & கால அளவு காட்சி**: தற்போதைய லூப் இடைவெளியில் நிகழ்நேர பின்னணி நிலை மற்றும் மொத்த மீடியா கால அளவைக் காட்டுகிறது (`00:00 / 00:00`).
  - **முதன்மை நிலைமாற்றி (`youtubeLoopEnabled`)**: `chrome.storage.sync` மற்றும் `local` இல் சேமிக்கப்பட்டு, குறிப்புகள் தனிப்பயனாக்குதல் அமைப்புகள் பக்கம் (`YoutubeLoopSection.svelte`) வழியாக YouTube மற்றும் YouTube Shorts முழுவதும் லூப் பொத்தான்களை இயக்க அல்லது முடக்க பயனர்களை அனுமதிக்கிறது.

### 4.6 YouTube Shorts முன்னோட்ட ஆடியோ
- **ஆடியோ அன்மியூட் ஹூக் (`youtubePreviewAudioHook.js`)**:
  - `ytd-video-preview` கூறுகளில் உள்ள `#inline-preview-player` பண்பை அணுக `MAIN` இயக்க உலகில் இயங்குகிறது.
  - **கட்டாய ஒலியடக்கத்தை முறியடித்தல்**: ஆடியோ கட்டுப்பாடுகளை அழித்து உள் `volumechange` கேட்பிகள் வழியாக `muted = true` என்பதை மீட்டமைப்பதன் மூலம் Shorts முன்னோட்டங்களில் YouTube கட்டாய ஒலியடக்கத்தை செயல்படுத்துகிறது.
  - இந்த நீட்டிப்பு இலக்கு `<video>` கூறில் உள்ள `HTMLMediaElement.prototype.muted` பண்புக்கூறு விளக்கத்தை நகர்த்தும்போது இடைமறிக்கிறது. இது பயனரின் ஒலியடக்க நீக்கத்தை அனுமதிக்கும் அதே வேளையில் YouTube-இன் கட்டாய மறு-ஒலியடக்கத்தை கைவிடுகிறது; மவுஸ் வெளியேறும் வரை லூப் மறுதொடக்கங்கள் முழுவதும் ஒலி தடைபடாமல் தொடர்ந்து இயங்குவதை உறுதி செய்கிறது.

### 4.7 பிக்சர்-இன்-பிக்சர் (PiP) கட்டமைப்பு
- **ஆவண பிக்சர்-இன்-பிக்சர் (`wp`)**:
  - முழு வலைப்பக்கத்தையும் அல்லது உரைத் துண்டுகளையும் எப்போதும் மேலே இருக்கும் மிதக்கும் சாளரத்திற்குள் திறக்க நவீன `documentPictureInPicture` API-ஐப் பயன்படுத்துகிறது.
  - மீடியாவை மாற்றும்போது வீடியோ பிளேபேக் நேர முத்திரைகளைத் தானாகவே ஒத்திசைக்கிறது.
  - மறுமுயற்சி தர்க்கத்தைக் கொண்டுள்ளது (`itgRetryIfPipFrameRefused`) மற்றும் மூடும்போது DNR iframe தலைப்புகளை அழிக்கிறது.
- **வீடியோ பிக்சர்-இன்-பிக்சர் (`wv`)**:
  - `videoPipHook.js` வழியாக `HTMLVideoElement.prototype.requestPictureInPicture` ஐ இடைமறிக்கிறது.
  - லூப் கட்டுப்பாடுகள் மற்றும் பிளேபேக் வேக தேர்வாளர்களுடன் வீடியோ பிளேயர்களை தனிப்பயன் PiP பிரேம்களுக்கு திருப்பி விடுகிறது.
- **தானியங்கி-PiP (Auto-PiP)**:
  - `as`: உருட்டலில் தானியங்கி-PiP-ஐ மாற்றவும் (பார்வைப்பகுதிக்கு வெளியே உருட்டும்போது வீடியோவை PiP-இல் தொடங்குகிறது).
  - `ah`: தாவல் மறைப்பில் தானியங்கி-PiP-ஐ மாற்றவும் (மற்றொரு தாவலுக்கு மாறும்போது வீடியோவை PiP-இல் தொடங்குகிறது).

### 4.8 பக்க வாசிப்பு முறைகள் & காட்சி மேலடுக்குகள்
- **CSS வடிகட்டி தீம்கள்**: வலைப்பக்கங்களில் பாதிப்பில்லாத பாணிகளைச் செலுத்துகிறது:
  - `mb` / `mB`: கருப்பு (இருண்ட உயர் மாறுபாடு) — தாவல் வரம்பு / உலகளாவிய வரம்பு.
  - `ms` / `mS`: செபியா (சூடான காகிதம்) — தாவல் வரம்பு / உலகளாவிய வரம்பு.
  - `mp` / `mP`: காகிதம் (மோனோக்ரோம் கிரேஸ்கேல்) — தாவல் வரம்பு / உலகளாவிய வரம்பு.
  - `ml` / `mL`: வெளிச்சம் (மென்மையான வெள்ளை) — தாவல் வரம்பு / உலகளாவிய வரம்பு.
  - `me` / `mE`: தனிப்பயன் பயனர் வரையறுத்த CSS வடிகட்டி — தாவல் வரம்பு / உலகளாவிய வரம்பு.
  - `ESC`: செயலில் உள்ள பக்க வடிப்பானை உடனடியாக நீக்குகிறது.
- **ரீடர் பயன்முறை & TTS சத்தமாக வாசித்தல்**:
  - `fetchContentForReaderView`: விளம்பரங்கள், பக்கப்பட்டிகள் மற்றும் வழிசெலுத்தல் இடையூறுகளை நீக்கி சுத்தமான கட்டுரை உள்ளடக்கத்தைப் பிரித்தெடுக்கிறது.
  - வாக்கியம் வாக்கியமாக உரையை சத்தமாக வாசிக்கும் உள்ளமைக்கப்பட்ட Text-to-Speech (TTS) எஞ்சின்.
  - விசைப்பலகை வழிசெலுத்தல் கட்டுப்பாடுகள்: `zp` (இயக்கு/இடைநிறுத்து), `zn` (அடுத்த வாக்கியம்), `zb` (முந்தைய வாக்கியம்), `zq` (ரீடர் மேலடுக்கை மூடு).

### 4.9 வார்ப்புரு மாறிகளுடன் கூடிய உரை துணүктள் துணை அமைப்பு
உரை துணுக்குகள் துணை அமைப்பு (`src/utils/hint/snippets.js` மற்றும் `src/utils/snippet-panel.js` இல் உள்ள `SnippetManager`) எந்தவொரு உள்ளீடு, textarea அல்லது ரிச் எடிட்டரிலும் உரை குறுக்குவழிகளை விரிவுபடுத்துவதன் மூலம் தட்டச்சு செய்வதை துரிதப்படுத்துகிறது:
- **தூண்டுதல் முறைகள்**: குறுக்குவழியைத் தட்டச்சு செய்து Space அழுத்தவும், அல்லது ஊடாடும் துணுக்குகள் தேடல் பாப்அப்பை அழைக்க `$$` எனத் தட்டச்சு செய்யவும்.
- **கிளிப்போர்டு API ஒருங்கிணைப்பு**: கிளிப்போர்டு API வழியாக வடிவமைக்கப்பட்ட HTML மற்றும் எளிய உரை செருகலை ஆதரிக்கிறது, Google Docs, Notion மற்றும் Slack போன்ற சிக்கலான எடிட்டர்களுடன் 100% இணக்கத்தன்மையை உறுதி செய்கிறது.
- **வார்ப்புரு மாறிகள்**: விரிவாக்கத்தின் போது மாறிகளை மாறும் வகையில் தீர்மானிக்கிறது:
  - `{{date}}` / `date`: வடிவமைக்கப்பட்ட உள்ளூர் தேதி (`toLocaleDateString`).
  - `{{isodate}}` / `isodate`: ISO 8601 தேதி (`YYYY-MM-DD`).
  - `{{longdate}}` / `longdate`: கிழமை, நாள், மாதம் மற்றும் ஆண்டுடன் கூடிய நீண்ட தேதி.
  - `{{time}}` / `time`: 2-இலக்க வடிவமைக்கப்பட்ட நேரம் (`HH:MM`).
  - `{{datetime}}` / `datetime`: தேதியும் நேரமும் இணைந்தது.
  - `{{weekday}}` / `weekday`: முழு நாளின் பெயர் (எ.கா., Monday).
  - `{{day}}` / `day`: மாதத்தின் நாள் (1-31).
  - `{{month}}` / `month`: முழு மாதத்தின் பெயர் (எ.கா., October).
  - `{{year}}` / `year`: முழு 4-இலக்க ஆண்டு.
  - `{{tomorrow}}` / `tomorrow`: அடுத்த நாள் தேதி (+1 நாள்).
  - `{{yesterday}}` / `yesterday`: முந்தைய நாள் தேதி (-1 நாள்).
  - `{{nextweek}}` / `nextweek`: 7 நாட்கள் பிந்தைய தேதி (+7 நாட்கள்).
  - `{{timestamp}}` / `timestamp`: Epoch மில்லி விநாடி நேர முத்திரை (`Date.now()`).
  - `{{url}}` / `url`: செயலில் உள்ள வலைப்பக்க URL (`window.location.href`).
  - `{{domain}}` / `domain`: செயலில் உள்ள டொமைன் ஹோஸ்ட்பெயர் (`window.location.hostname`).
  - `{{pagetitle}}` / `pagetitle`: செயலில் உள்ள ஆவணத் தலைப்பு (`document.title`).
  - `{{uuid}}` / `uuid`: குறியாக்கவியல் ரீதியாகப் பாதுகாப்பான தனித்துவ அடையாளங்காட்டி (`crypto.randomUUID()`).
  - `{{random}}` / `random`: 1 மற்றும் 1000 இடையே உள்ள சீரற்ற முழு எண்.
  - `{{clipboard}}` / `clipboard`: கணினி கிளிப்போர்டு இடையக உரை.

### 4.10 உட்பொதிக்கப்பட்ட உற்பத்தித்திறன் கருவிகள்
- **வலது கிளிக் அனுமதிக்கும் ஹூக் (`allowRightClickHook.js`)**:
  - வலது கிளிக் சூழல் மெனுக்கள், நகலெடுத்தல், வெட்டுதல் அல்லது உரைத் தேர்வை முடக்கும் வலை ஸ்கிரிப்ட்களை நடுநிலையாக்க `MAIN` இயக்க உலகில் செலுத்தப்படுகிறது.
  - `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown`, மற்றும் `mouseup` ஆகியவற்றில் `preventDefault()` மற்றும் `stopPropagation()` ஐ இடைமறிக்கிறது.
  - ஒரு நிலையான `MutationObserver` வழியாக இன்லைன் `oncontextmenu="return false"` கையாளுபவர்களை நீக்குகிறது.
  - முறையான வலை எடிட்டர்களை (Google Docs, Telegram Web) உடைப்பதைத் தடுக்க கிளிப்போர்டு பேலோடுகளைச் சரிபார்க்கிறது.
- **குக்கீ எடிட்டர் (Cookie Editor)**: செயலில் உள்ள டொமைனுக்கான HTTP மற்றும் HTTPS குக்கீகளை ஆய்வு செய்தல், திருத்துதல், உருவாக்குதல் மற்றும் நீக்குதல் செய்யும் பக்கத்திற்குள்ளான மாதிரி சாளரம்.
- **QR குறியீடு ஜெனரேட்டர்**: விரைவான மொபைல் பகிர்வுக்கு செயலில் உள்ள தாவல் URL-க்கான SVG/Canvas QR குறியீடுகளை உருவாக்குகிறது.
- **சுத்தமான PDF அச்சு ஏற்றுமதி**: தலைப்புகள், விளம்பரங்கள் மற்றும் வழிசெலுத்தல் இரைச்சல்கள் நீக்கப்பட்ட சுத்தமான ஆவண காப்பகத்திற்காக இலக்கு பக்கங்களை `print.html` வழியாக வழிநடத்துகிறது.

### 4.11 விரிவான 3-அடுக்கு நகல் நீக்கம் & அறிவார்ந்த நிராகரிப்பு
- **விரிவான 3-அடுக்கு நகல் நீக்கம்**:
  1. **தாவல் நகல் நீக்கம் (`removeDuplicateTabsCommand`)**: சாளரங்கள் அல்லது கவனம் செலுத்தப்பட்ட குழுக்கள் முழுவதும் திறந்த தாவல்களை ஸ்கேன் செய்கிறது, நகல் URL-களை அடையாளம் காண்கிறது, `Split` திரை தாவல்களுக்கு விலக்கு அளிக்கிறது, மற்றும் செயலில் உள்ள அல்லது பழமையான தாவலை வைத்திருக்கும் போது தேவையற்ற தாவல்களை மூடுகிறது. டெஸ்க்டாப் சுருக்க அறிவிப்பைக் காட்டுகிறது.
  2. **புக்மார்க் நகல் நீக்கம்**: Chrome புக்மார்க் மரங்களை ஆழமாக ஸ்கேன் செய்கிறது, கோப்புறைகளில் ஒரே மாதிரியான URL நகல்களைக் கண்டறிகிறது, மற்றும் புக்மார்க்குகளை சுத்தமாக வைத்திருக்க தொகுதி ஒருங்கிணைப்பை வழங்குகிறது.
  3. **விதி நகல் நீக்கம் (`feature_v100_dedup_add_to_rule`)**: ஏற்கனவே உள்ள தனிப்பயன் குழுவாக்க விதிகளில் URL-களைச் சேர்க்கும்போது நகல் URL வடிவங்களைத் தானாகவே நீக்குகிறது, இது விதி பெருக்கத்தைத் தடுக்கிறது.
- **அறிவார்ந்த நினைவக நிராகரிப்பு (`suspendInactiveTabsIntelligently`)**:
  - அலாரம் `itg-periodic-tasks` வழியாக ஒவ்வொரு 1 நிமிடத்திற்கும் மதிப்பீடு செய்யப்படுகிறது.
  - `discardingTimeMinutes` (இயல்புநிலை: 60 நிமிடங்கள்) நேரத்திற்கு மேல் செயலற்ற தாவல்களை நிராகரிக்கிறது.
  - உள்ளமைக்கப்பட்ட நோய் எதிர்ப்பு பாதுகாப்புகள்: செயலில் உள்ள தாவல்கள், ஆடியோவை இயக்கும் கேட்கக்கூடிய தாவல்கள், பின் செய்யப்பட்ட தாவல்கள் அல்லது ஏற்கனவே இடைநிறுத்தப்பட்ட தாவல்களை ஒருபோதும் நிராகரிக்காது.

## 5. பிரிவு 4: AI உதவியாளர் & தன்னாட்சி ஏஜென்ட் (Asistente AI)

AI உதவியாளர் சூழல்சார்ந்த புரிதல், தானியங்கு பணிப்பாய்வுகள் மற்றும் நேரடி உலாவி ஆட்டோமேஷனை வழங்க பெரிய மொழி மாதிரிகளை உலாவியில் ஒருங்கிணைக்கிறது.

### 5.1 இரட்டை மாதிரி எஞ்சின் கட்டமைப்பு (Dual Model Engine Architecture)
1. **Google Gemini Cloud API (`gemini-api.js`)**:
   - Google Generative Language REST இறுதிப்புள்ளிகளுடன் (`v1beta/models/{model}:generateContent` மற்றும் `:streamGenerateContent`) ஒருங்கிணைக்கிறது.
   - Gemini 2.5 Flash, Gemini 2.5 Pro மற்றும் தனிப்பயன் மாதிரி இறுதிப்புள்ளிகளை ஆதரிக்கிறது.
   - **பல-விசை சுழற்சி (Multi-Key Rotation)**: `geminiApiKeysList` இல் விசை குளங்களை நிர்வகிக்கிறது. சேமிப்பக மறைத்தல் `enc_` முன்னொட்டுகளைப் பயன்படுத்துகிறது.
   - **அதிவேக பின்னடைவு (Exponential Backoff)**: தானியங்கு பின்னடைவு மறுமுயற்சியுடன் (1.5s -> 3s -> 6s) HTTP 429 ஒதுக்கீட்டுத் தீர்வைக் கையாள்கிறது.
   - **தேடல் அடிப்படை (Search Grounding)**: Google Search Grounding ஐ இயக்குகிறது (`google_search: {}`). தேடல் கருவிகளில் ஒதுக்கீட்டு கட்டுப்பாடுகள் காரணமாக HTTP 403 ஏற்பட்டால், அது தானாகவே அடிப்படை இல்லாமல் மீண்டும் முயற்சிக்கிறது.
2. **Chrome உள்ளமைக்கப்பட்ட AI / Prompt API (`localAiService.js`)**:
   - `window.LanguageModel` வழியாக சாதனத்தில் இயங்கும் Gemini Nano ஒருங்கிணைப்பு.
   - பூஜ்ஜிய-நெட்வொர்க் உள்ளூர் இயக்கத்தை ஆதரிக்கிறது. மாதிரி கிடைக்கும் தன்மையைச் சரிபார்த்தல் மற்றும் நேரடி பதிவிறக்க முன்னேற்றக் கண்காணிப்பு ஆகியவை அடங்கும்.

### 5.2 தன்னாட்சி உலாவி ஏஜென்ட் (`agent-backend.js`)
தன்னாட்சி ஏஜென்ட் 40+ கட்டமைக்கப்பட்ட கருவிகள் மூலம் முழு உலாவி கட்டுப்பாட்டை வழங்குகிறது:
- **தாவல் & குழு கட்டுப்பாடு**: `getOpenTabs`, `switchToTab`, `createNewTab`, `closeTab`, `closeTabs`, `duplicateTab`, `findAndSwitchToTab`, `groupTabs`, `ungroupTabs`, `deleteTabGroup`, `collapseTabGroup`, `expandTabGroup`, `collapseAllGroups`, `expandAllGroups`, `setGroupColor`, `renameTabGroup`, `regroupAllTabs`, `removeDuplicateTabs`, `closeTabsWithSound`.
- **வழிசெலுத்தல் & தேடல்**: `openUrl`, `searchGoogle`, `getActiveTab`, `getActiveTabContent`.
- **அறிவு & புக்மார்க்குகள்**: `getBookmarks`, `searchBookmarks`, `createBookmark`, `getHistory`, `getRecentlyClosed`.
- **விதிகள் & தோற்றம்**: `getRules`, `createRule`, `updateRule`, `deleteRule`, `getActiveTheme`, `getSavedThemes`, `applyTheme`.

### 5.3 கறை கண்காணிப்பு & ப்ராம்ப்ட் ஊடுருவல் தடுப்பு (Taint Tracking & Prompt Injection Defense)
நம்பத்தகாத வலைப்பக்கங்களிலிருந்து மறைமுக ப்ராம்ப்ட் ஊடுருவல் தாக்குதல்களை நடுநிலையாக்க, ஏஜென்ட் பின்தளம் கடுமையான கறை கண்காணிப்பை செயல்படுத்துகிறது:
- **கறை குறித்தல்**: `getActiveTabContent` ஐ அழைப்பது ஒரு வலைப்பக்கத்திலிருந்து உரையைப் பிரித்தெடுத்து தற்போதைய இயக்கத்தை கறைபடிந்ததாகக் குறிக்கிறது (`taintedAgentRuns.add(runId)`).
- **வெளியேற்றக் காவலர் (Egress Guard)**: கறைபடிந்த இயக்கங்கள் வெளியேற்றக் கருவிகளை (`AGENT_EGRESS_TOOLS`) செயல்படுத்துவது கண்டிப்பாகத் தடைசெய்யப்பட்டுள்ளது:
  * `openUrl`, `searchGoogle`, `createBookmark`, `createRule`, `addUrlToRule`, `createSiteShortcut`, `updateSiteShortcut`, `updateRule`.
- **மறுப்பு வழிமுறை**: கையாளப்படாத விதிவிலக்கை வீசுவதற்குப் பதிலாக, எஞ்சின் ஒரு கட்டமைக்கப்பட்ட பாதுகாப்பு விளக்கத்தை அளிக்கிறது. வெளிப்படையான பயனர் அனுமதியின்றி வெளிப்புறத் தரவை வெளியேற்ற முடியாது என்று LLM பயனருக்குத் தெரிவிக்கிறது.

### 5.4 திட்டமிடப்பட்ட Gemini வினவல்கள் துணை அமைப்பு (`GeminiScheduleModal.svelte`)
- **பின்னணி இயங்குதள எஞ்சின்**:
  - `chrome.alarms` (`gemini-scheduled-*`) வழியாக பின்னணி சேவைப் பணியாளருக்குள் நேரடியாக திட்டமிடப்பட்ட AI ப்ராம்ப்ட் இயக்கத்தை தானியங்குபடுத்துகிறது.
  - ஒரு நாளைக்கு 6 திட்டமிடப்பட்ட வினவல்கள் வரை ஆதரிக்கிறது (`MAX_TIMES = 6`).
  - **திட்டமிடல் முறைகள்**:
    - தொடர்ச்சியான அட்டவணைகள்: வாரத்தின் தேர்ந்தெடுக்கப்பட்ட நாட்களில் மீண்டும் மீண்டும் செயல்படுத்தப்படுகிறது (`selectedDays`).
    - ஒரு முறை அட்டவணைகள்: ஒரு குறிப்பிட்ட இலக்கு தேதி மற்றும் நேரத்தில் செயல்படுத்தப்படுகிறது (`formDate`).
  - **ப்ராம்ப்ட் வரம்புகள்**: நிகழ்நேர எழுத்து கவுண்டர்களுடன் கடுமையான 1,000 எழுத்துகள் கொண்ட ப்ராம்ப்ட் வரம்பை (`MAX_QUERY_CHARS = 1000`) செயல்படுத்துகிறது.
  - **பின்னணி அறிவிப்புகள்**: பின்னணி வினவல் முடிந்ததும் ஒரு துணுக்கு முன்னோட்டத்துடன் டெஸ்க்டாப் அறிவிப்பை அனுப்புகிறது. அறிவிப்பைக் கிளிக் செய்வது உடனடியாக பக்கப் பலக அரட்டைக்குள் பதில் தொடரைத் திறக்கும்.

### 5.5 Gemini உரையாடல் மேலாண்மை & ஏற்றுமதி
- **நிலையான IndexedDB சேமிப்பகம் (`geminiConversations`)**: பல அடுக்கு அரட்டை அமர்வுகள் IndexedDB `Intelligent_Workspace` இன் `geminiConversations` சேமிப்பகத்தில் சேமிக்கப்படுகின்றன.
- **முழு உரை வரலாற்றுத் தேடல்**: Omnibar கட்டளைகள் `lai:` (உரையாடல்களை உலாவுதல்) மற்றும் `laiq:` (செய்திகளைத் தேடுதல்) மூலம் கடந்த கால உரையாடல்கள் மற்றும் தனிப்பட்ட செய்திகள் முழுவதும் உடனடி தேடல்.
- **நான்கு ஏற்றுமதி வடிவங்கள்**:
  1. **வடிவமைக்கப்பட்ட HTML**: உரையாடல் குமிழ்கள், பாத்திர பேட்ஜ்கள், நேர முத்திரைகள் மற்றும் தொடரியல்-சிறப்பித்துக் காட்டப்பட்ட குறியீட்டுத் தொகுதிகள் கொண்ட தனித்த வடிவமைப்புடைய HTML ஆவணம்.
  2. **மூல JSON**: செய்தி வரிசைகள், டோக்கன் பயன்பாடு, மாதிரி கட்டமைப்பு மற்றும் தேடல் மேற்கோள்கள் உள்ளிட்ட முழுமையான கட்டமைக்கப்பட்ட தரவுக் குவியல்.
  3. **Markdown**: தலைப்புகள், நேர முத்திரைகள் மற்றும் குறியீட்டுத் தொகுதிகள் (` ``` `) கொண்டு வடிவமைக்கப்பட்ட நிலையான Markdown கோப்பு.
  4. **எளிய உரை (Plain Text)**: மின்னஞ்சல் அல்லது குறிப்புகளுக்கு ஏற்ற சுத்தமான, வடிவமைக்கப்படாத உரையாடல் படியெடுத்தல்.
- **அடிப்படை மெட்டாடேட்டா கண்காணிப்பு**: மாதிரி ஐடி, டோக்கன் பயன்பாட்டு புள்ளிவிவரங்கள், செயல்படுத்தும் நேர முத்திரைகள் மற்றும் Google Search Grounding மூலம் பெறப்பட்ட மூல மேற்கோள்களைக் கண்காணிக்கிறது.

### 5.6 மல்டிமாடல் உள்ளீடுகள் & கோப்பு இணைப்புகள் (`feature_geminiAttachFiles`)
- **மல்டிமாடல் இணைப்புகள்**: நிலைமாற்றி `feature_geminiAttachFiles` அரட்டைத் தூண்டுதல்களில் நேரடி படம் மற்றும் ஆவண இணைப்புகளை செயல்படுத்துகிறது:
  - படக் கோப்புகள் (JPEG, PNG, WebP, HEIC/HEIF).
  - PDF ஆவணங்கள் மற்றும் ஆய்வுக் கட்டுரைகள்.
  - எளிய உரைக் கோப்புகள் மற்றும் குறியீட்டுக் கோப்புகள்.
  - CSV கட்டமைக்கப்பட்ட தரவுத்தொகுப்புகள்.
- **குரல் ஆதரவு**:
  - கைகளைப் பயன்படுத்தாமல் ப்ராம்ப்ட்களை உள்ளிட Web Speech STT (Speech-to-Text).
  - பதில்களை சத்தமாக வாசிக்க Web Speech TTS (Text-to-Speech).

### 5.7 செயல்படுத்தும் முறைகள் (Invocation Modalities)
- **பக்கப் பலகப் பாதை**: `?view=gemini` அல்லது குறுக்குவழி `pa`.
- **பக்கத்திற்குள்ளான Omnibar முன்னொட்டுகள்**:
  - `qai: <query>` — கட்டமைக்கப்பட்ட Gemini மாதிரியிடம் நேரடிக் கேள்வி கேட்கவும்.
  - `qaia: <prompt>` — கருவி இயக்கத்துடன் கூடிய தன்னாட்சி ஏஜென்ட் மூலம் ப்ராம்ப்ட்டை இயக்கவும்.
  - `lai:` — கடந்த கால AI உரையாடல்களை உலாவவும்.
  - `laiq:` — அனைத்து AI உரையாடல் செய்திகளிலும் முழு உரைத் தேடல் செய்யவும்.
- **Omnibox AI தாவல் தேடல் (`find <query>`)**:
  - URL பட்டி முக்கிய சொல் `find` கலப்பின தேடலைத் தொடங்குகிறது.
  - இயல்பான மொழி வினவல்களின் அடிப்படையில் திறந்த தாவல்களைக் கண்டறிந்து கவனம் செலுத்த, Regex சொல்-எல்லை மதிப்பெண்ணை Gemini சொற்பொருள் தெளிவுடன் ஒருங்கிணைக்கிறது.

## 6. பிரிவு 5: குறிப்புகள் பார்வை & அறிவு மேலாண்மை (Ver Notas)

உலாவி தாவல் குழுக்கள் மற்றும் வழிசெலுத்தல் சூழல்களுடன் பிணைக்கப்பட்ட உள்ளூர்-முதல், சூழல்-விழிப்புணர்வு குறிப்பெடுக்கும் எஞ்சின்.

### 6.1 சேமிப்பகக் கட்டமைப்பு (`notesStore`)
IndexedDB தரவுத்தளத்தில் `Intelligent_Workspace` (v8) `notesStore` ஆப்ஜெக்ட் ஸ்டோரில் சேமிக்கப்படுகிறது:
```typescript
interface NoteRecord {
  id: string;          // Unique note identifier.
  title: string;       // Note title.
  text: string;        // Rich text HTML, Markdown, or serialized task payload.
  type: NoteType;      // 'text' | 'checklist' | 'kanban'
  url?: string;        // Origin URL where note was created.
  contextKey: string;  // Scoping key binding note to workspace hierarchy.
  createdAt: number;   // Creation timestamp.
  modifiedAt: number;  // Last edit timestamp.
  isPersistent: boolean; // Pin flag protecting note from group deletion cleanup.
}
```

### 6.2 சிறப்பு குறிப்பு வடிவங்கள் & மேம்பட்ட ரெண்டரிங்
1. **உரைக் குறிப்பு (`NoteTextEditor.svelte`)**:
   - ரிச் டெக்ஸ்ட் `contenteditable` தளம்.
   - ஊடகங்களை நேரடியாக உட்பொதிக்கிறது: படங்கள், ஆடியோ, வீடியோ மற்றும் PDF ஆவணங்கள்.
   - உள்ளமைக்கப்பட்ட HTML துப்புரவாக்கல் மற்றும் நிகழ்நேர சொல் மற்றும் எழுத்து கவுண்டர்கள்.
   - **Mermaid வரைபட ரெண்டரிங்**: Markdown தொகுதிகளிலிருந்து (` ```mermaid `) நேரடியாக பாய்வுப்படங்கள், வரிசை வரைபடங்கள், வகுப்பு வரைபடங்கள் மற்றும் நிலை இயந்திரங்களை உருவாக்குகிறது.
   - **KaTeX கணித LaTeX**: உயர் துல்லிய அச்சுக்கலையுடன் இன்லைன் சமன்பாடுகள் (`$...$`) மற்றும் தொகுதி சமன்பாடுகளை (`$$...$$`) வழங்குகிறது.
2. **சரிபார்ப்புப் பட்டியல் குறிப்பு (`NoteChecklistEditor.svelte`)**:
   - தனிப்பட்ட நிறைவு தேர்வுப்பெட்டிகளுடன் கூடிய ஊடாடும் பணி பட்டியல்.
   - விசைப்பலகை மூலம் இயக்கப்படும் உருப்படி மறுவரிசைப்படுத்தல் மற்றும் முன்னேற்றக் கண்காணிப்பை ஆதரிக்கிறது.
3. **Kanban குறிப்பு (`NoteKanbanEditor.svelte`)**:
   - 3-நெடுவரிசை பணிப்பாய்வு பலகை: `To Do` -> `In Progress` -> `Done`.
   - விரைவான பணி மாற்றங்களுக்கான சுழற்சி நிலை சில்லுகள்.
- **மாறும் இழப்பற்ற மாற்றம்**: உரை, சரிபார்ப்புப் பட்டியல் மற்றும் Kanban பிரதிநிதித்துவங்களுக்கு இடையில் எந்த இழப்பும் இன்றி குறிப்புகள் மாற்றப்படுகின்றன.

### 6.3 எல்லை & சூழல் படிநிலை (Scoping & Context Hierarchy)
`contextKey` வழியாக உலாவல் சூழல்களுடன் குறிப்புகள் பிணைக்கப்படுகின்றன:
- **குழு எல்லை (`g_<groupId>` அல்லது `g_<groupKey>`)**: முழு தாவல் குழுவுடன் இணைக்கப்பட்டுள்ளது.
- **துணைக் குழு எல்லை (`s_<groupId>_<domain>`)**: தாவல் குழுவிற்குள் உள்ள ஒரு குறிப்பிட்ட டொமைனுடன் இணைக்கப்பட்டுள்ளது.
- **குழுவாக்கப்படாத எல்லை (`g_ungrouped` / `s_ungrouped_<domain>`)**: தாவல் குழுக்களுக்கு வெளியே உள்ள தாவல்களில் உருவாக்கப்பட்ட குறிப்புகள்.
- **Pomodoro & பொதுவான எல்லைகள் (`pomodoro`, `general`)**: பணிச்சூழல் அளவிலான குறிப்புகள்.
- **அனாதை கண்டறிதல் எஞ்சின்**: தாவல் குழுக்கள் அல்லது டொமைன்கள் நீக்கப்படும் போது, தொடர்புடைய நிலையற்ற குறிப்புகள் அனாதை கண்டறிதல் மூலம் பிடிக்கப்படுகின்றன. மீண்டும் ஒதுக்குவதற்கோ அல்லது நீக்குவதற்கோ குறிப்புகள் UI இல் அணுகக்கூடியதாக இருக்கும்.

### 6.4 செயல்படுத்தும் முறைகள் (Invocation Modalities)
- **UI துவக்கிகள்**: குழு அட்டைகள் மற்றும் துணைக் குழு அட்டைகளில் "View Notes" பொத்தான்; பாப்அப் தலைப்பில் "Quick Notes" பொத்தான்; பக்கப் பலகப் பாதை `?view=notes` (`pk`).
- **சூழல் மெனு தூண்டுதல்**: எந்த வலைப்பக்கத்திலும் உரையைத் தேர்ந்தெடுக்கவும் -> வலது கிளிக் -> "Crear Nota desde Selección" (`note-from-selection`). தேர்ந்தெடுக்கப்பட்ட உரையைத் தானாகவே பிரித்தெடுத்து, அருகிலுள்ள `h1`-`h3` தலைப்பைத் தலைப்பாக அமைக்கிறது.
- **Vim குறிப்பு**: `ao` தற்போதைய தேர்விலிருந்து ஒரு குறிப்பை உருவாக்குகிறது.
- **Omnibar**: `lnt:` உடனடி முழு உரை தேடலுடன் குறிப்புகள் உலாவியைத் திறக்கிறது.
- **ஆடியோ வாசிப்பு**: எடிட்டரில் உள்ள TTS பொத்தான் Web Speech API-ஐப் பயன்படுத்தி குறிப்பு உள்ளடக்கத்தை சத்தமாக வாசிக்கிறது.

## 7. பிரிவு 6: மீடியா & கேலரி பார்வை (Ver Galería)

உயர் செயல்திறன் கொண்ட மீடியா பிடிப்பு, சிறுகுறிப்பு மற்றும் ஆப்டிகல் கேரக்டர் ரெகக்னிஷன் (OCR) பைப்லைன்.

### 7.1 பிடிப்பு முறைகள் & பொறியியல் (அனைத்து 7 பிடிப்பு வகைகள்)
ஒற்றை தாவல், குறுக்கு தாவல், செதுக்கப்பட்ட மற்றும் வண்ணத் தட்டு செயல்பாடுகளை உள்ளடக்கிய 7 சிறப்புப் பிடிப்பு முறைகளை நீட்டிப்பு செயல்படுத்துகிறது:
1. **`visible` (தெரியும் காட்சிப்பகுதி பிடிப்பு - `cs`)**:
   - `chrome.tabs.captureVisibleTab` ஐப் பயன்படுத்தி செயலில் உள்ள தாவலின் சரியான பார்வைப்பகுதியைப் படம்பிடிக்கிறது.
   - பிடிப்பை தானாகவே IndexedDB `screenshots` சேமிப்பகத்திற்குச் சேமித்து, பட பிட்மேப்பை நேரடியாக கணினி கிளிப்போர்டுக்கு நகலெடுக்கிறது (`screenshotSavedAndCopied`).
2. **`fullPage` (தடையற்ற முழுப் பக்க உருட்டல் கேன்வாஸ் - `cp`)**:
   - நிரல் ரீதியான பக்க உருட்டலைச் செயல்படுத்துகிறது, மொத்த ஆவண உருட்டல் உயரத்தைக் கணக்கிடுகிறது.
   - காட்சி நடுக்கத்தை அகற்ற ஆரம்பப் பிரிவிற்குப் பிறகு ஸ்க்ரோல்பாரை அடக்குகிறது மற்றும் நிலையான வழிசெலுத்தல் பட்டிகளை மறைக்கிறது.
   - பிட்மேப் துண்டுகளை 30,000px உயரம் வரை உள்ள `OffscreenCanvas` இல் தைக்கிறது (`captureFullPageDataUrl`), பிரேம் பிடிப்புகளுக்கு இடையே Chromium-இணக்கமான 600ms தாமதங்களை செயல்படுத்துகிறது.
3. **`fullPageParts` (தொடர்ச்சியான துண்டாக்கப்பட்ட பகுதிகள் - `cpp` / `cP`)**:
   - உயரமான ஆவணங்களைத் தொடர்ச்சியான தனிப்பட்ட பார்வைப்பகுதி உயர படப் பகுதிகளாகத் துண்டாக்குகிறது (`captureFullPageParts`), பக்க எண்ணிக்கைக்கு 60 எண்ணிடப்பட்ட படத் துண்டுகள் வரை உருவாக்குகிறது.
4. **`area` (ஊடாடும் செவ்வக இழுத்து செதுக்குதல் - `ca`)**:
   - நிகழ்நேர எல்லைப் பெட்டி பரிமாணங்களுடன் கூடிய குறுக்கு நாற்காலி கேன்வாஸை மேலடுக்கி, `area-selector.js` ஐ செலுத்துகிறது.
   - இழுக்கக்கூடிய தேர்வு கைப்பிடிகள், பரிமாண உதவிக்குறிப்பு, உறுதிப்படுத்தல் தூண்டுதல், `Esc` விசை ரத்து மற்றும் பல தாவல் பயிர் வரிசைப்படுத்தல் (`handleCaptureAreaFromShortcut`).
5. **`groupTabs` (செயலில் உள்ள குழு தாவல் உலாவுதல் தொகுதி - `Cs`, `Cp`, `CP`)**:
   - செயலில் உள்ள தாவல் குழுவில் உள்ள ஒவ்வொரு தாவலையும் வரிசையாக மீண்டும் செய்கிறது (`handleCaptureGroupFromShortcut`).
   - தெரியும், முழுப் பக்கம் அல்லது துண்டாக்கப்பட்ட பாகங்கள் பயன்முறையில் தொகுதி பிடிப்பை ஆதரிக்கிறது, அவற்றை ஒரு ஒருங்கிணைந்த தொகுப்பாகத் தொகுக்கிறது.
6. **`omnibarPickedTabs` (தனிப்பயன் பல-தாவல் வரிசைப் பிடிப்பு)**:
   - Omnibar கட்டளைகள் `cs:`, `cp:`, `cpp:`, அல்லது `ca:` (`handleCaptureTabs`) மூலம் தொடங்கப்பட்டது.
   - பயனர் வடிகட்டிய அனைத்து தாவல்களிலும் தொடர்ச்சியான பிடிப்புகளைச் செயல்படுத்துகிறது, நிகழ்நேர முன்னேற்றக் குறிகாட்டிகளை வழங்குகிறது.
7. **`colorPickerCapture` (பின்னணி திரை ஐட்ராப்பர் மாற்று)**:
   - சொந்த `window.EyeDropper` ஆதரவு இல்லாத இயக்க முறைமைகளில் (எ.கா., Linux) துல்லியமான ஹெக்ஸ் ஐட்ராப்பர் உருப்பெருக்கி கருவியை இயக்க பின்னணி திரை பிடிப்பை எடுக்கிறது.

### 7.2 கேலரி பயனர் இடைமுகம் & நிலைத்தன்மை
- **இடைமுகம்**: லைட்பாக்ஸ் ஜூம், பான் மற்றும் சுழற்று கருவிகளுடன் பதிலளிக்கக்கூடிய மேசன்ரி/கிரிட் அமைப்பு.
- **நிலைத்தன்மை (`screenshots` சேமிப்பகம்)**: IndexedDB `Intelligent_Workspace` இல் சேமிக்கப்படுகிறது. பின் செய்யப்படாத பிடிப்புகள் பராமரிப்பின் போது தானாகவே அழிக்கப்படும்; பின் ஐகானைக் கிளிக் செய்வது (`isPersistent = true`) பிடிப்புகளை காலவரையின்றி பாதுகாக்கிறது.

### 7.3 ஏற்றுமதி, உலாவிக்குள்ளான OCR & வெளிப்புற மார்க்அப்
- **ஏற்றுமதி வடிவங்கள் (`captureDownloadFormats`)**:
  - உயர் திறன் வடிவங்கள்: PNG, WebP, AVIF.
  - `pdf.js` வழியாக பல பக்க தொகுக்கப்பட்ட PDF ஆவண ஏற்றுமதி.
- **சாதனத்திலுள்ள WASM OCR**:
  - முன்பே ஏற்றப்பட்ட ஸ்பானிஷ் மற்றும் ஆங்கிலம் (`spa+eng`) மொழி மாதிரிகளைப் பயன்படுத்தும் உலாவிக்குள் Tesseract.js WebWorker.
  - நெட்வொர்க்கில் படத் தரவை அனுப்பாமல் கிளிப்போர்டுக்கு நேரடியாக உரையைப் பிரித்தெடுக்கிறது.
- **நேரடி அனுப்புதல் ஒருங்கிணைப்பு**:
  - பிரித்தெடுக்கப்பட்ட OCR உரை அல்லது பட இணைப்புகளை குறிப்புகள் (`notesStore`) அல்லது Gemini AI தூண்டுதல்களுக்கு (`feature_geminiAttachFiles`) ஒரே கிளிக்கில் மாற்றுதல்.
  - **Excalidraw மார்க்அப்**: ஒரே கிளிக்கில் ஏற்றுமதி செய்வது கைப்பற்றப்பட்ட படங்களை இலவச வரைதல், அம்புக்குறிகள் மற்றும் திசையன் சிறப்பம்சங்களுக்காக நேரடியாக `https://excalidraw.com/` க்கு அனுப்புகிறது.

### 7.4 செயல்படுத்தும் முறைகள் (Invocation Modalities)
- **UI**: குழு அட்டை கேமரா பொத்தான், பாப்அப் விரைவு நடவடிக்கை, பக்கப் பலக கேலரி பாதை `?view=gallery` (`ps`).
- **Vim குறிப்புகள்**: `cs` (தெரியும் பகுதி), `cp` (முழுப் பக்கம்), `cP` (பாகங்கள்), `ca` (பகுதி செதுக்குதல்), `Cs` (குழு தெரியும் பகுதி), `Cp` (குழு முழுப் பக்கம்), `CP` (குழு பாகங்கள்).
- **Omnibar முன்னொட்டுகள்**: `cs:`, `cp:`, `cpp:`, `ca:`, மற்றும் `limg:` (கேலரியை உலாவுதல்).

## 8. பிரிவு 7: Pomodoro & நேரக் கண்காணிப்புத் தொகுப்பு (Pomodoro)

உலாவி தூக்க சுழற்சிகள் முழுவதும் முழுமையான துல்லியத்திற்காக வடிவமைக்கப்பட்ட கவனம் மற்றும் நேரக் கண்காணிப்புத் தொகுப்பு.

### 8.1 நேரக்கட்டுப்பாட்டு எஞ்சின் & பின்னணிக் கட்டமைப்பு
- **பூஜ்ஜிய-விலகல் நேர முத்திரை கணிதம்**: முழுமையான Unix நேர முத்திரைகளுடன் (`startTime`, `pausedAt`) நிலை `chrome.storage.local` இல் நீடிக்கிறது. சேவைப் பணியாளர் பணிநிறுத்தங்கள், உலாவி மறுதொடக்கங்கள் மற்றும் இயக்க முறைமை தூக்க நிலைகள் ஆகியவை பூஜ்ஜிய கடிகார விலகலை ஏற்படுத்துகின்றன.
- **அலாரம் அனுப்புநர்**:
  - `chrome.alarms` (`pomodoroTick` 1s இடைவெளி) மூலம் இயக்கப்படும் உயர் தெளிவுத்திறன் கவுண்டவுன் டிக்கர்.
  - பின்னணி பராமரிப்பு மற்றும் நீண்ட கால இடைவெளி துடைப்புகள் `itg-periodic-tasks` (1 நிமிடம் இடைவெளி) மூலம் நிர்வகிக்கப்படுகிறது.
- **ஆஃப்ஸ்கிரீன் ஆடியோ மணிகள் (`offscreen.html`)**: ஆடியோ மணிகள் `AUDIO_PLAYBACK` காரணத்துடன் உருவாக்கப்பட்ட பிரத்யேக Chrome Offscreen ஆவணம் வழியாக உருவாக்கப்படுகின்றன. நினைவகத்தைப் பாதுகாக்க ஒலி முடிந்த 3.5 வினாடிகளுக்குப் பிறகு தானாகவே மூடப்படும்.

### 8.2 விரிவான 4 நேரப் பயன்முறைகள்
1. **Pomodoro (`pomodoro`)**:
   - வேலை காலம்: 1 முதல் 180 நிமிடங்கள் (இயல்புநிலை: 25 நிமிடம்).
   - குறுகிய இடைவேளை: 1 முதல் 120 நிமிடங்கள் (இயல்புநிலை: 5 நிமிடம்).
   - நீண்ட இடைவேளை: 1 முதல் 180 நிமிடங்கள் (இயல்புநிலை: 15 நிமிடம்).
   - நீண்ட இடைவேளைக்கு முந்தைய சுழற்சிகள்: 1 முதல் 12 சுழற்சிகள் (இயல்புநிலை: 4).
   - இலக்கு சுழற்சி இலக்கு: 1 முதல் 99 சுழற்சிகள் (இயல்புநிலை: 8).
   - தானியங்கி-தொடக்க வேலை, தானியங்கி-தொடக்க இடைவேளைகள் மற்றும் அறிவிப்பு எச்சரிக்கைகள் மாற்றியமைக்கக்கூடியவை.
2. **நிறுத்தக் கடிகாரம் (`cronometro`)**: மடியில் பதிவுசெய்தல் மற்றும் இடைநிறுத்தத்தை நிறுத்துதல் திறன் கொண்ட முற்போக்கான டைமர்.
3. **கவுண்டவுன் (`temporizador`)**: மணிநேரம், நிமிடங்கள் மற்றும் வினாடிகளைக் குறிப்பிடும் தனிப்பயன் கவுண்டவுன் டைமர்.
4. **இலக்கு நேர அலாரம் (`tiempo`)**: எதிர்கால சரியான நேர முத்திரைக்கு அலாரத்தை அமைக்கும் காலண்டர் தேதி தேர்வாளர் மற்றும் கடிகார தேர்வாளர்.

### 8.3 பக்கத்திற்குள்ளான மிதக்கும் டைமர் விட்ஜெட்
- வலைப்பக்கங்களில் நேரடியாக நிகழ்நேர கவுண்டவுன், இடைநிறுத்தம்/மீண்டும் தொடங்குதல் மற்றும் தவிர் பொத்தான்களைக் காண்பிக்கும் இழுக்கக்கூடிய, குறைந்தபட்ச மேலடுக்கு.
- நீட்டிப்பு குழு அல்லது பாப்அப்பிற்கு மாறாமல் கவன அமர்வுகளைக் கண்காணிக்க அனுமதிக்கிறது.

### 8.4 செயலற்ற நிலையில் குழு தானியங்கி-மடங்கல் டைமர்
- 1 நிமிடம் செயலற்ற நிலைக்குப் பிறகு செயலற்ற குழுக்களையும் (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`), 15 நிமிடங்கள் செயலற்ற நிலைக்குப் பிறகு செயலில் உள்ள குழுவையும் (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`) தானாகவே மடக்க கவன நடைமுறைகளுடன் இணைந்து செயல்படுகிறது. 0 முதல் 1440 நிமிடங்கள் வரை மாற்றியமைக்கலாம்.

### 8.5 திட்டக் குறியிடுதல் & மெட்டாடேட்டா
ஒவ்வொரு அமர்வும் வகைப்படுத்தல் மெட்டாடேட்டாவை ஆதரிக்கிறது:
- திட்டப் பெயர் (18 எழுத்துகள் வரை)
- திட்டக் குறிச்சொல் (எ.கா., `#research`, `#dev`)
- திட்டக் கோப்புறை (எ.கா., `/client/project`)

### 8.6 பகுப்பாய்வு எஞ்சின் & 19 KPI அட்டைகள்
முழு டாஷ்போர்டு (`dashboard.html` அல்லது பக்கப் பலகம் `dashboard.html?context=sidepanel`) நகல் நீக்கப்பட்ட அமர்வுகளிலிருந்து (`sessionStarted` மூலம் `dedupeSessions`) 19 முக்கிய செயல்திறன் குறிகாட்டிகளைக் கணக்கிடுகிறது:
1. `focus`: மொத்த கவனக் குவிப்பு நேரம்.
2. `sessions`: முடிக்கப்பட்ட மொத்த அமர்வுகள்.
3. `cycles`: முடிக்கப்பட்ட மொத்த வேலைச் சுழற்சிகள்.
4. `efficiency`: சராசரி திறன் சதவீதம் (`Total Focus / Total Time * 100`).
5. `activeDays`: தனித்துவமான செயலில் உள்ள நாட்களின் எண்ணிக்கை.
6. `break`: மொத்த இடைவேளை காலம்.
7. `interruptions`: கைமுறை இடைநிறுத்தங்கள்/குறுக்கீடுகளின் மொத்த எண்ணிக்கை.
8. `interruptionTime`: இடைநிறுத்தப்பட்ட நிலையில் கழித்த ஒட்டுமொத்த நேரம்.
9. `bestSession`: மிக நீண்ட ஒற்றை தடையில்லா கவன அமர்வு.
10. `avgFocus`: முடிந்த ஒரு சுழற்சிக்கான சராசரி கவனக் காலம்.
11. `totalTime`: வேலை மற்றும் இடைவேளைகளில் கழித்த ஒட்டுமொத்த நேரம்.
12. `workRest`: வேலை காலத்திற்கும் ஓய்வு காலத்திற்கும் உள்ள விகிதம் (`1 : X`).
13. `distractionRate`: கவனக் குவிப்பு மணிநேரத்திற்கான குறுக்கீடுகள்.
14. `bestDay`: வாரத்தின் மிகவும் பயனுள்ள நாள்.
15. `goldenHour`: நாளின் உச்ச கவனக் குவிப்பு மணிநேர இடைவெளி (எ.கா., `10:00 - 11:00`).
16. `projects`: கண்காணிக்கப்பட்ட தனித்துவமான திட்டங்களின் எண்ணிக்கை.
17. `avgIntDuration`: ஒவ்வொரு குறுக்கீட்டின் சராசரி காலம்.
18. `topProject`: அதிக ஒட்டுமொத்த கவன நேரத்தைக் கொண்ட திட்டம்.
19. `focusIntensity`: ஒரு செயலில் உள்ள நாளுக்கான சராசரி கவனக் குவிப்பு மணிநேரம்.

கூடுதல் காட்சிப் பகுப்பாய்வுகளில் நாள் தொடர் வெப்ப வரைபட காலண்டர் (Day Streak Heatmap), மணிநேர கவன விநியோகப் பட்டை விளக்கப்படம், திட்ட வகை முறிவு மற்றும் முழு JSON தரவு இறக்குமதி/ஏற்றுமதி ஆகியவை அடங்கும்.

## 9. பிரிவு 8: செயல்பாடு & வரலாறு குழு (Panel de Actividad)

Declarative Net Request (DNR) கண்காணிப்பு, பகுப்பாய்வு மற்றும் இணைய ஆளுமை எஞ்சின்.

### 9.1 தரவு எஞ்சின் & சேமிப்பக இடவியல் (`ITG_WEB_ACTIVITY`)
`ITG_WEB_ACTIVITY` இன் கீழ் நிர்வகிக்கப்படுகிறது:
- `wa:day:YYYY-MM-DD`: ஒரு நாளைக்கான டொமைன் கவுண்டர்கள் (`{ domains: { host: { t: seconds, v: visits, s: sessions, h: { hour: seconds } } } }`).
- `wa:days`: பதிவுசெய்யப்பட்ட தேதி விசைகளின் முதன்மை குறியீட்டு வரிசை.
- `wa:recent`: சமீபத்திய 400 வருகை காலவரிசை உள்ளீடுகளைச் சேமிக்கும் ரிங் பஃபர்.
- `wa:openSegment`: `chrome.storage.session` இல் செயலில் உள்ள நேரப் பிரிவு, செயலற்ற நிகழ்வுகள் இல்லாமல் இயந்திரம் தூங்கினால் புள்ளிவிவரங்கள் சிதைவதைத் தடுக்க `WA_MAX_SEGMENT_SECONDS = 900s` (15 நிமிடங்கள்) என உச்சவரம்பு வைக்கப்பட்டுள்ளது.
- **செயலற்ற நிலைக் கண்டறிதல்**: `chrome.idle` ஐப் பயன்படுத்துகிறது (இயல்புநிலை: 300s / 5m). `countAudible = true` எனில் சாளரங்கள் கவனம் செலுத்தப்படாத போதும் ஆடியோ பிளேபேக் செயலில் உள்ள கண்காணிப்பைப் பாதுகாக்கிறது.
- **வைத்திருத்தல் (Retention)**: `retentionDays` (இயல்புநிலை: 180 நாட்கள்) விட பழைய நாள் பதிவுகளைத் தானாகவே நீக்குகிறது.

### 9.2 Declarative Net Request (DNR) தளத் தடுப்பான்
- **டைனமிக் விதி ஒதுக்கீடு**: `9000` முதல் `9999` வரையிலான ஐடி வரம்பில் டைனமிக் விதிகளை ஒதுக்குகிறது.
- **மறுதிசைவு இலக்கு**: தடுக்கப்பட்ட கோரிக்கைகள் `src/ui/pages/web-activity/blocked.html?d=<domain>&u=\1` க்கு திருப்பி விடப்படும்.
- **திறந்த தாவல் துடைப்பு**: ஒரு தள வரம்பு காலாவதியாகும்போது, பின்னணிப் பணியாளர் உடனடியாக டொமைனுடன் பொருந்தக்கூடிய திறந்திருக்கும் தாவல்களைத் துடைத்துத் திருப்பி விடுகிறார்.
- **இரவு நேர அட்டவணை இடைவெளி**: நள்ளிரவைத் தாண்டிய அட்டவணைகள் (எ.கா., `22:00` முதல் `02:00` வரை) தானாகவே நாள் எல்லைகளில் மதிப்பிடப்படும்.
- **சலுகை / உறக்கநிலை காலம் (+5 நிமிடம்)**: தடுப்புத் திரை தற்காலிக 5 நிமிட உறக்கநிலைக் கடந்துசெல்லலை அனுமதிக்கிறது, இது `wa:snoozeUses` இல் கண்காணிக்கப்படுகிறது.

### 9.3 சமச்சீரற்ற பாதுகாப்புப் பூட்டு (`blockLock.js`)
தள வரம்புகளை சமச்சீரற்ற கடவுச்சொல் பூட்டு மூலம் பாதுகாக்கலாம்:
- **ஹாஷ் சேமிப்பகம்**: சீரற்ற 16-பைட் உப்பு மற்றும் SHA-256 ஹெக்ஸ் டைஜெஸ்ட்டைச் சேமிக்கிறது (`wa:settings.blockPassword`).
- **சமச்சீரற்ற விதிக் கொள்கை**: புதிய வரம்புகளை உருவாக்கும் போது அல்லது விதிகளை மிகவும் கடுமையானதாக மாற்றும்போது (எ.கா., நேரக் கொடுப்பனவுகளைக் குறைப்பது அல்லது அட்டவணை கட்டுப்பாடுகளைச் சேர்ப்பது) கடவுச்சொல் **ஒருபோதும் கோரப்படாது**.
- **பாதுகாக்கப்பட்ட செயல்கள்**: **விதிகளை தளர்த்தும்போது** (வரம்பை நீக்குதல், நேரக் கொடுப்பனவுகளை அதிகரிப்பது அல்லது அட்டவணைகளை முடக்குவது) அல்லது தினசரி இலவச வரம்பைத் தாண்டிய பிறகு உறக்கநிலையை இயக்கும்போது மட்டுமே கடவுச்சொல் கோரப்படும் (`snoozePasswordAfter`).

### 9.4 வகைப்படுத்தல் & காட்சிப் பகுப்பாய்வு
- **16 உள்ளமைக்கப்பட்ட பிரிவுகள்**: `social`, `video`, `music`, `news`, `shopping`, `reading`, `entertainment`, `dev`, `work`, `education`, `games`, `finance`, `mail`, `ai`, `search`, `other`.
- **தனிப்பயன் பிரிவுகள்**: `custom:` உடன் முன்னொட்டு வைக்கப்பட்ட பயனர் வரையறுத்த பிரிவுகளை ஆதரிக்கிறது.
- **கவன விகிதம் (Focus Ratio)**: உற்பத்திப் பிரிவுகளை (`dev`, `work`, `education`, `reading`, `finance`, `mail`) கவனச்சிதறல் பிரிவுகளுடன் (`social`, `video`, `games`, `shopping`, `entertainment`) வேறுபடுத்துகிறது.
- **காட்சிகள்**: Chart.js மணிநேர செயல்பாட்டு விநியோகங்கள், வகை டோனட் முறிவு மற்றும் டொமைன் தரவரிசைப் பட்டியல்கள்.

### 9.5 பதிவிறக்கங்கள் மேலாளர் துணை அமைப்பு (`switchMainView('downloads')`)
- **பிரத்யேகப் பாதை**: `switchMainView('downloads')` (`?view=downloads`) வழியாக பக்கப் பலகத்தில் அணுகப்படுகிறது.
- **நேரடி Chrome API ஒருங்கிணைப்பு**: நிகழ்நேரத்தில் அனைத்து உலாவிப் பதிவிறக்கங்களையும் கண்காணிக்க, நிர்வகிக்க மற்றும் ஆய்வு செய்ய `chrome.downloads` ஐ இணைக்கிறது.
- **நிகழ்நேர தெளிவற்ற தேடல்**: கோப்பு பெயர், கோப்பு பாதை அல்லது பதிவிறக்க மூல URL மூலம் உடனடி தேடல்.
- **நிலை வடிகட்டி சில்லுகள்**: பதிவிறக்கங்களை நிலை வாரியாக விரைவாக வடிகட்டவும்: `All`, `In Progress`, `Complete`, `Paused`, மற்றும் `Interrupted`.
- **காலண்டர் தேதி வரம்பு வடிகட்டுதல்**: குறிப்பிட்ட தேதிகள் அல்லது நேர இடைவெளிகள் மூலம் பதிவிறக்கங்களைச் சுருக்கவும்.
- **தொகுதி குழு பதிவிறக்கி**: செயலில் உள்ள குழுவில் திறந்திருக்கும் தாவல்களிலிருந்து அனைத்து பதிவிறக்க இணைப்புகளையும் பிரித்தெடுத்து, முன்னேற்றக் கண்காணிப்புடன் ஒத்திசைக்கப்பட்ட தொகுதிப் பதிவிறக்கங்களைத் தொடங்குகிறது.
- **கோப்பு மேலாண்மை**: ஒரே கிளிக்கில் நேரடி கோப்பு திறப்பு (`chrome.downloads.open`) மற்றும் கோப்புறை வெளிப்படுத்தல் (`chrome.downloads.show`).

### 9.6 சமீபத்தில் மூடப்பட்ட தாவல்கள் & உலாவல் வரலாறு துணை அமைப்பு
- **சமீபத்தில் மூடப்பட்ட தாவல்கள் பார்வை**:
  - `chrome.sessions.getRecentlyClosed` உடன் நேரடியாக ஒருங்கிணைக்கப்பட்டது.
  - தானியங்கி உச்சரிப்பு மடிப்புடன் நிகழ்நேர தேடல் (`deaccent`).
  - ஒற்றை தாவல் மீட்டமைப்பு மற்றும் முழு சாளர அமர்வு மீட்டமைப்பு ஒரே கிளிக்கில் அல்லது Omnibar கட்டளை `c:` மூலம்.
- **உலாவல் வரலாறு பார்வை**:
  - தேவையற்ற `chrome.history.search` வினவல் சலசலப்பை அகற்ற 10-வினாடி TTL நினைவக கேச்சிங்குடன் ஆழமான தேடல்.
  - டொமைன், முக்கிய சொல் மற்றும் காலண்டர் தேதி வரம்புகள் மூலம் வடிகட்டக்கூடிய தேடல்.
  - ஏற்கனவே திறந்திருந்தால் ஒரே கிளிக்கில் தாவலை செயல்படுத்துதல், அல்லது புதிய தாவல் உருவாக்கம், Omnibar `h:` வழியாக அணுகலாம்.

### 9.7 தீம் திட்டமிடல் துணை அமைப்பு (`ThemeScheduleModal.svelte`)
- **தானியங்கி தீம் திட்டமிடல்**:
  - தீம்கள் பக்கப் பலகப் பார்வைக்குள் (`?view=themes` / `pt`) `ThemeScheduleModal.svelte` வழியாக நிர்வகிக்கப்படுகிறது.
  - நாளின் நேரம் (`HH:MM`) மற்றும் வாரத்தின் செயலில் உள்ள நாட்களின் (`[0..6]`) அடிப்படையில் தானியங்கி தீம் மாறுதலை ஆதரிக்கிறது.
  - அதிகபட்சமாக 7 உலகளாவிய தீம் அட்டவணைகள் (`MAX_GLOBAL_SCHEDULES = 7`).
  - **தானாக மீட்டமைத்தல்**: குறிப்பிட்ட நிறைவு நேரங்களில் தானாகவே இயல்புநிலை பகல்நேர அல்லது பணியிட தீம்களுக்குத் திரும்புகிறது.
  - **டெஸ்க்டாப் எச்சரிக்கைகள்**: தானியங்கி தீம் மாற்றங்கள் நிகழும்போது டெஸ்க்டாப் அறிவிப்புகளை வெளியிடுகிறது (`chrome.notifications`).
  - **இரட்டை நிலைத்தன்மை**: `chrome.storage.sync` (ரோமிங் விருப்பத்தேர்வுகள்) மற்றும் `chrome.storage.local` இல் `savedThemes` மற்றும் `themeSchedules` ஆகியவற்றின் கீழ் சேமிக்கப்படுகிறது.

### 9.8 சுருக்கமான பக்கப் பலகப் பார்வை (Compact Sidepanel View)
- **பக்கப் பலகப் பாதை (`?view=activity` / `pw`)**: நிகழ்நேர கண்காணிப்புக்கு உகந்ததாக 350px நெடுவரிசை, கால தேர்வாளர் சில்லுகள் (`Today`, `7d`, `30d`, `All`) மற்றும் டொமைன் வரம்பு முன்னேற்றப் பட்டிகளைக் கொண்டுள்ளது.

## 10. பல-முறைமை செயல்படுத்தல் மேட்ரிக்ஸ் (Multi-Modal Invocation Matrix)

### 10.1 பாப்அப் பயனர் இடைமுகம்
- **விதிகள் தாவல்**: விரைவு விதி நிலைமாற்றிகள், செயலில் உள்ள நிலை குறிகாட்டிகள் மற்றும் விதி URL துவக்கி.
- **குழுக்கள் தாவல்**: தாவல் மாறுதல் மற்றும் குழு துப்புரவுடன் கூடிய சுருக்கமான அக்கார்டியன் பட்டியல்.
- **AI துவக்கி**: பக்கப் பலகத்திற்கு வினவல்களை வழிநடத்தும் நேரடி அரட்டை உள்ளீட்டுப் பெட்டி.
- **விரைவு செயல்கள் கருவிப்பட்டி**: பகுதி ஸ்கிரீன்ஷாட், முழுப் பக்க பிடிப்பு, விரைவுக் குறிப்புகள், Pomodoro தொடக்கம்/இடைநிறுத்தம் மற்றும் பக்கப் பலக விரிவாக்கம் ஆகியவற்றிற்கான ஒரே கிளிக்கில் பொத்தான்கள்.

### 10.2 பக்கப் பலக வழிசெலுத்தல் பாதைகள் (`?view=...`)
- `?view=rules` — விரிவான விதிகள் மேலாளர் மற்றும் URL வடிவமைப்பு எடிட்டர் (`pg`).
- `?view=listgroup` — இழுத்துப் போடும் மறுவரிசைப்படுத்தலுடன் கூடிய முழு குழு மற்றும் தாவல் பணிச்சூழல் (`pl`).
- `?view=notes` — குறிப்புகள் பணிச்சூழல் (Text, Checklist, Kanban, Mermaid, KaTeX) (`pk`).
- `?view=gallery` — ஸ்கிரீன்ஷாட் கேலரி, OCR, மற்றும் Excalidraw கருவிகள் (`ps`).
- `?view=gemini` — மல்டிமாடல் AI உதவியாளர் மற்றும் தன்னாட்சி ஏஜென்ட் இடைமுகம் (`pa`).
- `?view=activity` — வலை செயல்பாட்டுக் கண்காணிப்பாளர், வரம்புகள் மற்றும் வகை அளவீடுகள் (`pw`).
- `?view=themes` — தீம் எடிட்டர் மற்றும் தானியங்கு திட்டமிடல் தட்டு (`pt`).
- `?view=hints` — Vim குறுக்குவழிகள், Omnibar மற்றும் YouTube லூப் அமைப்புகள் (`pn`).
- `?view=downloads` — பதிவிறக்கங்கள் மேலாளர் மற்றும் தொகுதி இணைப்பு பதிவிறக்கி (`switchMainView('downloads')`).

### 10.3 Manifest விசைப்பலகை குறுக்குவழிகள் (24 கட்டளைகள்)
1. `toggle-current-group` (`Ctrl+Shift+Z` / Mac `Command+Shift+Z`): செயலில் உள்ள குழுவின் மடிப்பை மாற்றவும்.
2. `toggle-all-groups` (`Ctrl+Shift+Q` / Mac `Command+Shift+Q`): அனைத்து குழுக்களின் மடிப்பை மாற்றவும்.
3. `toggle-sort-alpha` (`Ctrl+Shift+S` / Mac `Command+Shift+S`): அகரவரிசை குழு வரிசையாக்கத்தை மாற்றவும்.
4. `open-popup` (`Alt+Shift+P`): பாப்அப்பைத் திறக்கவும் அல்லது பக்கப் பலகத்தில் கவனம் செலுத்தவும்.
5. `toggle-collapse-timer`: குழு தானியங்கி-மடங்கல் டைமரை மாற்றவும்.
6. `toggle-all-rules`: அனைத்து தனிப்பயன் விதிகளுக்கான முதன்மை நிலைமாற்றி (`Alt+M`).
7. `toggle-expand-all`: பணிச்சூழலில் உள்ள அனைத்து குழுக்களையும் விரிவாக்கவும்.
8. `rules-manager`: ஒரு பிரத்யேக தாவலில் விதிகள் மேலாளரைத் திறக்கவும் (`Alt+R`).
9. `toggle-prefixes`: காட்சி குழு முன்னொட்டு குறிகாட்டிகளை மாற்றவும் (`🔒`, `🔍`, `🗝️`, `⚠️`).
10. `toggle-domain-grouping`: தானியங்கி டொமைன் கிளஸ்டரிங்கை மாற்றவும்.
11. `toggle-subdomain-grouping`: தானியங்கி துணை டொமைன் கிளஸ்டரிங்கை மாற்றவும்.
12. `toggle-compact-mode`: சுருக்கமான ஒற்றை எழுத்து குழு தலைப்புகளை மாற்றவும்.
13. `toggle-chrome-grouping`: சிறப்பு Chrome உள் பக்கங்கள் குழுவை மாற்றவும்.
14. `toggle-files-grouping`: சிறப்பு உள்ளூர் `file://` பக்கங்கள் குழுவை மாற்றவும்.
15. `toggle-extensions-grouping`: சிறப்பு `chrome-extension://` குழுவை மாற்றவும்.
16. `toggle-misc-grouping`: கிளஸ்டர் செய்யப்படாத இதர குழுவை மாற்றவும்.
17. `toggle-ip-address-grouping`: IP முகவரி / localhost குழுவை மாற்றவும்.
18. `toggle-clustering`: அனைத்து தானியங்கி கிளஸ்டரிங்கிற்குமான முதன்மை நிலைமாற்றி.
19. `regroup-all-tabs`: விரிவான தாவல் மறுசீரமைப்பு பாஸைத் தூண்டவும் (`Alt+Shift+R`).
20. `toggle-hints`: பக்கத்திற்குள்ளான Vim குறிப்புகள் மேலடுக்கு எஞ்சினை மாற்றவும்.
21. `open-side-panel`: நீட்டிப்பு பக்கப் பலகத்தைத் திறக்கவும்.
22. `open-theme-selector`: தீம் தனிப்பயனாக்குதல் பேனலைத் திறக்கவும்.
23. `remove-duplicate-tabs`: சாளரம் முழுவதும் நகல் தாவல்களை சுத்தம் செய்யவும்.
24. `open-list-group-sidepanel-command`: பக்கப் பலகத்தில் குழு பட்டியல் பார்வையைத் திறக்கவும்.

### 10.4 பக்கத்திற்குள்ளான Vim குறிப்பு விசைகள் (40+ சேர்க்கைகள்)
- **உருட்டுதல் & நகர்வு**:
  - `j` / `k`: கீழே / மேலே உருட்டவும் (75px படி).
  - `d` / `u`: பக்கத்தின் கீழே / மேலே உருட்டவும்.
  - `h` / `l`: இடது / வலதுபுறமாக உருட்டவும் (அல்லது பக்கத்தை உருட்ட முடியாவிட்டால் முந்தைய / அடுத்த தாவலுக்கு மாறவும்).
  - `H` / `L`: உலாவி வரலாற்றில் பின்னோக்கி / முன்னோக்கி செல்லவும்.
  - `esc`: செயலில் உள்ள உள்ளீட்டை மங்கலாக்குங்கள், கூறுகளின் கவனத்தை நீக்குங்கள்.
- **தாவல் & சாளர மேலாண்மை**:
  - `t`: புதிய தாவலைத் திறக்கவும்.
  - `x`: தற்போதைய தாவலை மூடவும்.
  - `yt`: தற்போதைய தாவலை நகலெடுக்கவும்.
  - `s`: முந்தைய செயலில் உள்ள தாவலுக்கு மாறவும்.
  - `ts`: அருகருகே திரை பிரிப்பு சாளரத்தை மாற்றவும்.
  - `we`: தனித்த பாப்அப் சாளரத்தில் செயலில் உள்ள தாவலைத் திறக்கவும்.
  - `wp`: ஆவண பிக்சர்-இன்-பிக்சரில் செயலில் உள்ள தாவலைத் திறக்கவும்.
  - `wv`: தனிப்பயன் வீடியோ பிக்சர்-இன்-பிக்சரில் செயலில் உள்ள வீடியோவைத் திறக்கவும்.
  - `dg`: தற்போதைய தாவல் குழுவை மூடவும்/நீக்கவும்.
- **இணைப்பு குறிப்புகள் & தொடர்பு**:
  - `f`: Vim இணைப்பு குறிப்புகளை இயக்கவும் (கூறை கிளிக் செய்யவும்).
  - `cf`: இணைப்பு URL-ஐ நகலெடுக்க Vim இணைப்பு குறிப்புகளை இயக்கவும்.
  - `i`: பக்கத்தின் முதல் உரை உள்ளீட்டில் கவனம் செலுத்தவும்.
  - `c`: தற்போதைய URL-ஐ கிளிப்போர்டுக்கு நகலெடுக்கவும்.
  - `y`: தற்போதைய தேர்வை கிளிப்போர்டு இடையகத்தில் சேர்க்கவும்.
  - `vs`: பக்க மூலத்தைக் காண்க (`view-source:`).
  - `vp`: இணைப்பு முன்னோட்ட மாதிரியை மாற்றவும்.
  - `as` / `ah`: உருட்டலில் / தாவல் மறைப்பில் தானியங்கி-PiP ஐ மாற்றவும்.
  - `ar`: Text-to-Speech சத்தமாக வாசிப்பதை மாற்றவும்.
  - `ao`: தேர்விலிருந்து குறிப்பை உருவாக்கவும்.
  - `at`: பக்கத்தை மொழிபெயர்க்கவும்.
- **பக்கப் பலக நேரடி அணுகல்**:
  - `ph`: முதன்மை பக்கப் பலகப் பார்வையைத் திறக்கவும்.
  - `pt`: தீம்கள் பக்கப் பலகத்தைத் திறக்கவும்.
  - `pl`: குழு பட்டியல் பக்கப் பலகத்தைத் திறக்கவும்.
  - `pk`: குறிப்புகள் பக்கப் பலகத்தைத் திறக்கவும்.
  - `ps`: ஸ்கிரீன்ஷாட் கேலரி பக்கப் பலகத்தைத் திறக்கவும்.
  - `pa`: AI உதவியாளர் பக்கப் பலகத்தைத் திறக்கவும்.
  - `pw`: வலை செயல்பாடு பக்கப் பலகத்தைத் திறக்கவும்.
  - `pg`: விதிகள் பக்கப் பலகத்தைத் திறக்கவும்.
  - `pn`: குறிப்புகள் தனிப்பயனாக்குதல் பக்கப் பலகத்தைத் திறக்கவும்.
- **மீடியா பிடிப்பு**:
  - `cs`: தெரியும் பார்வைப்பகுதியைப் படம்பிடிக்கவும்.
  - `cp`: முழுப் பக்கத்தைப் படம்பிடிக்கவும் (தைக்கப்பட்டது).
  - `cP`: தொடர்ச்சியான பாகங்களாக முழுப் பக்கத்தைப் படம்பிடிக்கவும்.
  - `ca`: செதுக்கப்பட்ட பகுதியை படம்பிடிக்கவும்.
  - `Cs`: குழுவில் உள்ள அனைத்து தாவல்களையும் படம்பிடிக்கவும் (தெரியும் பகுதி).
  - `Cp`: குழுவில் உள்ள அனைத்து தாவல்களையும் படம்பிடிக்கவும் (முழுப் பக்கம்).
  - `CP`: குழுவில் உள்ள அனைத்து தாவல்களையும் படம்பிடிக்கவும் (பாகங்கள்).
- **ஆடியோ & வாசிப்பு முறைகள்**:
  - `st`: தற்போதைய தாவலில் மியூட் மாற்றவும்.
  - `so`: கேட்கக்கூடிய அனைத்து தாவல்களையும் மியூட் செய்யவும்.
  - `mb` / `mB`: கருப்பு பக்க முறை (தாவல் / உலகளாவிய).
  - `ms` / `mS`: செபியா பக்க முறை (தாவல் / உலகளாவிய).
  - `mp` / `mP`: காகித பக்க முறை (தாவல் / உலகளாவிய).
  - `ml` / `mL`: வெளிச்ச பக்க முறை (தாவல் / உலகளாவிய).
  - `me` / `mE`: தனிப்பயன் CSS வடிகட்டி முறை (தாவல் / உலகளாவிய).
- **Text-to-Speech (சத்தமாக வாசித்தல்) ரீடர் வழிசெலுத்தல்**:
  - `zp`: பேச்சு தொகுப்பு ரீடர் மேலடுக்கை இயக்கு / இடைநிறுத்து.
  - `zn`: சத்தமாக வாசிக்கும் அமர்வில் அடுத்த வாக்கியம்.
  - `zb`: சத்தமாக வாசிக்கும் அமர்வில் முந்தைய வாக்கியம்.
  - `zq`: சத்தமாக வாசிக்கும் பேச்சு மேலடுக்கை மூடு / நிறுத்து.
- **குழு காப்புநகல்கள் & விதிகள்**:
  - `bg`: அனைத்து குழுக்களையும் IndexedDB-க்கு காப்புப் பிரதி எடுக்கவும்.
  - `br`: IndexedDB-யிலிருந்து அனைத்து குழுக்களையும் மீட்டெடுக்கவும்.
  - `cr`: தற்போதைய பக்கத்திலிருந்து தனிப்பயன் விதியை உருவாக்கவும்.
  - `ae`: ஏற்கனவே உள்ள விதியில் தற்போதைய பக்கத்தைச் சேர்க்கவும்.
- **விரைவு URL துவக்கிகள்**:
  - `gy`: YouTube, `gm`: Gmail, `gp`: Google Maps, `gx`: X (Twitter), `gi`: Instagram, `gu`: Udemy, `gc`: ChatGPT, `gg`: Gemini.

### 10.5 பக்கத்திற்குள்ளான Omnibar துணை அமைப்பு முன்னொட்டுகள் (41 முன்னொட்டுகள்)
மிதக்கும் Omnibar-ஐத் திறக்க எந்தப் பக்கத்திலும் `o` எனத் தட்டச்சு செய்யவும். கிடைக்கக்கூடிய அனைத்து கட்டளைகளையும் காண `@` எனத் தட்டச்சு செய்யவும்:
1. `we:` — தேர்ந்தெடுக்கப்பட்ட தாவலை தனித்த பாப்அப் சாளரமாகத் திறக்கவும்.
2. `wp:` — தேர்ந்தெடுக்கப்பட்ட தாவலை ஆவண பிக்சர்-இன்-பிக்சராகத் திறக்கவும்.
3. `wv:` — தேர்ந்தெடுக்கப்பட்ட தாவலை வீடியோ பிக்சர்-இன்-பிக்சராகத் திறக்கவும்.
4. `sp:` — URL, தேடல் அல்லது தாவலை பக்கப் பலகத்தில் திறக்கவும்.
5. `ar:` — ஒரு தாவலைத் தேர்ந்தெடுத்து அதன் உரையை TTS வழியாக சத்தமாகப் படிக்கவும்.
6. `b:` — உலாவி புக்மார்க்குகளில் முழு உரைத் தேடல் செய்யவும்.
7. `h:` — உலாவல் வரலாற்றைத் தேடவும்.
8. `c:` — சமீபத்தில் மூடப்பட்ட தாவல்களை உலாவவும் மீண்டும் திறக்கவும்.
9. `dg:` — தாவல் குழுக்களைத் தேடி நீக்கவும் அல்லது மாறவும்.
10. `dt:` — பல தாவல்களைத் தேடி மூடவும்.
11. `ts:` — தாவல்களைத் தேர்ந்தெடுத்து அருகருகே திரை பிரிப்பில் தொடங்கவும்.
12. `cs:` — தேர்ந்தெடுக்கப்பட்ட தாவல்களின் தெரியும் பகுதியைப் படம்பிடிக்கவும்.
13. `cp:` — தேர்ந்தெடுக்கப்பட்ட தாவல்களின் முழுப் பக்கத்தையும் படம்பிடிக்கவும்.
14. `cpp:` — தேர்ந்தெடுக்கப்பட்ட தாவல்களின் முழுப் பக்கத்தையும் தொடர்ச்சியான பாகங்களாகப் படம்பிடிக்கவும்.
15. `ca:` — தேர்ந்தெடுக்கப்பட்ட தாவல்களில் தனிப்பயன் செதுக்கப்பட்ட பகுதியை படம்பிடிக்கவும்.
16. `bg:` — தாவல் குழுக்களை உடனடியாக IndexedDB-க்கு காப்புப் பிரதி எடுக்கவும்.
17. `bgr:` — காப்புப் பிரதி எடுக்கப்பட்ட குழுக்கள் மற்றும் தாவல்களைத் தேடி மீட்டெடுக்கவும்.
18. `f:` — திறந்திருக்கும் அனைத்து தாவல்களிலும் ஆழமான முழு உரைத் தேடல் செய்யவும்.
19. `qai:` — கட்டமைக்கப்பட்ட AI மாதிரியிடம் நேரடியாக வினவல் கேட்கவும்.
20. `qaia:` — செயல்களைச் செய்ய தன்னாட்சி AI ஏஜென்டிற்கு அறிவுறுத்தவும்.
21. `lai:` — கடந்த கால AI உரையாடல் வரலாற்றை உலாவவும்.
22. `laiq:` — AI செய்திகளுக்குள் தேடவும்.
23. `limg:` — கைப்பற்றப்பட்ட ஸ்கிரீன்ஷாட்கள் மற்றும் கேலரி படங்களை உலாவவும்.
24. `lnt:` — சேமிக்கப்பட்ட குறிப்புகளைத் தேடவும் பார்க்கவும்.
25. `atcr:` — ஏற்கனவே உள்ள தனிப்பயன் விதியில் செயலில் உள்ள தாவல் URL-ஐச் சேர்க்கவும்.
26. `atr:` — ஏற்கனவே உள்ள விதியில் திறந்த தாவல்கள் அல்லது கைமுறை URL-களைச் சேர்க்கவும்.
27. `rl:` — விதிகளைத் தேடி தொடர்புடைய URL-களைத் தொடங்கவும்.
28. `cr:` — புதிய விதியை உருவாக்கவும் (`cr: name` அல்லது `cr: name, url1, url2`).
29. `ccr:` — தனிப்பயன் விதியின் நிறத்தை மாற்றவும்.
30. `ccg:` — செயலில் உள்ள தாவல் குழுவின் நிறத்தை மாற்றவும்.
31. `dr:` — விதிகளிலிருந்து விதிகள் அல்லது தனிப்பட்ட URL-களை நீக்கவும்.
32. `er:` — ஏற்கனவே உள்ள விதியை மறுபெயரிடவும் அல்லது திருத்தவும்.
33. `st:` — Omnibar ஊடாடும் பயிற்சியைத் திறக்கவும்.
34. `g:` — Google-இல் தேடவும் (`g: <query>`).
35. `y:` — YouTube-இல் தேடவும் (`y: <query>`).
36. `d:` — DuckDuckGo-இல் தேடவும் (`d: <query>`).
37. `w:` — Wikipedia-இல் தேடவும் (`w: <query>`).
38. `gm:` — Google Maps-இல் தேடவும் (`gm: <query>`).
39. `x:` — X / Twitter-இல் தேடவும் (`x: <query>`).
40. `am:` — Amazon-இல் தேடவும் (`am: <query>`).
41. `ams:` — Amazon Spain-இல் தேடவும் (`ams: <query>`).

### 10.6 சூழல் மெனு படிநிலை மரம் (அனைத்து 5 குழுக்கள் & 30+ செயல்கள்)
சூழல் மெனுவானது 5 செயல்பாட்டுக் கட்டளைக் குழுக்களாக ஒழுங்கமைக்கப்பட்ட முழுமையான படிநிலை மரத்தை வழங்குகிறது:
1. **குழு 1: விதிகள் & URL துணைமெனு**:
   - முதன்மை விதிகள் தேர்வுப்பெட்டி நிலைமாற்றி ("Activar/Desactivar Todas las Reglas").
   - தனிப்பயன் விதிகளை உடனுக்குடன் இயக்க அல்லது முடக்குவதற்கான விதி வாரியான நிலைமாற்றிகள்.
   - "Abrir Todas las URLs": தேர்ந்தெடுக்கப்பட்ட விதியில் பதிவுசெய்யப்பட்ட அனைத்து இலக்கு URL-களையும் திறக்கிறது.
   - மாறும் திறந்த தாவல் எண்ணிக்கைகளுடன் `[N]` தனிப்பட்ட URL துணைமெனுக்கள்: URL உடன் பொருந்தக்கூடிய தற்போது திறந்திருக்கும் தாவல் எண்ணிக்கையைக் காட்டுகிறது, URL-க்கு ஒரே கிளிக்கில் வழிசெலுத்தலை வழங்குகிறது, மற்றும் பொருந்தும் அனைத்து தாவல்களையும் முடிக்க "Cerrar Pestañas para esta URL" ஐ வழங்குகிறது.
   - விரைவு விதி உருவாக்கம்: "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa".
   - ஏற்கனவே உள்ள விதியில் சேர்த்தல்: "Añadir a Regla Existente" -> விதியைத் தேர்ந்தெடுக்கவும் -> "Añadir Raíz del Sitio" / "Añadir URL Completa".
2. **குழு 2: தாவல் சுத்தம் & ஆடியோ கட்டுப்பாடுகள்**:
   - "Eliminar Pestañas Duplicadas [N]": கண்டறியப்பட்ட தேவையற்ற தாவல்களின் எண்ணிக்கையைக் காட்டுகிறது மற்றும் சாளரங்கள் முழுவதும் அவற்றை மூடுகிறது.
   - "Eliminar Pestañas por Dominio": திறந்த தாவல் எண்ணிக்கைகளுடன் `[N]` அனைத்து டொமைன்களையும் பட்டியலிடும் மாறும் துணைமெனு, டொமைன் வாரியாக துல்லியமான தாவல் மூடுதலை அனுமதிக்கிறது.
   - "Cerrar Todos Excepto el Grupo Activo": செயலில் கவனம் செலுத்தப்பட்ட குழுவைத் தக்கவைத்து மற்ற அனைத்து குழுக்களையும் மூடுகிறது.
   - "Reagrupar Todas las Pestañas": திறந்திருக்கும் அனைத்து தாவல்களிலும் முழு பின்னணி மறுசீரமைப்பு பாஸைத் தூண்டுகிறது.
   - "Silenciar Todas las Pestañas" / "Reactivar Sonido en Todas las Pestañas": உலகளாவிய ஆடியோ மியூட் மற்றும் அன்மியூட் கட்டுப்பாடுகள்.
3. **குழு 3: வாசிப்பு, தேர்வு & குறிப்புகள்**:
   - "Leer Página en Voz Alta" (TTS): மேலடுக்கு கட்டுப்பாடுகளுடன் கூடிய முழு பக்க உரையிலிருந்து பேச்சுக்கு ரீடர்.
   - "Leer Selección en Voz Alta": பேச்சுத் தொகுப்பைப் பயன்படுத்தி சிறப்பித்துக் காட்டப்பட்ட DOM தேர்வை சத்தமாகப் படிக்கிறது.
   - "Crear Nota desde Selección": உரைத் தேர்வைப் பிரித்தெடுக்கிறது, தானாகவே அருகிலுள்ள தலைப்பிலிருந்து (`h1`-`h3`) குறிப்பு தலைப்பைப் பெறுகிறது, மேலும் அதை `notesStore` இல் சேமிக்கிறது.
4. **குழு 4: நீட்டிப்பு, PiP & பேனல்களைத் திற**:
   - "Abrir como PiP" / "Abrir como Ventana Emergente": இலக்குப் பக்கம், சிறப்பித்துக் காட்டப்பட்ட தேர்வு அல்லது இலக்குப் படத்தை மிதக்கும் பிக்சர்-இன்-பிக்சர் அல்லது தனித்த பாப்அப் சாளரத்தில் தொடங்கவும்.
   - "Abrir Extensión": நீட்டிப்பு பாப்அப்பைத் திறக்கிறது அல்லது பக்கப் பலகத்தை விரிவுபடுத்துகிறது.
   - "Gestionar Reglas": ஒரு பிரத்யேக உலாவி தாவலில் முழு விதிகள் மேலாளரைத் திறக்கிறது.
   - நேரடி பக்கப் பலக துவக்கிகள்: குழு பட்டியல் (`?view=listgroup`), தீம்கள் (`?view=themes`), AI உதவியாளர் (`?view=gemini`), மற்றும் குறிப்புகள் தனிப்பயனாக்குதல் (`?view=hints`) ஆகியவற்றிற்கு ஒரே கிளிக்கில் வழிசெலுத்துதல்.
5. **குழு 5: அமைப்புகள் & கிளஸ்டரிங் விருப்பங்கள்**:
   - **குழு மேலாண்மை (Gestión de Grupos)**: Alternar Grupo Actual (செயலில் உள்ள குழு மடிப்பை மாற்றவும்), Alternar Todos los Grupos (அனைத்து குழுக்கள் மடிப்பை மாற்றவும்).
   - **குழுவாக்க விருப்பங்கள் (Opciones de Agrupación)**:
     - Agrupación Inteligente (தானியங்கி ஹியூரிஸ்டிக் கிளஸ்டரிங்கை மாற்றவும்).
     - Modo Compacto (ஒற்றை எழுத்து குழு தலைப்பு பயன்முறையை மாற்றவும்).
     - Dominio / Subdominio (டொமைன் மற்றும் துணை டொமைன் குழுவாக்கத்தை மாற்றவும்).
     - Páginas Especiales: Chrome பக்கங்கள் (`chrome://`), உள்ளூர் கோப்புகள் (`file:///`), நீட்டிப்புகள் (`chrome-extension://`), இதர (`Misc`), IP முகவரிகள் & Localhost.
   - **பொதுவான விருப்பங்கள் (Opciones Generales)**:
     - Ordenar Alfabéticamente (தாவல் பட்டி முழுவதும் அகரவரிசைப்படி வரிசைப்படுத்துதலை செயல்படுத்தவும்).
     - Ubicación Miscelánea: ஆரம்பம் (`start`), முடிவு (`end`), அகரவரிசைப்படி (`alpha`).
     - Temporizador de Auto-Colapso (செயலற்ற குழு தானியங்கி-மடங்கல் டைமரை மாற்றவும்).
     - Prefijos Visuales (`🔒`, `🔍`, `🗝️`, `⚠️` நிலை குறிப்பான்களை மாற்றவும்).
     - Vista Previa de Enlaces (பக்கத்திற்குள்ளான இணைப்பு முன்னோட்ட மாதிரியை மாற்றவும்).

## 11. சேமிப்பகத் திட்டங்கள் & தரவு நிலைத்தன்மை (Storage Schemas & Data Persistence)

நீட்டிப்பானது IndexedDB மற்றும் Chrome Storage API-கள் முழுவதும் பல அடுக்கு சேமிப்பக மாதிரியைப் பயன்படுத்துகிறது:

### 11.1 IndexedDB தரவுத்தளம்: `Intelligent_Workspace` (திட்ட பதிப்பு 8)
1. `screenshots`: keyPath: `'id'`, autoIncrement: true. இரண்டாம் நிலை குறியீடு: `'createdAt'`. பைனரி ஸ்கிரீன்ஷாட்கள், கேன்வாஸ் தரவு URL-கள், நிலையான கொடிகள், பரிமாணங்கள் மற்றும் பிரிவு மொத்த குறியீடுகளைக் கொண்டுள்ளது.
2. `geminiConversations`: keyPath: `'id'`, autoIncrement: true. 0 இரண்டாம் நிலை குறியீடுகள் (ஐடி மூலம் பெறப்பட்டது/நிர்வகிக்கப்படுகிறது). பல அடுக்கு அரட்டை தொடர்கள், செய்தி பாத்திரங்கள், டோக்கன் அளவீடுகள் மற்றும் தேடல் அடிப்படை மெட்டாடேட்டாவைச் சேமிக்கிறது.
3. `notesStore`: keyPath: `'id'`, autoIncrement: false. 0 இரண்டாம் நிலை குறியீடுகள் (contextKey மூலம் நினைவகத்தில் வடிகட்டப்பட்டது). ரிச் டெக்ஸ்ட், சரிபார்ப்புப் பட்டியல் வரிசைகள், Kanban பலகை அட்டைகள், Mermaid விவரக்குறிப்புகள் மற்றும் KaTeX சூத்திரங்களைச் சேமிக்கிறது.
4. `backupsGroups`: keyPath: `'group.id'`. 0 இரண்டாம் நிலை குறியீடுகள் (உள்ளமைக்கப்பட்ட `'group.id'` மூலம் விசை செய்யப்பட்ட காப்பு குழு பொருட்களைச் சேமிக்கிறது). சுருக்கப்பட்ட குழு கட்டமைப்புகள், வண்ணங்கள், தலைப்புகள் மற்றும் மூடப்பட்ட தாவல் பதிவுகளைச் சேமிக்கிறது.
5. `pomodoroStats`: keyPath: `'id'`, autoIncrement: true. இரண்டாம் நிலை குறியீடுகள்: `'projectName'` (keyPath `'projectName'`) மற்றும் `'savedAt'` (keyPath `'savedAt'`) (`date` குறியீடு இல்லை). கவனக் குவிப்பு பகுப்பாய்வு, சுழற்சி அளவீடுகள் மற்றும் குறுக்கீடு பதிவுகளைக் கொண்டுள்ளது.

### 11.2 Chrome சேமிப்பக இரட்டை வழித்தடமாக்கல் (`StorageService`)
- பயனர் சாதனங்கள் முழுவதும் எடுத்துச்செல்லக்கூடிய அமைப்புகளுக்கு `chrome.storage.sync` மற்றும் அதிக எடை கொண்ட விருப்பத்தேர்வுகளுக்கு `chrome.storage.local` ஆகியவற்றிற்கு இடையே படித்தல் மற்றும் எழுதுதல்களை மாறும் வகையில் வழிநடத்துகிறது.
- முக்கிய மாதிரிகள்:
  - `customRules`: விதி வரையறைகளின் வரிசை (`[{ name, color, active, urls }]`).
  - `clusterConfig`: தானியங்கி கிளஸ்டரிங் அளவுருக்கள் (வரம்புகள், சுருக்கமான பயன்முறை, சிறப்பு பிரிவுகள்).
  - `userPrefixes`: எமோஜி முன்னொட்டு பணிகள் (`{ lock, openKey, loupe, checked, warning }`).
  - `activeTheme`, `savedThemes`, & `themeSchedules`: 9-வண்ணத்தட்டு வண்ண கட்டமைப்புகள் மற்றும் `ThemeScheduleModal.svelte` வழியாக உள்ளமைக்கப்பட்ட திட்டமிடப்பட்ட சுழற்சி விதிகள்.
  - `pomodoroState`: நிகழ்நேர அமர்வு நேர முத்திரைகள், இடைநிறுத்தப்பட்ட காலம் மற்றும் சுழற்சி இலக்குகள்.
  - `wa:settings` & `wa:limits`: இணைய செயல்பாட்டுக் கண்காணிப்பு விருப்பத்தேர்வுகள், தள வரம்புகள் மற்றும் அட்டவணை சாளரங்கள்.
  - `youtubeLoopEnabled`: YouTube மற்றும் Shorts லூப் பொத்தான்களைக் கட்டுப்படுத்தும் பூலியன் கொடி.

### 11.3 Chrome சேமிப்பக அமர்வு (`chrome.storage.session`)
மிக விரைவான, நிலையற்ற இயக்கநேர ஒருங்கிணைப்புக்கு பயன்படுத்தப்படுகிறது:
- `tabsEverActive`: தற்போதைய உலாவி அமர்வின் போது செயல்படுத்தப்பட்ட தாவல் ஐடிகளின் தொகுப்பு.
- `groupExpandedEver`: தற்போதைய அமர்வின் போது விரிவாக்கப்பட்ட குழுக்களின் பதிவு.
- `groupInfoMap`: குழு ஐடிகளை டைனமிக் தலைப்புகள் மற்றும் கிளஸ்டரிங் வகைகளுடன் இணைக்கும் நிகழ்நேர பதிவேடு.
- `splitScreenState`: அசல் திரை பரிமாணங்களை மீட்டெடுப்பதற்கான தற்காலிக சேமிப்பு சாளர எல்லைகள்.
- `contextMenusSignature`: விரைவான தாவல் மாறுதல்களின் போது தேவையற்ற சூழல் மெனு மறுவடிவமைப்பு சலசலப்பைத் தடுக்கும் ஹாஷ் கையொப்பம்.
- `wa:openSegment`: தற்போதைய செயலில் உள்ள வலைத்தள நேரப் பிரிவு.
- `hiddenYoutubeView`: `HiddenGroupsBar.svelte` இல் நிறுத்தப்பட்ட YouTube பிளேயர் பார்வைக்கான குறிப்பு.

## 12. தற்காப்புப் பொறியியல் & விளிம்பு நிலை கையாளுதல் (Defensive Engineering & Edge Case Handling)

1. **Declarative Net Request தலைப்பு தடையை நீக்குதல் (`dnr.js`)**:
   - வெளிப்புற தளங்கள் பக்கப் பலகம் மற்றும் பிக்சர்-இன்-பிக்சர் ஐபிரேம்களில் ரெண்டர் செய்ய அனுமதிக்கும் வகையில், `X-Frame-Options` மற்றும் கட்டுப்பாடான `Content-Security-Policy` தலைப்புகளை அகற்ற மாறும் DNR விதிகள் வழியாக மறுமொழி தலைப்புகளை மாற்றியமைக்கிறது.
   - **WhatsApp Web பாதுகாப்பு**: அதன் WebAssembly Signal கிரிப்டோகிராஃபிக் செயலாக்கத்தை உடைப்பதைத் தடுக்க `web.whatsapp.com` இல் `Cross-Origin-Opener-Policy` (COOP) மற்றும் `Cross-Origin-Embedder-Policy` (COEP) ஆகியவற்றை வெளிப்படையாகப் பாதுகாக்கிறது.
2. **வலது கிளிக் & தேர்வு தடுப்பு நீக்கி (`allowRightClickHook.js`)**:
   - நகலெடுத்தல், ஒட்டுதல், சூழல் மெனு மற்றும் உரைத் தேர்வைத் தடுக்கும் விரோத வலைத்தளங்களை முறியடிக்கிறது.
   - `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown`, மற்றும் `mouseup` ஆகியவற்றில் `preventDefault()` மற்றும் `stopPropagation()` ஐ இடைமறிக்க `MAIN` உலகில் இயங்குகிறது.
   - `MutationObserver` வழியாக இன்லைன் `oncontextmenu="return false"` கையாளுபவர்களை நீக்குகிறது.
   - ரத்துசெய்யப்பட்ட பேஸ்ட் நிகழ்வுகளை மீண்டும் செலுத்துவதற்கு முன் கிளிப்போர்டு உள்ளடக்கங்களைச் சரிபார்ப்பதன் மூலம் முறையான வலைப் பயன்பாடுகளைப் பாதுகாக்கிறது (எ.கா., Telegram Web, Google Docs).
3. **YouTube முன்னோட்ட ஆடியோ கட்டாய-ஒலியடக்க மேலெழுதுதல் (`youtubePreviewAudioHook.js`)**:
   - `ytd-video-preview #inline-preview-player` இல் `MAIN` உலகில் இயங்குகிறது.
   - மவுஸ் நகர்த்தும்போது இலக்கு `<video>` கூறில் உள்ள `HTMLMediaElement.prototype.muted` பண்புக்கூறு விளக்கத்தை மேலெழுதுகிறது.
   - YouTube-இன் உள் `volumechange` கட்டாய-ஒலியடக்க பந்தய நிலையை நீக்குகிறது, மவுஸ் இருக்கும் வரை லூப் மறுதொடக்கங்கள் முழுவதும் ஒலியடக்கப்படாத ஆடியோவைப் பராமரிக்கிறது.
4. **YouTube Shorts ஊட்ட வரிசை வழிசெலுத்தல் ஹூக் (`youtubeShortsFeedHook.js`)**:
   - `ytd-shorts` இல் `MAIN` உலகில் இயங்குகிறது.
   - நீட்டிப்பின் தனிமைப்படுத்தப்பட்ட உலகத்திலிருந்து கண்ணுக்கு தெரியாத `shortsProcessedSequence` பண்பை இடைமறித்து, பக்கத்தை மீண்டும் ஏற்றாமல் அல்லது மிதக்கும் சாளர நிலையை இழக்காமல் `ytd-app` இல் சொந்த `yt-navigate` நிகழ்வுகளை அனுப்புகிறது.
5. **முடிவிலா-உருட்டல் கேன்வாஸ் பாதுகாப்பு (Infinite-Scroll Canvas Protection)**:
   - முழுப் பக்க ஸ்கிரீன்ஷாட் உலாவுதலை 60 பிரிவுகள் (`MAX_FULL_PAGE_SEGMENTS`) மற்றும் அதிகபட்ச கேன்வாஸ் உயரம் 30,000px (`MAX_FULL_PAGE_CANVAS_PX`) என உச்சவரம்பு வைக்கிறது, இது நினைவகம் போதாமல் உலாவி தாவல் செயலிழப்பதைத் தவிர்க்கிறது.
6. **Linux திரை வண்ணத் தேர்வாளர் ஐட்ராப்பர் மாற்று**:
   - Chromium `window.EyeDropper` API இல்லாத Linux சூழல்களில் இயங்கும்போது, நீட்டிப்பு `screen-color-picker.js` ஐ செலுத்துகிறது, இது RGB/HEX/HSL கணக்கீட்டுடன் 9x உருப்பெருக்கப்பட்ட பிக்சல் லென்ஸை வழங்குகிறது.
7. **தொடக்க அமர்வு நிலைபெறுதல் தாமதம் (Startup Session Settling Delay)**:
   - குழு ஒதுக்கீடுகளை மதிப்பீடு செய்வதற்கு முன் அமர்வு தாவல்கள் மற்றும் சாளர நிலைகள் நிலைபெற அனுமதிக்க, உலாவி தொடங்கப்பட்டவுடன் குழு கத்தரிப்பை 20 வினாடிகள் தாமதப்படுத்துகிறது (`groupsHaveSettledAfterStartup()`).
