# Intelligent Workspace

> Intelligent Workspace는 Svelte, Vite 및 CRXJS로 구축된 고급 Manifest V3 브라우저 확장 프로그램이자 생산적인 작업 공간 환경입니다. 지능형 탭 정리, 자동 및 규칙 기반 클러스터링, 자율형 AI 에이전트 실행(Google Gemini Cloud API 및 Chrome Built-in Prompt API 지원), 페이지 내 Vim 스타일 링크 탐색, 41개 접두사 기반 Omnibar 명령 시스템, 다중 형식 노트 작성(서식 있는 텍스트, 체크리스트, Kanban, Mermaid 다이어그램, KaTeX 수식), 고화질 미디어 캡처 및 브라우저 내 WASM OCR, 제로 드리프트 알람 및 오프스크린 오디오 재생을 지원하는 Pomodoro 타이머, Declarative Net Request (DNR) 기반 웹 활동 측정, 도메인 제한 및 사이트 차단 기능을 총괄 조율합니다.

## 1. 아키텍처 기반 및 런타임 수명 주기

이 확장 프로그램은 Google Chrome의 Manifest V3 아키텍처 하에 실행되며, 백그라운드 Service Worker, 샌드박스 처리된 UI 패널, 오프스크린 오디오 문서, 페이지 내 콘텐츠 스크립트 오버레이 전반에 걸쳐 지속 프로세스를 분리합니다:

1. **매니페스트 구성 (`manifest.json`)**:
   - **권한 (21개 항목)**: `tabs`, `tabGroups`, `storage`, `favicon`, `contextMenus`, `notifications`, `sidePanel`, `scripting`, `downloads`, `downloads.open`, `system.display`, `declarativeNetRequestWithHostAccess`, `cookies`, `history`, `sessions`, `bookmarks`, `readingList`, `clipboardWrite`, `alarms`, `offscreen`, `idle`.
   - **호스트 권한**: `["<all_urls>"]`.
   - **Service Worker**: 동기식 `importScripts` 모듈 로딩을 사용하는 `src/core/background.js`.
   - **툴바 액션**: 의도적으로 `default_popup`을 생략합니다. 런타임에서 `chrome.action.setPopup({ popup: '' })`을 강제하여 `chrome.action.onClicked`가 동기식으로 트리거되도록 보장하며, 팝업 초기화 지연 시간 없이 사용자가 고정한 뷰로 `chrome.sidePanel`을 즉시 엽니다.
   - **Omnibox 키워드**: 등록된 키워드 `"find"`.
   - **명령**: `commands` 아래에 등록된 24개의 시스템 수준 키보드 단축키.
   - **콘텐츠 보안 정책 (CSP)**: `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`.

2. **프로세스 간 통신 (IPC) 보안**:
   - `src/core/background/messaging.js`는 콘텐츠 스크립트에서 전송된 메시지를 명시적 화이트리스트(`ALLOWED_CONTENT_SCRIPT_ACTIONS`)와 비교하여 필터링합니다. 권한이 없는 웹 프레임은 내부 스토리지 작성기, 임의의 Chrome API 또는 규칙 변경자를 호출할 수 없습니다.

3. **이중 실행 환경 (Dual Execution Worlds)**:
   - 콘텐츠 스크립트는 `ISOLATED`(확장 프로그램 범위) 및 `MAIN`(페이지 실행 범위) 환경 모두에서 작동합니다. `allowRightClickHook.js`, `videoPipHook.js`, `youtubePreviewAudioHook.js`, `youtubeShortsFeedHook.js`와 같은 스크립트는 프로토타입 메서드를 가로채고, 프로퍼티 디스크립터를 재정의하며, 커스텀 이벤트를 직접 처리하기 위해 `MAIN` 환경에서 실행됩니다.

## 2. 섹션 1: 규칙 관리 (Gestionar Reglas)

규칙 관리 서브시스템은 사용자가 정의한 엄격하고 결정론적인 기준에 따라 탭 그룹화를 자동화합니다.

### 2.1 데이터 스키마 (`CustomRule`)
각 커스텀 규칙은 다음 인터페이스를 준수합니다:
```typescript
interface CustomRule {
  name: string;        // 1~16자. 공백 문자를 포함할 수 없음.
  color: RuleColor;    // 9가지 색상 중 하나: 'grey' | 'blue' | 'red' | 'yellow' | 'green' | 'pink' | 'purple' | 'cyan' | 'orange'
  urls: string[];      // 유효한 URL, 도메인 또는 호스트 이름 배열.
  active: boolean;     // 규칙 평가 활성화/비활성화 마스터 토글.
  isStarred?: boolean; // 우선적인 UI 정렬을 위해 즐겨찾기로 표시하는 선택적 플래그.
}
```

### 2.2 우선순위 아키텍처
`src/core/background/groupManager.js`의 `groupTabs()`에 의해 탭이 처리될 때, 엄격한 계층 순서에 따라 그룹화 계층과 비교 평가됩니다:
1. **커스텀 규칙 (`applyCustomRules`)**: 표시 순서 또는 사용자 우선순위에 따라 활성 커스텀 규칙을 매칭합니다. 그룹화가 완료되면 해당 탭 ID는 `groupedTabIds`에 등록되어 후속 계층에서 제외됩니다.
2. **특수 시스템 그룹**: 시스템 URL을 가로채 전용 색상 그룹으로 클러스터링합니다:
   - `chrome://` 및 내부 브라우저 페이지
   - `file:///` 로컬 디스크 파일
   - `chrome-extension://` 확장 프로그램 페이지
   - IP 주소 및 Localhost (`localhost`, `127.0.0.1`, `[::1]`, IPv4/IPv6 호스트)
3. **도메인 클러스터링**: 동일한 루트 도메인을 공유하는 탭 수가 `domainThreshold`(기본값: 2개 탭) 이상인 경우 탭을 그룹화합니다.
4. **서브도메인 클러스터링**: 활성화된 경우 도메인 내의 탭을 특정 서브도메인별로 그룹화합니다(예: `docs.github.com` 대 `gist.github.com`).
5. **기타("Misc") 그룹**: 그룹화 임계값을 충족하지 못하고 남은 미분류 탭은 `Misc` 그룹에 배치됩니다(배치 위치 설정 가능: 시작 `start`, 끝 `end`, 알파벳순 `alpha`).

### 2.3 URL 정규화 및 매칭 시맨틱
매칭 엔진(`src/core/background/utils.js`의 `matchesRule(tabUrl, ruleUrl)`)은 엄격한 정규화를 적용합니다:
- **스킴 무관**: HTTP 및 HTTPS 프로토콜은 상호 호환 가능한 것으로 처리됩니다(`http://example.com`은 `https://example.com`과 매칭됨). 웹 프로토콜이 아닌 경우(`file://`, `chrome://`) 정확한 스킴 매칭이 필요합니다.
- **호스트 정규화**: 선행 `www.` 접두사는 제거됩니다(`www.github.com`은 `github.com`으로 정규화됨). 호스트 이름은 소문자로 변환되며 punycode를 통해 국제화 도메인 네임(IDN)을 지원합니다.
- **포트 민감도**: 규칙에 포트가 지정된 경우(예: `localhost:3000`), 탭은 해당 정확한 포트와 일치해야 합니다.
- **경로 매칭**: 후행 슬래시는 제거됩니다. 규칙에 경로가 지정된 경우(예: `example.com/docs`), 해당 정확한 경로 또는 하위 경로(`example.com/docs/api`)와 일치하는 탭과 매칭되지만, 형제 경로(`example.com/blog`)와는 매칭되지 않습니다.
- **쿼리 및 해시 매칭**: 규칙에 쿼리 스트링(`?page=1`)이나 해시(`#section`)가 명시적으로 포함된 경우, 탭은 해당 매개변수와 정확히 일치해야 합니다.
- **숫자 Dword 보호 (`ruleValidation.js`)**: 유효성 검사기는 WHATWG URL 파서가 유효한 IPv4 정수 DWORD로 처리하는 순수 숫자 입력(예: `3242342424`)을 엄격히 거부하여 의도치 않은 그룹화 왜곡을 방지합니다.

### 2.4 규칙 관리 설정 세부 분석
규칙 관리자는 포괄적인 동작 제어 및 설정 스위트를 제공합니다:
- **스토리지 라우팅 선택**: 사용자는 `chrome.storage.sync`(Google 프로필에 로그인된 모든 기기 간 설정 동기화, Chrome 동기화 할당량 총 100KB 및 항목당 8KB 제한 적용)와 `chrome.storage.local`(수백 개의 패턴이 포함된 대규모 규칙 세트에 적합한 무제한 로컬 용량) 간에 규칙 스토리지 경로를 지정할 수 있습니다.
- **클러스터링 마스터 토글 및 임계값**:
  - `toggle-clustering`: 사용자가 생성한 커스텀 규칙을 비활성화하지 않고 자동 도메인/서브도메인 클러스터링을 활성화하거나 비활성화하는 마스터 키보드 단축키 및 UI 토글.
  - `domainThreshold`: 자동 탭 그룹을 트리거하는 데 필요한 동일 도메인의 최소 탭 수(기본값: 2개 탭). 1에서 50까지 구성 가능.
  - `subdomainThreshold`: 분리된 하위 그룹 클러스터를 생성하기 전 서브도메인의 최소 탭 수.
  - 서브도메인 토글 (`toggle-subdomain-grouping`): 독립된 서브도메인을 구분(예: `news.ycombinator.com` 대 `ycombinator.com`).
- **그룹 알파벳순 자동 정렬 (`toggle-sort-alpha`)**: 브라우저 탭 스트립의 모든 열린 탭 그룹에 알파벳순 정렬을 적용하는 실시간 정렬 엔진(`Ctrl+Shift+S` / `Cmd+Shift+S`).
- **시각적 상태 접두사 (`toggle-prefixes`)**: 검사 상태를 나타내기 위해 그룹 제목 앞에 동적으로 추가되는 이모지 마커:
  - `🔒` (자물쇠): 방문하지 않은 읽지 않은 탭이 포함된 그룹.
  - `🔍` (돋보기): 일부만 방문한 탭이 포함된 그룹.
  - `🗝️` (열린 열쇠): 그룹 내 모든 탭이 열려 검토 완료됨.
  - `⚠️` (경고): 다른 창의 그룹과 중복된 그룹 이름 충돌 감지됨.
- **비활성 그룹 자동 접기 (`toggle-collapse-timer`)**: 깔끔한 탭 스트립을 유지하기 위해 비활성 상태일 때 그룹을 자동으로 접습니다.
- **마스터 일시 중지 그룹화 (`feature_pauseGrouping`)**: 탭을 임의의 사용자 배열 상태로 유지해야 하는 활성 리서치 세션 중에 모든 자동 그룹화 작업(규칙 매칭 및 휴리스틱 클러스터링 모두)을 일시적으로 중단하는 마스터 동결 스위치.
- **단일 탭 그룹화 (`featureSingleTabGrouping`)**: 커스텀 규칙이 다중 탭 임계값 요구 사항을 우회하여 일치하는 단일 탭에 대해 즉시 탭 그룹을 생성할 수 있도록 허용.
- **컴팩트 보기 (`toggle-compact-mode`)**: 그룹 제목에 한 글자 배지만 렌더링하여 브라우저 탭 스트립의 탭 헤더 너비를 최소화.
- **드래그 앤 드롭 우선순위**: `Rules.svelte` 목록에서 규칙 순서를 변경하면 평가 우선순위가 즉시 변경됩니다. 상단의 규칙이 먼저 평가됩니다.
- **퍼지 검색**: 규칙 관리자 및 Omnibar에서 실시간 필터링을 지원하여 제목이나 일치하는 URL 패턴으로 규칙을 즉시 찾을 수 있습니다.
- **JSON 가져오기 / 내보내기**:
  - `add` 모드: 중복을 제외하고 가져온 규칙을 기존 컬렉션에 병합합니다.
  - `overwrite` 모드: 스키마 유효성 검사 후 활성 규칙 컬렉션을 가져온 페이로드로 완전히 대체합니다.
- **동적 규칙 생성**: Chrome 북마크 폴더 또는 하위 그룹 도메인 컬렉션에서 직접 클릭 한 번으로 커스텀 규칙을 생성합니다.
- **규칙 중복 제거 (`feature_v100_dedup_add_to_rule`)**: 기존 커스텀 규칙에 URL 또는 도메인을 추가할 때 중복 URL 패턴을 자동으로 제거하여 규칙 팽창과 불필요한 평가를 방지합니다.

### 2.5 작업 및 영속성 (`mutateRulesAndSync`)
- **중앙 집중식 뮤테이터**: 모든 규칙 수정은 `src/core/background/handlers/rules.js`의 `mutateRulesAndSync(mutateFn, sendResponse)`를 통해 라우팅됩니다. 이를 통해 스토리지 동기화, 메모리 내 캐시 갱신(`extensionSettings.customRules`), UI 알림(`rulesUpdated`), 자동 탭 재그룹화(`groupTabs()`)가 보장됩니다.
- **실시간 유효성 검사**: 저장 전 이름의 고유성, 길이(1~16자), 문자 제한 및 유효한 URL 구문을 실시간으로 검사합니다.

### 2.6 호출 방식
- **규칙 관리자 페이지 (`Rules.svelte`)**: 전체 탭 보기 또는 사이드 패널(`?view=rules` / `pg`)에서 접근할 수 있습니다. 완전한 드래그 앤 드롭 재정렬, 인라인 색상 선택기, URL 태그 칩 및 규칙 토글을 제공합니다.
- **Omnibar 명령**:
  - `rl:` — 규칙을 검색하고 연결된 URL을 엽니다.
  - `cr: <name> [, url1, url2]` — 명령 표시줄에서 직접 새 규칙을 생성합니다.
  - `atcr:` — 활성 탭의 도메인 또는 URL을 기존 규칙에 추가합니다.
  - `atr:` — 선택한 열린 탭 또는 수동 URL을 기존 규칙에 추가합니다.
  - `ccr:` — 커스텀 규칙의 색상을 변경합니다.
  - `dr:` — 규칙 또는 규칙의 개별 URL을 삭제합니다.
  - `er:` — 기존 규칙을 편집하거나 이름을 변경합니다.
- **컨텍스트 메뉴**:
  - 페이지 우클릭 -> "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa".
  - 페이지 우클릭 -> "Añadir a Regla Existente" -> 규칙 선택 -> "Añadir Raíz del Sitio" / "Añadir URL Completa".
  - 페이지 우클릭 -> "Reglas" -> 활성 상태 토글, 모든 규칙 URL 열기 또는 일치하는 탭 닫기.
- **키보드 단축키**:
  - `Alt+R`: 규칙 관리자 열기.
  - `Alt+M`: 모든 규칙 활성화를 동시에 토글 (`toggle-all-rules`).

## 3. 섹션 2: 그룹 목록 및 작업 (Listar Grupos)

그룹 목록 보기는 브라우저 탭 그룹 및 개별 탭을 검사, 조작 및 재정렬할 수 있는 대화형 작업 공간을 제공합니다.

### 3.1 UI 아키텍처
- **컴포넌트 스택**: `ListGroup.svelte`, `GroupCard.svelte`, `GroupActions.svelte`, `TabItem.svelte`, `TabActions.svelte`로 구축되었습니다.
- **카드 기능**: 그룹 제목, 색상 배지, 탭 수 뱃지, 접기/펼치기 아코디언 토글, 카드 고정 및 사용자 정의 가능한 작업 버튼 그룹을 표시합니다.
- **탭 항목**: 색상 대체 기능이 있는 탭 파비콘, 제목, 소리 재생 배지, 음소거 표시기, 활성 상태 표시기 및 탭별 작업(닫기, 복제, 고정, 분할, 메모리 해제)을 표시합니다.

### 3.2 그룹 수명 주기 및 동작
- **아코디언 제어**: 부드러운 펼치기 및 접기 상태를 제공합니다. 선택적 자동 아코디언 모드는 새 그룹이 확장될 때 유휴 그룹을 자동으로 접습니다.
- **비활성 자동 접기 유휴 타이머**:
  - 시각적 복잡함을 줄이기 위해 유휴 탭 그룹을 자동으로 접습니다.
  - 두 가지 고유한 임계값: 비활성 그룹은 1분 동안 비활성 상태일 때 접히고(`INACTIVITY_THRESHOLD_INACTIVE_GROUP`), 활성 그룹은 15분 동안 비활성 상태일 때 접힙니다(`INACTIVITY_THRESHOLD_ACTIVE_GROUP`). 0분에서 1440분까지 설정 가능합니다.
- **인라인 이름 변경 및 유예 기간**:
  - 사용자는 브라우저 탭 스트립 또는 UI에서 직접 그룹 이름을 변경할 수 있습니다.
  - `GROUP_NAMING_GRACE_MS`(5000ms)는 사용자가 편집하는 동안 자동 재그룹화를 일시 중지하여 타이핑 도중 제목이 덮어써지는 것을 방지합니다.
  - 평가 중 제로 너비 공백(`\u200B`, `\u200C`, `\u200D`, `\u2060`, `\uFEFF`)은 제거됩니다.
  - 자동 생성된 그룹의 이름을 변경하면 사용자 명명 그룹으로 변환되어 해당 커스텀 규칙을 업데이트하거나 영구 그룹으로 표시합니다.
- **시각적 그룹 접두사 표시기**:
  - 상태 기호를 동적으로 앞에 붙입니다: `🔒` (미방문), `🔍` (일부 방문), `🗝️` (모두 확인), `⚠️` (충돌).
- **드래그 앤 드롭 재정렬**: 그룹 내에서 탭을 재정렬하거나, 그룹 간에 탭을 이동하거나, 그룹 카드를 재정렬할 수 있도록 `sortable.js`와 통합되었습니다.
- **숨김 그룹 기능**:
  - 브라우저 탭 스트립에서 그룹 제목 앞에 `_hidden_`을 추가합니다.
  - 메인 목록 보기에서 그룹 카드를 숨기고 `HiddenGroupsBar.svelte`로 전송합니다.
  - 사용자는 클릭 한 번으로 숨겨진 그룹을 즉시 표시하거나 복원할 수 있습니다.

### 3.3 그룹 작업 및 메모리 관리
- **그룹 해제 (Ungroup)**: 그룹을 해제하고 창에 탭을 열어 둡니다.
- **그룹 닫기 (Close Group)**: 그룹의 모든 탭을 닫고 그룹 ID를 해제합니다.
- **다른 그룹 닫기 (Close Other Groups)**: 현재 포커스된 그룹을 제외한 모든 탭 그룹을 닫습니다.
- **모든 탭 재그룹화 (`Alt+Shift+R`)**: 커스텀 규칙, 시스템 그룹 및 도메인 클러스터 전반에 걸쳐 포괄적인 재평가 과정을 실행합니다.
- **그룹 스크린샷 연속 캡처 (Group Screenshot Walk)**: 그룹 내의 모든 탭을 순차적으로 순회하며 캡처합니다(`Cs` 표시 영역, `Cp` 전체 페이지, `CP` 전체 페이지 분할).

### 3.4 그룹 백업 및 복원 서브시스템
- **IndexedDB `backupsGroups` 저장소**:
  - 단일 탭 그룹 또는 열려 있는 모든 그룹의 작업 공간 전체 스냅샷을 IndexedDB `Intelligent_Workspace`의 `backupsGroups` 저장소에 백업합니다.
  - 완전한 그룹 구조 캡처: 그룹 제목, 색상, 접힘 상태, 탭 제목, URL, 파비콘, 고정 상태 및 상대적 탭 위치.
  - **메모리 절약**: 백업된 탭은 깔끔하게 닫혀 시스템 RAM을 확보하고 CPU 오버헤드를 줄입니다.
  - **복원 메커니즘**:
    - 한 번의 클릭으로 그룹을 복원할 수 있는 `ListGroup.svelte`의 백업 UI 보기.
    - 키보드 단축키 `br` (복원) 및 `bg` (전체 백업).
    - Omnibar 명령 `bgr:` (백업된 그룹 검색 및 복원) 및 `b:` (북마크 검색).
  - **JSON 내보내기 및 가져오기**: 기기 간 원활한 마이그레이션 및 장기 오프라인 보관을 위한 완벽한 JSON 백업 내보내기 및 가져오기를 지원합니다.

### 3.5 숨김 그룹 바의 주차된 YouTube 플레이어
- **아키텍처 (`HiddenGroupsBar.svelte`)**:
  - 사용자가 활성 YouTube 비디오 뷰에서 다른 곳으로 이동하거나 사이드 패널 내부에서 비디오 콘텐츠를 실행할 때 플레이어가 닫히거나 유실되지 않습니다. `HiddenGroupsBar.svelte`에 주차된 YouTube 표시기(`.youtube-indicator`)로 자동 도킹됩니다.
  - `src/ui/stores/appStore.svelte.js`의 `hiddenYoutubeView` 저장소를 통해 반응형으로 관리됩니다.
  - **원클릭 작업**:
    - 주차된 표시기를 클릭하면 `restoreYoutubeView()`가 호출되어 플레이어가 활성 작업 공간 뷰로 즉시 복귀합니다.
    - 삭제 배지를 클릭하면 `discardYoutubeView()`가 호출되어 재생이 깔끔하게 종료되고 리소스가 회수됩니다.
  - 활성 탭 목록을 어지럽히지 않고 ListGroup 보기 상단의 숨겨진 탭 그룹과 나란히 원활하게 배치됩니다.

## 4. 섹션 3: 탐색 및 탭 관리 (Navegación)

단축키 기반의 빠른 탐색 및 작업 공간 제어를 통해 마우스 조작 없이 여러 탭을 완벽하게 제어할 수 있습니다.

### 4.1 빠른 탭 점프 제스처
- **제스처 구문**: `Alt + [groupPrefix] + [tabIndex] + Enter`
- **실행**:
  - `Alt` 키를 누른 상태에서 그룹 이름이나 접두사 문자를 입력한 다음, 원하는 1 기반 탭 인덱스를 입력하고 `Enter` 키를 누릅니다.
  - 예시: `Alt + git + 2 + Enter`는 "GitHub" 그룹의 두 번째 탭으로 직접 이동합니다.
  - 인덱스 `0`은 그룹의 *마지막* 탭으로 이동하는 단축키 역할을 합니다.
  - 인덱스를 생략하면 그룹의 *첫 번째* 탭으로 이동합니다.
  - 악센트는 자동으로 정규화(`deaccent`)되며 발음 구별 부호가 통합 매칭됩니다.

### 4.2 단계별 이동, 전환 및 수명 주기 키
- `s`: 이전에 활성화되었던 탭으로 즉시 전환 (`previousActiveTabId`).
- `h` / `l`: 이전/다음 탭으로 단계 이동(페이지가 허용하는 경우 가로 스크롤).
- `H` / `L`: 브라우저 방문 기록에서 뒤로/앞으로 이동.
- `t`: 새 빈 탭 열기.
- `x`: 현재 활성 탭 닫기.
- `yt`: 현재 탭 복제.
- `r` / `R`: 페이지 새로고침 / 캐시를 무시하고 강제 새로고침.
- `d` / `u`: 페이지 하단/상단으로 스크롤.
- `j` / `k`: 부드러운 아래/위 스크롤 (75px 단위).
- `f`: Vim 링크 힌트 활성화(클릭 가능한 요소 위에 문자가 표시되어 클릭 가능).
- `cf`: Vim 링크 힌트를 활성화하여 대상 URL을 클립보드에 복사.

### 고급 사용자를 위한 기능

숙련된 고급 사용자는 브라우저를 전체 화면 모드로 전환하고 마우스를 전혀 사용하지 않고 키보드로만 완전히 탐색할 수 있습니다.

#### 전체 화면 몰입 및 마우스 없는 브라우징
- **전체 화면 토글**: `F11`(Windows/Linux) 또는 `Command+Control+F`(macOS)를 누릅니다. 브라우저 크롬, 주소 표시줄, 탭 스트립 및 운영 체제 패널이 숨겨져 디스플레이의 100%를 콘텐츠에 할당합니다.
- **페이지 내 Vim 링크 탐색 (`f` / `cf`)**:
  - `f`를 누르면 DOM의 클릭 가능한 모든 요소, 버튼, 입력창 및 링크 위에 고대비 2글자 노란색 링크 힌트가 생성됩니다.
  - 대상과 일치하는 두 글자를 입력하여 마우스 조작 없이 직접 클릭을 시뮬레이션합니다.
  - `cf`를 누르면 대상 링크의 URL을 시스템 클립보드에 직접 복사하는 힌트 배지가 표시됩니다.
  - `vp`를 누르면 대상 링크의 페이지 내 미리보기 모달이 열립니다.
  - 언제든지 `Esc`를 눌러 링크 힌트를 취소하고 일반 스크롤로 돌아갈 수 있습니다.
- **즉각적인 탭 점프 및 전환**:
  - `Alt + [groupPrefix] + [tabIndex] + Enter`: 빠른 탭 점프 제스처 실행(예: `Alt + dev + 1 + Enter`는 "Dev" 그룹의 첫 번째 탭으로 직접 이동, 인덱스 `0`은 그룹의 마지막 탭 선택).
  - `s`: 현재 탭과 이전에 활성화되었던 탭(`previousActiveTabId`) 간 즉각 전환.
  - `h` / `l`: 탭 스트립에서 이전/다음 탭으로 순차적 이동.
  - `H` / `L`: 브라우저 탐색 기록을 앞/뒤로 이동.
  - `t` / `x` / `yt`: 새 탭 열기(`t`), 현재 탭 닫기(`x`), 탭 복제(`yt`).
- **플로팅 Omnibar 명령 서브시스템 (`o`)**:
  - 임의의 페이지에서 `o`를 눌러 중앙 정렬된 Omnibar 오버레이를 호출합니다.
  - `@`를 입력하여 41개 명령 접두사의 대화형 디렉터리를 표시합니다.
  - `f: <query>`를 입력하여 열려 있는 모든 창에서 심층 전체 텍스트 탭 검색을 실행합니다.
  - `sp:`를 입력하여 사이드패널 뷰(`rules`, `listgroup`, `notes`, `gallery`, `gemini`, `activity`, `themes`, `hints`, `downloads`)로 직접 이동합니다.
  - `qai: <query>` 또는 `qaia: <task>`를 입력하여 키보드에서 손을 떼지 않고도 Gemini에 질의하거나 자율형 브라우저 에이전트에 지시를 내립니다.
  - `ts:`를 입력하여 열려 있는 탭을 나란히 분할 화면으로 분할합니다.
- **페이지 내 탐색 및 포커스**:
  - `j` / `k`: 부드러운 아래/위 스크롤 (75px 증분).
  - `d` / `u`: 반 페이지 아래/위 스크롤.
  - `i`: 페이지의 기본 텍스트 입력 필드로 커서 포커스 즉시 이동.
  - `ESC`: 입력 포커스를 해제하고 키보드 포커스를 탐색 모드로 복귀.

### 4.3 오디오 및 사운드 관리
- 오디오를 재생하는 탭은 ListGroup UI에 스피커 배지를 표시합니다.
- `st`: 현재 활성 탭의 음소거 상태 토글.
- `so`: 브라우저 전체에서 소리가 나는 모든 탭을 음소거.
- 컨텍스트 메뉴: "Silenciar Todas las Pestañas" / "Reactivar Sonido en Todas las Pestañas".

### 4.4 분할 화면 워크플로
- **트리거**: Vim 힌트 `ts` 또는 Omnibar 접두사 `ts:`.
- **동작**: `chrome.system.display`를 사용하여 화면 지오메트리를 계산합니다. 두 개의 탭을 인접한 창으로 나란히 분할하여 전용 `Split` 탭 그룹 아래에 그룹화합니다.
- **복원**: 분할 창을 닫거나 분할 화면을 토글하면 원래 창 크기와 좌표로 복원됩니다.

### 4.5 YouTube 반복 재생 서브시스템
YouTube 반복 재생 서브시스템은 YouTube 플레이어에 직접 통합된 정밀 미디어 반복 제어 기능을 제공합니다:
- **데스크톱 플레이어 버튼 (`#itg-yt-loop-button`)**: 표준 YouTube 플레이어 컨트롤 바(`.ytp-right-controls`) 내의 Cast / Remote 버튼 또는 PiP 실행기 왼쪽에 주입됩니다. 애니메이션 SVG 반복 재생 글리프, 토글 강조 스타일(`ytp-loop-active`, `var(--interactive-color, #ff4444)`), `aria-pressed` 상태를 지원합니다.
- **Shorts 플레이어 버튼 (`#itg-yt-shorts-loop-button`)**: YouTube Shorts 우측 컨트롤 컬럼(`ytd-shorts`)의 `#itg-yt-shorts-loop-wrapper` 내부에 주입되어 세로형 비디오 콘텐츠를 원클릭으로 반복 재생할 수 있도록 지원합니다.
- **반복 메뉴 및 PiP 팝업 (`#itg-yt-loop-menu` 및 `#itg-pip-loop-popup`)**: 반복 버튼에 마우스를 올리거나 클릭하면 포괄적인 반복 설정 메뉴가 열립니다:
  - **A-B 구간 반복**: 대화형 범위 슬라이더와 수동 시간 필드를 통해 밀리초 단위 정밀도로 사용자 정의 시작 지점(A)과 종료 지점(B)을 설정할 수 있습니다.
  - **사이클 모드 및 시퀀스 반복 횟수**: 특정 반복의 반복 횟수를 설정하거나 무한 반복 모드(`itg-loop-seq-inf`)를 토글합니다.
  - **반복 목록 및 다중 세그먼트 시퀀스**: 구성된 반복 횟수에 따라 연속적으로 재생되는 여러 A-B 반복 간격을 큐에 등록합니다.
  - **상태 및 재생 시간 표시**: 현재 반복 간격 내의 실시간 재생 위치와 총 미디어 재생 시간을 표시합니다(`00:00 / 00:00`).
  - **마스터 토글 (`youtubeLoopEnabled`)**: `chrome.storage.sync` 및 `local`에 영속화되어, 사용자가 힌트 사용자 지정 설정 페이지(`YoutubeLoopSection.svelte`)를 통해 YouTube 및 YouTube Shorts 전반에서 반복 버튼을 활성화하거나 비활성화할 수 있습니다.

### 4.6 YouTube Shorts 미리보기 오디오
- **오디오 음소거 해제 훅 (`youtubePreviewAudioHook.js`)**:
  - `ytd-video-preview` 요소의 `#inline-preview-player` 프로퍼티에 접근하기 위해 `MAIN` 실행 환경에서 실행됩니다.
  - **강제 음소거 극복**: YouTube는 오디오 컨트롤을 지우고 내부 `volumechange` 리스너를 통해 `muted = true`를 복원함으로써 Shorts 미리보기에 강제 음소거를 적용합니다.
  - 이 확장 프로그램은 마우스 오버 시 대상 `<video>` 요소의 `HTMLMediaElement.prototype.muted` 프로퍼티 디스크립터를 후킹합니다. 사용자의 음소거 해제는 허용하면서 YouTube의 강제 재음소거 처리는 무시하여, 마우스가 벗어날 때까지 반복 재생이 다시 시작되어도 오디오가 중단 없이 지속적으로 재생되도록 보장합니다.

### 4.7 PIP(Picture-in-Picture) 아키텍처
- **문서 Picture-in-Picture (`wp`)**:
  - 최신 `documentPictureInPicture` API를 활용하여 전체 웹페이지나 텍스트 스니펫을 항상 위에 표시되는 플로팅 창에서 엽니다.
  - 미디어를 전송할 때 비디오 재생 타임스탬프를 자동으로 동기화합니다.
  - 재시도 로직(`itgRetryIfPipFrameRefused`)을 갖추고 있으며 창을 닫을 때 DNR iframe 헤더를 정리합니다.
- **비디오 Picture-in-Picture (`wv`)**:
  - `videoPipHook.js`를 통해 `HTMLVideoElement.prototype.requestPictureInPicture`를 후킹합니다.
  - 비디오 플레이어를 반복 재생 제어 및 재생 속도 선택기가 포함된 커스텀 PiP 프레임으로 리디렉션합니다.
- **Auto-PiP**:
  - `as`: 스크롤 시 Auto-PiP 토글 (뷰포트 밖으로 스크롤될 때 PiP로 비디오 실행).
  - `ah`: 탭 숨김 시 Auto-PiP 토글 (다른 탭으로 전환할 때 PiP로 비디오 실행).

### 4.8 페이지 읽기 모드 및 시각적 오버레이
- **CSS 필터 테마**: 웹 페이지에 비파괴적 스타일을 주입합니다:
  - `mb` / `mB`: 블랙 (어두운 고대비) — 탭 범위 / 전역 범위.
  - `ms` / `mS`: 세피아 (따뜻한 종이 느낌) — 탭 범위 / 전역 범위.
  - `mp` / `mP`: 페이퍼 (단색 그레이스케일) — 탭 범위 / 전역 범위.
  - `ml` / `mL`: 라이트 (부드러운 흰색) — 탭 범위 / 전역 범위.
  - `me` / `mE`: 사용자 정의 CSS 필터 — 탭 범위 / 전역 범위.
  - `ESC`: 활성 페이지 필터를 즉시 제거.
- **리더 모드 및 TTS 낭독 (Read Aloud)**:
  - `fetchContentForReaderView`: 광고, 사이드바 및 불필요한 탐색 요소를 제거하고 깔끔한 기사 콘텐츠를 추출합니다.
  - 텍스트를 문장 단위로 소리 내어 읽어주는 내장 텍스트 음성 변환(TTS) 엔진.
  - 키보드 탐색 컨트롤: `zp` (재생/일시정지), `zn` (다음 문장), `zb` (이전 문장), `zq` (리더 오버레이 닫기).

### 4.9 템플릿 변수가 포함된 텍스트 스니펫 서브시스템
텍스트 스니펫 서브시스템(`src/utils/hint/snippets.js` 및 `src/utils/snippet-panel.js`의 `SnippetManager`)은 모든 입력창, 텍스트 영역 또는 서식 있는 편집기에서 텍스트 단축어를 확장하여 입력 속도를 높입니다:
- **트리거 방식**: 단축어를 입력한 후 스페이스바를 누르거나, `$$`를 입력하여 대화형 스니펫 검색 팝업을 호출합니다.
- **클립보드 API 통합**: 클립보드 API를 통한 서식 있는 HTML 및 일반 텍스트 삽입을 지원하여 Google Docs, Notion, Slack과 같은 복잡한 편집기와의 100% 호환성을 보장합니다.
- **템플릿 변수**: 확장 시점에 변수를 동적으로 변환합니다:
  - `{{date}}` / `date`: 로케일 형식 날짜 (`toLocaleDateString`).
  - `{{isodate}}` / `isodate`: ISO 8601 날짜 (`YYYY-MM-DD`).
  - `{{longdate}}` / `longdate`: 요일, 일, 월, 연도가 포함된 긴 형식의 날짜.
  - `{{time}}` / `time`: 2자리 형식 시간 (`HH:MM`).
  - `{{datetime}}` / `datetime`: 날짜와 시간 결합.
  - `{{weekday}}` / `weekday`: 전체 요일 이름 (예: Monday).
  - `{{day}}` / `day`: 일 (1-31).
  - `{{month}}` / `month`: 전체 월 이름 (예: October).
  - `{{year}}` / `year`: 전체 4자리 연도.
  - `{{tomorrow}}` / `tomorrow`: 다음 날 날짜 (+1일).
  - `{{yesterday}}` / `yesterday`: 이전 날 날짜 (-1일).
  - `{{nextweek}}` / `nextweek`: 7일 후 날짜 (+7일).
  - `{{timestamp}}` / `timestamp`: Epoch 밀리초 타임스탬프 (`Date.now()`).
  - `{{url}}` / `url`: 활성 웹페이지 URL (`window.location.href`).
  - `{{domain}}` / `domain`: 활성 도메인 호스트 이름 (`window.location.hostname`).
  - `{{pagetitle}}` / `pagetitle`: 활성 문서 제목 (`document.title`).
  - `{{uuid}}` / `uuid`: 암호학적으로 안전한 고유 식별자 (`crypto.randomUUID()`).
  - `{{random}}` / `random`: 1에서 1000 사이의 무작위 정수.
  - `{{clipboard}}` / `clipboard`: 시스템 클립보드 버퍼 텍스트.

### 4.10 내장 생산성 도구
- **우클릭 허용 훅 (`allowRightClickHook.js`)**:
  - 우클릭 컨텍스트 메뉴, 복사, 잘라내기 또는 텍스트 선택을 비활성화하는 악성 웹 스크립트를 무력화하기 위해 `MAIN` 실행 환경에 주입됩니다.
  - `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown`, `mouseup`에 대한 `preventDefault()` 및 `stopPropagation()`을 가로챕니다.
  - 지속적인 `MutationObserver`를 통해 인라인 `oncontextmenu="return false"` 핸들러를 제거합니다.
  - 합법적인 웹 편집기(Google Docs, Telegram Web)의 정상적인 동작을 방해하지 않도록 클립보드 페이로드를 검증합니다.
- **쿠키 편집기**: 활성 도메인의 HTTP 및 HTTPS 쿠키를 검사, 편집, 생성 및 삭제하는 페이지 내 모달.
- **QR 코드 생성기**: 빠른 모바일 전환을 위해 활성 탭 URL에 대한 SVG/Canvas QR 코드를 생성합니다.
- **깔끔한 PDF 인쇄 내보내기**: 깔끔한 문서 보관을 위해 헤더, 광고 및 내비게이션 노이즈를 제거하고 `print.html`을 통해 대상 페이지를 라우팅합니다.

### 4.11 포괄적인 3단계 중복 제거 및 지능형 메모리 해제
- **포괄적인 3단계 중복 제거**:
  1. **탭 중복 제거 (`removeDuplicateTabsCommand`)**: 창 전체 또는 포커스된 그룹에서 열려 있는 탭을 검사하고, 중복 URL을 식별하며, `Split` 화면 탭을 예외 처리하고, 활성 탭 또는 가장 오래된 탭을 유지하면서 중복 탭을 닫습니다. 데스크톱 요약 알림을 표시합니다.
  2. **북마크 중복 제거**: Chrome 북마크 트리를 정밀 검사하여 여러 폴더에 걸쳐 있는 동일한 URL 중복을 찾고, 북마크를 깔끔하게 유지할 수 있도록 일괄 통합 기능을 제공합니다.
  3. **규칙 중복 제거 (`feature_v100_dedup_add_to_rule`)**: 기존 커스텀 그룹화 규칙에 URL을 추가할 때 중복 URL 패턴을 자동으로 제거하여 규칙 팽창을 방지합니다.
- **지능형 메모리 해제 (`suspendInactiveTabsIntelligently`)**:
  - `itg-periodic-tasks` 알람을 통해 1분마다 평가됩니다.
  - `discardingTimeMinutes`(기본값: 60분) 이상 비활성 상태인 탭을 메모리에서 해제(discard)합니다.
  - 내장된 보호 예외 처리: 활성 탭, 소리를 재생 중인 탭, 고정된 탭 또는 이미 일시 중단된 탭은 절대 메모리에서 해제하지 않습니다.

## 5. 섹션 4: AI 어시스턴트 및 자율형 에이전트 (Asistente AI)

AI 어시스턴트는 대규모 언어 모델을 브라우저에 통합하여 맥락 이해, 자동화된 워크플로 및 직접적인 브라우저 자동화를 제공합니다.

### 5.1 듀얼 모델 엔진 아키텍처
1. **Google Gemini Cloud API (`gemini-api.js`)**:
   - Google Generative Language REST 엔드포인트(`v1beta/models/{model}:generateContent` 및 `:streamGenerateContent`)와 통합됩니다.
   - Gemini 2.5 Flash, Gemini 2.5 Pro 및 커스텀 모델 엔드포인트를 지원합니다.
   - **다중 키 순환 (Multi-Key Rotation)**: `geminiApiKeysList`에서 키 풀을 관리합니다. 스토리지 난독화에는 `enc_` 접두사를 사용합니다.
   - **지수 백오프 (Exponential Backoff)**: 자동 백오프 재시도(1.5초 -> 3초 -> 6초)를 통해 HTTP 429 할당량 소진을 처리합니다.
   - **검색 그라운딩 (Search Grounding)**: Google 검색 그라운딩(`google_search: {}`)을 활성화합니다. 검색 도구의 할당량 제한으로 인해 HTTP 403이 발생하면 그라운딩 없이 자동으로 재시도합니다.
2. **Chrome 내장 AI / Prompt API (`localAiService.js`)**:
   - `window.LanguageModel`을 통한 온디바이스 Gemini Nano 통합.
   - 네트워크 연결이 필요 없는 제로 네트워크 로컬 실행을 지원합니다. 모델 가용성 확인 및 실시간 다운로드 진행률 추적 기능이 포함되어 있습니다.

### 5.2 자율형 브라우저 에이전트 (`agent-backend.js`)
자율형 에이전트는 40개 이상의 구조화된 도구를 통해 완벽한 브라우저 제어를 제공합니다:
- **탭 및 그룹 제어**: `getOpenTabs`, `switchToTab`, `createNewTab`, `closeTab`, `closeTabs`, `duplicateTab`, `findAndSwitchToTab`, `groupTabs`, `ungroupTabs`, `deleteTabGroup`, `collapseTabGroup`, `expandTabGroup`, `collapseAllGroups`, `expandAllGroups`, `setGroupColor`, `renameTabGroup`, `regroupAllTabs`, `removeDuplicateTabs`, `closeTabsWithSound`.
- **탐색 및 검색**: `openUrl`, `searchGoogle`, `getActiveTab`, `getActiveTabContent`.
- **지식 및 북마크**: `getBookmarks`, `searchBookmarks`, `createBookmark`, `getHistory`, `getRecentlyClosed`.
- **규칙 및 외관**: `getRules`, `createRule`, `updateRule`, `deleteRule`, `getActiveTheme`, `getSavedThemes`, `applyTheme`.

### 5.3 오염 추적 및 프롬프트 주입 방어
신뢰할 수 없는 웹 페이지로부터의 간접적인 프롬프트 주입 공격을 무력화하기 위해 에이전트 백엔드는 엄격한 오염 추적을 구현합니다:
- **오염 표시**: `getActiveTabContent`를 호출하면 웹 페이지에서 텍스트를 추출하고 현재 실행 실행을 오염된 상태로 표시합니다(`taintedAgentRuns.add(runId)`).
- **외부 유출 방지 가드 (Egress Guard)**: 오염된 실행은 외부 유출 도구(`AGENT_EGRESS_TOOLS`) 호출이 엄격히 금지됩니다:
  * `openUrl`, `searchGoogle`, `createBookmark`, `createRule`, `addUrlToRule`, `createSiteShortcut`, `updateSiteShortcut`, `updateRule`.
- **거부 메커니즘**: 처리되지 않은 예외를 던지는 대신 구조화된 보안 설명을 반환합니다. 그러면 LLM은 명시적인 사용자 동의 없이 외부 데이터를 유출할 수 없음을 사용자에게 알립니다.

### 5.4 예약된 Gemini 쿼리 서브시스템 (`GeminiScheduleModal.svelte`)
- **백그라운드 실행 엔진**:
  - `chrome.alarms`(`gemini-scheduled-*`)를 통해 백그라운드 서비스 워커 내에서 예약된 AI 프롬프트 실행을 직접 자동화합니다.
  - 하루 최대 6개의 예약된 쿼리를 지원합니다(`MAX_TIMES = 6`).
  - **예약 모드**:
    - 반복 예약: 선택한 요일(`selectedDays`)에 반복적으로 실행됩니다.
    - 일회성 예약: 특정 목표 날짜 및 시간(`formDate`)에 실행됩니다.
  - **프롬프트 제한**: 실시간 글자 수 카운터와 함께 엄격한 1,000자 프롬프트 제한(`MAX_QUERY_CHARS = 1000`)을 적용합니다.
  - **백그라운드 알림**: 백그라운드 쿼리가 완료되면 미리보기 스니펫이 포함된 데스크톱 알림을 트리거합니다. 알림을 클릭하면 사이드패널 채팅 내에서 해당 응답 스레드가 즉시 열립니다.

### 5.5 Gemini 대화 관리 및 내보내기
- **영속적 IndexedDB 스토리지 (`geminiConversations`)**: 멀티턴 채팅 세션은 IndexedDB `Intelligent_Workspace`의 `geminiConversations` 저장소에 저장됩니다.
- **전체 텍스트 기록 검색**: Omnibar 명령 `lai:`(대화 탐색) 및 `laiq:`(메시지 검색)을 통해 모든 이전 대화 및 개별 메시지 전반에서 즉각적인 검색을 제공합니다.
- **4가지 내보내기 형식**:
  1. **스타일이 적용된 HTML**: 스타일이 적용된 대화 말풍선, 역할 배지, 타임스탬프 및 구문 강조 표시된 코드 블록이 포함된 독립형 서식 지정 HTML 문서.
  2. **원시 JSON**: 메시지 배열, 토큰 사용량, 모델 구성 및 검색 인용 정보를 포함한 완전한 구조화된 데이터 덤프.
  3. **Markdown**: 헤더, 타임스탬프 및 펜스 코드 블록(` ``` `)으로 서식이 지정된 표준 Markdown 파일.
  4. **일반 텍스트**: 이메일이나 메모에 적합한 서식 없는 깔끔한 대화 기록.
- **그라운딩 메타데이터 추적**: Google 검색 그라운딩에서 반환된 모델 ID, 토큰 사용 통계, 실행 타임스탬프 및 출처 인용 정보를 추적합니다.

### 5.6 멀티모달 입력 및 파일 첨부 (`feature_geminiAttachFiles`)
- **멀티모달 첨부 파일**: 토글 `feature_geminiAttachFiles`를 통해 채팅 프롬프트에서 이미지 및 문서 첨부를 직접 지원합니다:
  - 이미지 파일 (JPEG, PNG, WebP, HEIC/HEIF).
  - PDF 문서 및 연구 논문.
  - 일반 텍스트 파일 및 코드 파일.
  - CSV 구조화된 데이터셋.
- **음성 지원**:
  - 핸즈프리로 프롬프트를 받아쓰기 위한 Web Speech STT (음성-텍스트 변환).
  - 응답을 소리 내어 읽어주는 Web Speech TTS (텍스트-음성 변환).

### 5.7 호출 방식
- **사이드패널 라우트**: `?view=gemini` 또는 단축키 `pa`.
- **페이지 내 Omnibar 접두사**:
  - `qai: <query>` — 구성된 Gemini 모델에 직접 질문.
  - `qaia: <prompt>` — 도구 실행을 통해 자율형 에이전트로 프롬프트 실행.
  - `lai:` — 이전 AI 대화 기록 탐색.
  - `laiq:` — AI 대화 메시지 전체 텍스트 검색.
- **Omnibox AI 탭 검색 (`find <query>`)**:
  - URL 표시줄 키워드 `find`로 하이브리드 검색을 시작합니다.
  - 정규식 단어 경계 점수 계산과 Gemini 시맨틱 해석을 결합하여 자연어 쿼리를 기반으로 열려 있는 탭을 찾고 포커스합니다.

## 6. 섹션 5: 노트 보기 및 지식 관리 (Ver Notas)

브라우저 탭 그룹 및 탐색 컨텍스트에 긴밀히 연결된 로컬 우선 컨텍스트 인식 노트 작성 엔진입니다.

### 6.1 스토리지 아키텍처 (`notesStore`)
IndexedDB 데이터베이스 `Intelligent_Workspace` (v8)의 `notesStore` 객체 저장소에 저장됩니다:
```typescript
interface NoteRecord {
  id: string;          // 고유 노트 식별자.
  title: string;       // 노트 제목.
  text: string;        // 서식 있는 텍스트 HTML, Markdown 또는 직렬화된 작업 페이로드.
  type: NoteType;      // 'text' | 'checklist' | 'kanban'
  url?: string;        // 노트가 생성된 원본 URL.
  contextKey: string;  // 노트를 작업 공간 계층에 바인딩하는 스코프 키.
  createdAt: number;   // 생성 타임스탬프.
  modifiedAt: number;  // 마지막 수정 타임스탬프.
  isPersistent: boolean; // 그룹 삭제 정리로부터 노트를 보호하는 고정 플래그.
}
```

### 6.2 특화된 노트 형식 및 고급 렌더링
1. **텍스트 노트 (`NoteTextEditor.svelte`)**:
   - 서식 있는 텍스트 `contenteditable` 입력 영역.
   - 미디어 직접 임베드: 이미지, 오디오, 비디오 및 PDF 문서.
   - 내장 HTML 살균(sanitization) 및 실시간 단어/글자 수 카운터.
   - **Mermaid 다이어그램 렌더링**: Markdown 펜스(` ```mermaid `)에서 플로우차트, 시퀀스 다이어그램, 클래스 다이어그램 및 상태 머신을 직접 동적으로 렌더링.
   - **KaTeX 수학적 LaTeX**: 인라인 수식(`$...$`) 및 블록 수식(`$$...$$`)을 고정밀 타이포그래피로 렌더링.
2. **체크리스트 노트 (`NoteChecklistEditor.svelte`)**:
   - 개별 완료 체크박스가 포함된 대화형 작업 목록.
   - 키보드 기반 항목 재정렬 및 진행 상황 추적 지원.
3. **Kanban 노트 (`NoteKanbanEditor.svelte`)**:
   - 3개 열 워크플로 보드: `To Do` -> `In Progress` -> `Done`.
   - 신속한 작업 상태 전환을 위한 순환 상태 칩.
- **동적 무손실 변환**: 텍스트, 체크리스트, Kanban 표현 간에 데이터 손실 없이 자유롭게 변환됩니다.

### 6.3 스코프 및 컨텍스트 계층 구조
노트는 `contextKey`를 통해 브라우징 컨텍스트에 바인딩됩니다:
- **그룹 스코프 (`g_<groupId>` 또는 `g_<groupKey>`)**: 탭 그룹 전체에 연결됨.
- **하위 그룹 스코프 (`s_<groupId>_<domain>`)**: 탭 그룹 내의 특정 도메인에 연결됨.
- **그룹 해제 스코프 (`g_ungrouped` / `s_ungrouped_<domain>`)**: 탭 그룹 외부의 탭에서 생성된 노트.
- **Pomodoro 및 일반 스코프 (`pomodoro`, `general`)**: 작업 공간 전역 노트.
- **고아 노트 감지 엔진 (Orphan Detection Engine)**: 탭 그룹 또는 도메인이 삭제되면 연결된 비영속 노트가 고아 감지기에 의해 캡처됩니다. 해당 노트는 UI에서 재할당하거나 삭제할 수 있도록 접근 가능한 상태로 유지됩니다.

### 6.4 호출 방식
- **UI 실행기**: 그룹 카드 및 하위 그룹 카드의 "View Notes" 버튼, 팝업 헤더의 "Quick Notes" 버튼, 사이드패널 라우트 `?view=notes` (`pk`).
- **컨텍스트 메뉴 트리거**: 웹 페이지에서 텍스트 선택 -> 우클릭 -> "Crear Nota desde Selección" (`note-from-selection`). 선택한 텍스트를 자동으로 추출하고 가장 가까운 `h1`-`h3` 제목을 노트 제목으로 설정합니다.
- **Vim 힌트**: `ao`는 현재 선택 항목에서 노트를 생성합니다.
- **Omnibar**: `lnt:`는 즉각적인 전체 텍스트 검색을 지원하는 노트 브라우저를 엽니다.
- **오디오 낭독**: 편집기 내 TTS 버튼을 사용하여 Web Speech API로 노트 내용을 소리 내어 읽어줍니다.

## 7. 섹션 6: 미디어 및 갤러리 보기 (Ver Galería)

고성능 미디어 캡처, 주석 달기 및 광학 문자 인식(OCR) 파이프라인입니다.

### 7.1 캡처 모드 및 엔지니어링 (전체 7가지 캡처 유형)
확장 프로그램은 단일 탭, 다중 탭, 자르기 및 팔레트 작업을 포괄하는 7가지 특화된 캡처 방식을 구현합니다:
1. **`visible` (표시 영역 뷰포트 캡처 - `cs`)**:
   - `chrome.tabs.captureVisibleTab`을 사용하여 활성 탭의 정확한 표시 뷰포트를 캡처합니다.
   - 캡처 결과를 IndexedDB `screenshots` 저장소에 자동으로 커밋하고 이미지 비트맵을 시스템 클립보드에 직접 복사합니다(`screenshotSavedAndCopied`).
2. **`fullPage` (원활한 전체 페이지 스크롤 캔버스 - `cp`)**:
   - 프로그래밍 방식의 페이지 스크롤을 실행하여 문서의 총 스크롤 높이를 계산합니다.
   - 시각적 끊김 현상을 제거하기 위해 초기 세그먼트 이후 스크롤바를 억제하고 고정/스티키 내비게이션 바를 숨깁니다.
   - Chromium 규격을 준수하는 프레임 캡처 간 600ms 지연을 적용하여 최대 30,000px 높이의 `OffscreenCanvas`에 비트맵 조각을 이어 붙입니다(`captureFullPageDataUrl`).
3. **`fullPageParts` (순차 분할 세그먼트 - `cpp` / `cP`)**:
   - 긴 문서를 순차적인 개별 뷰포트 높이 이미지 파트로 분할하여(`captureFullPageParts`), 페이지 매김을 위해 번호가 매겨진 이미지 덩어리를 최대 60개까지 생성합니다.
4. **`area` (대화형 직사각형 드래그 자르기 - `ca`)**:
   - `area-selector.js`를 주입하여 실시간 경계 상자 치수가 표시되는 십자선 캔버스를 오버레이합니다.
   - 드래그 가능한 선택 핸들, 치수 툴팁, 확인 트리거, `Esc` 키 취소 및 다중 탭 자르기 큐 등록(`handleCaptureAreaFromShortcut`).
5. **`groupTabs` (활성 그룹 탭 일괄 연속 캡처 - `Cs`, `Cp`, `CP`)**:
   - 활성 탭 그룹 내의 모든 탭을 순차적으로 순회합니다(`handleCaptureGroupFromShortcut`).
   - 표시 영역, 전체 페이지 또는 분할 파트 모드로 일괄 캡처를 지원하며 통합 컬렉션으로 컴파일합니다.
6. **`omnibarPickedTabs` (사용자 지정 다중 탭 큐 캡처)**:
   - Omnibar 명령 `cs:`, `cp:`, `cpp:` 또는 `ca:`를 통해 시작됩니다(`handleCaptureTabs`).
   - 사용자가 필터링한 모든 탭에서 순차적 캡처를 실행하고 실시간 진행률 표시기를 제공합니다.
7. **`colorPickerCapture` (백그라운드 화면 스포이트 대체 동작)**:
   - 네이티브 `window.EyeDropper` 지원이 없는 운영 체제(예: Linux)에서 정밀 16진수 스포이트 돋보기 도구를 지원하기 위해 백그라운드 화면 캡처를 수행합니다.

### 7.2 갤러리 UI 및 영속성
- **인터페이스**: 라이트박스 확대/축소, 이동 및 회전 도구를 갖춘 반응형 매스너리/그리드 레이아웃.
- **영속성 (`screenshots` 저장소)**: IndexedDB `Intelligent_Workspace`에 저장됩니다. 고정되지 않은 캡처는 유지 관리 중에 자동으로 정리되며, 핀 아이콘을 클릭하면(`isPersistent = true`) 캡처가 영구적으로 보존됩니다.

### 7.3 내보내기, 브라우저 내 OCR 및 외부 마크업
- **내보내기 형식 (`captureDownloadFormats`)**:
  - 고효율 형식: PNG, WebP, AVIF.
  - `pdf.js`를 통한 다중 페이지 컴파일 PDF 문서 내보내기.
- **온디바이스 WASM OCR**:
  - 사전 로드된 스페인어 및 영어(`spa+eng`) 언어 모델을 활용하는 브라우저 내 Tesseract.js WebWorker.
  - 네트워크로 이미지 데이터를 전송하지 않고 텍스트를 클립보드로 직접 추출합니다.
- **직접 전송 통합**:
  - 추출된 OCR 텍스트 또는 이미지 첨부 파일을 노트(`notesStore`) 또는 Gemini AI 프롬프트(`feature_geminiAttachFiles`)로 원클릭 전송.
- **Excalidraw 마크업**: 자유형 드로잉, 화살표 및 벡터 주석을 위해 캡처된 이미지를 `https://excalidraw.com/`으로 직접 전송하는 원클릭 내보내기 지원.

### 7.4 호출 방식
- **UI**: 그룹 카드의 카메라 버튼, 팝업의 빠른 작업, 사이드패널 갤러리 라우트 `?view=gallery` (`ps`).
- **Vim 힌트**: `cs` (표시 영역), `cp` (전체 페이지), `cP` (분할 파트), `ca` (영역 자르기), `Cs` (그룹 표시 영역), `Cp` (그룹 전체 페이지), `CP` (그룹 분할 파트).
- **Omnibar 접두사**: `cs:`, `cp:`, `cpp:`, `ca:`, `limg:` (갤러리 탐색).

## 8. 섹션 7: Pomodoro 및 타이머 스위트 (Pomodoro)

브라우저 절전 주기 전반에 걸쳐 절대적인 정확성을 보장하도록 설계된 집중 및 타이밍 스위트입니다.

### 8.1 타이밍 엔진 및 백그라운드 아키텍처
- **제로 드리프트 타임스탬프 연산**: 상태는 절대 Unix 타임스탬프(`startTime`, `pausedAt`)와 함께 `chrome.storage.local`에 유지됩니다. 서비스 워커 종료, 브라우저 재시작, 운영 체제 절전 상태가 발생해도 시간 오차가 전혀 발생하지 않습니다.
- **알람 디스패처**:
  - `chrome.alarms`로 구동되는 고해상도 카운트다운 틱커(`pomodoroTick` 1초 간격).
  - `itg-periodic-tasks`(1분 간격)에 의해 관리되는 백그라운드 유지 관리 및 장기 간격 점검.
- **오프스크린 오디오 차임 (`offscreen.html`)**: 오디오 차임은 `AUDIO_PLAYBACK` 이유로 생성된 전용 Chrome 오프스크린 문서를 통해 생성됩니다. 사운드가 완료된 후 메모리를 절약하기 위해 3.5초 후에 자동으로 닫힙니다.

### 8.2 포괄적인 4가지 타이밍 모드
1. **Pomodoro (`pomodoro`)**:
   - 작업 시간: 1~180분 (기본값: 25분).
   - 짧은 휴식: 1~120분 (기본값: 5분).
   - 긴 휴식: 1~180분 (기본값: 15분).
   - 긴 휴식 전 사이클 수: 1~12사이클 (기본값: 4).
   - 목표 사이클 수: 1~99사이클 (기본값: 8).
   - 작업 자동 시작, 휴식 자동 시작 및 알림 알림 구성 가능.
2. **스톱워치 (`cronometro`)**: 랩 기록 및 일시 정지 후 정지 기능을 갖춘 점진적 타이머.
3. **카운트다운 (`temporizador`)**: 시, 분, 초를 지정하는 사용자 정의 카운트다운 타이머.
4. **목표 시간 알람 (`tiempo`)**: 달력 날짜 선택기 및 시계 선택기를 통해 미래의 정확한 타임스탬프에 알람을 설정.

### 8.3 페이지 내 플로팅 타이머 위젯
- 웹 페이지 위에 직접 실시간 카운트다운, 일시 정지/재개 및 건너뛰기 버튼을 표시하는 드래그 가능한 미니멀 오버레이.
- 확장 프로그램 패널이나 팝업으로 다시 전환하지 않고도 집중 세션을 모니터링할 수 있습니다.

### 8.4 그룹 비활성 자동 접기 타이머
- 집중 루틴과 연동되어 1분 동안 비활성 상태인 비활성 그룹(`INACTIVITY_THRESHOLD_INACTIVE_GROUP`)과 15분 동안 비활성 상태인 활성 그룹(`INACTIVITY_THRESHOLD_ACTIVE_GROUP`)을 자동으로 접습니다. 0분에서 1440분까지 구성 가능합니다.

### 8.5 프로젝트 태깅 및 메타데이터
각 세션은 분류 메타데이터를 지원합니다:
- 프로젝트 이름 (최대 18자)
- 프로젝트 태그 (예: `#research`, `#dev`)
- 프로젝트 폴더 (예: `/client/project`)

### 8.6 분석 엔진 및 19개 KPI 카드
전체 대시보드(`dashboard.html` 또는 사이드패널 `dashboard.html?context=sidepanel`)는 중복 제거된 세션(`sessionStarted` 기준 `dedupeSessions`)에서 19개의 핵심 성과 지표를 계산합니다:
1. `focus`: 총 집중 시간.
2. `sessions`: 총 완료된 세션 수.
3. `cycles`: 총 완료된 작업 사이클 수.
4. `efficiency`: 평균 효율성 백분율 (`총 집중 시간 / 총 시간 * 100`).
5. `activeDays`: 고유 활성 일수.
6. `break`: 총 휴식 시간.
7. `interruptions`: 수동 일시 정지/방해의 총 횟수.
8. `interruptionTime`: 일시 정지 상태에서 보낸 누적 시간.
9. `bestSession`: 중단 없는 가장 긴 단일 집중 세션.
10. `avgFocus`: 완료된 사이클당 평균 집중 시간.
11. `totalTime`: 작업 및 휴식에 소요된 누적 시간.
12. `workRest`: 작업 시간 대 휴식 시간 비율 (`1 : X`).
13. `distractionRate`: 집중 시간당 방해 횟수.
14. `bestDay`: 요일 중 가장 생산적인 날.
15. `goldenHour`: 하루 중 최고 집중 시간대 간격 (예: `10:00 - 11:00`).
16. `projects`: 추적된 서로 다른 프로젝트 수.
17. `avgIntDuration`: 각 방해의 평균 지속 시간.
18. `topProject`: 누적 집중 시간이 가장 높은 프로젝트.
19. `focusIntensity`: 활성 일당 평균 집중 시간.

추가적인 시각적 분석에는 일별 연속 달성 히트맵(Day Streak Heatmap) 달력, 시간대별 집중 분포 막대 차트, 프로젝트 다양성 분석, 완전한 JSON 데이터 가져오기/내보내기가 포함됩니다.

## 9. 섹션 8: 활동 및 방문 기록 패널 (Panel de Actividad)

Declarative Net Request (DNR) 기반의 추적, 분석 및 웹 거버넌스 엔진입니다.

### 9.1 데이터 엔진 및 스토리지 토폴로지 (`ITG_WEB_ACTIVITY`)
`ITG_WEB_ACTIVITY` 아래에서 관리됩니다:
- `wa:day:YYYY-MM-DD`: 일별 도메인 카운터 (`{ domains: { host: { t: seconds, v: visits, s: sessions, h: { hour: seconds } } } }`).
- `wa:days`: 기록된 날짜 키의 마스터 인덱스 배열.
- `wa:recent`: 최근 400개의 방문 타임라인 항목을 저장하는 링 버퍼.
- `wa:openSegment`: `chrome.storage.session`의 활성 시간 측정 세그먼트로, 유휴 이벤트를 발생시키지 않고 컴퓨터가 절전 모드로 전환될 때 통계가 왜곡되는 것을 방지하기 위해 `WA_MAX_SEGMENT_SECONDS = 900s`(15분)로 제한됩니다.
- **유휴 상태 감지**: `chrome.idle`을 사용합니다(기본값: 300초 / 5분). `countAudible = true`인 경우 창에 포커스가 없어도 오디오 재생 중에는 활성 추적이 유지됩니다.
- **보존 기간**: `retentionDays`(기본값: 180일)보다 오래된 일일 레코드를 자동으로 정리합니다.

### 9.2 Declarative Net Request (DNR) 사이트 차단기
- **동적 규칙 할당**: ID 범위 `9000`에서 `9999`까지 동적 규칙을 할당합니다.
- **리디렉션 대상**: 차단된 요청은 `src/ui/pages/web-activity/blocked.html?d=<domain>&u=\1`로 리디렉션됩니다.
- **열린 탭 일괄 검사**: 사이트 제한 시간이 만료되면 백그라운드 워커는 해당 도메인과 일치하는 열려 있는 기존 탭을 즉시 검사하여 리디렉션합니다.
- **자정을 넘나드는 스케줄 지원**: 자정을 넘나드는 스케줄(예: `22:00`부터 `02:00`까지)은 날짜 경계를 넘어 자동으로 평가됩니다.
- **유예 / 스누즈 시간 (+5분)**: 차단 화면에서 임시 5분 스누즈 패스를 허용하며, 이는 `wa:snoozeUses`에서 추적됩니다.

### 9.3 비대칭 보안 잠금 (`blockLock.js`)
사이트 제한은 비대칭 비밀번호 잠금으로 보호할 수 있습니다:
- **해시 스토리지**: 무작위 16바이트 솔트와 SHA-256 16진수 다이제스트를 저장합니다(`wa:settings.blockPassword`).
- **비대칭 규칙 정책**: 새로운 제한을 생성하거나 규칙을 더 엄격하게 만들 때(예: 허용 시간 단축 또는 일정 제한 추가)는 비밀번호가 **절대 요구되지 않습니다**.
- **보호 대상 작업**: 비밀번호는 **규칙을 완화할 때**(제한 삭제, 허용 시간 증가, 일정 비활성화) 또는 일일 무료 임계값(`snoozePasswordAfter`)을 초과한 후 스누즈를 호출할 때만 요구됩니다.

### 9.4 분류 및 시각적 분석
- **16가지 내장 카테고리**: `social`, `video`, `music`, `news`, `shopping`, `reading`, `entertainment`, `dev`, `work`, `education`, `games`, `finance`, `mail`, `ai`, `search`, `other`.
- **사용자 정의 카테고리**: `custom:` 접두사가 붙은 사용자 정의 카테고리를 지원합니다.
- **집중도 비율**: 생산적 카테고리(`dev`, `work`, `education`, `reading`, `finance`, `mail`)와 주의 분산 카테고리(`social`, `video`, `games`, `shopping`, `entertainment`)를 대조 분석합니다.
- **시각화**: Chart.js 시간별 활동 분포, 카테고리 도넛 차트 분석 및 도메인 순위 목록.

### 9.5 다운로드 관리자 서브시스템 (`switchMainView('downloads')`)
- **전용 라우트**: `switchMainView('downloads')` (`?view=downloads`)를 통해 사이드 패널에서 접근합니다.
- **직접 Chrome API 통합**: `chrome.downloads`를 후킹하여 모든 브라우저 다운로드를 실시간으로 추적, 관리 및 검사합니다.
- **실시간 퍼지 검색**: 파일 이름, 파일 경로 또는 다운로드 소스 URL로 즉시 검색할 수 있습니다.
- **상태 필터 칩**: 상태별로 다운로드를 신속하게 필터링: `All`, `In Progress`, `Complete`, `Paused`, `Interrupted`.
- **달력 날짜 범위 필터링**: 특정 날짜 또는 시간 간격으로 다운로드를 좁혀서 조회합니다.
- **배치 그룹 다운로더**: 활성 그룹에서 열려 있는 탭의 모든 다운로드 링크를 추출하고 진행 상황 추적과 함께 동기화된 일괄 다운로드를 시작합니다.
- **파일 관리**: 원클릭 직접 파일 열기(`chrome.downloads.open`) 및 폴더 열기(`chrome.downloads.show`).

### 9.6 최근 닫은 탭 및 브라우징 기록 서브시스템
- **최근 닫은 탭 보기**:
  - `chrome.sessions.getRecentlyClosed`와 직접 통합되었습니다.
  - 발음 구별 부호 및 악센트 자동 정규화(`deaccent`)가 적용된 실시간 검색.
  - 클릭 한 번 또는 Omnibar 명령 `c:`를 통해 단일 탭 복원 및 전체 창 세션 복원을 지원합니다.
- **브라우징 기록 보기**:
  - 불필요한 `chrome.history.search` 쿼리 낭비를 제거하기 위해 10초 TTL 메모리 내 캐싱이 적용된 심층 검색.
  - 도메인, 키워드 및 달력 날짜 범위별로 검색 필터링 가능.
  - 이미 열려 있는 경우 원클릭 탭 활성화 또는 새 탭 생성이 가능하며, Omnibar `h:`를 통해 접근할 수 있습니다.

### 9.7 테마 예약 서브시스템 (`ThemeScheduleModal.svelte`)
- **자동 테마 예약**:
  - 테마 사이드 패널 보기(`?view=themes` / `pt`) 내부의 `ThemeScheduleModal.svelte`를 통해 관리됩니다.
  - 하루 중 시간대(`HH:MM`) 및 활성 요일(`[0..6]`)을 기준으로 자동 테마 전환을 지원합니다.
  - 최대 7개의 글로벌 테마 일정 지원(`MAX_GLOBAL_SCHEDULES = 7`).
  - **자동 복원**: 지정된 완료 시간에 기본 주간 테마 또는 업무 테마로 자동 복귀합니다.
  - **데스크톱 알림**: 자동 테마 전환이 발생할 때 데스크톱 알림을 발송합니다(`chrome.notifications`).
  - **이중 영속화**: `chrome.storage.sync`(로밍 환경설정) 및 `chrome.storage.local`의 `savedThemes` 및 `themeSchedules` 아래에 유지됩니다.

### 9.8 컴팩트 사이드패널 보기
- **사이드패널 라우트 (`?view=activity` / `pw`)**: 기간 선택 칩(`Today`, `7d`, `30d`, `All`)과 도메인 제한 진행률 표시줄을 갖춘 실시간 모니터링에 최적화된 350px 컬럼 뷰입니다.

### 10.2 사이드패널 내비게이션 라우트 (`?view=...`)

- `?view=downloads` — 다운로드 관리자 및 일괄 링크 다운로더 (`switchMainView('downloads')`).

### 10.6 컨텍스트 메뉴 트리 계층 구조 (전체 5개 그룹 및 30개 이상의 작업)
컨텍스트 메뉴는 5개의 기능 명령 그룹으로 구성된 완전한 계층 트리를 제공합니다:
1. **그룹 1: 규칙 및 URL 하위 메뉴**:
   - 마스터 규칙 체크박스 토글 ("Activar/Desactivar Todas las Reglas").
   - 개별 커스텀 규칙을 즉석에서 활성화하거나 비활성화할 수 있는 규칙별 토글.
   - "Abrir Todas las URLs": 선택한 규칙에 등록된 모든 대상 URL을 엽니다.
   - 동적 열린 탭 개수 `[N]`가 표시되는 개별 URL 하위 메뉴: URL과 일치하는 현재 열려 있는 탭 수를 표시하고, URL로의 원클릭 탐색을 제공하며, 일치하는 모든 탭을 닫을 수 있는 "Cerrar Pestañas para esta URL"을 제공합니다.
   - 빠른 규칙 생성: "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa".
   - 기존 규칙에 추가: "Añadir a Regla Existente" -> 규칙 선택 -> "Añadir Raíz del Sitio" / "Añadir URL Completa".
2. **그룹 2: 탭 정리 및 오디오 제어**:
   - "Eliminar Pestañas Duplicadas [N]": 감지된 중복 탭 수를 표시하고 창 전체에서 닫습니다.
   - "Eliminar Pestañas por Dominio": 열린 탭 수 `[N]`가 포함된 모든 도메인을 나열하는 동적 하위 메뉴로, 도메인별 정밀 탭 닫기가 가능합니다.
   - "Cerrar Todos Excepto el Grupo Activo": 활성 포커스 그룹을 유지하고 다른 모든 그룹을 닫습니다.
   - "Reagrupar Todas las Pestañas": 열려 있는 모든 탭에 대해 전체 백그라운드 재그룹화 과정을 트리거합니다.
   - "Silenciar Todas las Pestañas" / "Reactivar Sonido en Todas las Pestañas": 전역 오디오 음소거 및 음소거 해제 컨트롤.
3. **그룹 3: 읽기, 선택 및 메모**:
   - "Leer Página en Voz Alta" (TTS): 오버레이 컨트롤이 포함된 전체 페이지 텍스트 음성 변환 리더.
   - "Leer Selección en Voz Alta": 음성 합성을 사용하여 강조 표시된 DOM 선택 항목을 소리 내어 읽습니다.
   - "Crear Nota desde Selección": 텍스트 선택 항목을 추출하고 가장 가까운 제목(`h1`-`h3`)에서 노트 제목을 자동으로 도출하여 `notesStore`에 저장합니다.
4. **그룹 4: 확장 프로그램 열기, PiP 및 패널**:
   - "Abrir como PiP" / "Abrir como Ventana Emergente": 대상 페이지, 강조 표시된 선택 항목 또는 대상 이미지를 플로팅 Picture-in-Picture 또는 독립형 팝업 창으로 시작합니다.
   - "Abrir Extensión": 확장 프로그램 팝업을 열거나 사이드 패널을 펼칩니다.
   - "Gestionar Reglas": 전용 브라우저 탭에서 전체 규칙 관리자를 엽니다.
   - 사이드패널 직접 실행기: List Groups(`?view=listgroup`), 테마(`?view=themes`), AI 어시스턴트(`?view=gemini`), 힌트 사용자 지정(`?view=hints`)으로 원클릭 라우팅.
5. **그룹 5: 설정 및 클러스터링 옵션**:
   - **그룹 관리 (Gestión de Grupos)**: Alternar Grupo Actual (활성 그룹 접기 토글), Alternar Todos los Grupos (모든 그룹 접기 토글).
   - **그룹화 옵션 (Opciones de Agrupación)**:
     - 스마트 그룹화 (Agrupación Inteligente: 자동 휴리스틱 클러스터링 토글).
     - 컴팩트 모드 (Modo Compacto: 한 글자 그룹 제목 모드 토글).
     - 도메인 / 서브도메인 (Dominio / Subdominio: 도메인 및 서브도메인 그룹화 토글).
     - 특수 페이지 (Páginas Especiales): Chrome 페이지 (`chrome://`), 로컬 파일 (`file:///`), 확장 프로그램 (`chrome-extension://`), 기타 (`Misc`), IP 주소 & Localhost.
   - **일반 옵션 (Opciones Generales)**:
     - 알파벳순 정렬 (Ordenar Alfabéticamente: 탭 스트립 전반에 걸쳐 알파벳순 정렬 적용).
     - 기타 배치 (Ubicación Miscelánea): 시작 (`start`), 끝 (`end`), 알파벳순 (`alpha`).
     - 자동 접기 타이머 (Temporizador de Auto-Colapso: 유휴 그룹 접기 타이머 토글).
     - 시각적 접두사 (Prefijos Visuales: `🔒`, `🔍`, `🗝️`, `⚠️` 상태 마커 토글).
     - 링크 미리보기 (Vista Previa de Enlaces: 페이지 내 링크 미리보기 모달 토글).

## 11. 스토리지 스키마 및 데이터 영속성

이 확장 프로그램은 IndexedDB 및 Chrome Storage API 전반에 걸쳐 다중 계층 스토리지 모델을 사용합니다:

### 11.1 IndexedDB 데이터베이스: `Intelligent_Workspace` (스키마 버전 8)
1. `screenshots`: keyPath: `'id'`, autoIncrement: true. 보조 인덱스: `'createdAt'`. 바이너리 스크린샷, 캔버스 데이터 URL, 고정 플래그, 크기 및 세그먼트 총 인덱스를 저장합니다.
2. `geminiConversations`: keyPath: `'id'`, autoIncrement: true. 보조 인덱스 0개 (ID로 검색/관리). 멀티턴 채팅 스레드, 메시지 역할, 토큰 지표 및 검색 그라운딩 메타데이터를 저장합니다.
3. `notesStore`: keyPath: `'id'`, autoIncrement: false. 보조 인덱스 0개 (contextKey로 메모리에서 필터링). 서식 있는 텍스트, 체크리스트 배열, Kanban 보드 카드, Mermaid 사양 및 KaTeX 수식을 저장합니다.
4. `backupsGroups`: keyPath: `'group.id'`. 보조 인덱스 0개 (중첩된 `'group.id'`로 키 지정된 백업 그룹 객체 저장). 압축된 그룹 구조, 색상, 제목 및 닫힌 탭 레코드를 저장합니다.
5. `pomodoroStats`: keyPath: `'id'`, autoIncrement: true. 보조 인덱스: `'projectName'` (keyPath `'projectName'`) 및 `'savedAt'` (keyPath `'savedAt'`) (`date` 인덱스 없음). 집중 분석 데이터, 사이클 지표 및 방해 로그를 유지합니다.

### 11.2 Chrome Storage 이중 라우팅 (`StorageService`)
- `chrome.storage.sync`(사용자 기기 간 포터블 설정용)와 `chrome.storage.local`(대용량 환경설정용) 간의 읽기 및 쓰기를 동적으로 라우팅합니다.
- 주요 모델:
  - `customRules`: 규칙 정의 배열 (`[{ name, color, active, urls }]`).
  - `clusterConfig`: 자동 클러스터링 매개변수 (임계값, 컴팩트 모드, 특수 카테고리).
  - `userPrefixes`: 이모지 접두사 할당 (`{ lock, openKey, loupe, checked, warning }`).
  - `activeTheme`, `savedThemes`, & `themeSchedules`: `ThemeScheduleModal.svelte`를 통해 구성된 9가지 팔레트 색상 구성 및 예약된 순환 규칙.
  - `pomodoroState`: 실시간 세션 타임스탬프, 일시 정지 시간 및 사이클 목표.
  - `wa:settings` & `wa:limits`: 웹 활동 추적 환경설정, 사이트 제한 및 스케줄 윈도우.
  - `youtubeLoopEnabled`: YouTube 및 Shorts 반복 버튼을 제어하는 부울 플래그.

### 11.3 Chrome Storage Session (`chrome.storage.session`)
초고속 임시 런타임 조율을 위해 사용됩니다:
- `tabsEverActive`: 현재 브라우저 세션 중에 활성화된 탭 ID 집합.
- `groupExpandedEver`: 현재 세션 중에 확장된 그룹의 기록.
- `groupInfoMap`: 그룹 ID를 동적 제목 및 클러스터링 유형에 매핑하는 실시간 레지스트리.
- `splitScreenState`: 원래 화면 크기를 복원하기 위한 캐시된 창 범위.
- `contextMenusSignature`: 빠른 탭 전환 중 불필요한 컨텍스트 메뉴 재구축 오버헤드를 방지하는 해시 시그니처.
- `wa:openSegment`: 현재 활성 웹사이트 시간 세그먼트.
- `hiddenYoutubeView`: `HiddenGroupsBar.svelte`에 도킹된 주차된 YouTube 플레이어 보기에 대한 참조.

## 12. 방어적 엔지니어링 및 예외 상황 처리

1. **Declarative Net Request 헤더 차단 해제 (`dnr.js`)**:
   - 외부 사이트가 사이드 패널 및 Picture-in-Picture iframe에서 렌더링될 수 있도록 동적 DNR 규칙을 통해 응답 헤더를 수정하여 `X-Frame-Options` 및 제한적인 `Content-Security-Policy` 헤더를 제거합니다.
   - **WhatsApp Web 안전성**: `web.whatsapp.com`의 WebAssembly Signal 암호화 구현이 손상되지 않도록 `Cross-Origin-Opener-Policy`(COOP) 및 `Cross-Origin-Embedder-Policy`(COEP)를 명시적으로 보존합니다.
2. **우클릭 및 선택 차단 해제기 (`allowRightClickHook.js`)**:
   - 복사, 붙여넣기, 컨텍스트 메뉴 및 텍스트 선택을 차단하는 악성 웹사이트를 무력화합니다.
   - `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown`, `mouseup`에서 `preventDefault()` 및 `stopPropagation()`을 가로채기 위해 `MAIN` 환경에서 실행됩니다.
   - `MutationObserver`를 통해 인라인 `oncontextmenu="return false"` 핸들러를 제거합니다.
   - 취소된 붙여넣기 이벤트를 다시 주입하기 전에 클립보드 내용을 확인함으로써 정상적인 웹 애플리케이션(예: Telegram Web, Google Docs)을 보호합니다.
3. **YouTube 마우스 오버 미리보기 오디오 강제 음소거 재정의 (`youtubePreviewAudioHook.js`)**:
   - `ytd-video-preview #inline-preview-player`의 `MAIN` 환경에서 실행됩니다.
   - 마우스 오버 시 대상 `<video>` 요소의 `HTMLMediaElement.prototype.muted` 프로퍼티 디스크립터를 재정의합니다.
   - YouTube의 내부 `volumechange` 강제 음소거 경쟁 상태를 제거하여 마우스 오버 중 루프가 다시 시작되어도 음소거 해제 상태를 지속적으로 유지합니다.
4. **YouTube Shorts 피드 시퀀스 탐색 훅 (`youtubeShortsFeedHook.js`)**:
   - `ytd-shorts`의 `MAIN` 환경에서 실행됩니다.
   - 확장 프로그램의 격리된 환경에서는 보이지 않는 `shortsProcessedSequence` 프로퍼티를 가로채고, 페이지를 새로고침하거나 플로팅 창 상태를 잃지 않고 `ytd-app`에 네이티브 `yt-navigate` 이벤트를 디스패치합니다.
5. **무한 스크롤 캔버스 보호**:
   - 메모리 부족으로 인한 브라우저 탭 충돌을 방지하기 위해 전체 페이지 스크린샷 탐색을 최대 60개 세그먼트(`MAX_FULL_PAGE_SEGMENTS`) 및 최대 30,000px 캔버스 높이(`MAX_FULL_PAGE_CANVAS_PX`)로 제한합니다.
6. **Linux 화면 색상 선택기 스포이트 대체 동작**:
   - Chromium `window.EyeDropper` API가 없는 Linux 환경에서 실행될 때, 확장 프로그램은 `screen-color-picker.js`를 주입하여 RGB/HEX/HSL 계산 기능이 있는 9배율 픽셀 렌즈를 렌더링합니다.
7. **시작 세션 안정화 지연**:
   - 브라우저 실행 시 그룹 할당을 평가하기 전에 세션 탭과 창 상태가 안정화될 수 있도록 그룹 정리를 20초 동안 지연합니다(`groupsHaveSettledAfterStartup()`).
