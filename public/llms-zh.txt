# Intelligent Workspace

> Intelligent Workspace 是一款先进的 Manifest V3 浏览器扩展与高效率工作区环境，基于 Svelte、Vite 和 CRXJS 构建。它集成了智能标签页整理、基于规则与自动聚类、自主 AI Agent 执行（支持 Google Gemini Cloud API 与 Chrome Built-in Prompt API）、页面内 Vim 风格链接导航、41 个前缀的 Omnibar 命令系统、多格式笔记记录（富文本、清单、看板、Mermaid 图表、KaTeX 公式）、高保真媒体截取与浏览器内 WASM OCR、带零漂移闹钟及离屏音频播放的番茄钟计时套件，以及 Declarative Net Request (DNR) 网络活动计量、域名限制和网站屏蔽功能。

## 1. 架构基础与运行时生命周期

本扩展运行在 Google Chrome 的 Manifest V3 架构下，将持久化进程解耦分布于后台 Service Worker、沙箱化 UI 面板、离屏音频文档以及页面内 content script 覆盖层之中：

1. **Manifest 配置 (`manifest.json`)**：
   - **权限（21 项）**：`tabs`、`tabGroups`、`storage`、`favicon`、`contextMenus`、`notifications`、`sidePanel`、`scripting`、`downloads`、`downloads.open`、`system.display`、`declarativeNetRequestWithHostAccess`、`cookies`、`history`、`sessions`、`bookmarks`、`readingList`、`clipboardWrite`、`alarms`、`offscreen` 以及 `idle`。
   - **主机权限**：`["<all_urls>"]`。
   - **Service Worker**：`src/core/background.js`，采用同步 `importScripts` 模块化加载机制。
   - **工具栏操作**：有意省略了 `default_popup`。运行时强制执行 `chrome.action.setPopup({ popup: '' })`，确保 `chrome.action.onClicked` 同步触发，直接将 `chrome.sidePanel` 打开至用户固定的视图，消除弹出窗口初始化的延迟。
   - **Omnibox 关键字**：注册关键字 `"find"`。
   - **命令**：在 `commands` 下注册了 24 个系统级键盘快捷键。
   - **内容安全策略 (CSP)**：`script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`。

2. **进程间通信安全**：
   - `src/core/background/messaging.js` 对来自 content scripts 的消息执行显式白名单 (`ALLOWED_CONTENT_SCRIPT_ACTIONS`) 过滤。无特权的网页 frame 无法调用内部存储写入器、任意 Chrome API 或规则变更器。

3. **双重执行环境 (Worlds)**：
   - Content scripts 分别运行在 `ISOLATED`（扩展作用域）和 `MAIN`（页面执行作用域）两个环境中。例如 `allowRightClickHook.js`、`videoPipHook.js`、`youtubePreviewAudioHook.js` 和 `youtubeShortsFeedHook.js` 等脚本运行在 `MAIN` 环境中，以便拦截原型链方法、重写属性描述符并直接处理自定义事件。

## 2. 第 1 节：规则管理 (Gestionar Reglas)

规则管理子系统基于用户定义的严格确定性条件自动化执行标签页分组。

### 2.1 数据模式 (`CustomRule`)
每个自定义规则均遵循以下接口定义：
```typescript
interface CustomRule {
  name: string;        // 1 到 16 个字符。不能包含任何空白字符。
  color: RuleColor;    // 9 种颜色之一：'grey' | 'blue' | 'red' | 'yellow' | 'green' | 'pink' | 'purple' | 'cyan' | 'orange'
  urls: string[];      // 有效 URL、域名或主机名的数组。
  active: boolean;     // 启用或禁用规则计算的主开关。
  isStarred?: boolean; // 可选标志，将规则标记为收藏项以在 UI 中优先排序。
}
```

### 2.2 优先级架构
当标签页在 `src/core/background/groupManager.js` 中由 `groupTabs()` 处理时，将严格按照层级顺序依次评估分组层：
1. **自定义规则 (`applyCustomRules`)**：按规则出现顺序或用户优先级匹配已启用的自定义规则。一旦完成分组，标签页 ID 将注册至 `groupedTabIds` 并从后续层中排除。
2. **特殊系统分组**：拦截系统 URL 并归类至专用彩色分组：
   - `chrome://` 与内部浏览器页面
   - `file:///` 本地磁盘文件
   - `chrome-extension://` 扩展页面
   - IP 地址与本地主机（`localhost`、`127.0.0.1`、`[::1]`、IPv4/IPv6 主机）
3. **域名聚类**：当共享相同根域名的标签页数量达到或超过 `domainThreshold`（默认：2 个标签页）时进行分组。
4. **子域名聚类**：若启用，同一域名下的标签页将按具体子域名进行分组（例如 `docs.github.com` 与 `gist.github.com`）。
5. **杂项 ("Misc") 分组**：未达到聚类阈值的剩余未分组标签页将被归入 `Misc` 分组（位置可配置：`start` 开头、`end` 末尾或 `alpha` 按字母排序）。

### 2.3 URL 规范化与匹配语义
匹配引擎（`src/core/background/utils.js` 中的 `matchesRule(tabUrl, ruleUrl)`）执行严格的规范化处理：
- **协议无关**：HTTP 与 HTTPS 协议视为等价互通（`http://example.com` 匹配 `https://example.com`）。非网页协议（`file://`、`chrome://`）则要求协议完全精确匹配。
- **主机规范化**：去除前导 `www.` 前缀（`www.github.com` 规范化为 `github.com`）。主机名转为全小写，并通过 punycode 支持国际化域名 (IDN)。
- **端口敏感性**：若规则指定了端口（例如 `localhost:3000`），标签页必须严格匹配该端口。
- **路径匹配**：去除末尾斜杠。若规则指定了路径（例如 `example.com/docs`），则匹配该精确路径或其子路径（`example.com/docs/api`），但不匹配同级路径（`example.com/blog`）。
- **查询参数与哈希匹配**：若规则显式包含查询字符串（`?page=1`）或哈希（`#section`），标签页必须逐字精确匹配这些参数。
- **纯数字 DWORD 防护 (`ruleValidation.js`)**：验证器严格拒绝纯数字输入（例如 `3242342424`），防止 WHATWG URL 解析器将其视为合法 IPv4 整数 DWORD 处理，从而避免意外的分组错乱。

### 2.4 规则管理设置详解
规则管理器提供了一套完备的行为控制与配置项：
- **存储路由选择**：用户可在 `chrome.storage.sync`（用于在登录同一 Google 个人资料的所有设备间同步设置，受限于 Chrome 同步配额：总计 100 KB，单项 8 KB）与 `chrome.storage.local`（具备无限本地容量，适合包含数百条模式的大型规则集）之间切换规则存储路由。
- **聚类主开关与阈值**：
  - `toggle-clustering`：键盘快捷键兼 UI 主开关，可在不禁用用户自定义规则的前提下，启用或禁用自动域名/子域名聚类。
  - `domainThreshold`：触发自动标签页分组所需的同一域名最低标签页数（默认：2 个标签页）。可在 1 至 50 之间配置。
  - `subdomainThreshold`：创建独立子分组前，子域名所需的最低标签页数。
  - 子域名开关 (`toggle-subdomain-grouping`)：区分独立子域名（例如 `news.ycombinator.com` 与 `ycombinator.com`）。
- **按字母自动排序分组 (`toggle-sort-alpha`)**：实时排序引擎，强制浏览器标签页栏中所有打开的标签页分组按字母顺序排列（`Ctrl+Shift+S` / `Cmd+Shift+S`）。
- **视觉状态前缀 (`toggle-prefixes`)**：动态添加到分组标题前面的 Emoji 标记，用以指示检查状态：
  - `🔒`（锁）：分组包含未访问、未阅读的标签页。
  - `🔍`（放大镜）：分组包含部分已访问的标签页。
  - `🗝️`（钥匙）：分组内的所有标签页均已打开并浏览完毕。
  - `⚠️`（警告）：检测到与另一窗口分组发生重名冲突。
- **空闲分组自动折叠 (`toggle-collapse-timer`)**：在分组处于非活动状态时自动折叠，保持标签栏整洁。
- **分组总暂停 (`feature_pauseGrouping`)**：全局冻结开关，在用户进行需要保持随意排列的研究会话期间，临时挂起所有自动分组操作（包括规则匹配与启发式聚类）。
- **单标签页分组 (`featureSingleTabGrouping`)**：允许自定义规则针对单个匹配的标签页立即创建分组，绕过必须多个标签页的阈值限制。
- **紧凑视图 (`toggle-compact-mode`)**：通过在分组标题上仅渲染单字母徽标，最大限度缩小浏览器标签栏中的分组标题宽度。
- **拖放优先级**：在 `Rules.svelte` 列表中重新排列规则顺序会立即改变其评估优先级。顶部的规则优先计算。
- **模糊搜索**：规则管理器与 Omnibar 中的实时过滤功能，可通过标题或匹配的 URL 模式即时定位规则。
- **JSON 导入 / 导出**：
  - 模式 `add`：将导入的规则合并至现有集合中，去除重复项。
  - 模式 `overwrite`：在模式验证通过后，用导入的数据完全替换当前活动的规则集合。
- **动态规则创建**：一键直接从 Chrome 书签文件夹或子分组域名集合中创建自定义规则。
- **规则去重 (`feature_v100_dedup_add_to_rule`)**：向现有自定义规则添加 URL 或域名时，自动剔除重复的 URL 模式，防止规则膨胀和冗余计算。

### 2.5 操作与持久化 (`mutateRulesAndSync`)
- **集中式变更器**：所有规则修改均通过 `src/core/background/handlers/rules.js` 中的 `mutateRulesAndSync(mutateFn, sendResponse)` 路由。这确保了存储同步、内存缓存刷新（`extensionSettings.customRules`）、UI 通知广播（`rulesUpdated`）以及自动标签页重新分组（`groupTabs()`）。
- **实时验证**：保存前实时校验名称唯一性、长度（1-16 字符）、字符限制以及合法 URL 语法。

### 2.6 调用形式
- **规则管理页面 (`Rules.svelte`)**：支持全标签页视图或侧边栏访问（`?view=rules` / `pg`）。提供完整的拖放重排、内联颜色选择器、URL 标签胶囊及规则开关。
- **Omnibar 命令**：
  - `rl:` — 搜索规则并打开关联的 URL。
  - `cr: <name> [, url1, url2]` — 直接从命令栏创建新规则。
  - `atcr:` — 将当前活动标签页的域名或 URL 添加到现有规则中。
  - `atr:` — 将选中的打开标签页或手动输入的 URL 添加到现有规则中。
  - `ccr:` — 更改自定义规则的颜色。
  - `dr:` — 删除规则或从规则中删除单个 URL。
  - `er:` — 编辑或重命名现有规则。
- **右键上下文菜单**：
  - 右键点击页面 -> "Crear Regla para esta Página" -> "Añadir Raíz del Sitio" / "Añadir URL Completa"。
  - 右键点击页面 -> "Añadir a Regla Existente" -> 选择规则 -> "Añadir Raíz del Sitio" / "Añadir URL Completa"。
  - 右键点击页面 -> "Reglas" -> 切换启用状态、打开该规则下的所有 URL，或关闭匹配的标签页。
- **键盘快捷键**：
  - `Alt+R`：打开规则管理器。
  - `Alt+M`：同时切换所有规则的启用/禁用状态 (`toggle-all-rules`)。

## 3. 第 2 节：分组列表与操作 (Listar Grupos)

分组列表视图提供了一个交互式工作区，用于检查、操作和重新排列浏览器标签页分组及单个标签页。

### 3.1 UI 架构
- **组件栈**：采用 `ListGroup.svelte`、`GroupCard.svelte`、`GroupActions.svelte`、`TabItem.svelte` 和 `TabActions.svelte` 构建。
- **卡片功能**：展示分组标题、颜色徽标、标签数量胶囊、折叠/展开手风琴切换、卡片置顶固定以及可自定义的操作按钮组。
- **标签页项**：显示带有后备颜色的标签页 Favicon、标题、正在播放声音徽章、静音指示器、活动状态标记以及针对单标签页的操作（关闭、复制、固定、分屏、丢弃）。

### 3.2 分组生命周期与行为
- **手风琴控制**：平滑展开与折叠状态。可选的自动手风琴模式会在展开新分组时自动折叠空闲分组。
- **不活跃空闲自动折叠计时器**：
  - 自动折叠空闲标签页分组，减少视觉混乱。
  - 两个独立阈值：非活动分组在闲置 1 分钟后折叠 (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`)，而活动分组在闲置 15 分钟后折叠 (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`)。可在 0 到 1440 分钟之间配置。
- **内联重命名与宽限期**：
  - 用户可直接在浏览器标签栏或 UI 中重命名分组。
  - `GROUP_NAMING_GRACE_MS` (5000ms) 会在用户编辑期间暂停自动重新分组，防止输入中途标题被覆盖。
  - 评估期间会过滤零宽字符（`\u200B`、`\u200C`、`\u200D`、`\u2060`、`\uFEFF`）。
  - 重命名自动生成的分组会将其转换为用户命名分组，更新相应的自定义规则或将其标记为永久保留。
- **视觉分组前缀指示器**：
  - 动态添加状态符号：`🔒`（未访问）、`🔍`（部分已读）、`🗝️`（全部浏览完毕）、`⚠️`（命名冲突）。
- **拖放重新排序**：集成 `sortable.js`，支持在分组内重排标签页、跨分组移动标签页，或对分组卡片重新排序。
- **隐藏分组功能**：
  - 在浏览器标签栏中为分组标题添加 `_hidden_` 前缀。
  - 从主列表视图中隐藏该分组卡片，转移至 `HiddenGroupsBar.svelte`。
  - 用户只需轻轻一点即可立即取消隐藏或恢复分组。

### 3.3 分组操作与内存管理
- **Ungroup (取消分组)**：解散分组，保留窗口中打开的各个标签页。
- **Close Group (关闭分组)**：关闭分组内的所有标签页并释放该分组 ID。
- **Close Other Groups (关闭其他分组)**：关闭除当前聚焦分组之外的所有标签页分组。
- **Regroup All Tabs (`Alt+Shift+R`) (重新分组所有标签页)**：针对自定义规则、系统分组和域名聚类执行全量重新评估处理。
- **分组截图巡检**：依次轮转并截取分组内的每一个标签页（`Cs` 可见区域、`Cp` 完整长图、`CP` 分段长图）。

### 3.4 分组备份与恢复子系统
- **IndexedDB `backupsGroups` 存储库**：
  - 将单个标签页分组或包含所有打开分组的工作区全局快照备份至 IndexedDB `Intelligent_Workspace` 数据库的 `backupsGroups` 对象仓库中。
  - 捕获完整的分组结构：分组标题、颜色、折叠状态、标签页标题、URL、Favicon、固定状态以及相对标签页位置。
  - **内存节约**：已备份的标签页将被干净关闭，以回收系统内存并降低 CPU 占用。
  - **恢复机制**：
    - `ListGroup.svelte` 中的备份 UI 视图，支持一键分组恢复。
    - 键盘快捷键 `br`（恢复）和 `bg`（备份全部）。
    - Omnibar 命令 `bgr:`（搜索并恢复已备份分组）与 `b:`（书签搜索）。
  - **JSON 导出与导入**：支持完整的 JSON 备份导出与导入，方便在多设备间迁移和长期离线存档。

### 3.5 隐藏分组栏中的停泊 YouTube 播放器
- **架构 (`HiddenGroupsBar.svelte`)**：
  - 当用户离开活动的 YouTube 视频视图或在侧边栏内启动视频内容时，播放器不会被关闭或丢失。它会自动停泊在 `HiddenGroupsBar.svelte` 中，显示为停泊的 YouTube 指示器 (`.youtube-indicator`)。
  - 通过 `src/ui/stores/appStore.svelte.js` 中的 `hiddenYoutubeView` store 进行响应式管理。
  - **一键快捷操作**：
    - 点击停泊指示器调用 `restoreYoutubeView()`，将播放器立即带回活动工作区视图。
    - 点击删除图标调用 `discardYoutubeView()`，彻底终止播放并回收资源。
  - 与 ListGroup 视图顶部的隐藏标签页分组无缝并置，不干扰正在活动的标签页列表。

## 4. 第 3 节：导航与标签页管理 (Navegación)

通过加速键盘导航和工作区控制，无需鼠标交互即可无缝操控多个标签页。

### 4.1 快速标签页跳转手势
- **手势语法**：`Alt + [groupPrefix] + [tabIndex] + Enter`
- **执行方式**：
  - 按住 `Alt` 并键入分组名称或前缀字母，紧接着输入从 1 开始的标签页序号，然后按下 `Enter`。
  - 示例：`Alt + git + 2 + Enter` 直接跳转至 "GitHub" 分组中的第 2 个标签页。
  - 索引 `0` 代表跳转至该分组的*最后一个*标签页。
  - 省略序号则默认跳转至该分组的*第一个*标签页。
  - 重音符号自动折叠规范化 (`deaccent`)，匹配时自动抹平变音符号差异。

### 4.2 步进、交换与生命周期快捷键
- `s`：立即切换至上一个活动标签页 (`previousActiveTabId`)。
- `h` / `l`：切换至上一个 / 下一个标签页（若页面支持水平滚动则优先水平滚动）。
- `H` / `L`：在浏览器历史记录中后退 / 前进。
- `t`：打开新的空白标签页。
- `x`：关闭当前活动标签页。
- `yt`：复制当前标签页。
- `r` / `R`：重新加载页面 / 强制绕过缓存重新加载。
- `d` / `u`：滚动至页面底部 / 顶部。
- `j` / `k`：平滑向下 / 向上滚动（每次 75px）。
- `f`：激活 Vim 链接提示（可点击元素上方出现字母以供点击）。
- `cf`：激活 Vim 链接提示以将目标 URL 复制到剪贴板。

### 面向高级用户

进阶用户可将浏览器切换至全屏模式，完全依靠键盘进行操作，全程无需使用鼠标。

#### 全屏沉浸与免鼠标浏览
- **切换全屏**：按 `F11`（Windows/Linux）或 `Command+Control+F`（macOS）。浏览器边框、地址栏、标签栏及操作系统面板均被隐藏，将 100% 的显示面积留给网页内容。
- **页面内 Vim 链接导航 (`f` / `cf`)**：
  - 按 `f` 键，在 DOM 中每个可点击元素、按钮、输入框和链接上方生成高对比度的双字母黄色提示标签。
  - 输入匹配目标的两个字母，即可模拟直接点击，全程无需鼠标。
  - 按 `cf` 键触发提示徽标，可将目标链接的 URL 直接复制至系统剪贴板。
  - 按 `vp` 键在页面内弹出目标链接的预览浮层。
  - 随时按 `Esc` 键退出链接提示，恢复正常滚动模式。
- **即时标签页跳转与切换**：
  - `Alt + [groupPrefix] + [tabIndex] + Enter`：执行快速标签页跳转手势（例如 `Alt + dev + 1 + Enter` 直接跳至 "Dev" 分组的第一个标签页；输入索引 `0` 则选中分组的最后一个标签页）。
  - `s`：在当前标签页与上一个活动标签页 (`previousActiveTabId`) 之间即时互切。
  - `h` / `l`：在标签栏中顺次移动到上一个 / 下一个标签页。
  - `H` / `L`：在浏览器导航历史记录中向后 / 向前移动。
  - `t` / `x` / `yt`：新建标签页 (`t`)、关闭当前标签页 (`x`) 或复制标签页 (`yt`)。
- **悬浮 Omnibar 命令子系统 (`o`)**：
  - 在任意页面按 `o` 即可唤起居中的 Omnibar 覆盖层。
  - 输入 `@` 可展开包含全部 41 个命令前缀的交互式目录。
  - 输入 `f: <query>` 跨所有打开的窗口执行深层全文标签页搜索。
  - 输入 `sp:` 将导航直接导向任意侧边栏视图（`rules`、`listgroup`、`notes`、`gallery`、`gemini`、`activity`、`themes`、`hints`、`downloads`）。
  - 输入 `qai: <query>` 或 `qaia: <task>` 向 Gemini 提问或向自主浏览器 Agent 下达指令，双手无需离开键盘。
  - 输入 `ts:` 将打开的标签页分屏并排显示。
- **页面内导航与聚焦**：
  - `j` / `k`：平滑向下 / 向上滚动（步进 75px）。
  - `d` / `u`：半屏向下 / 向上滚动。
  - `i`：将光标焦点立即跳入页面上的主文本输入框中。
  - `ESC`：取消输入框焦点并将键盘控制交还给导航模式。

### 4.3 音频与声音管理
- 正在播放音频的标签页在 ListGroup UI 中会显示喇叭徽章。
- `st`：切换当前活动标签页的静音状态。
- `so`：静音整个浏览器中所有发声的标签页。
- 右键菜单："Silenciar Todas las Pestañas"（静音所有标签页）/ "Reactivar Sonido en Todas las Pestañas"（恢复所有标签页声音）。

### 4.4 分屏工作流
- **触发方式**：Vim 提示键 `ts` 或 Omnibar 前缀 `ts:`。
- **行为机制**：调用 `chrome.system.display` 计算屏幕尺寸几何数据。将两个标签页并排拆分至相邻的窗口中，并将其归集在专用的 `Split` 标签页分组下。
- **恢复状态**：关闭分屏窗口或切换分屏模式即可还原原始窗口尺寸与坐标。

### 4.5 YouTube 循环播放子系统
YouTube 循环播放子系统提供了直接集成到 YouTube 播放器内的精准媒体循环控制功能：
- **桌面播放器按钮 (`#itg-yt-loop-button`)**：注入到标准 YouTube 播放器控制栏 (`.ytp-right-controls`) 中，位于投放/遥控按钮或画中画启动器左侧。具有 SVG 循环动画符号、切换高亮样式 (`ytp-loop-active`, `var(--interactive-color, #ff4444)`) 以及 `aria-pressed` 状态。
- **Shorts 播放器按钮 (`#itg-yt-shorts-loop-button`)**：注入在 YouTube Shorts 右侧控制列 (`ytd-shorts`) 的 `#itg-yt-shorts-loop-wrapper` 内，为垂直短视频内容提供一键循环。
- **循环菜单与画中画弹窗 (`#itg-yt-loop-menu` & `#itg-pip-loop-popup`)**：悬停或点击循环按钮可打开详尽的循环设置菜单：
  - **A-B 循环**：用户可通过交互式滑块和手动时间输入框，设置精确到毫秒级的自定义起点 (A) 和终点 (B)。
  - **循环模式与序列重复**：设置指定循环的重复次数或开启无限循环模式 (`itg-loop-seq-inf`)。
  - **循环列表与多片段序列**：排队添加多个 A-B 循环区间，按配置的重复次数顺次连贯播放。
  - **状态与时长显示**：实时显示当前循环区间内的播放进度以及媒体总时长 (`00:00 / 00:00`)。
  - **主开关 (`youtubeLoopEnabled`)**：持久化保存在 `chrome.storage.sync` 和 `local` 中，允许用户在自定义提示设置页面 (`YoutubeLoopSection.svelte`) 中全局启用或禁用 YouTube 和 YouTube Shorts 上的循环按钮。

### 4.6 YouTube Shorts 预览音频
- **音频取消静音挂钩 (`youtubePreviewAudioHook.js`)**：
  - 在 `MAIN` 执行环境中运行，以访问 `ytd-video-preview` 元素上的 `#inline-preview-player` 属性。
  - **克服强制静音机制**：YouTube 会通过清除音频控件并在内部 `volumechange` 监听器中恢复 `muted = true`，强制对 Shorts 预览实施静音。
  - 扩展在鼠标悬停时挂钩目标 `<video>` 元素上的 `HTMLMediaElement.prototype.muted` 属性描述符。在允许用户取消静音的同时，拦截并丢弃 YouTube 发起的强制重新静音，确保声音在循环重新开始时不会被打断，持续播放直至鼠标移出。

### 4.7 画中画 (PiP) 架构
- **文档画中画 (`wp`)**：
  - 利用现代 `documentPictureInPicture` API，在置顶悬浮窗口中打开完整网页或文本片段。
  - 在转移媒体时自动同步视频播放时间戳。
  - 具备重试机制 (`itgRetryIfPipFrameRefused`)，并在关闭时自动清理 DNR iframe 请求头。
- **视频画中画 (`wv`)**：
  - 通过 `videoPipHook.js` 拦截 `HTMLVideoElement.prototype.requestPictureInPicture`。
  - 将视频播放器重定向到具有循环控制和倍速播放选择器的自定义画中画框架中。
- **自动画中画 (Auto-PiP)**：
  - `as`：切换滚动自动画中画（当视频滚出视口时自动开启画中画模式）。
  - `ah`：切换隐藏标签页自动画中画（当切换至其他标签页时自动开启画中画模式）。

### 4.8 页面阅读模式与视觉滤镜覆盖层
- **CSS 滤镜主题**：向网页注入非破坏性样式：
  - `mb` / `mB`：黑色（高对比度深色）—— 标签页作用域 / 全局作用域。
  - `ms` / `mS`：复古（暖色护眼纸）—— 标签页作用域 / 全局作用域。
  - `mp` / `mP`：报纸（单色灰度）—— 标签页作用域 / 全局作用域。
  - `ml` / `mL`：柔光（护眼浅白）—— 标签页作用域 / 全局作用域。
  - `me` / `mE`：自定义用户 CSS 滤镜 —— 标签页作用域 / 全局作用域。
  - `ESC`：立即清除当前应用的页面滤镜。
- **阅读模式与 TTS 朗读**：
  - `fetchContentForReaderView`：提取干净的正文内容，剔除广告、侧边栏和杂乱导航。
  - 内置文本转语音 (TTS) 引擎逐句朗读文本。
  - 键盘控制导航：`zp`（播放/暂停）、`zn`（下一句）、`zb`（上一句）、`zq`（关闭阅读覆盖层）。

### 4.9 带模板变量的文本片段子系统
文本片段子系统（`src/utils/hint/snippets.js` 和 `src/utils/snippet-panel.js` 中的 `SnippetManager`）可在任意 input、textarea 或富文本编辑器中通过展开文本缩写来加速文字输入：
- **触发方式**：输入快捷指令后按空格，或输入 `$$` 唤起交互式代码片段搜索弹窗。
- **剪贴板 API 集成**：支持通过剪贴板 API 插入格式化 HTML 与纯文本，确保与 Google Docs、Notion 和 Slack 等复杂编辑器 100% 兼容。
- **模板变量**：在展开瞬间动态求值并填充变量：
  - `{{date}}` / `date`：本地格式化日期 (`toLocaleDateString`)。
  - `{{isodate}}` / `isodate`：ISO 8601 日期 (`YYYY-MM-DD`)。
  - `{{longdate}}` / `longdate`：包含星期、日、月、年的完整长日期。
  - `{{time}}` / `time`：2 位格式化时间 (`HH:MM`)。
  - `{{datetime}}` / `datetime`：日期与时间组合。
  - `{{weekday}}` / `weekday`：完整星期名称（例如 Monday）。
  - `{{day}}` / `day`：月份中的日 (1-31)。
  - `{{month}}` / `month`：完整月份名称（例如 October）。
  - `{{year}}` / `year`：4 位完整年份。
  - `{{tomorrow}}` / `tomorrow`：明天的日期 (+1 天)。
  - `{{yesterday}}` / `yesterday`：昨天的日期 (-1 天)。
  - `{{nextweek}}` / `nextweek`：7 天后的日期 (+7 天)。
  - `{{timestamp}}` / `timestamp`：Unix 毫秒时间戳 (`Date.now()`)。
  - `{{url}}` / `url`：当前网页 URL (`window.location.href`)。
  - `{{domain}}` / `domain`：当前网页域名主机名 (`window.location.hostname`)。
  - `{{pagetitle}}` / `pagetitle`：当前文档标题 (`document.title`)。
  - `{{uuid}}` / `uuid`：密码学安全的全局唯一标识符 (`crypto.randomUUID()`)。
  - `{{random}}` / `random`：1 到 1000 之间的随机整数。
  - `{{clipboard}}` / `clipboard`：系统剪贴板缓冲区文本。

### 4.10 内置生产力工具
- **解除右键限制挂钩 (`allowRightClickHook.js`)**：
  - 注入到 `MAIN` 执行环境中，瓦解恶意网页禁用右键菜单、复制、剪切或选中文本的脚本限制。
  - 拦截 `contextmenu`、`copy`、`cut`、`selectstart`、`mousedown` 和 `mouseup` 上的 `preventDefault()` 与 `stopPropagation()`。
  - 通过持久运行的 `MutationObserver` 清理内联的 `oncontextmenu="return false"` 处理器。
  - 验证剪贴板数据载荷，防止破坏正规在线编辑器（如 Google Docs、Telegram Web）的功能。
- **Cookie 编辑器**：页面内弹窗，用于检查、编辑、创建和删除当前域名的 HTTP 与 HTTPS Cookie。
- **二维码生成器**：为当前标签页 URL 生成 SVG/Canvas 二维码，以便快速流转至移动设备。
- **纯净 PDF 打印导出**：将目标网页通过 `print.html` 路由并剔除页眉、广告和导航噪点，导出干净整洁的归档文档。

### 4.11 全面 3 层去重与智能休眠丢弃
- **全面 3 层去重**：
  1. **标签页去重 (`removeDuplicateTabsCommand`)**：扫描跨窗口或聚焦分组中的打开标签页，识别重复的 URL，豁免 `Split` 分屏标签页，并在保留活动或最早标签页的同时关闭多余重复项。并在桌面弹出汇总通知。
  2. **书签去重**：深度扫描 Chrome 书签树，定位跨文件夹的完全相同 URL 重复项，并提供批量合并清理以维持书签整洁。
  3. **规则去重 (`feature_v100_dedup_add_to_rule`)**：向现有自定义分组规则添加 URL 时自动剔除重复 URL 模式，避免规则臃肿。
- **智能内存丢弃休眠 (`suspendInactiveTabsIntelligently`)**：
  - 通过闹钟 `itg-periodic-tasks` 每 1 分钟评估一次。
  - 丢弃休眠闲置时长 >= `discardingTimeMinutes`（默认：60 分钟）的标签页。
  - 内置免休眠保护策略：绝不丢弃休眠活动标签页、正在发声播放音频的标签页、固定标签页或已经处于休眠状态的标签页。

## 5. 第 4 节：AI 助手与自主 Agent (Asistente AI)

AI 助手将大型语言模型集成到浏览器中，提供上下文理解、自动化工作流和直接的浏览器自动化能力。

### 5.1 双模型引擎架构
1. **Google Gemini Cloud API (`gemini-api.js`)**：
   - 与 Google Generative Language REST 端点（`v1beta/models/{model}:generateContent` 和 `:streamGenerateContent`）集成。
   - 支持 Gemini 2.5 Flash、Gemini 2.5 Pro 及自定义模型端点。
   - **多密钥轮换**：在 `geminiApiKeysList` 中维护密钥池。存储混淆使用 `enc_` 前缀。
   - **指数退避**：遭遇 HTTP 429 配额耗尽错误时执行自动退避重试（1.5 秒 -> 3 秒 -> 6 秒）。
   - **搜索事实依据 (Search Grounding)**：启用 Google Search Grounding (`google_search: {}`)。若因搜索工具配额限制发生 HTTP 403 错误，系统将自动降级并重试无 Grounding 的请求。
2. **Chrome 内置 AI / Prompt API (`localAiService.js`)**：
   - 通过 `window.LanguageModel` 集成端侧 Gemini Nano。
   - 支持零网络消耗的本地离线执行。包括模型可用性检查与实时下载进度跟踪。

### 5.2 自主浏览器 Agent (`agent-backend.js`)
自主 Agent 通过 40 多个结构化工具提供对浏览器的全面控制：
- **标签页与分组控制**：`getOpenTabs`、`switchToTab`、`createNewTab`、`closeTab`、`closeTabs`、`duplicateTab`、`findAndSwitchToTab`、`groupTabs`、`ungroupTabs`、`deleteTabGroup`、`collapseTabGroup`、`expandTabGroup`、`collapseAllGroups`、`expandAllGroups`、`setGroupColor`、`renameTabGroup`、`regroupAllTabs`、`removeDuplicateTabs`、`closeTabsWithSound`。
- **导航与搜索**：`openUrl`、`searchGoogle`、`getActiveTab`、`getActiveTabContent`。
- **知识与书签**：`getBookmarks`、`searchBookmarks`、`createBookmark`、`getHistory`、`getRecentlyClosed`。
- **规则与外观**：`getRules`、`createRule`、`updateRule`、`deleteRule`、`getActiveTheme`、`getSavedThemes`、`applyTheme`。

### 5.3 污点追踪与 Prompt 注入防御
为抵御来自不可信网页的间接 Prompt 注入攻击，Agent 后台实现了严格的污点追踪机制：
- **污点标记**：调用 `getActiveTabContent` 从网页提取文本时，当前执行任务将被标记为受污染状态 (`taintedAgentRuns.add(runId)`)。
- **出站工具防御守卫**：受污染的任务被严格禁止调用任何可能造成数据泄露的出站工具 (`AGENT_EGRESS_TOOLS`)：
  * `openUrl`、`searchGoogle`、`createBookmark`、`createRule`、`addUrlToRule`、`createSiteShortcut`、`updateSiteShortcut`、`updateRule`。
- **安全拒答机制**：引擎不抛出未捕获的异常，而是返回结构化的安全解释说明。随后 LLM 会向用户解释，在未经用户显式许可的情况下无法将外部数据向外发送。

### 5.4 定时 Gemini 查询子系统 (`GeminiScheduleModal.svelte`)
- **后台执行引擎**：
  - 通过 `chrome.alarms` (`gemini-scheduled-*`) 在后台 Service Worker 内直接自动执行计划中的 AI 提示词任务。
  - 每天最多支持 6 个定时查询 (`MAX_TIMES = 6`)。
  - **定时模式**：
    - 循环排期：在选定的每周各天重复执行 (`selectedDays`)。
    - 单次排期：在指定的目标日期和时间执行一次 (`formDate`)。
    - **提示词字数限制**：强制限制提示词长度不超过 1,000 个字符 (`MAX_QUERY_CHARS = 1000`)，并提供实时字数统计。
  - **后台通知**：后台查询完成后，弹出包含回答摘要预览的桌面通知。点击该通知即可直接在侧边栏聊天窗口中打开对应的问答会话。

### 5.5 Gemini 对话管理与导出
- **持久化 IndexedDB 存储 (`geminiConversations`)**：多轮对话会话存储在 IndexedDB 数据库 `Intelligent_Workspace` 的 `geminiConversations` 仓库中。
- **全文历史检索**：通过 Omnibar 命令 `lai:`（浏览对话）和 `laiq:`（搜索消息），即时搜索所有过往对话记录和单独消息。
- **四种导出格式**：
  1. **样式化 HTML**：格式化独立的 HTML 文档，包含样式化气泡、角色徽标、时间戳及语法高亮代码块。
  2. **原始 JSON**：完整的结构化数据导出，包括消息数组、Token 消耗、模型配置和搜索引用来源。
  3. **Markdown**：标准的 Markdown 文件，格式化输出标题、时间戳和围栏代码块 (` ``` `)。
  4. **纯文本**：干净无格式的对话文字记录，便于通过邮件发送或粘贴至笔记中。
- **Grounding 元数据追踪**：记录模型 ID、Token 消耗统计、执行时间戳以及 Google Search Grounding 返回的源引用链接。

### 5.6 多模态输入与文件附件 (`feature_geminiAttachFiles`)
- **多模态附件**：开关 `feature_geminiAttachFiles` 允许在聊天提示词中直接上传图像和文档附件：
  - 图像文件（JPEG、PNG、WebP、HEIC/HEIF）。
  - PDF 文档与研究论文。
  - 纯文本文件与源代码文件。
  - CSV 结构化数据集。
- **语音支持**：
  - Web Speech STT（语音转文字），实现免提语音输入提示词。
  - Web Speech TTS（文字转语音），将 AI 回复朗读出来。

### 5.7 调用形式
- **侧边栏路由**：`?view=gemini` 或快捷键 `pa`。
- **页面内 Omnibar 前缀**：
  - `qai: <query>` — 向已配置的 Gemini 模型直接发起提问。
  - `qaia: <prompt>` — 指派自主 Agent 结合工具执行提示词任务。
  - `lai:` — 浏览过往 AI 对话。
  - `laiq:` — 全文检索所有 AI 对话消息。
- **Omnibox AI 标签页搜索 (`find <query>`)**：
  - 在地址栏输入关键字 `find` 触发混合搜索。
  - 结合正则表达式词界评分与 Gemini 语义解析，根据自然语言查询定位并聚焦目标标签页。

## 6. 第 5 节：笔记视图与知识管理 (Ver Notas)

一个本地优先、感知上下文的笔记引擎，深度绑定到浏览器标签页分组与导航上下文。

### 6.1 存储架构 (`notesStore`)
数据存储在 IndexedDB 数据库 `Intelligent_Workspace` (v8) 的 `notesStore` 对象仓库中：
```typescript
interface NoteRecord {
  id: string;          // 唯一样记标识符。
  title: string;       // 笔记标题。
  text: string;        // 富文本 HTML、Markdown 或序列化的任务载荷。
  type: NoteType;      // 'text' | 'checklist' | 'kanban'
  url?: string;        // 创建该笔记的来源 URL。
  contextKey: string;  // 将笔记绑定至工作区层级的作用域键。
  createdAt: number;   // 创建时间戳。
  modifiedAt: number;  // 最后修改时间戳。
  isPersistent: boolean; // 置顶固定标记，保护笔记不被分组清理操作误删。
}
```

### 6.2 专用笔记格式与高级渲染
1. **文本笔记 (`NoteTextEditor.svelte`)**：
   - 富文本 `contenteditable` 编辑区。
   - 直接内嵌媒体：图像、音频、视频及 PDF 文档。
   - 内置 HTML 清洗防注入机制，以及实时单词和字符计数器。
   - **Mermaid 图表渲染**：直接从 Markdown 围栏 (` ```mermaid `) 中动态渲染流程图、时序图、类图和状态机图。
   - **KaTeX 数学 LaTeX 渲染**：以高精度排版渲染行内公式 (`$...$`) 和块级公式 (`$$...$$`)。
2. **清单笔记 (`NoteChecklistEditor.svelte`)**：
   - 带独立勾选框的交互式任务列表。
   - 支持键盘驱动的条目重排及进度追踪。
3. **看板笔记 (`NoteKanbanEditor.svelte`)**：
   - 3 列工作流面板：`To Do` -> `In Progress` -> `Done`。
   - 循环切换状态标签，快速流转任务状态。
- **动态无损转换**：笔记可在文本、清单和看板展现形式之间无损互相转换。

### 6.3 作用域与上下文层级
笔记通过 `contextKey` 绑定到具体的浏览上下文：
- **分组作用域 (`g_<groupId>` 或 `g_<groupKey>`)**：附加至整个标签页分组。
- **子分组作用域 (`s_<groupId>_<domain>`)**：附加至标签页分组内的指定域名。
- **未分组作用域 (`g_ungrouped` / `s_ungrouped_<domain>`)**：在分组之外的独立标签页上创建的笔记。
- **番茄钟与全局作用域 (`pomodoro`, `general`)**：面向整个工作区的通用笔记。
- **孤儿检测引擎**：当标签页分组或域名被删除时，关联的非持久笔记会被孤儿检测器捕获。这些笔记仍可在 UI 中访问，以供重新分配或删除。

### 6.4 调用形式
- **UI 启动入口**：分组卡片和子分组卡片上的 "View Notes"（查看笔记）按钮；弹出窗口顶部的 "Quick Notes"（快速笔记）按钮；侧边栏路由 `?view=notes` (`pk`)。
- **右键菜单触发**：在任意网页上划选文字 -> 右键点击 -> "Crear Nota desde Selección" (`note-from-selection`)。自动提取所选文字，并将最近的 `h1`-`h3` 标题设为笔记标题。
- **Vim 提示键**：`ao` 从当前划选内容创建笔记。
- **Omnibar**：`lnt:` 打开笔记浏览器，支持实时全文检索。
- **语音朗读**：编辑器内内置 TTS 按钮，利用 Web Speech API 朗读笔记内容。

## 7. 第 6 节：媒体与图库视图 (Ver Galería)

高性能的媒体捕获、标注和光学字符识别 (OCR) 处理管线。

### 7.1 截取模式与工程实现（全部 7 种截取类型）
扩展实现了覆盖单标签页、跨标签页、裁剪和调色板操作的 7 种专用截取模式：
1. **`visible`（可视区域截取 - `cs`）**：
   - 利用 `chrome.tabs.captureVisibleTab` 截取当前活动标签页的精确视口。
   - 自动将截图提交至 IndexedDB 的 `screenshots` 仓库，并将图像位图直接复制至系统剪贴板 (`screenshotSavedAndCopied`)。
2. **`fullPage`（无缝整页长截图画布 - `cp`）**：
   - 执行程序化页面滚动，计算文档总滚动高度。
   - 隐藏滚动条并在第一屏后隐藏吸顶/固定导航栏，消除画面拼接断层。
   - 将位图切片拼接到最高支持 30,000px 的 `OffscreenCanvas` 上 (`captureFullPageDataUrl`)，严格遵守 Chromium 要求的帧截取间 600ms 间隔。
3. **`fullPageParts`（分段切片截图 - `cpp` / `cP`）**：
   - 将长文档顺次切片为视口高度的单张图片分卷 (`captureFullPageParts`)，生成最多 60 个带编号的图片块以供分页排版。
4. **`area`（交互式矩形拖拽裁剪 - `ca`）**：
   - 注入 `area-selector.js`，覆盖一层带实时边界框尺寸的十字准星画布。
   - 提供可拖拽的选择手柄、尺寸提示框、确认触发键、`Esc` 键取消以及多标签页裁剪排队机制 (`handleCaptureAreaFromShortcut`)。
5. **`groupTabs`（活动分组全标签页批量轮巡截取 - `Cs`, `Cp`, `CP`）**：
   - 顺次遍历活动标签页分组内的每一个标签页 (`handleCaptureGroupFromShortcut`)。
   - 支持以可视区域、整页长图或分段切片模式进行批量截取，并归档汇编为统一的合集。
6. **`omnibarPickedTabs`（自定义多标签页队列截取）**：
   - 通过 Omnibar 命令 `cs:`、`cp:`、`cpp:` 或 `ca:` 触发 (`handleCaptureTabs`)。
   - 针对用户筛选出的所有标签页执行顺次截取，并实时显示进度条。
7. **`colorPickerCapture`（后台屏幕吸管工具后备方案）**：
   - 在缺少原生 `window.EyeDropper` API 支持的操作系统（如 Linux）上，通过在后台截取屏幕画面，驱动高精度的 Hex 放大镜拾色工具。

### 7.2 图库 UI 与持久化
- **界面**：响应式瀑布流/网格布局，带有灯箱放大、平移和旋转工具。
- **持久化 (`screenshots` 仓库)**：保存在 IndexedDB 数据库 `Intelligent_Workspace` 中。未锁定的截图会在维护周期自动清理；点击图钉图标固定 (`isPersistent = true`) 则永久保留。

### 7.3 导出、浏览器内 OCR 与外部标注
- **导出格式 (`captureDownloadFormats`)**：
  - 高效图片格式：PNG、WebP、AVIF。
  - 通过 `pdf.js` 导出多页拼接的 PDF 文档。
- **设备端 WASM OCR**：
  - 浏览器内 Tesseract.js WebWorker，预装西班牙语和英语 (`spa+eng`) 语言模型。
  - 直接提取文本复制到剪贴板，无需通过网络外传图像数据。
- **一键发送集成**：
  - 一键将提取出的 OCR 文本或图像附件发送至笔记 (`notesStore`) 或 Gemini AI 提示词中 (`feature_geminiAttachFiles`)。
  - **Excalidraw 标注**：一键将截图直接推送到 `https://excalidraw.com/`，进行手绘涂鸦、箭头标注和矢量图形批注。

### 7.4 调用形式
- **UI**：分组卡片相机按钮、弹出窗口快捷操作、侧边栏图库路由 `?view=gallery` (`ps`)。
- **Vim 提示键**：`cs`（可视区域）、`cp`（整页长图）、`cP`（分段切片）、`ca`（区域裁剪）、`Cs`（分组可视区域）、`Cp`（分组整页长图）、`CP`（分组分段切片）。
- **Omnibar 前缀**：`cs:`、`cp:`、`cpp:`、`ca:` 以及 `limg:`（浏览图库）。

## 8. 第 7 节：番茄钟与计时套件 (Pomodoro)

专为抵御浏览器休眠周期影响而设计的绝对精准专注计时套件。

### 8.1 计时引擎与后台架构
- **零漂移时间戳计算**：状态持久化在 `chrome.storage.local` 中，采用绝对 Unix 时间戳（`startTime`、`pausedAt`）进行数学计算。无论 Service Worker 终止、浏览器重启还是操作系统睡眠，均不会产生时钟漂移。
- **闹钟调度器**：
  - 由 `chrome.alarms` 驱动的高精度倒计时心跳（`pomodoroTick`，每 1 秒触发一次）。
  - 后台维护与长期周期扫描由 `itg-periodic-tasks`（每 1 分钟触发一次）管理。
- **离屏音频提示音 (`offscreen.html`)**：音频提示音通过以 `AUDIO_PLAYBACK` 原因创建的专用 Chrome Offscreen 文档生成。声音播放结束 3.5 秒后自动关闭，节约系统内存。

### 8.2 详尽的 4 种计时模式
1. **番茄钟 (`pomodoro`)**：
   - 工作时长：1 至 180 分钟（默认：25 分钟）。
   - 短休息：1 至 120 分钟（默认：5 分钟）。
   - 长休息：1 至 180 分钟（默认：15 分钟）。
   - 进入长休息前的循环数：1 至 12 个周期（默认：4）。
   - 目标循环数：1 至 99 个周期（默认：8）。
   - 支持配置工作自动开始、休息自动开始以及通知提醒。
2. **秒表 (`cronometro`)**：支持计次圈数记录与暂停即停止的正向计时器。
3. **倒计时 (`temporizador`)**：支持自定义设定时、分、秒的倒计时器。
4. **指定时间闹钟 (`tiempo`)**：通过日历日期选择器和时钟选择器，针对未来确切的时间戳设定闹钟。

### 8.3 页面内悬浮计时器挂件
- 可拖拽的极简覆盖层，直接在网页上呈现倒计时、暂停/恢复和跳过按钮。
- 无需切回扩展面板或弹窗即可时刻洞悉专注进度。

### 8.4 分组空闲自动折叠计时器
- 协同专注工作流，在非活动分组闲置 1 分钟后自动折叠 (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`)，活动分组闲置 15 分钟后自动折叠 (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`)。可在 0 到 1440 分钟之间灵活配置。

### 8.5 项目标签与元数据
每个计时会话均支持分类元数据：
- 项目名称（最多 18 个字符）
- 项目标签（例如 `#research`、`#dev`）
- 项目文件夹（例如 `/client/project`）

### 8.6 分析引擎与 19 个 KPI 卡片
完整仪表盘（`dashboard.html` 或侧边栏 `dashboard.html?context=sidepanel`）从去重后的会话记录中（通过 `sessionStarted` 由 `dedupeSessions` 计算）得出 19 项关键绩效指标：
1. `focus`：总专注时长。
2. `sessions`：完成的会话总数。
3. `cycles`：完成的工作周期总数。
4. `efficiency`：平均效率百分比 (`总专注时长 / 总时长 * 100`)。
5. `activeDays`：活跃天数。
6. `break`：总休息时长。
7. `interruptions`：手动暂停/被打断的总次数。
8. `interruptionTime`：处于暂停状态的累计时长。
9. `bestSession`：最长单次无中断专注会话。
10. `avgFocus`：每个完成周期的平均专注时长。
11. `totalTime`：工作与休息的累计总耗时。
12. `workRest`：工作与休息时长的比例 (`1 : X`)。
13. `distractionRate`：每专注小时被打断率。
14. `bestDay`：一周中最高效的一天。
15. `goldenHour`：一天中专注力最高的黄金时段（例如 `10:00 - 11:00`）。
16. `projects`：追踪记录的独立项目总数。
17. `avgIntDuration`：每次被打断的平均时长。
18. `topProject`：累计专注时长最多的项目。
19. `focusIntensity`：每个活跃日的平均专注小时数。

扩展的可视化分析还包含连续打卡热力图日历、每小时专注分布柱状图、项目多样性细分图表，以及全量 JSON 数据导入/导出功能。

## 9. 第 8 节：活动与历史面板 (Panel de Actividad)

基于 Declarative Net Request (DNR) 的流量追踪、分析及网页治理引擎。

### 9.1 数据引擎与存储拓扑 (`ITG_WEB_ACTIVITY`)
在 `ITG_WEB_ACTIVITY` 下统一调度：
- `wa:day:YYYY-MM-DD`：按天划分的域名计时计数器 (`{ domains: { host: { t: seconds, v: visits, s: sessions, h: { hour: seconds } } } }`)。
- `wa:days`：记录日期主索引数组。
- `wa:recent`：存储最近 400 条访问时间线记录的环形缓冲区。
- `wa:openSegment`：保存在 `chrome.storage.session` 中的当前活跃计时分段，上限设为 `WA_MAX_SEGMENT_SECONDS = 900s`（15 分钟），防止设备休眠未触发空闲事件导致统计失真。
- **空闲检测**：采用 `chrome.idle` 检测（默认：300 秒 / 5 分钟）。若 `countAudible = true`，即使窗口失去焦点，播放音频的标签页也会保持活跃统计。
- **保留期限**：自动清理保留天数 `retentionDays`（默认：180 天）以前的历史日记录。

### 9.2 Declarative Net Request (DNR) 网站屏蔽器
- **动态规则分配**：在 ID 区间 `9000` 到 `9999` 之间分配动态规则。
- **重定向目标**：被拦截的请求会被重定向至 `src/ui/pages/web-activity/blocked.html?d=<domain>&u=\1`。
- **已打开标签页清理**：当某个网站配额耗尽时，后台 Worker 立即清查并重定向当前打开的匹配该域名的标签页。
- **跨午夜排期覆盖**：跨越午夜的限制排期（例如 `22:00` 至 `02:00`）可自动跨天连续执行。
- **宽限 / 小憩延时 (+5 分钟)**：拦截页面提供临时的 5 分钟小憩许可，统计在 `wa:snoozeUses` 中。

### 9.3 非对称安全锁 (`blockLock.js`)
网站配额限制支持通过非对称密码锁进行保护：
- **哈希存储**：存储随机 16 字节盐值及 SHA-256 十六进制摘要 (`wa:settings.blockPassword`)。
- **非对称规则策略**：创建新限制或**收紧规则**时（例如缩短配额时间或增加限制排期），**绝不要求输入密码**。
- **保护性操作**：只有在**放宽规则**时（删除限制、增加配额时间或停用排期），或在用尽每日免费小憩次数后请求延时时 (`snoozePasswordAfter`)，才强制验证密码。

### 9.4 分类与可视化分析
- **16 个内置分类**：`social`、`video`、`music`、`news`、`shopping`、`reading`、`entertainment`、`dev`、`work`、`education`、`games`、`finance`、`mail`、`ai`、`search`、`other`。
- **自定义分类**：支持前缀为 `custom:` 的用户自定义分类。
- **专注比率**：生产力分类（`dev`、`work`、`education`、`reading`、`finance`、`mail`）与分心分类（`social`、`video`、`games`、`shopping`、`entertainment`）之间的比例对比。
- **可视化呈现**：Chart.js 每小时活动分布、分类环形占比图以及域名访问排行列表。

### 9.5 下载管理器子系统 (`switchMainView('downloads')`)
- **专用路由**：在侧边栏通过 `switchMainView('downloads')` 访问（`?view=downloads`）。
- **Chrome 原生 API 集成**：挂钩 `chrome.downloads`，实时跟踪、管理与检查浏览器中的所有下载任务。
- **实时模糊搜索**：按文件名、文件路径或下载源 URL 即时过滤。
- **状态筛选标签**：按下载状态快速过滤：`All`（全部）、`In Progress`（进行中）、`Complete`（已完成）、`Paused`（已暂停）和 `Interrupted`（已中断）。
- **日历日期范围筛选**：按特定日期或时间段精确缩小下载列表。
- **批量分组下载器**：一键提取当前活动分组所有打开标签页中的下载链接，并启动带进度追踪的并发批量下载。
- **文件管理**：支持一键直接打开文件 (`chrome.downloads.open`) 和在文件夹中显示 (`chrome.downloads.show`)。

### 9.6 最近关闭的标签页与浏览历史子系统
- **最近关闭的标签页视图**：
  - 与 `chrome.sessions.getRecentlyClosed` 原生集成。
  - 支持带重音和变音符号自动折叠 (`deaccent`) 的实时搜索。
  - 单标签页恢复，或通过一键恢复或 Omnibar 命令 `c:` 还原整个窗口会话。
- **浏览历史视图**：
  - 深度检索，采用 10 秒 TTL 内存缓存以消除频繁调用 `chrome.history.search` 的冗余开销。
  - 支持按域名、关键字以及日历日期范围多维度筛选。
  - 若已处于打开状态则一键直接激活，或新开标签页访问，支持 Omnibar 命令 `h:` 调出。

### 9.7 主题调度子系统 (`ThemeScheduleModal.svelte`)
- **自动化主题调度**：
  - 在主题侧边栏视图（`?view=themes` / `pt`）内通过 `ThemeScheduleModal.svelte` 进行统一管理。
  - 支持根据一天中的具体时间 (`HH:MM`) 和星期生效日 (`[0..6]`) 自动切换主题。
  - 最多支持 7 个全局主题计划 (`MAX_GLOBAL_SCHEDULES = 7`)。
  - **自动还原**：到达设定结束时间时，自动切回默认日间或工作主题。
  - **桌面提醒**：主题自动切换时弹出桌面通知 (`chrome.notifications`)。
  - **双重持久化**：同时在 `chrome.storage.sync`（随账号漫游）和 `chrome.storage.local` 下的 `savedThemes` 与 `themeSchedules` 中双重存储。

### 9.8 紧凑侧边栏视图
- **侧边栏路由 (`?view=activity` / `pw`)**：针对实时监控优化的 350px 宽列，提供时间周期筛选标签（`Today`、`7d`、`30d`、`All`）及域名配额进度条。

   - "Eliminar Pestañas por Dominio"：动态子菜单，列出所有域名及其打开标签数 `[N]`，支持按域名精准批量关闭。
   - "Cerrar Todos Excepto el Grupo Activo"：保留当前聚焦的分组并关闭其余所有分组。
   - "Reagrupar Todas las Pestañas"：跨所有打开标签页触发完整的后台重新分组流程。
   - "Silenciar Todas las Pestañas" / "Reactivar Sonido en Todas las Pestañas"：全局静音与解除静音控制。
3. **第 3 组：阅读、划选与笔记**：
   - "Leer Página en Voz Alta" (TTS)：带浮层控制的全网页文本转语音朗读器。
   - "Leer Selección en Voz Alta"：通过语音合成朗读页面上高亮划选的文本。
   - "Crear Nota desde Selección"：提取划选文本，自动匹配最近的标题 (`h1`-`h3`) 作为笔记标题，并写入 `notesStore`。
4. **第 4 组：打开扩展、画中画与面板**：
   - "Abrir como PiP" / "Abrir como Ventana Emergente"：在浮动画中画或独立弹窗中打开目标页面、划选内容或目标图像。
   - "Abrir Extensión"：打开扩展弹出窗口或展开侧边栏。
   - "Gestionar Reglas"：在独立标签页中打开完整规则管理器。
   - 侧边栏直达入口：一键直达 List Groups (`?view=listgroup`)、Themes (`?view=themes`)、AI Assistant (`?view=gemini`) 与 Customize Hints (`?view=hints`)。
5. **第 5 组：设置与聚类选项**：
   - **Gestión de Grupos**：Alternar Grupo Actual（折叠/展开当前分组）、Alternar Todos los Grupos（折叠/展开所有分组）。
   - **Opciones de Agrupación**：
     - Agrupación Inteligente（切换启发式自动聚类）。
     - Modo Compacto（切换单字母分组标题模式）。
     - Dominio / Subdominio（切换域名和子域名分组）。
     - Páginas Especiales：Páginas Chrome (`chrome://`)、Archivos Locales (`file:///`)、Extensiones (`chrome-extension://`)、Miscelánea (`Misc`)、Direcciones IP & Localhost。
   - **Opciones Generales**：
     - Ordenar Alfabéticamente（强制标签栏按字母顺序排列）。
     - Ubicación Miscelánea：Principio (`start`)、Final (`end`)、Alfabéticamente (`alpha`)。
     - Temporizador de Auto-Colapso（切换空闲分组自动折叠计时器）。
     - Prefijos Visuales（切换 `🔒`、`🔍`、`🗝️`、`⚠️` 状态标记）。
     - Vista Previa de Enlaces（切换页面内链接浮层预览）。

## 11. 存储模式与数据持久化

扩展在 IndexedDB 与 Chrome Storage API 之间采用了分层存储模型：

### 11.1 IndexedDB 数据库：`Intelligent_Workspace`（架构版本 8）
1. `screenshots`：keyPath: `'id'`, autoIncrement: true。二级索引：`'createdAt'`。存储二进制截图、Canvas Data URL、置顶持久化标记、尺寸规格与分段总序号。
2. `geminiConversations`：keyPath: `'id'`, autoIncrement: true。0 个二级索引（按 ID 直接检索/管理）。存储多轮对话记录、消息角色、Token 消耗指标以及搜索 Grounding 引用元数据。
3. `notesStore`：keyPath: `'id'`, autoIncrement: false。0 个二级索引（在内存中按 contextKey 过滤）。存储富文本、清单数组、看板卡片、Mermaid 语法和 KaTeX 公式。
4. `backupsGroups`：keyPath: `'group.id'`。0 个二级索引（以嵌套的 `'group.id'` 为主键存储备份分组对象）。保存压缩的分组结构、颜色、标题及已关闭的标签页记录。
5. `pomodoroStats`：keyPath: `'id'`, autoIncrement: true。二级索引：`'projectName'`（keyPath 为 `'projectName'`）和 `'savedAt'`（keyPath 为 `'savedAt'`）（无 `date` 索引）。保存专注分析数据、周期指标及打断记录日志。

### 11.2 Chrome Storage 双通道路由 (`StorageService`)
- 在 `chrome.storage.sync`（用于在用户设备间漫游轻量设置）与 `chrome.storage.local`（用于大型首选项）之间动态路由读写请求。
- 关键数据模型：
  - `customRules`：规则定义数组 (`[{ name, color, active, urls }]`)。
  - `clusterConfig`：自动聚类参数（阈值、紧凑模式、特殊分类）。
  - `userPrefixes`：Emoji 前缀符号映射配置 (`{ lock, openKey, loupe, checked, warning }`)。
  - `activeTheme`, `savedThemes` 与 `themeSchedules`：9 种调色板颜色配置以及通过 `ThemeScheduleModal.svelte` 配置的定时轮换计划。
  - `pomodoroState`：实时会话时间戳、暂停时长及循环目标。
  - `wa:settings` 与 `wa:limits`：网络活动跟踪首选项、网站配额限制与排期窗口。
  - `youtubeLoopEnabled`：控制 YouTube 与 Shorts 循环播放按钮的布尔开关。

### 11.3 Chrome Storage 会话存储 (`chrome.storage.session`)
用于极速、临时的运行时状态协调：
- `tabsEverActive`：当前浏览器会话期间激活过的标签页 ID 集合。
- `groupExpandedEver`：当前会话中展开过的分组记录。
- `groupInfoMap`：将分组 ID 映射至动态标题和聚类类型的实时注册表。
- `splitScreenState`：用于还原原始屏幕尺寸的窗口边界缓存。
- `contextMenusSignature`：哈希签名，防止在快速切换标签页期间无谓地重建右键菜单。
- `wa:openSegment`：当前活跃的网站计时分段。
- `hiddenYoutubeView`：指向停泊在 `HiddenGroupsBar.svelte` 中的 YouTube 播放器视图的引用。

## 12. 防御性工程与边缘情况处理

1. **Declarative Net Request 响应头解除拦截 (`dnr.js`)**：
   - 通过动态 DNR 规则修改响应头，剥离 `X-Frame-Options` 与限制性的 `Content-Security-Policy` 请求头，允许外部网页在侧边栏和画中画 iframe 中正常渲染。
   - **WhatsApp Web 特殊安全保护**：在 `web.whatsapp.com` 上显式保留 `Cross-Origin-Opener-Policy` (COOP) 与 `Cross-Origin-Embedder-Policy` (COEP)，防止破坏其 WebAssembly Signal 加密协议的正常运行。
2. **解除右键与选中文本拦截 (`allowRightClickHook.js`)**：
   - 瓦解恶意网页对复制、粘贴、上下文菜单及文字划选的封锁。
   - 运行在 `MAIN` 环境中，拦截 `contextmenu`、`copy`、`cut`、`selectstart`、`mousedown` 和 `mouseup` 上的 `preventDefault()` 与 `stopPropagation()`。
   - 通过 `MutationObserver` 剔除内联的 `oncontextmenu="return false"` 处理器。
   - 在重新注入被取消的粘贴事件前核验剪贴板内容，保护正规在线应用（如 Telegram Web、Google Docs）免受意外干扰。
3. **YouTube 悬停预览强制静音覆盖 (`youtubePreviewAudioHook.js`)**：
   - 运行在 `MAIN` 环境中，挂钩 `ytd-video-preview #inline-preview-player`。
   - 悬停时重写目标 `<video>` 元素上的 `HTMLMediaElement.prototype.muted` 属性描述符。
   - 消除 YouTube 内部 `volumechange` 强制静音的竞态条件，保证悬停预览在循环重启时始终维持音频播放。
4. **YouTube Shorts 列表流连续导航挂钩 (`youtubeShortsFeedHook.js`)**：
   - 运行在 `MAIN` 环境中，挂钩 `ytd-shorts`。
   - 拦截扩展 isolated 环境无法直接访问的 `shortsProcessedSequence` 属性，并在 `ytd-app` 上派发原生 `yt-navigate` 事件，实现无需刷新页面即可平滑切换，避免丢失悬浮窗口状态。
5. **无限滚动长截图画布内存防护**：
   - 将整页滚动截图最大限制在 60 个切片 (`MAX_FULL_PAGE_SEGMENTS`) 及 30,000px 最大画布高度 (`MAX_FULL_PAGE_CANVAS_PX`) 以内，规避浏览器标签页内存溢出崩溃风险。
6. **Linux 屏幕拾色器放大镜后备方案**：
   - 在缺少 Chromium `window.EyeDropper` API 支持的 Linux 环境下，扩展会注入 `screen-color-picker.js`，渲染一个具备 9 倍放大镜头并可实时计算 RGB/HEX/HSL 值的取色浮层。
   - **启动会话平稳延迟**：
   - 浏览器启动时延迟 20 秒执行分组清理（`groupsHaveSettledAfterStartup()`），预留充分时间让会话标签页和窗口布局稳定，之后再准确评估分组归属。
