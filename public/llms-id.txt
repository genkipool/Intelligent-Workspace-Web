# Intelligent Workspace

> Intelligent Workspace adalah ekstensi peramban Manifest V3 tingkat lanjut dan lingkungan ruang kerja produktif yang dibangun dengan Svelte, Vite, dan CRXJS. Ekstensi ini mengorkestrasi pengorganisasian tab cerdas, pengelompokan otomatis dan berbasis aturan, eksekusi agen AI otonom (mendukung Google Gemini Cloud API dan Chrome Built-in Prompt API), navigasi tautan ala Vim di dalam halaman, sistem perintah Omnibar dengan 41 prefiks, pencatatan multi-format (rich text, daftar periksa, Kanban, diagram Mermaid, rumus KaTeX), perekaman media fidelitas tinggi dan WASM OCR dalam peramban, pewaktuan Pomodoro dengan alarm bebas pergeseran (zero-drift) dan pemutaran audio offscreen, serta pengukuran aktivitas web Declarative Net Request (DNR), batas domain, dan pemblokiran situs.

## 1. Fondasi Arsitektur & Siklus Hidup Runtime

Ekstensi ini berjalan di bawah arsitektur Manifest V3 Google Chrome, memisahkan proses-proses persisten di seluruh Service Worker latar belakang, panel UI yang di-sandbox, dokumen audio offscreen, dan overlay content script di dalam halaman:

1. **Konfigurasi Manifest (`manifest.json`)**:
   - **Izin (21 item)**: `tabs`, `tabGroups`, `storage`, `favicon`, `contextMenus`, `notifications`, `sidePanel`, `scripting`, `downloads`, `downloads.open`, `system.display`, `declarativeNetRequestWithHostAccess`, `cookies`, `history`, `sessions`, `bookmarks`, `readingList`, `clipboardWrite`, `alarms`, `offscreen`, dan `idle`.
   - **Izin Host**: `["<all_urls>"]`.
   - **Service Worker**: `src/core/background.js` menggunakan pemuatan modular `importScripts` secara sinkron.
   - **Toolbar Action**: Secara sengaja mengabaikan `default_popup`. Runtime menerapkan `chrome.action.setPopup({ popup: '' })`, memastikan `chrome.action.onClicked` terpicu secara sinkron dan membuka `chrome.sidePanel` ke tampilan yang disematkan pengguna tanpa latensi inisialisasi popup.
   - **Kata Kunci Omnibox**: Kata kunci terdaftar `"find"`.
   - **Perintah (Commands)**: 24 pintasan papan ketik tingkat sistem yang terdaftar di bawah `commands`.
   - **Content Security Policy**: `script-src 'self' 'wasm-unsafe-eval'; object-src 'self';`.

2. **Keamanan Komunikasi Antar-Proses**:
   - `src/core/background/messaging.js` memfilter pesan dari content script terhadap daftar putih eksplisit (`ALLOWED_CONTENT_SCRIPT_ACTIONS`). Bingkai web yang tidak memiliki hak istimewa tidak dapat memanggil pemroses penulisan penyimpanan internal, API Chrome sembarang, atau pemutasian aturan.

3. **Dunia Eksekusi Ganda**:
   - Content script beroperasi di seluruh dunia `ISOLATED` (cakupan ekstensi) dan `MAIN` (cakupan eksekusi halaman). Skrip seperti `allowRightClickHook.js`, `videoPipHook.js`, `youtubePreviewAudioHook.js`, dan `youtubeShortsFeedHook.js` berjalan di `MAIN` untuk mencegat metode prototipe, menimpa deskriptor properti, dan menangani peristiwa kustom secara langsung.

## 2. Bagian 1: Manajemen Aturan (Gestionar Reglas)

Subsistem Manajemen Aturan mengotomatiskan pengelompokan tab berdasarkan kriteria deterministik ketat yang ditentukan oleh pengguna.

### 2.1 Skema Data (`CustomRule`)
Setiap aturan kustom mematuhi antarmuka berikut:
```typescript
interface CustomRule {
  name: string;        // 1 hingga 16 karakter. Tidak boleh berisi karakter spasi kosong.
  color: RuleColor;    // Salah satu dari 9 warna: 'grey' | 'blue' | 'red' | 'yellow' | 'green' | 'pink' | 'purple' | 'cyan' | 'orange'
  urls: string[];      // Array URL, domain, atau hostname yang valid.
  active: boolean;     // Sakelar utama untuk mengaktifkan atau menonaktifkan evaluasi aturan.
  isStarred?: boolean; // Tanda opsional yang menandai aturan sebagai favorit untuk pengurutan prioritas di UI.
}
```

### 2.2 Arsitektur Presedensi
Saat tab diproses oleh `groupTabs()` di `src/core/background/groupManager.js`, tab dievaluasi terhadap lapisan pengelompokan dalam urutan hierarki yang ketat:
1. **Aturan Kustom (`applyCustomRules`)**: Mencocokkan aturan kustom yang aktif berdasarkan urutan kemunculan atau prioritas pengguna. Setelah dikelompokkan, ID tab didaftarkan di `groupedTabIds` dan dikecualikan dari lapisan berikutnya.
2. **Grup Sistem Khusus**: URL sistem dicegat dan dikelompokkan ke dalam grup berwarna khusus:
   - `chrome://` dan halaman internal peramban
   - `file:///` berkas disk lokal
   - `chrome-extension://` halaman ekstensi
   - Alamat IP & Localhost (`localhost`, `127.0.0.1`, `[::1]`, host IPv4/IPv6)
3. **Pengelompokan Domain**: Tab yang berbagi domain root yang sama dikelompokkan jika jumlah tab memenuhi atau melampaui `domainThreshold` (bawaan: 2 tab).
4. **Pengelompokan Subdomain**: Jika diaktifkan, tab di dalam domain dikelompokkan berdasarkan subdomain spesifik (misalnya, `docs.github.com` vs `gist.github.com`).
5. **Grup Lain-Lain ("Misc")**: Tab sisa yang tidak terkelompokkan dan tidak memenuhi ambang batas pengelompokan dimasukkan ke dalam grup `Misc` (penempatan dapat dikonfigurasi: `start`, `end`, atau alfabetis `alpha`).

### 2.3 Normalisasi URL & Semantik Pencocokan
Mesin pencocokan (`matchesRule(tabUrl, ruleUrl)` di `src/core/background/utils.js`) menerapkan normalisasi yang ketat:
- **Agnostik Skema**: Protokol HTTP dan HTTPS diperlakukan setara (`http://example.com` cocok dengan `https://example.com`). Protokol non-web (`file://`, `chrome://`) memerlukan kecocokan skema yang persis.
- **Normalisasi Host**: Awalan `www.` dihapus (`www.github.com` dinormalisasi menjadi `github.com`). Nama host diubah menjadi huruf kecil dan mendukung domain nama terinternasionalisasi (IDN) melalui punycode.
- **Sensitivitas Port**: Jika sebuah aturan menentukan port (misalnya, `localhost:3000`), tab harus cocok dengan port persis tersebut.
- **Pencocokan Jalur**: Garis miring di akhir dihapus. Jika sebuah aturan menentukan jalur (misalnya, `example.com/docs`), aturan tersebut cocok dengan tab yang memiliki jalur persis tersebut ATAU subjalur (`example.com/docs/api`), tetapi tidak cocok dengan jalur setingkat (`example.com/blog`).
- **Pencocokan Kueri & Hash**: Jika sebuah aturan secara eksplisit memuat string kueri (`?page=1`) atau hash (`#section`), tab harus cocok dengan parameter tersebut secara kata demi kata.
- **Proteksi Dword Numerik (`ruleValidation.js`)**: Validator secara ketat menolak masukan numerik murni (misalnya, `3242342424`) yang diperlakukan oleh parser WHATWG URL sebagai DWORD integer IPv4 yang valid, mencegah distorsi pengelompokan yang tidak disengaja.

### 2.4 Rincian Pengaturan Manajemen Aturan
Manajer Aturan menyediakan rangkaian lengkap kontrol perilaku dan pengaturan:
- **Pemilihan Perutean Penyimpanan**: Pengguna dapat mengarahkan penyimpanan aturan antara `chrome.storage.sync` (untuk pengaturan yang disinkronkan di semua perangkat yang masuk ke profil Google, tunduk pada kuota sinkronisasi Chrome sebesar 100 KB total dan 8 KB per item) dan `chrome.storage.local` (untuk kapasitas lokal tak terbatas yang cocok untuk kumpulan aturan besar berisi ratusan pola).
- **Sakelar Utama Pengelompokan & Ambang Batas**:
  - `toggle-clustering`: Pintasan papan ketik utama dan sakelar UI untuk mengaktifkan atau menonaktifkan pengelompokan otomatis domain/subdomain tanpa menonaktifkan aturan kustom yang dibuat pengguna.
  - `domainThreshold`: Jumlah tab minimum dari domain yang sama yang diperlukan untuk memicu grup tab otomatis (bawaan: 2 tab). Dapat dikonfigurasi dari 1 hingga 50.
  - `subdomainThreshold`: Jumlah tab minimum untuk subdomain sebelum membuat kluster subgrup terpisah.
  - Sakelar subdomain (`toggle-subdomain-grouping`): Membedakan subdomain independen (misalnya, `news.ycombinator.com` vs `ycombinator.com`).
- **Urutkan Grup Otomatis Berdasarkan Abjad (`toggle-sort-alpha`)**: Mesin pengurutan waktu nyata yang menerapkan urutan abjad di semua grup tab yang terbuka di bilah tab peramban (`Ctrl+Shift+S` / `Cmd+Shift+S`).
- **Prefiks Status Visual (`toggle-prefixes`)**: Penanda emoji yang secara dinamis ditambahkan di awal judul grup untuk menunjukkan status inspeksi:
  - `🔒` (Gembok): Grup berisi tab yang belum dikunjungi dan belum dibaca.
  - `🔍` (Kaca Pembesar): Grup berisi tab yang telah dikunjungi sebagian.
  - `🗝️` (Kunci Terbuka): Semua tab di dalam grup telah dibuka dan ditinjau.
  - `⚠️` (Peringatan): Benturan nama grup duplikat terdeteksi dengan grup jendela lain.
- **Auto-Collapse Grup Diam (`toggle-collapse-timer`)**: Secara otomatis menciutkan grup saat tidak aktif untuk menjaga kerapian bilah tab.
- **Jeda Pengelompokan Utama (`feature_pauseGrouping`)**: Sakelar pembekuan utama yang menangguhkan sementara semua operasi pengelompokan otomatis (baik kecocokan aturan maupun pengelompokan heuristik) selama sesi riset aktif ketika tab harus tetap berada dalam susunan bebas pengguna.
- **Pengelompokan Tab Tunggal (`featureSingleTabGrouping`)**: Memungkinkan aturan kustom untuk langsung membuat grup tab untuk satu tab yang cocok, melewati persyaratan ambang batas multi-tab.
- **Tampilan Ringkas (`toggle-compact-mode`)**: Meminimalkan lebar header tab di bilah tab peramban dengan hanya merender lencana satu huruf untuk judul grup.
- **Prioritas Drag-and-Drop**: Mengubah urutan aturan dalam daftar `Rules.svelte` secara instan mengubah presedensi evaluasinya. Aturan di posisi paling atas dievaluasi terlebih dahulu.
- **Pencarian Samar (Fuzzy Search)**: Pemfilteran langsung di Manajer Aturan dan Omnibar yang memungkinkan penemuan aturan secara instan berdasarkan judul atau pola URL yang cocok.
- **Impor / Ekspor JSON**:
  - Mode `add`: Menggabungkan aturan yang diimpor ke dalam koleksi yang ada, membuang duplikat.
  - Mode `overwrite`: Mengganti seluruh koleksi aturan aktif dengan muatan yang diimpor setelah validasi skema.
- **Pembuatan Aturan Dinamis**: Pembuatan aturan kustom sekali klik langsung dari folder bookmark Chrome atau koleksi domain subgrup.
- **Deduplikasi Aturan (`feature_v100_dedup_add_to_rule`)**: Secara otomatis membuang pola URL duplikat saat menambahkan URL atau domain ke aturan kustom yang ada, mencegah inflasi aturan dan evaluasi yang berulang.

### 2.5 Operasi & Persistensi (`mutateRulesAndSync`)
- **Mutator Terpusat**: Semua modifikasi aturan dialirkan melalui `mutateRulesAndSync(mutateFn, sendResponse)` di `src/core/background/handlers/rules.js`. Hal ini menjamin sinkronisasi penyimpanan, penyegaran cache dalam memori (`extensionSettings.customRules`), notifikasi UI (`rulesUpdated`), dan pengelompokan ulang tab otomatis (`groupTabs()`).
- **Validasi Langsung**: Pemeriksaan validasi waktu nyata untuk keunikan nama, panjang (1-16 karakter), batasan karakter, dan sintaks URL yang valid sebelum disimpan.

### 2.6 Modalitas Pemanggilan
- **Halaman Manajer Aturan (`Rules.svelte`)**: Dapat diakses dalam tampilan tab penuh atau panel samping (`?view=rules` / `pg`). Menyediakan pengurutan drag-and-drop lengkap, pemilih warna inline, chip tag URL, dan sakelar aturan.
- **Perintah Omnibar**:
  - `rl:` — Cari aturan dan buka URL terkait.
  - `cr: <name> [, url1, url2]` — Buat aturan baru langsung dari bilah perintah.
  - `atcr:` — Tambahkan domain atau URL tab aktif ke aturan yang sudah ada.
  - `atr:` — Tambahkan tab terbuka yang dipilih atau URL manual ke aturan yang sudah ada.
  - `ccr:` — Ubah warna aturan kustom.
  - `dr:` — Hapus aturan atau URL individual dari suatu aturan.
  - `er:` — Edit atau ganti nama aturan yang sudah ada.
- **Menu Konteks**:

## 3. Bagian 2: Daftar Grup & Operasi (Listar Grupos)

Tampilan Daftar Grup menyediakan ruang kerja interaktif untuk memeriksa, memanipulasi, dan mengatur ulang grup tab peramban serta tab individual.

### 3.1 Arsitektur UI
- **Tumpukan Komponen**: Dibangun dengan `ListGroup.svelte`, `GroupCard.svelte`, `GroupActions.svelte`, `TabItem.svelte`, dan `TabActions.svelte`.
- **Fitur Kartu**: Menampilkan judul grup, lencana warna, pil jumlah tab, sakelar akordeon ciutkan/bentangkan, penyematan kartu, dan grup tombol tindakan yang dapat disesuaikan.
- **Item Tab**: Menampilkan favicon tab dengan fallback warna, judul, lencana suara terdengar, indikator bisu, indikator status aktif, dan tindakan per-tab (tutup, duplikasi, sematkan, pisahkan, buang dari memori).

### 3.2 Siklus Hidup & Perilaku Grup
- **Kontrol Akordeon**: Status membentang dan menciut yang mulus. Mode auto-akordeon opsional secara otomatis menciutkan grup diam saat grup baru dibentangkan.
- **Pewaktu Diam Auto-Collapse Ketidakaktifan**:
  - Secara otomatis menciutkan grup tab yang diam untuk mengurangi kekacauan visual.
  - Dua ambang batas berbeda: Grup tidak aktif menciut setelah 1 menit tidak aktif (`INACTIVITY_THRESHOLD_INACTIVE_GROUP`), sedangkan grup aktif menciut setelah 15 menit tidak aktif (`INACTIVITY_THRESHOLD_ACTIVE_GROUP`). Dapat dikonfigurasi dari 0 hingga 1440 menit.
- **Penggantian Nama Inline & Masa Tenggang (Grace Period)**:
  - Pengguna dapat mengganti nama grup langsung di bilah tab peramban atau UI.
  - `GROUP_NAMING_GRACE_MS` (5000ms) menjeda pengelompokan ulang otomatis saat pengguna mengedit, mencegah penimpaan judul di tengah pengetikan.
  - Karakter spasi dengan lebar nol (`\u200B`, `\u200C`, `\u200D`, `\u2060`, `\uFEFF`) dibuang selama evaluasi.
  - Mengganti nama grup yang dibuat secara otomatis akan mengubahnya menjadi grup yang dinamai pengguna, memperbarui aturan kustom yang sesuai atau menandainya permanen.
- **Indikator Prefiks Grup Visual**:
  - Menambahkan simbol status secara dinamis di awal judul: `🔒` (belum dikunjungi), `🔍` (sebagian dikunjungi), `🗝️` (semua dilihat), `⚠️` (benturan).
- **Pengurutan Drag-and-Drop**: Terintegrasi dengan `sortable.js` untuk mengatur ulang tab di dalam grup, memindahkan tab antar grup, atau mengatur ulang kartu grup.
- **Fitur Grup Tersembunyi (Hidden Groups)**:
  - Menambahkan prefiks `_hidden_` pada judul grup di bilah tab peramban.
  - Menyembunyikan kartu grup dari tampilan daftar utama, memindahkannya ke `HiddenGroupsBar.svelte`.
  - Pengguna dapat menampilkan kembali atau memulihkan grup secara instan dengan satu klik.

### 3.3 Operasi Grup & Manajemen Memori
- **Ungroup (Pisahkan Grup)**: Membubarkan grup, membiarkan tab tetap terbuka di jendela.
- **Close Group (Tutup Grup)**: Menutup semua tab di dalam grup dan melepaskan ID grup.
- **Close Other Groups (Tutup Grup Lain)**: Menutup semua grup tab kecuali grup yang sedang difokuskan.
- **Regroup All Tabs (Kelompokkan Ulang Semua Tab) (`Alt+Shift+R`)**: Menjalankan evaluasi ulang menyeluruh di seluruh aturan kustom, grup sistem, dan kluster domain.
- **Tangkapan Layar Grup Sekuensial**: Berpindah dan merekam setiap tab di dalam grup secara berurutan (`Cs` terlihat, `Cp` halaman penuh, `CP` bagian halaman penuh).

### 3.4 Subsistem Pencadangan & Pemulihan Grup
- **Penyimpanan IndexedDB `backupsGroups`**:
  - Mencadangkan satu grup tab atau snapshot seluruh ruang kerja dari semua grup yang terbuka ke dalam penyimpanan IndexedDB `Intelligent_Workspace` bernama `backupsGroups`.
  - Menangkap struktur grup lengkap: judul grup, warna, status penciutan, judul tab, URL, favicon, status penyematan, dan posisi relatif tab.
  - **Penghematan Memori**: Tab yang dicadangkan ditutup dengan bersih untuk memulihkan RAM sistem dan mengurangi beban CPU.
  - **Mekanisme Pemulihan**:
    - Tampilan UI Pencadangan di `ListGroup.svelte` dengan pemulihan grup sekali klik.
    - Pintasan papan ketik `br` (pulihkan) dan `bg` (cadangkan semua).
    - Perintah Omnibar `bgr:` (cari dan pulihkan grup yang dicadangkan) dan `b:` (pencarian bookmark).
  - **Ekspor & Impor JSON**: Ekspor dan impor cadangan JSON penuh untuk migrasi mulus antar mesin dan pengarsipan luring jangka panjang.

### 3.5 Pemutar YouTube Terparkir di Hidden Groups Bar
- **Arsitektur (`HiddenGroupsBar.svelte`)**:
  - Saat pengguna bernavigasi menjauh dari tampilan video YouTube yang aktif atau memutar konten video di dalam panel samping, pemutar tidak ditutup atau hilang. Pemutar secara otomatis berlabuh di `HiddenGroupsBar.svelte` sebagai indikator YouTube terparkir (`.youtube-indicator`).
  - Dikelola secara reaktif melalui penyimpanan `hiddenYoutubeView` di `src/ui/stores/appStore.svelte.js`.
  - **Tindakan Sekali Klik**:
    - Mengklik indikator terparkir memanggil `restoreYoutubeView()`, mengembalikan pemutar seketika ke tampilan ruang kerja aktif.
    - Mengklik lencana hapus memanggil `discardYoutubeView()`, menghentikan pemutaran dengan bersih dan memulihkan sumber daya.
  - Berada berdampingan secara mulus dengan grup tab tersembunyi di bagian atas tampilan ListGroup tanpa mengacaukan daftar tab aktif.

## 4. Bagian 3: Navigasi & Manajemen Tab (Navegación)

Navigasi papan ketik yang dipercepat dan kontrol ruang kerja memungkinkan pengendalian multi-tab yang lancar tanpa interaksi tetikus (mouse).

### 4.1 Gestur Lompat Tab Cepat
- **Sintaks Gestur**: `Alt + [groupPrefix] + [tabIndex] + Enter`
- **Eksekusi**:
  - Tahan `Alt` dan ketik nama atau huruf prefiks grup, diikuti dengan indeks tab berbasis-1 yang diinginkan, lalu tekan `Enter`.
  - Contoh: `Alt + git + 2 + Enter` langsung melompat ke tab kedua di dalam grup "GitHub".
  - Indeks `0` bertindak sebagai pintasan untuk tab *terakhir* di dalam grup.
  - Mengabaikan indeks akan melompat ke tab *pertama* di dalam grup.
  - Tanda aksen secara otomatis dilipat (`deaccent`) dan pencocokan menormalisasi tanda diakritik.

### 4.2 Tombol Langkah, Pertukaran & Siklus Hidup
- `s`: Bertukar seketika ke tab yang aktif sebelumnya (`previousActiveTabId`).
- `h` / `l`: Melangkah ke tab sebelumnya / berikutnya (atau menggulir secara horizontal jika halaman memungkinkan).
- `H` / `L`: Navigasi mundur / maju dalam riwayat peramban.
- `t`: Buka tab kosong baru.
- `x`: Tutup tab aktif saat ini.
- `yt`: Gandakan tab saat ini.
- `r` / `R`: Muat ulang halaman / Muat ulang paksa melewati cache.
- `d` / `u`: Gulir ke bagian paling bawah / paling atas halaman.
- `j` / `k`: Gulir mulus ke bawah / ke atas (langkah 75px).
- `f`: Aktifkan petunjuk tautan Vim (huruf muncul di atas elemen yang dapat diklik untuk diklik).
- `cf`: Aktifkan petunjuk tautan Vim untuk menyalin URL target ke papan klip.

### Untuk pengguna tingkat lanjut

Pengguna yang lebih mahir dapat mengatur peramban ke mode layar penuh dan bernavigasi sepenuhnya menggunakan papan ketik, tanpa menggunakan tetikus sama sekali.

#### Imersi Layar Penuh & Penjelajahan Bebas Tetikus
- **Alihkan Layar Penuh**: Tekan `F11` (Windows/Linux) atau `Command+Control+F` (macOS). Bingkai peramban, bilah alamat, bilah tab, dan panel sistem operasi disembunyikan, mendedikasikan 100% tampilan untuk konten.
- **Navigasi Tautan Vim di Dalam Halaman (`f` / `cf`)**:
  - Tekan `f` untuk menghasilkan lencana petunjuk tautan kuning dua karakter dengan kontras tinggi di atas setiap elemen yang dapat diklik, tombol, masukan, dan tautan di DOM.
  - Ketik dua huruf yang cocok dengan target Anda untuk menyimulasikan klik langsung tanpa interaksi tetikus.
  - Tekan `cf` untuk memicu lencana petunjuk yang menyalin URL tautan target langsung ke papan klip sistem Anda.
  - Tekan `vp` untuk membuka modal pratinjau dalam halaman dari tautan target.
  - Tekan `Esc` kapan saja untuk membatalkan petunjuk tautan dan kembali ke pengguliran normal.
- **Lompat & Ganti Tab Seketika**:
  - `Alt + [groupPrefix] + [tabIndex] + Enter`: Jalankan gestur Lompat Tab Cepat (misalnya, `Alt + dev + 1 + Enter` melompat langsung ke tab pertama dalam grup "Dev"; indeks `0` memilih tab terakhir dalam grup).
  - `s`: Bertukar seketika antara tab saat ini dan tab yang aktif sebelumnya (`previousActiveTabId`).
  - `h` / `l`: Melangkah secara berurutan ke tab sebelumnya / berikutnya di bilah tab.
  - `H` / `L`: Bergerak mundur / maju melalui riwayat navigasi peramban.
  - `t` / `x` / `yt`: Buka tab baru (`t`), tutup tab saat ini (`x`), atau gandakan tab (`yt`).
- **Subsistem Perintah Omnibar Mengambang (`o`)**:
  - Tekan `o` di halaman mana pun untuk memunculkan overlay Omnibar di tengah layar.
  - Tekan `@` untuk menampilkan direktori interaktif dari semua 41 prefiks perintah.
  - Ketik `f: <query>` untuk menjalankan pencarian teks lengkap mendalam pada tab di semua jendela yang terbuka.
  - Ketik `sp:` untuk mengarahkan navigasi langsung ke tampilan Sidepanel mana pun (`rules`, `listgroup`, `notes`, `gallery`, `gemini`, `activity`, `themes`, `hints`, `downloads`).
  - Ketik `qai: <query>` atau `qaia: <task>` untuk mengajukan pertanyaan ke Gemini atau menginstruksikan agen peramban otonom tanpa mengangkat tangan dari papan ketik.
  - Ketik `ts:` untuk memisahkan tab terbuka menjadi layar terpisah berdampingan.
- **Navigasi & Fokus di Dalam Halaman**:
  - `j` / `k`: Gulir mulus ke bawah / ke atas (peningkatan 75px).
  - `d` / `u`: Gulir setengah halaman ke bawah / ke atas.
  - `i`: Lompatkan fokus kursor seketika ke bidang input teks utama di halaman.
  - `ESC`: Lepaskan fokus input dan kembalikan fokus papan ketik ke mode navigasi.

### 4.3 Manajemen Audio & Suara

## 5. Bagian 4: Asisten AI & Agen Otonom (Asistente AI)

Asisten AI mengintegrasikan model bahasa besar ke dalam peramban untuk memberikan pemahaman kontekstual, alur kerja otomatis, dan otomatisasi peramban langsung.

### 5.1 Arsitektur Mesin Model Ganda
1. **Google Gemini Cloud API (`gemini-api.js`)**:
   - Terintegrasi dengan endpoint REST Google Generative Language (`v1beta/models/{model}:generateContent` dan `:streamGenerateContent`).
   - Mendukung Gemini 2.5 Flash, Gemini 2.5 Pro, dan endpoint model kustom.
   - **Rotasi Multi-Kunci**: Mengelola kumpulan kunci API di `geminiApiKeysList`. Pengaburan penyimpanan menggunakan prefiks `enc_`.
   - **Exponential Backoff**: Menangani kehabisan kuota HTTP 429 dengan percobaan ulang berundur otomatis (1.5 detik -> 3 detik -> 6 detik).
   - **Search Grounding**: Mengaktifkan Google Search Grounding (`google_search: {}`). Jika HTTP 403 terjadi karena pembatasan kuota pada alat penelusuran, sistem secara otomatis mencoba ulang tanpa grounding.
2. **Chrome Built-in AI / Prompt API (`localAiService.js`)**:
   - Integrasi Gemini Nano di perangkat melalui `window.LanguageModel`.
   - Mendukung eksekusi lokal tanpa jaringan. Mencakup pemeriksaan ketersediaan model dan pelacakan kemajuan unduhan langsung.

### 5.2 Agen Peramban Otonom (`agent-backend.js`)
Agen otonom menyediakan kendali penuh atas peramban melalui 40+ alat terstruktur:
- **Kendali Tab & Grup**: `getOpenTabs`, `switchToTab`, `createNewTab`, `closeTab`, `closeTabs`, `duplicateTab`, `findAndSwitchToTab`, `groupTabs`, `ungroupTabs`, `deleteTabGroup`, `collapseTabGroup`, `expandTabGroup`, `collapseAllGroups`, `expandAllGroups`, `setGroupColor`, `renameTabGroup`, `regroupAllTabs`, `removeDuplicateTabs`, `closeTabsWithSound`.
- **Navigasi & Pencarian**: `openUrl`, `searchGoogle`, `getActiveTab`, `getActiveTabContent`.

### 5.3 Pelacakan Taint & Pertahanan Prompt Injection
Untuk menetralisir serangan injeksi prompt tidak langsung dari halaman web yang tidak tepercaya, backend agen menerapkan pelacakan taint yang ketat:
- **Penandaan Taint**: Memanggil `getActiveTabContent` mengekstrak teks dari halaman web dan menandai sesi eksekusi saat ini sebagai tercemar (`taintedAgentRuns.add(runId)`).
- **Penjaga Egress**: Sesi yang tercemar dilarang keras memanggil alat-alat egress (`AGENT_EGRESS_TOOLS`):
  * `openUrl`, `searchGoogle`, `createBookmark`, `createRule`, `addUrlToRule`, `createSiteShortcut`, `updateSiteShortcut`, `updateRule`.
- **Mekanisme Penolakan**: Alih-alih melempar exception yang tidak tertangani, mesin mengembalikan penjelasan keamanan terstruktur. LLM kemudian memberi tahu pengguna bahwa data eksternal tidak dapat diekfiltrasi tanpa persetujuan eksplisit pengguna.

## 6. Bagian 5: Tampilan Catatan & Manajemen Pengetahuan (Ver Notas)

interface NoteRecord {

## 7. Bagian 6: Tampilan Media & Galeri (Ver Galería)

Alur kerja perekaman media, anotasi, dan pengenalan karakter optis (OCR) berkinerja tinggi.

### 7.1 Mode & Rekayasa Perekaman (Semua 7 Tipe Perekaman)
Ekstensi ini menerapkan 7 modalitas perekaman khusus yang mencakup operasi tab tunggal, lintas-tab, pemotongan, dan palet:
1. **`visible` (Perekaman Area Pandang yang Terlihat - `cs`)**:
   - Menangkap area pandang persis yang terlihat dari tab aktif menggunakan `chrome.tabs.captureVisibleTab`.
   - Secara otomatis menyimpan tangkapan ke penyimpanan IndexedDB `screenshots` dan menyalin bitmap gambar langsung ke papan klip sistem (`screenshotSavedAndCopied`).
2. **`fullPage` (Kanvas Pengguliran Halaman Penuh Mulus - `cp`)**:
   - Menjalankan pengguliran halaman secara terprogram, menghitung total tinggi gulir dokumen.
   - Menekan bilah gulir dan menyembunyikan bilah navigasi lengket/tetap setelah segmen awal untuk menghilangkan gangguan visual.
   - Menjahit potongan bitmap ke `OffscreenCanvas` hingga setinggi 30.000px (`captureFullPageDataUrl`), menerapkan jeda 600ms yang patuh Chromium di antara perekaman bingkai.
3. **`fullPageParts` (Segmen Terpotong Sekuensial - `cpp` / `cP`)**:
   - Memotong dokumen panjang menjadi bagian-bagian gambar setinggi area pandang individual secara berurutan (`captureFullPageParts`), menghasilkan hingga 60 potongan gambar bernomor untuk penomoran halaman.
4. **`area` (Pemotongan Seret Persegi Panjang Interaktif - `ca`)**:
   - Menyuntikkan `area-selector.js`, menampilkan overlay kanvas crosshair dengan dimensi kotak pembatas waktu nyata.
   - Pegangan pilihan yang dapat diseret, tooltip dimensi, pemicu konfirmasi, pembatalan dengan tombol `Esc`, dan antrean pemotongan multi-tab (`handleCaptureAreaFromShortcut`).
5. **`groupTabs` (Penelusuran Tab Grup Aktif Massal - `Cs`, `Cp`, `CP`)**:
   - Mengiterasi secara berurutan setiap tab di dalam grup tab yang aktif (`handleCaptureGroupFromShortcut`).
   - Mendukung perekaman massal dalam mode terlihat, halaman penuh, atau bagian tersegmentasi, mengumpulkannya ke dalam satu koleksi terpadu.
6. **`omnibarPickedTabs` (Perekaman Antrean Multi-Tab Kustom)**:
   - Dimulai melalui perintah Omnibar `cs:`, `cp:`, `cpp:`, atau `ca:` (`handleCaptureTabs`).
   - Mengeksekusi perekaman berurutan di semua tab yang difilter pengguna, menyediakan indikator kemajuan waktu nyata.
7. **`colorPickerCapture` (Fallback Pipet Layar Latar Belakang)**:
   - Mengambil tangkapan layar latar belakang untuk mentenagai alat pembesar pipet hex presisi pada sistem operasi yang tidak memiliki dukungan bawaan `window.EyeDropper` (misalnya, Linux).

## 8. Bagian 7: Pomodoro & Paket Pewaktuan (Pomodoro)

Paket fokus dan pewaktuan yang dirancang untuk akurasi mutlak di seluruh siklus tidur peramban.

### 8.1 Mesin Pewaktuan & Arsitektur Latar Belakang
- **Matematika Stempel Waktu Bebas Pergeseran (Zero-Drift)**: Status dipersistensikan di `chrome.storage.local` dengan stempel waktu Unix absolut (`startTime`, `pausedAt`). Penghentian service worker, peramban dimulai ulang, dan status tidur sistem operasi tidak menyebabkan pergeseran jam sama sekali.
- **Pengirim Alarm (Alarm Dispatcher)**:
  - Penghitung mundur resolusi tinggi yang digerakkan oleh `chrome.alarms` (interval `pomodoroTick` 1 detik).
  - Pemeliharaan latar belakang dan pembersihan interval jangka panjang dikelola oleh `itg-periodic-tasks` (interval 1 menit).
- **Lonceng Audio Offscreen (`offscreen.html`)**: Lonceng audio dihasilkan melalui dokumen Chrome Offscreen khusus yang dibuat dengan alasan `AUDIO_PLAYBACK`. Ditutup secara otomatis 3,5 detik setelah suara selesai untuk menghemat memori.

### 8.2 4 Mode Pewaktuan Menyeluruh
1. **Pomodoro (`pomodoro`)**:
   - Durasi kerja: 1 hingga 180 menit (bawaan: 25 menit).
   - Istirahat pendek: 1 hingga 120 menit (bawaan: 5 menit).
   - Istirahat panjang: 1 hingga 180 menit (bawaan: 15 menit).
   - Siklus sebelum istirahat panjang: 1 hingga 12 siklus (bawaan: 4).
   - Target sasaran siklus: 1 hingga 99 siklus (bawaan: 8).
   - Mulai otomatis kerja, mulai otomatis istirahat, dan peringatan notifikasi yang dapat dikonfigurasi.
2. **Stopwatch (`cronometro`)**: Pewaktu progresif dengan pencatatan putaran (lap) dan kemampuan jeda-sebagai-berhenti.
3. **Hitung Mundur (`temporizador`)**: Pewaktu hitung mundur kustom yang menentukan jam, menit, dan detik.
4. **Alarm Waktu Target (`tiempo`)**: Pemilih tanggal kalender dan pemilih jam untuk mengatur alarm pada stempel waktu mendatang yang tepat.

### 8.3 Widget Pewaktu Mengambang di Dalam Halaman
- Overlay minimalis yang dapat diseret menampilkan hitungan mundur waktu nyata, tombol jeda/lanjutkan, dan tombol lewati langsung di halaman web.

### 8.5 Pelabelan Proyek & Metadata
Setiap sesi mendukung metadata kategorisasi:
- Nama Proyek (hingga 18 karakter)
- Tag Proyek (misalnya, `#research`, `#dev`)

### 8.6 Mesin Analitik & 19 Kartu KPI
Dasbor lengkap (`dashboard.html` atau panel samping `dashboard.html?context=sidepanel`) menghitung 19 indikator kinerja utama dari sesi yang telah dideduplikasi (`dedupeSessions` berdasarkan `sessionStarted`):

## 9. Bagian 8: Panel Aktivitas & Riwayat (Panel de Actividad)

Mesin pelacakan, analitik, dan tata kelola web berbasis Declarative Net Request (DNR).

### 9.1 Mesin Data & Topologi Penyimpanan (`ITG_WEB_ACTIVITY`)
Dikelola di bawah `ITG_WEB_ACTIVITY`:
- `wa:day:YYYY-MM-DD`: Penghitung domain per hari (`{ domains: { host: { t: seconds, v: visits, s: sessions, h: { hour: seconds } } } }`).
- `wa:days`: Array indeks utama dari kunci tanggal yang tercatat.
- `wa:recent`: Ring buffer yang menyimpan 400 entri garis waktu kunjungan terbaru.
- `wa:openSegment`: Segmen terhitung waktu aktif di `chrome.storage.session`, dibatasi pada `WA_MAX_SEGMENT_SECONDS = 900s` (15 menit) untuk mencegah distorsi statistik jika komputer tidur tanpa memicu event idle.
- **Deteksi Diam (Idle)**: Menggunakan `chrome.idle` (bawaan: 300 detik / 5 menit). Pemutaran audio mempertahankan pelacakan aktif meskipun jendela tidak difokuskan jika `countAudible = true`.
- **Retensi**: Secara otomatis memangkas catatan harian yang lebih lama dari `retentionDays` (bawaan: 180 hari).

### 9.2 Pemblokir Situs Declarative Net Request (DNR)
- **Alokasi Aturan Dinamis**: Mengalokasikan aturan dinamis dalam rentang ID `9000` hingga `9999`.
- **Target Pengalihan**: Permintaan yang diblokir dialihkan ke `src/ui/pages/web-activity/blocked.html?d=<domain>&u=\1`.
- **Pembersihan Tab Terbuka**: Ketika batas situs kedaluwarsa, worker latar belakang segera menyapu dan mengalihkan tab terbuka yang cocok dengan domain tersebut.
- **Rentang Jadwal Melewati Tengah Malam**: Jadwal yang melintasi tengah malam (misalnya, `22:00` hingga `02:00`) secara otomatis dievaluasi melintasi batas hari.
- **Masa Tenggang / Tunda (+5 menit)**: Layar blokir memungkinkan izin tunda (snooze) sementara selama 5 menit, dilacak dalam `wa:snoozeUses`.

### 9.3 Kunci Keamanan Asimetris (`blockLock.js`)
Batasan situs dapat dilindungi dengan kunci kata sandi asimetris:
- **Penyimpanan Hash**: Menyimpan salt acak 16-byte dan digest heksadesimal SHA-256 (`wa:settings.blockPassword`).
- **Kebijakan Aturan Asimetris**: Kata sandi **tidak pernah diminta** saat membuat batasan baru atau membuat aturan menjadi lebih ketat (misalnya, mengurangi jatah waktu atau menambahkan pembatasan jadwal).
- **Tindakan yang Dilindungi**: Kata sandi hanya diminta saat **melonggarkan aturan** (menghapus batasan, menambah jatah waktu, atau menonaktifkan jadwal) atau saat memanggil penundaan (snooze) setelah melampaui ambang batas gratis harian (`snoozePasswordAfter`).

### 9.4 Kategorisasi & Analitik Visual
- **16 Kategori Bawaan**: `social`, `video`, `music`, `news`, `shopping`, `reading`, `entertainment`, `dev`, `work`, `education`, `games`, `finance`, `mail`, `ai`, `search`, `other`.
- **Kategori Kustom**: Mendukung kategori yang ditentukan pengguna dengan prefiks `custom:`.
- **Rasio Fokus**: Membandingkan kategori Produktif (`dev`, `work`, `education`, `reading`, `finance`, `mail`) terhadap kategori Pengalih Perhatian (`social`, `video`, `games`, `shopping`, `entertainment`).
- **Visual**: Distribusi aktivitas per jam Chart.js, diagram donat kategori, dan daftar peringkat domain.

### 9.5 Subsistem Manajer Unduhan (`switchMainView('downloads')`)
- **Rute Khusus**: Diakses di panel samping melalui `switchMainView('downloads')` (`?view=downloads`).
- **Integrasi Langsung Chrome API**: Mengaitkan `chrome.downloads` untuk melacak, mengelola, dan memeriksa semua unduhan peramban secara waktu nyata.
- **Pencarian Samar Waktu Nyata**: Pencarian instan berdasarkan nama berkas, jalur berkas, atau URL sumber unduhan.
- **Chip Filter Status**: Memfilter unduhan dengan cepat berdasarkan status: `All`, `In Progress`, `Complete`, `Paused`, dan `Interrupted`.
- **Pemfilteran Rentang Tanggal Kalender**: Mempersempit unduhan berdasarkan tanggal tertentu atau interval waktu.
- **Pengunduh Grup Massal**: Mengekstrak semua tautan unduhan dari tab terbuka di grup aktif dan memulai unduhan massal yang disinkronkan dengan pelacakan kemajuan.
- **Manajemen Berkas**: Pembukaan berkas langsung dengan satu klik (`chrome.downloads.open`) dan penunjukan folder (`chrome.downloads.show`).

### 9.6 Subsistem Tab yang Baru Saja Ditutup & Riwayat Penjelajahan
- **Tampilan Tab yang Baru Saja Ditutup**:
  - Terintegrasi langsung dengan `chrome.sessions.getRecentlyClosed`.
  - Pencarian waktu nyata dengan pelipatan aksen dan tanda diakritik otomatis (`deaccent`).
  - Pemulihan tab tunggal dan pemulihan sesi seluruh jendela dengan satu klik atau perintah Omnibar `c:`.
- **Tampilan Riwayat Penjelajahan**:
  - Pencarian mendalam dengan cache dalam memori TTL 10 detik untuk menghilangkan beban kueri `chrome.history.search` yang berulang.
  - Pencarian dapat difilter berdasarkan domain, kata kunci, dan rentang tanggal kalender.
  - Aktivasi tab sekali klik jika sudah terbuka, atau pembuatan tab baru, dapat diakses melalui Omnibar `h:`.

### 9.7 Subsistem Penjadwalan Tema (`ThemeScheduleModal.svelte`)
- **Penjadwalan Tema Otomatis**:
  - Dikelola melalui `ThemeScheduleModal.svelte` di dalam tampilan panel samping Themes (`?view=themes` / `pt`).
  - Mendukung peralihan tema otomatis berdasarkan waktu (`HH:MM`) dan hari aktif dalam seminggu (`[0..6]`).
  - Maksimum 7 jadwal tema global (`MAX_GLOBAL_SCHEDULES = 7`).
  - **Kembali Otomatis (Auto-Revert)**: Kembali secara otomatis ke tema siang hari atau tema ruang kerja default pada jam penyelesaian yang ditentukan.
  - **Peringatan Desktop**: Mengeluarkan notifikasi desktop saat pergantian tema otomatis terjadi (`chrome.notifications`).
  - **Persistensi Ganda**: Dipersistensikan di `chrome.storage.sync` (preferensi jelajah) dan `chrome.storage.local` di bawah `savedThemes` dan `themeSchedules`.

### 9.8 Tampilan Panel Samping Ringkas
- **Rute Panel Samping (`?view=activity` / `pw`)**: Kolom 350px yang dioptimalkan untuk pemantauan waktu nyata, menampilkan chip pemilih periode (`Today`, `7d`, `30d`, `All`) dan bilah kemajuan batas domain.

## 11. Skema Penyimpanan & Persistensi Data

Ekstensi ini menggunakan model penyimpanan multi-tingkat di seluruh IndexedDB dan Chrome Storage API:

### 11.1 Basis Data IndexedDB: `Intelligent_Workspace` (Versi Skema 8)
1. `screenshots`: keyPath: `'id'`, autoIncrement: true. Indeks sekunder: `'createdAt'`. Menyimpan tangkapan layar biner, URL data kanvas, tanda persisten, dimensi, dan indeks total segmen.
2. `geminiConversations`: keyPath: `'id'`, autoIncrement: true. 0 indeks sekunder (diambil/dikelola berdasarkan ID). Menyimpan utas obrolan multi-putaran, peran pesan, metrik token, dan metadata search grounding.
3. `notesStore`: keyPath: `'id'`, autoIncrement: false. 0 indeks sekunder (difilter dalam memori berdasarkan contextKey). Menyimpan rich text, array daftar periksa, kartu papan Kanban, spesifikasi Mermaid, dan rumus KaTeX.
4. `backupsGroups`: keyPath: `'group.id'`. 0 indeks sekunder (menyimpan objek grup cadangan yang dikunci oleh `'group.id'` bersarang). Menyimpan struktur grup terkompresi, warna, judul, dan rekaman tab yang ditutup.
5. `pomodoroStats`: keyPath: `'id'`, autoIncrement: true. Indeks sekunder: `'projectName'` (keyPath `'projectName'`) dan `'savedAt'` (keyPath `'savedAt'`) (tanpa indeks `date`). Menyimpan analitik fokus, metrik siklus, dan log interupsi.

### 11.2 Perutean Ganda Chrome Storage (`StorageService`)
- Secara dinamis merutekan baca dan tulis antara `chrome.storage.sync` (untuk pengaturan portabel di seluruh perangkat pengguna) dan `chrome.storage.local` (untuk preferensi berukuran besar).
- Model-model utama:
  - `customRules`: Array definisi aturan (`[{ name, color, active, urls }]`).
  - `clusterConfig`: Parameter pengelompokan otomatis (ambang batas, mode ringkas, kategori khusus).
  - `userPrefixes`: Penetapan prefiks emoji (`{ lock, openKey, loupe, checked, warning }`).
  - `activeTheme`, `savedThemes`, & `themeSchedules`: Konfigurasi warna 9 palet dan aturan rotasi terjadwal yang dikonfigurasi melalui `ThemeScheduleModal.svelte`.
  - `pomodoroState`: Stempel waktu sesi waktu nyata, durasi dijeda, dan target sasaran siklus.
  - `wa:settings` & `wa:limits`: Preferensi pelacakan aktivitas web, batas situs, dan jendela jadwal.
  - `youtubeLoopEnabled`: Flag boolean yang mengontrol tombol pengulangan YouTube dan Shorts.

### 11.3 Chrome Storage Session (`chrome.storage.session`)
Digunakan untuk koordinasi runtime yang sangat cepat dan efemeral:
- `tabsEverActive`: Kumpulan ID tab yang pernah diaktifkan selama sesi peramban saat ini.
- `groupExpandedEver`: Rekaman grup yang pernah dibentangkan selama sesi saat ini.
- `groupInfoMap`: Registri waktu nyata yang memetakan ID grup ke judul dinamis dan tipe pengelompokan.
- `splitScreenState`: Batas jendela yang di-cache untuk memulihkan dimensi layar asli.
- `contextMenusSignature`: Tanda tangan hash yang mencegah rekonstruksi menu konteks berulang selama pergantian tab yang cepat.
- `wa:openSegment`: Segmen waktu situs web aktif saat ini.
- `hiddenYoutubeView`: Referensi ke tampilan pemutar YouTube terparkir yang berlabuh di `HiddenGroupsBar.svelte`.

## 12. Rekayasa Defensif & Penanganan Kasus Ekstrem (Edge Cases)

1. **Pembatalan Pemblokiran Header Declarative Net Request (`dnr.js`)**:
   - Memodifikasi header respons melalui aturan DNR dinamis untuk melucuti header `X-Frame-Options` dan `Content-Security-Policy` yang membatasi, memungkinkan situs eksternal dirender di Panel Samping dan iframe Picture-in-Picture.
   - **Keamanan WhatsApp Web**: Secara eksplisit mempertahankan `Cross-Origin-Opener-Policy` (COOP) dan `Cross-Origin-Embedder-Policy` (COEP) pada `web.whatsapp.com` untuk mencegah rusaknya implementasi kriptografi Signal WebAssembly miliknya.
2. **Pelepas Blokir Klik Kanan & Seleksi (`allowRightClickHook.js`)**:
   - Menaklukkan situs web agresif yang memblokir salin, tempel, menu konteks, dan pemilihan teks.
   - Berjalan di dunia `MAIN` untuk mencegat `preventDefault()` dan `stopPropagation()` pada `contextmenu`, `copy`, `cut`, `selectstart`, `mousedown`, dan `mouseup`.
   - Melucuti penangan inline `oncontextmenu="return false"` melalui `MutationObserver`.
   - Melindungi aplikasi web yang sah (misalnya, Telegram Web, Google Docs) dengan memverifikasi konten papan klip sebelum menyuntikkan kembali event tempel yang dibatalkan.
3. **Penebasan Bisu Paksa Pratinjau Sorot YouTube (`youtubePreviewAudioHook.js`)**:
   - Berjalan di dunia `MAIN` pada `ytd-video-preview #inline-preview-player`.
   - Menimpa deskriptor properti `HTMLMediaElement.prototype.muted` pada elemen `<video>` target saat disorot kursor.
   - Menghilangkan kondisi balapan (race condition) pembisuan paksa internal `volumechange` YouTube, mempertahankan audio tidak dibisukan di seluruh pengulangan restart saat kursor berada di atas elemen.
4. **Hook Navigasi Urutan Feed YouTube Shorts (`youtubeShortsFeedHook.js`)**:
   - Berjalan di dunia `MAIN` pada `ytd-shorts`.
   - Mencegat properti `shortsProcessedSequence`, yang tidak terlihat dari dunia terisolasi ekstensi, dan mengirimkan event bawaan `yt-navigate` pada `ytd-app` tanpa memuat ulang halaman atau kehilangan status jendela mengambang.
5. **Proteksi Kanvas Gulir Tak Terbatas (Infinite-Scroll)**:
   - Membatasi penelusuran tangkapan layar halaman penuh hingga 60 segmen (`MAX_FULL_PAGE_SEGMENTS`) dan tinggi kanvas maksimum 30.000px (`MAX_FULL_PAGE_CANVAS_PX`), menghindari kerusakan tab peramban akibat kehabisan memori (out-of-memory).
6. **Fallback Pipet Pemilih Warna Layar Linux**:
   - Saat berjalan di lingkungan Linux yang tidak memiliki API Chromium `window.EyeDropper`, ekstensi menyuntikkan `screen-color-picker.js`, merender lensa piksel dengan pembesaran 9x beserta kalkulasi RGB/HEX/HSL.
7. **Jeda Penyesuaian Sesi Awal Peramban (Startup Session Settling Delay)**:
   - Menunda pemangkasan grup selama 20 detik (`groupsHaveSettledAfterStartup()`) saat peramban diluncurkan untuk memungkinkan tab sesi dan status jendela stabil sebelum mengevaluasi penugasan grup.
